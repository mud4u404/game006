# 地基第二版的验证模拟

负责人（10-08）：
- 「你应该先建立一些测试模拟，对你的这套规则进行验证，有效后我们再接受。」
- 「需要进行严格多轮的测试，目的是找出问题和有效的部分，从玩家的体感上来进行判断。」
- 「思考是第一位的，去伪存真，无惧创新。」

这里的模拟器只做验证，不接游戏界面，种子固定，结果可以重跑。

- 看全量的验收表、体感对照、战报、江湖日记：`npm run model`
- 平时由 `tests/model.test.ts` 守着：每条验收标准的通过与否，要和记录的一致。

## 文件

| 文件 | 模拟什么 |
|---|---|
| `kernel.ts` | 一对一交手，以及围攻。流程照搬现有实战（`src/ui/fight.ts`）：每合一个 tick，势决定谁出手，重招带力、速、巧、隙四项强度，以己之长应对，破绽，绝招，杀招。新规则都做成开关。带战报 |
| `current.ts` | 把现有存档和对手换算进内核，量「现在的体感」作为基准线 |
| `person.ts` | 人：先天四项、后天根基、功力、偏科；标准人；换算成交手的两方 |
| `life.ts` | 模拟玩家按现实时间过日子：行走与静修、铁律、历练、参悟、瓶颈与机缘、打坐、伤、银两 |
| `migrate.ts` | 现有存档换算成新模型，只做检验 |
| `report.ts` | 全部验收标准、体感对照、规则开关对照、战报、江湖日记 |

## 怎样判断「体感」

一条规则留不留，看它让下面这些变好还是变坏。基准线是现在游戏里打屠千山的那一场，负责人说体感不错。

| 体感 | 怎样量 | 现在打屠千山 |
|---|---|---|
| 一场打多久 | 回合数换算成秒 | 约 41 秒 |
| 要做几次决断 | 重招应对、破绽、绝招 | 约 13 次 |
| 决断有没有分量 | 以己之长、固定套路、随手乱选的胜率差 | 62% / 28% / 37% |
| 胜负来自哪里 | 破绽、反击、绝招、杀招占玩家伤害的比例 | 81% |
| 有没有起伏 | 领先易手的次数、翻盘的比例 | 0.66 次、15% |
| 凭本事能不能以弱胜强 | 低一档的人会打与乱打的胜率 | — |
| 多久长进一次 | 最长几天没有看得见的长进 | — |

## 一轮一轮发现了什么，改了什么

| 轮 | 测什么 | 发现 | 怎么办 |
|---|---|---|---|
| 一 | 只换「人」的模型，规则照旧 | 同档玩家赢九成以上；档次越高，档与档越分不开 | 境界、功力的阶梯改成等距 |
| 二 | 标定各档 | 境界几乎不用加伤害（每重乘 1.02），高手强在应对的成算：看得准、拆得开 | 定下第一组数 |
| 三 | 逐条打开新规则 | 固定套路几乎和以己之长一样好，P5 不达标；内力比拼让会打的人吃亏；借力打力毫无作用 | 记下，下一轮查原因 |
| 四 | 换成偏科的人 | 根子在成算曲线压得太平，选哪种应对都差不多 | 下一轮把「选对应对」和「档次高低」分开 |
| 五 | 搜参数 | 招式四项强度拉开，人偏科，以己之长就比固定套路高 20 个点，档次又不陡 | 定下：尺度 26、每重火候 6、强度拉开 2.5 倍 |
| 六 | 新参数下逐条对照 | 差距压制有用；伤让翻盘变少；越用力越伤、加力比深浅、借力打力、无招、对掌都没有改善 | 后五条去掉 |
| 七 | 困兽犹斗 | 翻盘只多一个点 | 去掉 |
| 八 | 对手也会受伤 | 伤本身就会滚雪球，谁先占上风谁越打越顺 | — |
| 九 | 只有吃了重招才落伤 | 易手保住了，翻盘还是少 | — |
| 十 | 伤带到下一场 | 这一场体感不受影响；带伤上阵代价分明（一级掉 4 到 6 个点，三处各一级掉 18 个点） | 伤改为打完才起作用 |
| 十一 | 各档一致吗、围攻 | 耗内力用的是绝对数，低档硬接一次去掉大半内力，高档等于不要钱；围攻另写了一套，漏了破绽和反击 | 耗内力按比例；围攻并进同一个内核 |
| 十二、十三 | 再测 | 闪避按轻功重数直接加，对手的却是死的；一流对两个二流只赢两三成 | 闪避对等；查明是连打两个、中间不能喘气 |
| 十四 | 树倒猢狲散、点穴、备战、尺子 | 乌合之众见同伙倒下会溜，一流对两个能五五开；点穴太强；现有备战上限能越七档；练内功几乎没用 | 留下树倒猢狲散；内功每重气血加重；备战收紧 |
| 十五、十六 | 内功、点穴、装备 | 带点穴的招打出全额伤害，等于白占对方一合 | 点穴定一合、伤害减半（重在制人，不在伤人）；装备上限收到八分 |
| 十七 | 五种玩家过一百二十天 | 太慢；开篇到不了三流；最长二十多天毫无长进；狂刷反而比勤奋慢；银子后期泛滥 | 熟练系数按比例改；开篇加机缘；伤可以买药治；每重分十成火候 |
| 十八、十九 | 再测 | 反过来太快；狂刷第 45 天就到宗师 | 调慢；在线化历练减半；开篇的历练由剧情里的闭关化开 |
| 二十 | 瓶颈、化历练的上限、各种变体 | 卡在瓶颈时另两门也停了；大周天「聪明的打法」和全程小周天一样，全程大周天反而少两成；多打坐纯属吃亏 | 瓶颈时另两门照常长；大周天去掉 |
| 二十一 | 打坐和参悟同时进行 | 去寒潭静修功力只多 2% 到 10%：饱和曲线下功力其实跟着内功重数走，「功力看岁月」落空 | — |
| 二十二 | 岁月曲线 | 地利多三成；慢的人内力反而深（郭靖式）；根骨影响太大 | 功力改用岁月曲线 |
| 二十三 | 根骨、一次离开的上限 | 一天只上线一次的人静修少四成 | 根骨每点降到 1%；一次离开最多算十六日 |
| 验收 | 全部标准 | 看人的说法只有八成多对得上：拿来对照的实打只打六十场，误差本身就有六个点 | 实打加到三百场；公式（档次差加功力深浅）就有九成二对得上 |

## 留下的规则和定下的数

- 交手：`kernel.ts` 的 `NEW_RULES`；人：`person.ts` 的 `SCALE0`；修炼：`life.ts` 的 `LIFE0`。
- 去掉的：越用力越伤、加力比深浅、借力打力、无招、对掌、困兽犹斗、大周天。它们文化上都有味道，但测下来体感没有改善。以后要作为某一派的招牌，单独再测。

## 还没通过的

| 标准 | 实测 | 原因 | 要负责人定 |
|---|---|---|---|
| C4 一流对两个二流在 40% 到 60% | 乌合之众 50%，同门死士 26% | 连打两个、中间不能喘气；和「高一档胜八成」在数学上冲突 | 是把同门死士这一项的目标改成 20% 到 35%，还是另加规则（例如合击要练阵法） |
| G6 大周天 | 聪明的打法和全程小周天一样 | 功力贴着天花板，快一倍没用 | 已经去掉；改用岁月曲线 |

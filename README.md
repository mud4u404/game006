# 文字武侠地下城游戏

> 项目代号：**game006**  
> 类型：文字武侠 RPG · 地下城探索 · 资源管理 · 分支叙事  
> 核心体验：在一个会记住你的江湖里，以有限的体力、金钱和情报，做出每一次都可能改变命运的选择。

## 一、游戏简介

这是一款以文字为主要表现形式的武侠地下城冒险游戏。玩家将扮演一名初入江湖的无名侠客，深入被称为“九幽地宫”的危险遗迹，在机关、恶人、异兽和旧日秘密之间求生。

游戏不依赖大段动画或复杂操作，而是通过**环境描述、人物对话、战斗指令、道具信息和事件选择**构建江湖。每一次探索都可能获得武学、结识盟友、触发恩怨，也可能因为一个错误判断而失去生命、装备甚至重要剧情线索。

游戏强调以下体验：

- **探索的未知感**：地图由房间、通道、暗门和事件节点组成，玩家需要观察描述并判断方向。
- **武侠的抉择感**：正邪并非简单二选一，声望、承诺、利益和底线会共同塑造结局。
- **克制的资源管理**：药品、内力、火折子、金钱和负重都有限，贪心可能让你无法活着离开。
- **可复盘的成长**：失败会留下线索和知识，重新挑战时可以选择不同流派与路线。

## 二、世界观

### 2.1 江湖格局

故事发生在大晟王朝末期。朝廷多年失去对边地与地下交通线的控制，名门正派忙于争夺武林盟主之位，地方帮会则以镖局、盐路和黑市维系生计。表面平静的江湖之下，三股力量正在争夺一件失落已久的东西：**《天门遗卷》**。

传说遗卷记载着“天门”时代的武学与地脉机关，能够打开通往九幽地宫最深处的“无相库”。有人说那里藏着足以改变天下格局的兵书，也有人说里面封印着一门会吞噬心智的禁功。

### 2.2 九幽地宫

九幽地宫并非单一的迷宫，而是一座在地下不断扩展的古代城池。它由多个区域组成，每个区域都拥有独立的生态、势力和规则：

1. **葬风井**：地宫入口，遍布盗墓者、塌方和残破壁画，适合初次探索。
2. **赤铜矿廊**：旧朝矿道，机关密集，矿奴亡魂与铸甲傀儡出没。
3. **听雨楼**：地下水城，商旅、杀手和情报贩子聚集，昼夜规则与地面不同。
4. **白骨林**：没有阳光的菌林，毒雾、异兽和失控的药人占据此地。
5. **无相库**：地宫核心，入口会随玩家的声望、钥匙和剧情选择改变。

不同区域并非线性解锁。玩家可以冒险绕过推荐路线，但越级探索会带来更高的敌人强度、资源消耗和永久风险。

### 2.3 江湖势力

- **青城剑门**：重视门规、剑术和名声，愿意帮助守信之人，但厌恶偷盗与邪功。
- **千机楼**：以机关、情报和契约为生，立场中立但所有帮助都有价格。
- **血河帮**：控制地宫黑市与水路，崇尚强者，能提供灰色交易和危险武学。
- **白鹿医庐**：研究毒术、疗伤与药人之谜，关注真相胜过江湖名声。
- **无相教**：信奉“人无定相”，试图借禁功改造武林，其真正目标在游戏中逐步揭示。

玩家可以与多个势力合作，但部分关系会互相冲突。加入一个势力不等于永远效忠；背叛、隐瞒和违约都会被记录，并可能在后续事件中产生追杀、封锁或援助。

### 2.4 武侠世界的基本规则

1. **名声会影响现实**：声望高低会改变商店价格、对话选项、敌人态度与可进入区域。
2. **江湖记仇**：重要 NPC 会记住玩家的救助、欺骗、偷窃和杀戮。
3. **武学有代价**：强大的招式通常消耗内力、气血、寿元或道德声望。
4. **信息不是绝对真相**：地图、传闻和 NPC 证词可能过时或故意误导。
5. **死亡并非简单重置**：普通死亡结束本次远征；特殊结局会留下永久的世界状态或继承线索。

## 三、核心玩法循环

一次完整的冒险由以下循环组成：

```text
准备远征 → 选择路线 → 探索房间 → 处理事件/战斗 → 搜集资源与线索
    ↑                                                     ↓
    └────────────── 返回营地、升级与重新规划 ←──────────────┘
```

### 3.1 营地准备

在进入地宫前，玩家可以在营地完成以下操作：

- 分配属性点与装备武器、防具、饰品。
- 购买或制作药品、食物、火折子、解毒剂和开锁工具。
- 选择携带的武学套路与主动技能。
- 阅读已获得的地图、传闻和任务记录。
- 与已招募的伙伴交谈，了解其忠诚度与个人任务。

营地不是绝对安全区。随着剧情推进，敌对势力可能侦察营地，玩家也必须在“立即深入”与“带着现有战利品撤离”之间作出选择。

### 3.2 房间探索

每个房间以文字描述呈现，玩家通常可以选择：

- **观察**：寻找脚印、机关、暗门、毒雾或可交互物品。
- **移动**：前往相邻区域，可能触发伏击或消耗时间。
- **调查**：阅读碑文、检查尸体、解读地图或追踪线索。
- **交涉**：与 NPC 对话、交易、威慑、欺骗或承诺。
- **休息**：恢复少量状态，但可能刷新敌人或提高危险度。
- **撤离**：返回上一个安全节点或离开地宫。

探索结果不仅由属性决定，也受已知情报、携带道具、势力关系和过往选择影响。

### 3.3 时间与危险度

地宫使用“探索时段”记录时间。移动、战斗、休息和搜寻都会消耗时段。危险度随时间、噪声和异常行为增加：

- 危险度低：普通敌人较少，商旅与中立 NPC 更常出现。
- 危险度中：巡逻队增加，部分通道封锁，陷阱开始重置。
- 危险度高：精英敌人追踪玩家，资源价格上涨，随机事件变得致命。
- 危险度极高：触发区域灾变或势力围剿，建议立即撤离。

## 四、角色系统

### 4.1 基础属性

玩家拥有五项基础属性，属性值会影响判定、战斗和事件选项：

| 属性 | 作用 |
| --- | --- |
| **体魄** | 最大气血、负重、近战伤害与抗击倒能力 |
| **身法** | 先手顺序、闪避、逃跑和机关判定 |
| **根骨** | 最大内力、内力恢复和持续战斗能力 |
| **悟性** | 学习武学、识破招式、解读线索和制作成功率 |
| **胆识** | 威慑、抗恐惧、面对高压事件时的特殊选项 |

角色升级获得的属性点并不绑定固定职业，玩家可以自由塑造流派。

### 4.2 状态资源

- **气血**：降至 0 时倒地；若没有保命手段，本次远征失败。
- **内力**：施展主动武学与部分探索能力所需。
- **精力**：影响探索效率和连续战斗；过低时行动判定恶化。
- **饥渴**：长期忽视会降低最大气血与恢复效果。
- **负重**：超过上限会降低身法并提高精力消耗。
- **声望**：分别记录各势力关系以及总体江湖名声，不是单一善恶值。

### 4.3 武学流派

玩家可以混搭武学，但同一时间只能装备有限数量的招式。推荐流派包括：

- **剑道流**：高精准、高暴击，擅长寻找破绽；对内力管理要求较高。
- **刀盾流**：防御与反击优秀，适合正面作战；移动与潜行能力较弱。
- **拳掌流**：依靠连击、控制和气劲，能在无武器状态下保持战力。
- **暗器流**：擅长先手、毒伤和远程消耗；需要管理弹药与暴露风险。
- **医毒流**：通过治疗、药物和持续状态取胜；准备成本高但续航强。

禁功不属于常规流派。学习禁功会提供强大效果，同时增加**心魔值**；心魔达到临界点后，部分对话、战斗指令和结局会发生变化。

## 五、战斗规则

### 5.1 回合结构

战斗采用回合制指令系统。每回合顺序由身法、状态和部分技能共同决定：

1. 查看敌我状态、距离和已知弱点。
2. 选择行动：普通攻击、武学、招架、防御、使用物品、观察或逃跑。
3. 按先手顺序结算行动。
4. 处理流血、中毒、灼烧、破甲、眩晕等持续状态。
5. 更新仇恨、士气、环境危险度并进入下一回合。

### 5.2 战斗原则

- **距离**：近身、短距和远距会影响招式可用性与命中率。
- **架势**：攻击、防御、破招和蓄势之间存在克制关系。
- **破绽**：成功观察或连续防御可暴露敌人弱点，造成额外伤害。
- **环境**：火盆、水洼、狭窄地形、机关和高低差可被利用。
- **撤退**：逃跑不是必定成功；失败会受到追击，成功则消耗额外精力。
- **非杀解决**：击晕、缴械、谈判、收买和利用环境都可能结束战斗。

### 5.3 敌人类型

- **普通敌人**：可通过熟悉招式和弱点稳定处理。
- **精英敌人**：拥有专属机制、第二阶段或特殊掉落。
- **首领**：多阶段战斗，会根据玩家声望、线索和先前行为改变招式。
- **游荡威胁**：不一定需要击杀，可能通过躲避、交易或改变路线处理。

胜利不只看伤害。节省药品、保留内力、控制噪声和获取敌人情报，同样是战斗评价的一部分。

## 六、道具、经济与制作

### 6.1 道具分类

- **武器**：影响伤害类型、攻击距离和可用招式。
- **防具**：提供护甲、抗性和特殊被动，但通常增加负重。
- **消耗品**：恢复气血/内力、解除异常状态或临时强化属性。
- **工具**：开锁、照明、拆陷阱、攀爬和辨毒。
- **任务物品**：关键线索和剧情凭证，通常无法出售。
- **奇物**：改变规则的稀有物品，可能附带未知副作用。

### 6.2 金钱与交易

游戏货币为“碎银”和“金锭”。不同势力的商人会根据玩家声望、供需和交易历史调整价格。黑市可以买到禁药、假身份和未经鉴定的武学，但也可能遭遇诈骗或追踪。

### 6.3 制作与鉴定

玩家可以在营地或特定工作台制作药品、机关零件和简易武器。未鉴定装备可直接使用，但其属性和副作用未知。通过悟性、专业 NPC 或对应工具可以提高鉴定成功率。

---

## 七、伙伴与关系

玩家可以招募最多两名伙伴同行。伙伴拥有独立属性、战斗倾向、个人任务和底线：

- 伙伴会根据玩家的行为改变忠诚度。
- 伙伴之间可能产生冲突，部分组合无法长期共存。
- 伙伴倒下后可以被救治，但在特定剧情中可能永久离队。
- 完成个人任务可以解锁协同技能、专属结局和隐藏区域。
- 玩家可以命令伙伴攻击、防守、支援或保留资源，但伙伴未必无条件服从。

伙伴不是可消耗的战斗道具。一个伙伴的死亡可能改变城镇、势力和最终结局。

---

## 八、死亡、失败与结局

### 8.1 远征失败

角色在地宫中死亡、被俘或无法维持生存时，本次远征结束。玩家可以：

- 从最近的营地存档重新开始。
- 以较高代价接受救援，保留部分线索但损失装备。
- 在“铁律模式”中永久失去本次角色，继承已发现的世界情报。

游戏不会把失败视为单纯惩罚。失败可能揭示敌人的招式、地图陷阱和隐藏条件，鼓励玩家用新策略重新挑战。

### 8.2 结局条件

结局由以下因素共同决定：

- 无相库的真相是否被揭开。
- 《天门遗卷》被交给谁、销毁还是据为己有。
- 各势力的关系与存活状态。
- 玩家是否使用禁功以及心魔值。
- 伙伴任务完成情况。
- 江湖声望、关键承诺和已触发的区域事件。

计划中的结局类型包括：

- **归隐结局**：带着真相离开江湖，拒绝成为新的权力中心。
- **盟主结局**：整合多个势力，重建武林秩序，但也承担统治代价。
- **破局结局**：公开地宫秘密，摧毁旧有势力体系。
- **无相结局**：接受禁功的终极力量，成为新的地宫守门人。
- **失落结局**：在贪婪、背叛或心魔中失去自我，成为后续冒险的敌人。

同一结局也可能因关键 NPC 是否存活、地宫资源是否被耗尽而呈现不同文本与后果。

## 九、难度与模式

- **标准模式**：允许多个存档点，适合首次体验和了解世界观。
- **铁律模式**：死亡会永久结束角色，但继承图鉴、地图标记和已知情报。
- **挑战模式**：强化敌人机制，限制营地补给，并提供独特排行榜统计。

所有模式共享核心规则，不通过单纯提高数值制造难度；高难度主要增加资源压力、敌人行为复杂度和选择后果。

---

## 十、设计目标

1. 让文字承担画面功能：每段描述都应提供氛围、信息或决策价值。
2. 让玩家的选择具有可追踪后果，而不是只改变一句台词。
3. 让战斗、探索、交涉和资源管理彼此关联，避免单一最优解。
4. 让失败带来知识，让重玩产生新的路线，而不是机械重复。
5. 让武侠精神体现在“如何使用力量”上，而不仅是招式名称。

# 烬龙誓约 Emberoath

一款向九十年代经典战棋（《炎龙骑士团》系列）致敬的**原创** SRPG。
经典的回合制战棋玩法 + 剧情沉浸 + 队伍养成，画面采用 **HD-2D** 风格：
像素精灵角色站在实时光照的 3D 战场上，最高支持 4K 渲染。

> 全部角色、剧情、美术与音乐均为原创，并且**全部由程序实时生成**——
> 仓库里没有任何图片或音频文件。

## 运行

```bash
npm install
npm run dev        # 开发服务器，浏览器打开显示的地址
npm run build      # 生产构建，输出到 dist/
npm test           # 规则、章节数据、配乐与全章节自动对战测试
```

## 内容

- **11 章完整剧情**（序章 ～ 终章），双结局：集齐 6 片「龙鳞残片」进入真结局
- **13 名可操作角色**，含需要特定角色「交谈」才能加入的隐藏伙伴
- **18 段营地对话** 与 **9 组羁绊对话**（C / B / A 三级）
- 40 余种职业，Lv10 起可在教会转职，部分隐藏职业需要特殊道具
- 13 首原创配乐，围绕同一段「誓约动机」变奏；35 种合成音效

## 经典玩法

方格地图、我方 → 友军 → 敌方的阶段制、地形攻防修正、无法穿越敌人、
反击规则（魔法 / 空手 / 射程外不反击）、伤害可为 0（「无效」）、待机回复、
宝箱与盗贼、村庄拜访与劫掠、隐藏宝物（在特定格子待机）、交谈招降、
固定位置施放的大型魔法、教会复活与转职。规则细节见 [`docs/RESEARCH.md`](docs/RESEARCH.md)。

## 画面设置

设置面板可调整画质（低 / 中 / 高 / 极致）与渲染分辨率（自动、原生、1080p、1440p、4K 超采样）、
战斗演出（完整特写 / 简略 / 关闭）、文字速度、音量等。界面按视口缩放，像素立绘按设备像素整数倍放大。

## 技术

- TypeScript + Vite + three.js（ACES 色调映射、泛光、调色、阴影）
- `src/art/`：无抗锯齿像素光栅器、色相偏移色带、人形骨架与「3D 部件 → 像素」投影器（坐骑、魔物、巨龙）、像素立绘
- `src/render/`：程序化地形、水与熔岩着色器、植被、建筑、11 种场景主题、特效粒子、精灵公告板单位、电影化镜头
- `src/audio/`：WebAudio 合成器（弦乐、合唱、铜管、竖琴、钢琴、管风琴、打击乐……）、前瞻调度音序器、卷积混响
- `src/game/`：战斗规则、AI、成长与存档；`src/data/`：职业、道具、技能、角色、章节、对话
- `src/scenes/`：标题、剧情演出、营地、出击、战斗、结算、结局

## 开发辅助

- `?dev=章节序号&stage=battle|intro|camp` 直接跳到某章（自动组建当时的队伍）
- `sandbox/` 下有战场、精灵、立绘、配乐（离线渲染 + 频谱图）的独立预览页

# 文字武侠肉鸽割草生存游戏

> 项目代号：**game006**  
> 类型：文字武侠 RPG · Roguelite 肉鸽 · 割草式生存 · 武功构筑 · 装备刷取  
> 核心体验：**每次下山都是一场不断变强、不断冒险、也可能随时覆灭的江湖远征。**

## 一、游戏概念

玩家扮演一名初入江湖的侠客，从山门出发，沿着不断变化的下山路线行侠仗义。山下城镇、荒野、古战场、匪寨和秘境中会持续涌出敌人；玩家需要在敌潮中移动、出招、拾取经验与装备，临场组合武功，活到本次远征结束。

这不是传统的固定副本闯关，而是**文字驱动的肉鸽割草生存游戏**：

- 敌人会从四面八方持续出现，玩家需要在移动中自动施展或主动释放武功。
- 击败敌人获得经验、碎银、材料和随机装备，升级时从随机武学选项中做出选择。
- 每次下山的地图、事件、敌人组合、装备词条和武功奖励都会变化。
- 玩家可以在关键节点选择继续深入、挑战精英、救助百姓、进入秘境，或带着战利品提前回山。
- 角色死亡后，本次携带的临时成长归零；但门派解锁、图鉴、永久天赋和部分世界进度可以保留。

游戏的主要乐趣是：**用一套不完整的武功和有限的资源，临场构筑出一套能在敌潮中活下来的武学体系。**

## 二、世界观：下山即江湖

### 2.1 大晟末年

大晟王朝风雨飘摇，官府失去对州县和山道的控制。江湖中，门派以山门为城、以武学为国；镖局、商会、帮派、义军和邪教争夺城镇与交通要道。每到夜晚，山下便会出现成群的山贼、妖兽、死士、机关傀儡和被邪功催化的武人。

传闻天下地脉中埋藏着一部能够统合百家武学的《万流武经》。它并不记录某一门绝世神功，而是记载着武功从**入门、精通到化境**的完整规律。各大门派都想找到它：有人希望重振武林，有人想垄断天下武学，也有人想借它打破武道境界的限制。

玩家每一次下山，都是在这个逐渐失控的江湖中留下足迹。救下一座村庄、放走一个敌人、夺走一件神兵，都会改变后续遭遇和门派态度。

### 2.2 门派山门

玩家从一个可选门派开始游戏。门派决定初始武学、初始装备、天生被动和部分剧情路线，但不限制后续学习其他门派的武功。

随着远征和世界事件推进，玩家可以拜入、结盟、挑战或夺取其他门派的传承。不同门派之间存在正邪、师承、利益和血仇关系；跨门派修习武功可能带来强大的组合，也可能触发追杀与声望惩罚。

### 2.3 下山区域

每次远征从山门或城镇出发，沿程序生成的路线向山下推进。区域并非单纯的房间迷宫，而是由“连续战斗场景 + 事件节点 + 奖励节点”组成：

1. **山脚集市**：购买补给、接取悬赏、鉴定装备、选择路线。
2. **乱石官道**：山贼和流寇密集，适合建立初期武功构筑。
3. **枯水镇**：护送、救援、交易和门派冲突事件集中发生。
4. **赤铜矿场**：机关傀儡、矿奴和火属性敌人出没，装备掉落率较高。
5. **白骨荒原**：敌潮密度极高，拥有稀有材料和邪派武功。
6. **天裂秘境**：高风险精英区域，可能获得改变流派规则的传说装备。
7. **山下大劫**：本次远征的终局关卡，击败区域首领后可选择继续挑战或带战利品回山。

路线会根据玩家的门派、声望、已完成事件和前几次远征结果发生变化。

## 三、核心玩法循环

```text
选择门派与初始装备
        ↓
从山门下山，选择路线与事件
        ↓
在连续敌潮中移动、出招、拾取经验与装备
        ↓
升级三选一：强化武功 / 获得新武功 / 提升角色属性
        ↓
挑战精英、首领和特殊事件，构筑本次远征流派
        ↓
回山结算：保留永久成长，重新开始下一次下山
```

### 3.1 一局远征

一局远征通常由 10—30 分钟的连续战斗和多个事件节点组成。玩家不需要清空地图中的每一个敌人，而是需要在敌潮、奖励和风险之间做出选择：

- 继续前进，获得更高等级装备和更稀有的武学。
- 寻找安全节点，恢复气血、整理背包并调整构筑。
- 挑战精英敌人，争夺高品质装备或门派秘籍。
- 接受村民求助、护送商队、惩治恶霸，积累侠义声望。
- 放弃部分奖励，返回山门保存收获。

### 3.2 割草式生存

敌人会在场景中不断刷新并向玩家聚拢。玩家需要持续移动，避免被包围，同时利用范围武功、身法、控制和地形建立生存空间。

不同武功拥有不同的触发方式：

- **自动武功**：按冷却或条件自动施展，例如剑气环身、毒针齐射、护体罡气。
- **主动武功**：由玩家选择方向、目标或释放时机，例如掌风、飞剑、暗器雨。
- **被动心法**：永久改变角色规则，例如残血增伤、击杀回内、拾取范围扩大。
- **绝技**：消耗怒气或特殊资源，一次释放即可扭转敌潮，但冷却时间较长。

## 四、玩家成长与肉鸽规则

### 4.1 本次远征成长

每次下山开始时，玩家只有门派提供的基础武功与装备。远征中通过以下方式变强：

- 击败敌人获得经验，升级后从随机奖励中三选一。
- 开启宝箱、完成事件或击败精英，获得武器、防具、饰品和秘籍。
- 收集同一武功的重复秘籍，提高该武功的当前境界。
- 发现武功组合，触发连携、共鸣或流派强化。
- 使用临时奇遇，改变本局的规则但承担相应副作用。

本次远征死亡后，临时等级、临时装备和未带回的资源会丢失。这保证每次开局都有重新构筑的紧张感。

### 4.2 永久成长

回到山门后，玩家可以使用带回的资源进行永久建设：

- 解锁新的门派、初始武功和起始装备。
- 提升基础属性、背包容量、商店等级和恢复能力。
- 完成门派任务，获得永久天赋或特殊路线。
- 解锁新的地图事件、精英敌人、装备词条和结局。
- 完成图鉴，了解敌人的弱点和武功的隐藏联动。

永久成长应当拓展选择，而不是简单让玩家无条件碾压。更强的初始能力会打开更高难度区域，同时也会带来新的敌人和挑战。

## 五、武功系统：百家武学，境界为王

武功是游戏的核心成长系统。武功并非普通技能，而是带有门派、品级、属性、招式类型和境界成长的完整武学单位。

### 5.1 武功天生分级

每门武功从获得时就拥有固定品级。品级决定成长上限、基础威力、特殊机制复杂度和掉落稀有度：

| 品级 | 颜色/定位 | 说明 |
| --- | --- | --- |
| **凡品** | 灰 | 江湖基础武学，容易获得，适合前期过渡与组合素材 |
| **良品** | 绿 | 具备明确流派效果，是稳定构筑的核心 |
| **上品** | 蓝 | 拥有强化机制和较高成长上限，通常来自精英或门派任务 |
| **绝品** | 紫 | 能改变战斗方式的招牌武学，获取条件较高 |
| **神品** | 金 | 极其稀有的传世武学，拥有独特规则和专属境界 |
| **禁品** | 赤黑 | 以巨大代价换取超常力量，可能改变结局或永久污染角色 |

品级是武功的先天资质，不能通过普通升级改变。低品级武功依然可以通过组合、专精和特殊装备发挥作用，但其上限与神品武功不同。

### 5.2 武功境界

每门武功都拥有独立境界。境界越高，威力越大，并可能解锁新的攻击形态、范围、附加效果或触发条件：

1. **入门**：掌握基本招式，拥有核心效果。
2. **熟练**：伤害、范围或触发频率提升。
3. **精通**：解锁第二效果或强化连携。
4. **小成**：招式形态发生变化，形成稳定流派核心。
5. **大成**：获得强力被动或特殊机制。
6. **化境**：达到本品级的当前上限，武功表现完全成型。
7. **登峰**：仅部分绝品、神品和禁品可达，需要特殊传承或终局条件。

武功境界的基本规则：

- 同一门武功重复获得时，优先用于提升该武功境界。
- 高品级武功的境界提升需求更高，但每次提升的收益更显著。
- 部分门派传承可以降低特定武功的修炼需求。
- 装备、奇遇和心法可以临时提高境界，但不会永久替代修炼。
- 武功境界越高，越容易触发与同门派、同属性或同类型武功的共鸣。

### 5.3 武功属性与招式类型

武功可以拥有一种或多种属性：金、木、水、火、土、阴、阳。属性影响伤害、异常状态和武功之间的联动：

- **金**：破甲、穿透、暴击。
- **木**：中毒、回复、持续成长。
- **水**：减速、冰封、范围控制。
- **火**：灼烧、爆发、连锁扩散。
- **土**：护盾、击退、减伤。
- **阴**：吸血、诅咒、隐匿和心魔。
- **阳**：净化、增益、驱邪和复苏。

招式类型包括剑气、刀罡、拳劲、掌风、指劲、暗器、毒术、召唤、护体和身法。武功的品级、属性与类型共同决定其构筑位置。

### 5.4 武功共鸣与流派构筑

当玩家拥有满足条件的武功时，会触发流派共鸣。例如：

- **万剑归宗**：装备 3 门剑气武功后，剑气有概率追击额外目标。
- **烈火燎原**：火属性武功达到指定境界后，灼烧击杀会向附近敌人扩散。
- **毒经入骨**：同时拥有毒术与木属性心法时，中毒敌人死亡会留下毒雾。
- **金钟铁壁**：护体武功与土属性武功共鸣，受击时反弹部分伤害。
- **阴阳调和**：同时修习阴、阳武功，可减少异常状态，但需要持续平衡两类资源。

共鸣不是固定职业限制。玩家可以在每局根据随机奖励临场转型，形成剑修、刀盾、毒王、火法、召唤、纯阳、暗器或混合流派。

## 六、门派体系

### 6.1 门派定位

门派决定起点，但不决定终点。计划中的主要门派包括：

- **青城剑门**：剑气、身法、暴击和连击；擅长高速移动与单体穿透。
- **玄岳刀宗**：刀罡、护体、击退和破甲；擅长正面承受敌潮。
- **少阳观**：阳属性、内功、净化和持续回复；拥有稳定的生存能力。
- **寒江阁**：水属性、暗器、减速和远程控制；擅长风筝敌人。
- **百毒谷**：木属性、毒术、召唤毒物和持续伤害；前期较弱，成型后扩散能力极强。
- **千机楼**：机关、傀儡、陷阱和资源转化；战斗依赖布置与场地控制。
- **血河帮**：阴属性、吸血、狂暴和牺牲生命换伤害；风险高、爆发强。
- **天音寺**：音波、范围控制、护盾和团队增益；可以通过声波连锁清场。
- **无相教**：模仿、偷学和改变武功标签；构筑上限高，但会积累心魔。

### 6.2 门派关系

门派关系通过声望、任务、战绩和武功使用记录变化：

- 正面声望可获得拜师、折扣、专属秘籍和援军。
- 负面声望可能触发追杀、封锁商店或门派首领挑战。
- 同时修习互相敌对的门派武功，可能解锁隐藏流派，也可能导致叛门。
- 玩家可以保持游侠身份，不加入任何门派，依靠拾取和偷学建立自己的武学体系。

## 七、装备与掉落

### 7.1 装备部位

玩家可以装备武器、护具、护腕、鞋履、饰品和秘宝。装备除了基础数值，还可能改变武功规则：

- **武器**：决定主要伤害类型和部分武功形态。
- **护具**：提供气血、护甲、抗性和受击保护。
- **鞋履**：影响移速、闪避、拾取范围和身法触发。
- **饰品**：提供暴击、内力、异常效果和资源转化。
- **秘宝**：改变本局规则，例如让所有火焰伤害可暴击，或让击杀有概率刷新绝技。

### 7.2 装备品质与词条

装备品质从普通、精良、稀有、史诗到传说。敌人、精英、宝箱和首领会掉落不同等级的装备。高品质装备拥有更多随机词条，但不保证一定适合当前流派。

词条示例：

- 武功范围增加、投射物数量增加、冷却缩短。
- 击杀恢复内力、拾取经验自动吸附、残血增伤。
- 对中毒/灼烧/冰封敌人造成额外伤害。
- 每装备一门同门派武功，获得额外护盾。
- 降低某种伤害，但提高另一种伤害或增加心魔。

### 7.3 刷装备与取舍

装备掉落遵循“高风险、高回报”原则：

- 普通敌人提供稳定的基础装备和材料。
- 精英敌人提供定向词条或门派装备。
- 区域首领提供高品质装备和专属武功。
- 秘境和隐藏事件可能提供改变流派的传说秘宝。

背包空间有限。玩家必须在“立刻换上新装备”“保留旧装备等待合成”“丢弃低品质物品换取材料”之间做出选择。

## 八、战斗、生存与敌人

### 8.1 战斗操作

文字界面会持续显示场景、敌人数量、危险方向、武功冷却、掉落物和可交互事件。玩家主要进行以下操作：

- 移动：穿过敌群、躲避远程攻击、寻找有利地形。
- 释放主动武功：选择目标、方向或范围。
- 调整自动武功：设置优先级、目标条件和资源阈值。
- 拾取：吸收经验、收集装备、选择掉落奖励。
- 使用绝技：消耗怒气、真气或特殊资源清理敌潮。
- 进入事件：在战斗间隙处理村民、商人、门派弟子和悬赏。

### 8.2 敌人类型

- **杂兵**：数量多、单体威胁低，是经验和基础掉落的主要来源。
- **精英**：带有护盾、冲锋、召唤或特殊抗性，击败后获得高品质奖励。
- **远程敌人**：迫使玩家移动，优先处理或利用障碍物规避。
- **首领**：拥有多个阶段和区域机制，会根据玩家使用的流派改变应对方式。
- **灾厄敌人**：随时间或危险度出现，专门惩罚拖延和过度刷怪的玩家。

### 8.3 生存资源

- **气血**：归零即死亡。
- **内力/真气**：释放主动武功和部分心法所需。
- **怒气**：通过击杀、受击或完成事件积累，用于绝技。
- **精力**：影响移动、闪避和连续作战能力。
- **心魔**：使用禁功、邪派秘宝或违背承诺时增加，可能带来强力增益与失控风险。
- **侠义/恶名**：影响事件、奖励、门派关系和结局。

## 九、事件、行侠仗义与选择

割草战斗不是全部。每隔一段路，玩家会遇到随机事件：

- 村庄遭受山贼围攻：立刻救援可获得侠义，但可能错过宝箱。
- 受伤的门派弟子：救治、抢夺秘籍或将其交给敌对门派，会产生不同后果。
- 黑市商人：可以用恶名换稀有装备，也可能买到带诅咒的秘宝。
- 流民与灾民：提供食物会消耗资源，但可能解锁永久支持者。
- 迷路的妖兽：击杀能获得材料，放生可能在后续成为援军。
- 门派悬赏：专门追杀某类敌人，完成后获得定向武功奖励。

“行侠仗义”不是唯一正确答案。玩家可以选择侠义、利益、门派责任或个人复仇；系统会记录这些选择，并让它们在后续下山中产生实际影响。

## 十、死亡、结算与重玩

### 10.1 本次远征失败

角色气血归零、被首领击败或陷入特殊灾厄时，本次远征结束。玩家失去本局等级、临时武功境界、未带回装备和大部分消耗品。

为了避免失败只带来挫败感，玩家可以保留：

- 已解锁的门派、武功图鉴和敌人图鉴。
- 已完成的永久任务与山门建设。
- 部分带回山门的材料、声望和剧情线索。
- 在特殊条件下继承的一项武功、天赋或装备。

### 10.2 结算评价

每次回山会根据以下因素进行结算：

- 生存时间、击败数量和精英击杀数。
- 最高武功境界与完成的共鸣数量。
- 带回装备的品质和稀有词条。
- 救援事件、门派任务和侠义行为。
- 是否击败区域首领、发现秘境和完成隐藏目标。

结算评价会影响永久奖励、门派声望和下一局可选内容。

### 10.3 结局方向

长期远征会推动世界进入不同结局：

- **百家归流**：收集多门派传承，尝试重建开放的武学秩序。
- **一门独尊**：扶持某个门派成为新的江湖主宰。
- **游侠救世**：不依附门派，靠行侠仗义赢得各地支持。
- **魔功乱世**：大量使用禁功和邪派秘宝，以力量改写天下。
- **万流武经**：找到《万流武经》，决定公开、封印、独占或销毁它。

## 十一、模式与难度

- **标准模式**：保留永久成长，适合首次体验。
- **铁律模式**：角色死亡后清除更多成长，但保留图鉴与世界解锁。
- **门派挑战**：限定初始门派和武功，完成专属目标获得永久奖励。
- **无尽下山**：持续提高敌人强度，测试构筑上限和生存时间。
- **每日江湖**：固定种子、固定奖励规则，方便比较不同玩家的策略。

难度提升主要通过敌人机制、资源压力、路线风险和事件后果实现，而不是单纯提高血量。

---

## 十二、设计目标

1. **让每局都值得重开**：地图、奖励和事件组合产生不同构筑路线。
2. **让割草有武侠味**：敌潮不是单纯数字，而是招式、身法、内功和门派风格的碰撞。
3. **让武功有明确成长感**：武功天生分级，境界提升带来清晰、可感知的威力和形态变化。
4. **让刷装备服务于构筑**：装备不是单纯数值更高，而是能改变武功规则。
5. **让行侠仗义影响世界**：战斗以外的选择同样会改变门派、路线、敌人和结局。
6. **让失败带来长期进步**：死亡损失本局成果，但保留知识、解锁和新的策略空间。

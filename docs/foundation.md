## 〇、总原则

1. **一套模型**：
   - 人只有一种。玩家、师父、对手、路人、家将，都由同一套根基、功力、武功、身体、装备构成。
   - 地方也只有一种模型，势力只有一种，事只有一种。
   - 这样做的好处：
     - 强弱讲得出道理，「他内力深厚」「他左臂有旧伤」都是真的；
     - 平衡用同一套模型去模拟；
     - 写内容的人只写「这是谁，练了什么，练到哪一重」，数值自己算出来。
2. **一把尺子：十点根基，抵一重境界**。根基、境界、功力、装备、伤势，都折算到这把尺子上比较，不各说各话。
3. **一切换算成玩家的时间**。每个数都要回答：玩家要花多少工夫，才能让它涨一点。
4. **世界不等玩家**。玩家不出手，事情照样发生。

## 一、这是一个怎样的世界

**要回答**：故事发生在什么年代、什么地方？世界由哪几股力量构成？玩家是谁？

**定下来**：
- **年代**：大胤景和年间，是架空的朝代，气象像明朝中叶，有东厂、锦衣卫、漕运、盐政、九边烽火、倭寇。武学以金庸为底（宪章 P4、P11）。
- **三股力量**：
  - **江湖**：门派、帮会、绿林、隐世高人。
  - **朝廷**：官府、六扇门、军伍、厂卫。
  - **市井**：商帮、漕运、盐号、镖局、百姓。
- 三股力量互相缠绕：盐银养着厂卫，漕帮护着私盐，门派靠香火和产业过活，绿林劫的是商路。
- **玩家**：沈孤舟，十七岁，瓜洲渡渔家的养子，身负谜团。
- **谜团**：寒江旧案和盐银账册，正好穿过这三股力量：朝廷线、江湖线、漕运线（`docs/story.md`）。所以追查谜团的过程，就是认识这个世界的过程。

**为什么**：世界由三股力量构成，人生的路才有三个大方向：武道、官场、商贾。而且走哪条路，都会碰上另外两股力量。

**留给后面**：三股力量的具体模型在第七步，人生的路在第七、八步。

## 二、时间：世界的第一根轴

**要回答**：
- 游戏里的时间怎样走？和现实时间是什么关系？
- 挂机怎样算？
- 怎样做到「慢」，又不让人憋屈？

### 1. 只有一座钟：江湖历

- **刻度**：年、月、日、十二时辰。一年十二个月，每月三十日。
- **开局**：景和某年三月初五。具体是哪一年，和 `docs/story.md` 对齐。
- **季节有实效**：
  - 冬天运河封冻，漕运停；
  - 夏天有汛，有的渡口过不去；
  - 冬天利于修阴性内功，夏天利于修阳性内功（第四步）。
- **节令有事**：元宵、端午、中秋、腊八，各有集市、庙会，各有人物出现。
- **时辰有实效**：
  - 子时阴盛，午时阳盛；
  - 入夜城门关闭，有宵禁；
  - 有的人物只在某个时辰出现。
- **人有年纪**：开局十七岁。人会长大，也会老。

### 2. 钟怎样走：行走与静修

一个人在任何时刻，只处在两种状态之一。

**行走**：在线做事，每个动作拨动江湖历。

| 动作 | 江湖历过去多久 |
|---|---|
| 交谈、交易 | 一刻 |
| 切磋、打斗 | 一刻到半个时辰 |
| 练一趟功、调息 | 一个时辰 |
| 城里走动 | 一两刻 |
| 去邻县 | 半日 |
| 跨州 | 数日 |

**静修**：打坐、闭关、养伤、经营家业。这时钟**按现实时间走：现实一小时，江湖一日**。
- **下线就是静修**。下线前选好这段日子做什么，回来时结算，并且告诉玩家这几日江湖上出了什么事。
- 一次离开最多算十日（初定）。离开一个礼拜再回来，江湖也不至于已经换了一季。
- 在线也可以静修，钟照样按现实时间走。

### 3. 一条铁律：江湖跑不过现实

- 江湖历过去的日数，最多比「开局以来的现实小时数」多十日。这多出来的十日叫**余裕**。
- 行走得太快，余裕用光了，人物就「连日奔波，疲惫不堪」，要静修一阵，才能接着赶路、打斗。
- 寻常的玩法碰不到这条线。它只拦两件事：
  - 一口气狂刷；
  - 连点「歇息」快进时间，去刷产业分红、刷冷却。
- 防改钟：本机的时间可以被人改。登录云存档时，以后台的时间为准。

**为什么要这条铁律**：
- 游戏里按日算的东西，都自动受现实时间约束，包括打坐长功力、闭关化历练、产业分红、养伤、差事冷却。宪章 P7「挂机按现实时间累积，有上限，不能速成」只靠这一条规则就守住了，不用每个系统各设一个上限。
- 「一切换算成玩家的时间」也变得具体：**江湖一日，约等于玩家现实中的一小时**。

### 4. 时间的分工

- **行走挣的是经历**：历练、银两、人情、线索，还有伤。
- **静修把经历化成本事**：把历练化成武功境界，把打坐化成功力，把伤养好，让家业生息。
- 两样缺一不可：
  - 只在线不下线，历练攒着化不开；
  - 只挂机不在线，没有历练可化（第六步）。

### 5. 数（初定）

- 一个现实日，江湖大约过十五日：在线时行走三到五日，两次离开共约十日。
- 认真玩三个月（宪章 P7 定的成宗师的时间），江湖过三四年。十七岁步入江湖，二十出头成名，和金庸笔下的少年英雄相当。

**留给后面**：打坐和闭关的速率（第四、六步），每日的开销（第八步），世界按月运转（第七步）。

## 三、空间：天下怎样分

**要回答**：世界多大？地方之间怎样连？远近怎么算？危险怎样让玩家看见？

**定下来**：
- **分三层**：道 → 州县 → 地点。
  - 道：江南道、中原、关中、川蜀、塞北九边、西域、岭南、京畿……
  - 地点：码头、客栈、山门、衙门、寒潭、破庙……
- **首发只做江南道**。其余各道先以「远方」的身份存在：靠传闻、来客、分舵、下院，把远方带进江南道。
- **地点只有一种模型**，每个地点都写清：

| 项 | 说明 |
|---|---|
| 归属 | 在哪个州县，是哪个势力的地盘（第七步） |
| 人物 | 有谁在；有的人按时辰、季节出现 |
| 能做的事 | 交谈、交易、拜师、打坐、差事…… |
| **地利** | 寒潭利阴性内功，山巅利阳性内功，古刹利佛门，道观利道家，江上利水性的功夫（第四步打坐时用） |
| 物产和物价 | 第八步 |
| **治安** | 官府管得着的地方，打斗要惹官司；荒郊野外，生死自负 |

- **路**：两个地点之间的一段路，有三样东西：
  - **路程**：要走多久，按江湖历算。官道快，山路慢；水路要坐船，有漕帮的门路就更快、更便宜；有坐骑省时。
  - **路况**：官道、山路、水路、荒野。
  - **凶险**：遇上事的几率，遇上的事有多凶。
- **凶险看得见**：每段路、每处险地都标出「太平、不太平、凶险、九死一生」，而且按玩家自己的档次来说。负责人要「迎难而上或知难而退」，前提是玩家看得出难。

**为什么**：远近就是时间，时间就是开销和机会。空间这样就自然接上了时间、经济，以及「撞上的」玩法。

**留给后面**：地利在第四步打坐里用，地盘在第七步，物价在第八步，路上的事在第九步。

## 四、人：一个人由什么构成

**要回答**：负责人问的五个问题（属性、内力、武功、装备、人体），其实是同一个问题：**一个人由什么构成，这些东西怎样换算成本事**。

一个人由四部分构成：

| 部分 | 包括 | 在哪里讲 |
|---|---|---|
| 生来的 | 根基（六项显示，一项暗藏）、年纪、性情 | 本步第一节 |
| 练出来的 | 功力（内力）、武功（各门练到第几重） | 本步第二、三节 |
| 身上的 | 身体（伤势、穴道、毒）、装备 | 本步第四、五节 |
| 世上的 | 名望、侠义与恶名、身份、人情、银两 | 第七、八步 |

### 1. 根基：一个人生来的样子

**要求**：
- 每一项管一件**互不重叠**的事；
- 每一项在战斗、修炼、行走江湖三处**都有用**，没有摆设；
- 项数少，玩家一眼记得住。

于是定为**六项显示的，一项暗藏的**：

| 根基 | 本质 | 战斗中 | 修炼中 | 行走江湖 |
|---|---|---|---|---|
| **膂力** | 外力 | 外功的力道；硬接外力 | 外门硬功练得快；驾驭重兵器 | 推石、扛物、破门 |
| **体魄** | 承受 | 气血多少，伤势轻重 | 伤好得快，抗毒 | 斗酒，耐寒暑，赶长路 |
| **根骨** | 经脉，内力的容器 | 功力的上限；硬接内劲 | 内功、打坐练得快，经脉不易走火 | 运功疗伤，逼毒 |
| **身法** | 速度 | 闪避，先手 | 轻功练得快 | 潜行，追人，赶路省时 |
| **悟性** | 看破 | 拆招，点穴准不准，看出破绽 | 招式类的外功练得快；闭关消化快；上乘武功的门槛 | 细看，解谜，偷学 |
| **胆魄** | 意志 | 怒气，抢攻，不怕震慑 | 心境稳，不起心魔 | 威吓，夜探，斗狠 |
| **福缘**（不显示） | 运气 | — | — | 撞上机缘的几率；奇遇里的好结果 |

福缘不显示数字，只在故事里流露，例如「你今天运气似乎不错」。负责人说成长要靠「勤奋或机缘」，福缘就是机缘的来处。

**常人是十**：
- 开局每项在六到十六之间，序章的「童年三忆」定下长成什么样子。偏科的人有偏科的活法。
- 上限三十。

**根基管两件事，分量不同**：

1. **主要管「长得多快，能走哪条路」**：
   - **修炼速度**：每高于常人一点，对应的修炼快 3%。根骨十六的人练内功，比根骨十的人快约两成。
   - **门槛**：上乘武功要悟性，重兵器要膂力，大周天要根骨。够不着，这条路就走不了。
2. **次要管「眼前多强」**：
   - 每高于常人一点，在它管的那件事上加 1%（伤害、气血、内力容量）；
   - 或者加一点火候（拆招、闪避、点穴这类比拼）。
   - 十点根基，正好抵一重境界。

**为什么这样分**：武侠里的资质，决定进境快慢、能学什么；眼前谁强谁弱，看的是苦功。根基好坏要让人在意，又不能让人一开局就定了强弱。

**每一点根基值多少**：

| 根基 | 眼前（每高一点） | 修炼（每高一点） | 门槛举例 |
|---|---|---|---|
| 膂力 | 外功伤害 +1%；硬接外力 +1 火候 | 外门硬功 +3% | 大刀、铁杖、锤这类重兵器，要膂力十四 |
| 体魄 | 气血上限 +1%；伤势升级的门槛 +1% | 伤愈、解毒 +3% | 横练功夫要体魄十四 |
| 根骨 | 内力回复 +1%；硬接内劲 +1 火候 | 内功、打坐 +3%；**功力的天花板 +10%**（见下一节）；经脉走火的几率 −3% | 大周天要根骨十二；上乘内功要十四 |
| 身法 | 闪避、先手 +1 火候 | 轻功 +3%；赶路省时 +1% | 上乘轻功要身法十四 |
| 悟性 | 拆招、点穴、看破 +1 火候 | 招式类外功 +3%；闭关消化 +3% | 镇派绝学要悟性十六；解谜、偷学 |
| 胆魄 | 怒气 +3%；抢攻、抗震慑 +1 火候 | 心魔走火的几率 −3% | 杀招要胆魄十二；威吓、夜探 |

根骨对功力天花板的影响特别大，这是有意的：武侠里说一个人「根骨奇佳」，指的正是他将来能走多远。它只抬高天花板，眼前的功力还是要一日一日去坐。

**根基怎样长**（极慢，每一点都是大事）：
- **武功里程碑**：一门武功练到第四、第七、第九重，相应的根基加一。内功长根骨，轻功长身法，外门硬功长膂力。
- **机缘**：奇遇、灵药、高人洗髓，加一到三点。福缘高的人碰得上。
- **苦熬**：特定的长期苦修，例如负石登山练膂力、寒潭浸身练根骨。一生只能做有限几次，每次要花大量静修的日子。
- **一生大约能长十点**，等于一重境界。根基重要，但压不倒苦功。

### 2. 功力：一个人熬出来的内力

**武侠里的内力是什么**：
- 内力是**年月熬出来的**。武侠里说「三十年的功力」：少年天才招式再精，内力也浅；老前辈招式平平，一掌却有千钧。
- 内力有**性质**：阴寒的、纯阳的、佛门的、道家的。不同的内力会相冲。
- 内力**什么都用得上**：出手加劲、护体、硬接、疗伤、逼毒、冲穴、施展轻功和绝招，都靠它。
- 内力会**突飞猛进**：靠灵药、传功、奇遇，一夜之间多出十年功力。这就是「机缘」。

**北大侠客行的打坐，哪里对，哪里不对**：
- **对的，要留下**：
  - 内力分两层：**上限**慢慢攒，**当前**的内力在战斗里花掉，还能回复。
  - 上限靠时间一点点攒，而且有天花板，由内功的高低和根骨决定。少年再勤奋，天花板也压着他。
  - 内功是根本。内功不高，内力上不去。
- **不对的，要改掉**：
  - 打坐就是反复敲同一个命令，没有选择，只有重复。结果人人挂机器人，打坐成了最无聊的事。
  - 打坐和世界无关，在哪里坐、什么时候坐都一样。

**我们的内力：两层，加一个性质**
- **功力**（内力上限）：以「年」来显示，例如「七年功力」。一年功力等于三十点内力。
- **当前内力**：战斗里花，战后调息回复。
- **性质**：由所修的内功决定，分阴、阳、刚、柔、中正。
  - 改修性质相冲的内功，原来的内力会冲撞、流失，还可能走火入魔。
  - 这是门派限制最自然的来由：练了阴寒内功的人，不能说改就改练纯阳的。

**功力的天花板**：
- 天花板 =（内功第几重 + 1）× 5 年 × 根骨 ÷ 10。不会内功的人，最多两年。
- 举例：
  - 内功第三重、常人根骨，天花板二十年；
  - 内功第九重、根骨十四，天花板七十年。
- 到了天花板，打坐再多也不长，只能先把内功练上去。「练内功」和「攒功力」互相等着，谁也不能单独冲上去。
- **机缘可以冲破天花板，但驾驭不住**：传功、灵药给的功力超出天花板时，超出的部分只能护体，不能加力、不能用来出绝招，要等内功练上来才化为己用。就像虚竹得了七十年功力，却要学了天山武功才使得出来。

**功力怎样长**：

| 来路 | 怎样 | 多少 |
|---|---|---|
| **打坐**（勤奋） | 静修的一种：选内功、选地方、选周天，然后下线 | 常人根骨、寻常的地方、小周天，**打坐一日约长一月功力**。认真的玩家一个现实日约长半年 |
| **机缘** | 灵药、高人传功、古墓秘府里的奇遇 | 一次三年到二十年，可遇不可求 |
| **吸功**（邪路） | 吸星大法、北冥神功这类，从别人身上吸 | 快，但内力驳杂，越吸越容易反噬 |

**打坐要有选择，不只是等**：
- **地利**：在寒潭、山巅、古刹这类和内功性质相合的地方打坐，快三成。这给了玩家探索江湖的理由。
- **天时**：冬天利阴性，夏天利阳性，快一成。
- **周天**：
  - 小周天稳而慢；
  - 大周天快一倍，但有走火入魔的风险。风险由根骨（经脉）、胆魄（心魔）、内力是否驳杂、胸腹有没有伤共同决定。
- **丹药**：花钱买快，接上经济。
- **走火入魔**：
  - 轻的，功力上限暂时降低一成；
  - 重的，受内伤，数日不能动武；
  - 极少数，功力散去三成。
  - 有风险，才谈得上博弈。

**功力在战斗里的用处**：
- **加力**：每一击都可以多灌内力，加成按功力的深浅算。同样一招，三十年功力打出来和五年功力完全不同。
- **绝招**：要耗内力。
- **护体**：内力充盈时减伤；内力见底，护体就破了。
- **硬接、对掌**：比的是双方功力的深浅，不只是招式。
- **冲穴**：被点了穴，可以用内力冲开。功力越深，冲得越快。
- **战后**：运功疗伤、逼毒，都要耗内力。

**功力在尺子上值多少**：按比例算，**功力翻一倍，约抵两重境界**（初定，由模拟验证）。

### 3. 武功：除了描述和伤害，还有什么

**一门武功由什么构成**：

| 部分 | 回答什么 |
|---|---|
| **门类** | 放在哪个位置用（内功、轻功、拳脚、兵刃、绝技），要不要兵器 |
| **品级** | 先天的上限，从凡品到禁品。品级越高，同一重境界就越强，但差距有限 |
| **境界** | 后天的苦功，共九重。一重境界的分量大于一个品级（宪章 P4） |
| **性质** | 刚、柔、阴、阳、中正，决定相克 |
| **招式** | 一招一式。每招有：威力；打向哪个部位；造成哪种伤；练到第几重才会 |
| **绝招** | 耗内力、要调息的特殊一击，可以带效果：点穴、流血、卸力、护体…… |
| **被动** | 内功、轻功的长期作用：护体、回内力、闪避 |
| **师承** | 哪个门派的；按什么地位传授；前置武功是什么；要用哪门内功作根 |
| **合璧** | 和哪门武功搭配有加成 |

所以一门武功不只是「伤害多少」，它要回答：**怎样出手，打到哪里，造成什么伤，要花什么，要靠什么，和谁相生相克**。

**招式不分「力、速、巧」**：负责人否决过「重则避、气则接、虚则拆」这种靠找规律就能破解的应对（宪章 P5）。所以一招只有一个威力。哪种应对最好，由自己练成的武功和身上的伤来决定（第五步），不由对方的招式类型决定。

**克制分四层，每层只有一条规则，各有封顶**：

| 层 | 规则 | 封顶 |
|---|---|---|
| **性质** | 柔克刚，刚克阴，阴克阳，阳克柔；中正不克别人，也不被克 | 成算、命中 ±8% |
| **兵器长短** | 一寸长一寸强，一寸短一寸险 | 抢攻、拆招 ±5% |
| **身体** | 招式和身体相互作用产生克制：重手破护体，点穴怕内力深厚，毒怕逼毒，快剑怕重甲（本步第四节） | 由身体模型自然产生 |
| **打法** | 七种打法的相克环：刚猛、浑厚、阴毒、绵柔、迅捷、擒拿、吸纳（`docs/menpai.md`） | 不另加数字。由前三层合起来自然产生，用模拟验证：克的一方胜率约 56% 到 60% |

叠起来也有限：**境界的分量永远大于克制**。相克只让人吃点亏，不能让人必输。

**搭配：给自由，也不乱**
- **五个位置**：内功、轻功、拳脚、兵刃、绝技。同一时间只使一门外功：手里的兵器对得上，就用兵刃位的武功；对不上，就用拳脚位的。
- **硬规矩**：这些是武侠自己的逻辑，不是人为加的限制。
  - **内功为根**：门派的绝招要用本门内功来使，否则只剩普通招式。
  - **外功不过内功一重**：内功不到，招式练不上去。
  - **内力性质相冲**：改修相冲的内功，原来的功力要付代价。
  - **兵器要对**：剑法要用剑。
  - **门规**：严的门派不许兼修别派。
- **软引导**：同门的武功合璧有加成；内功和外功出自同一门派，也有加成。
- **结果**：玩家可以混搭，但每一步的代价都清清楚楚。最好的混搭也强不过纯修本门多少，由模拟来保证。

### 4. 身体：伤害和战斗的依据

**为什么要有身体**：现在的战斗只有一个数，就是气血。挨一刀和挨一掌一样，只是扣血。有了身体以后：
- **伤害有依据**：打在哪里，造成什么伤，后果不同。
- **战斗有起伏**：伤了手，剑就拿不稳；伤了腿，就躲不开；被点了穴，就动不了。
- **战后有后果**：伤要治，要花钱、花时间，要找大夫，要运功疗伤。这就接上了经济和时间。
- **门派有特色**：点穴、擒拿、毒、重手、快剑，在身体上各有各的用处。

**八个部位，各管一样功能**：

| 部位 | 管什么 | 轻伤 | 重伤 | 残（可以治好） |
|---|---|---|---|---|
| **头** | 神志 | 偶尔眩晕，慢半拍 | 常常眩晕 | 昏迷，这一战就输了 |
| **胸** | 气息 | 内力回复变慢 | 内伤吐血，绝招多耗内力 | 运不了功 |
| **腹** | 丹田 | 加力减弱 | 功力上限暂时降低 | 内力使不出来 |
| **背** | 护体 | 护体减弱 | 护体大减 | 护体全失 |
| **左臂、右臂** | 出手、持兵器 | 威力下降 | 兵器可能脱手 | 这只手不能用。用惯的那只手残了，拳脚、兵刃都大打折扣 |
| **左腿、右腿** | 身法 | 闪避、先手下降 | 闪避大减，轻功使不出 | 走不动，逃不了 |

**伤的种类**：

| 伤 | 怎么来的 | 特点 |
|---|---|---|
| **割伤** | 刀剑划过 | 流血，每一合掉血，要止血 |
| **刺伤** | 剑尖、枪尖 | 伤得深；刺在胸腹，会转成内伤 |
| **砸伤、瘀伤** | 拳掌、棍棒、锤 | 伤筋骨，重了会骨折，那个部位的功能就丧失 |
| **内伤** | 内家掌力，硬接失败 | 伤经脉：内力回复慢，功力上限暂时降低；要运功疗伤，或者吃内伤药 |
| **冻伤、灼伤** | 寒性、火性的武功 | 冻伤让人迟缓，灼伤持续掉血 |
| **毒伤** | 毒掌、毒针、淬毒的兵器 | 持续掉血，人变虚弱；要解药，或者运功逼毒 |

**伤势怎样累积**：
- 每次挨打，伤势记在被打中的部位上：伤势 = 这一击的伤害 ÷ 气血上限 × 伤型系数。体魄高的人不容易升级。
- 伤势分轻、重、残三级。
- 伤没好之前，气血上限也跟着降低。这是北大侠客行的「有效气血」，这一条好，留下。
- **目标**：同档交手一场，通常落下一两处轻伤，偶尔一处重伤；残只在惨败，或者被重手专攻时才出现。

**战后**：
- 伤不会自己消失。要靠时间（体魄决定快慢）、药、大夫，或者运功疗伤（耗内力，根骨决定快慢）。
- 重伤的时候不能闭关，赶路也慢。逞强有代价，这就是「知难而退」的依据。

**穴位**：点穴是武侠最有味道的东西之一，值得做成系统，但要简洁：**不做几百个穴，只做五类穴，每类一种效果**。

| 穴类 | 例子 | 被点中以后 | 怎样解 |
|---|---|---|---|
| **麻穴** | 肩井、曲池 | 一只手动不了 | 等时间过去，或者用内力冲开 |
| **软穴** | 环跳、委中 | 腿软，闪避、逃跑都不行 | 同上 |
| **哑穴** | 哑门 | 内息被封，使不出绝招 | 同上 |
| **定穴** | 膻中、气海 | 全身不能动，这一合出不了手 | 同上，但难冲得多 |
| **昏穴** | 睡穴 | 昏过去 | 只有杀招级别的点穴才点得中 |

- **点不点得中**：看点穴一方的悟性和点穴武功的境界，对比挨点一方的闪避和护体内力。内力深厚的人，点不住。
- **冲穴**：被点的人可以用内力冲开。功力深的冲得快，功力浅的冲得慢，甚至冲不开。
- **克制自然就有了**：
  - 擒拿、点穴的门派，克身法快、内力浅的人；
  - 遇上内力深厚的人，点穴的门派就吃亏；
  - 有的奇功能「移穴换位」，点穴对他无效。

### 5. 装备：外物只能锦上添花

**原则**：武功和功力是根本，装备是辅助。一身神兵利甲，加起来也不超过同档武功的两成。一把神兵，不能让三流打赢一流。

| 类 | 例子 | 效能 |
|---|---|---|
| **兵器** | 剑、刀、枪、棍、杖、鞭、斧、锤、奇门兵器 | **类型**：兵刃位的武功用不用得上。<br>**长短**：长短相克。<br>**轻重**：重兵器力道大、先手慢，要有膂力才拿得动；轻兵器反之。<br>**锋利**：破不破得了甲。<br>**特性**：寒铁兵器附带寒气；淬毒兵器附带毒，但用的人要背恶名 |
| **护具** | 冠、衣、甲、护腕、靴 | **护住部位**：冠护头，衣甲护胸腹背，护腕护臂，靴护腿。被护住的部位，割伤、刺伤、砸伤都减轻。<br>**代价**：重甲减身法 |
| **佩饰** | 玉佩、香囊、指环 | 回内力，稳心境，加一两点根基；少数有特殊效果 |
| **信物** | 腰牌、玉佩、令符 | 没有数值，只有身份和剧情上的作用，例如六扇门的腰牌 |
| **暗器** | 飞蝗石、袖箭、毒针 | 消耗品，要配暗器手法 |
| **药** | 金疮药、内伤药、解毒丹、大还丹 | 治对应的伤，回内力；大还丹这类属于机缘 |
| **坐骑** | 驴、马、良驹 | 赶路省时；要喂养，接上经济 |

装备的效能全在和**身体**、**兵器类型**、**功力**三样东西打交道，所以装备排在身体后面。

### 6. 人的其余部分

- **年纪**：会长。年少的人修炼快一些；老了，气血慢慢衰退，功力却还在。
- **性情**：只有人物有，玩家没有，玩家的性情由玩家自己的选择体现。人物的性情分豪爽、阴狠、贪财、好名、重情……决定他遇事怎样做。
- **所求**：每个人物都想要点什么。宪章 P9 要求任务有人物动机，动机就从这里来。

**留给后面**：交手在第五步，成长在第六步，名望和身份在第七步，银两在第八步。

## 五、交手

**要回答**：一次出手从头到尾怎样算？打输了怎么办？

### 1. 打的几种

| 打法 | 什么时候 | 后果 |
|---|---|---|
| **切磋** | 同门、朋友、擂台 | 点到为止，伤势最多轻伤；输了不丢东西 |
| **比武** | 公开场合，有人看 | 和切磋一样，但胜负传开，影响名望 |
| **拼命** | 结仇、路劫、剿匪 | 伤势不封顶；输了重伤、被擒、破财 |
| **擒拿** | 官府拿人，或者帮会捉人 | 打赢了可以把人押走，不必杀 |

### 2. 打输了

**玩家不会死**。拼命输了，会被救、被擒，或者被丢在路边：
- 落下重伤，要养很久，代价是时间；
- 可能丢了银两、身上的东西；
- 由败局生出新的事：被谁救了，欠了谁的人情，被关在哪里，要怎样逃。

**为什么**：三个月的养成，一死清零太狠；而败了还要付时间和后果，「知难而退」才有分量。人物会死。

### 3. 一次出手的完整流程

```
出手的一方挑一招：普通招式、绝招，或者杀招
  │ 这一招有：威力、打向的部位、伤型、要花的内力
  ▼
挨打的一方应对：以己之长（宪章 P5）
  │ 平时由他自己的武功和根基自动应对；对方出重招时，玩家亲自选：
  │   硬接：内功、根骨、膂力、功力深浅；胸腹有伤就吃亏
  │   闪避：轻功、身法；腿上有伤就吃亏
  │   拆招：外功、悟性；手上有伤就吃亏
  │ 成算 = 自己这门武功的火候 + 对应的根基 − 这一招的火候 ± 伤势 ± 相克
  ▼
没有拆开，就算伤害：
  伤害 = 招式威力 × 境界 × 膂力 × 兵器 ×（1 + 加力）× 相克
         ÷ 护体（功力、背伤）÷ 护具（护住这个部位的那一件）
  ▼
后果：扣气血；伤势记在部位上，按伤型累积；绝招的效果上身（点穴、流血……）
  ▼
伤势和效果改变后面的一切：手伤了出手轻，腿伤了躲不开，胸伤了内力回得慢，被点穴就动不了
```

- 哪种应对最好，由自己的武功和身上的伤决定，而且一场打下来会变：开头闪避最稳，腿上挨了一刀以后，就该改为拆招了。这没有固定的规律可找，却处处讲得出道理。
- 玩家、所有人物、门派对打的模拟，走的都是这一个流程。

### 4. 数（初定）

- 同档交手，八到十五合分出胜负。
- 高一档，胜率约八成；高两档，几乎必胜。
- 一合是双方各出一手，即时回合（宪章 P5）。

**留给后面**：打完以后得到的历练在第六步，传闻和人情在第九步。

## 六、成长：一个人怎样长起来

**要回答**：什么会长？靠什么长？多快？什么样算三流、二流、一流？

### 1. 什么靠什么长

```
在线行走 ──→ 历练（实战、了结的事、高人指点、见识）
                 │
静修·闭关 ──────┴──→ 武功境界（悟性定消化的快慢）
静修·打坐 ──────────→ 功力（天花板由内功定）
武功里程碑、机缘、苦熬 ──→ 根基
机缘（秘籍、传功、灵药、顿悟）──→ 破瓶颈、冲破天花板
行事 ──→ 名望、身份（第七步）；银两、家业（第八步）
```

- **根基定快慢**：悟性、根骨、身法分别决定外功、内功、轻功练得多快。
- **苦功定高低**：境界和功力，要一日一日攒。
- **机缘破瓶颈**：
  - 每门武功练到入一流的那一重、入宗师的那一重，各有一道瓶颈；
  - 要高人指点、实战顿悟，或者找到秘籍的下卷，才能突破（宪章 P7）。
- **静修的日子要分配**：同一段日子，是打坐长功力，是闭关化历练，还是养伤，由玩家选。这就是「放着的」玩法里的头一个博弈。

### 2. 档次：用「标准人」来定

档次不是凭感觉起名字，而是由「标准人」来定。标准人是根基都是十的常人，练一派武功，练到下表的程度。一个人能和哪一档的标准人打成平手，他就是哪一档。

| 档次 | 主修武功 | 功力 | 在江湖上 |
|---|---|---|---|
| **不入流** | 第一重 | 两年以内 | 乡勇、渔夫、刚入门的弟子 |
| **三流** | 第二、三重 | 三到八年 | 镖师、捕快、寻常的门派弟子 |
| **二流** | 第四、五重 | 十到二十年 | 一派的好手、一方的豪强 |
| **一流** | 第六、七重 | 二十五到四十年 | 门派长老、成名的大侠 |
| **绝顶** | 第八重 | 四十到六十年 | 一派掌门、天下有数的人物 |
| **宗师** | 第九重 | 六十年以上 | 开宗立派，一代传奇 |

标准人有三个用处：
- 写对手时，直接写「二流，练某派」，数值自己出来；
- 交手的目标（同档八到十五合）就是标准人对打；
- 门派的平衡，就是各派的标准人互相打。

### 3. 目标曲线（先定下，再用模拟玩家去验证，不对就调数）

| 认真的玩家 | 现实时间 | 江湖历 | 档次 | 功力 |
|---|---|---|---|---|
| 走完开篇 | 约三小时 | 数日 | 三流 | 三四年（开篇里有一次小机缘） |
| 二流 | 勤奋约两周，或者一次大机缘 | 约半年 | 二流 | 十年以上 |
| 一流 | 一到两个月 | 一年半到两年 | 一流 | 二十五年以上 |
| 宗师 | 三个月以上，而且一定要有机缘 | 三四年 | 宗师 | 六十年以上 |

- 只做主线的玩家，到不了二流：缺历练。
- 只挂机的玩家，到不了二流：闭关只能化历练，没有历练可化。

### 4. 数（初定）

- 打坐：常人根骨、寻常地方、小周天，一日约长一月功力。
- 闭关：一日化多少历练，由悟性和这门武功的品级决定。具体的数，按上面的曲线反推。
- 历练的来路和递减，沿用现在的做法（`src/engine/lilian.ts`），再按曲线重新定数。

## 七、势力：江湖、朝廷、市井怎样运转

**要回答**：门派、帮会、官府……怎样统一成一个模型？玩家和它们是什么关系？「世界自己运转」具体是怎样转？

### 1. 势力只有一种模型

| 项 | 说明 |
|---|---|
| 类别 | 门派、帮会、官府、军伍、厂卫、商帮、绿林、世家 |
| 名声 | 正、邪、官，或者亦正亦邪 |
| 地盘 | 哪些地点归它管（第三步） |
| 人 | 有地位的人物，每一个都是第四步的「人」 |
| 实力 | 由它的人算出来，高手越多越强 |
| 财力 | 银两和产业 |
| 所求 | 它想要什么：扩张、复仇、敛财、清名、自保 |
| 恩怨 | 和别的势力的关系 |
| 立身之道 | 特权、帮手、生计、差事、软肋（`docs/lizu.md`） |

三十个门派是这个模型的一部分。它们的差异和平衡，用 `docs/blueprint.md` 第四节的数学模型来管。

### 2. 玩家和势力

- **声望**：玩家在每个势力那里各有一个声望，从「仇视」到「敬重」。
- **名望**：天下有多少人知道你。
- **侠义与恶名**：两条线，互不抵消（已有）。
- **身份**：
  - **一人一师门**（已定）。官场也走这条路：投六扇门、投军，就是拜了这个「师门」。
  - **家业**另算（第八步）。商贾这条路是家业，和师门并行，不冲突。
- **人情**：和每个人物的恩怨，一个人一个（已有）。

### 3. 世界自己转

- **每月结算一次**：每个势力按自己的所求和实力，行动一次，比如扩张、报复、结盟、敛财、内斗。
- **结果写进世界**：地盘易手，路的凶险变了，物价变了，人物生死，然后化成传闻，传到玩家耳朵里。
- **大事日程**：有些大事按江湖历定好时间，比如某年的武林大会、漕运改道。到了时候就发生；玩家站在哪一边、出多少力，影响结果。
- **玩家的作为算进去**：杀了谁的人，帮了谁的忙，都会改变势力的实力和恩怨。
- **首发的规模**：江南道八到十个活跃的势力，规则从简。

**为什么**：负责人说「剩下来就是这个世界自动运行或玩家自行发掘的任务了」。世界自己转，玩家下线回来，江湖才真的变了样。

## 八、经济：衣食住行与家业

**要回答**：钱从哪里来，到哪里去？多少钱算多？经济怎样和时间、成长接上？

### 1. 一把尺子

- 只有一种钱：银两。一两等于十钱，等于一千文，这只是不同的说法。
- **常人一日的嚼用 = 一钱银子**，也就是下等客栈住一宿、吃两餐。所有物价、工钱都按这个来定。

### 2. 衣食住行

| 住处 | 一日 | 好处 | 坏处 |
|---|---|---|---|
| 露宿、破庙 | 不花钱 | — | 伤好得慢；静修没有地利；可能遭窃、遇险 |
| 客栈下房 | 一钱 | 安稳 | — |
| 客栈上房 | 五钱 | 伤好得快一些 | 贵 |
| 师门 | 不花钱 | 门派管吃住 | 受门规管 |
| 自家宅子 | 不花钱，要养 | 能存放东西；有静室作地利；家将住在这里 | 买宅子很贵 |

- 衣：护具就是衣裳的一部分（第四步）。
- 行：船资、车马钱，坐骑要草料。
- 下线静修的日子也要吃住。没钱就自动露宿，不会欠债。

### 3. 钱从哪里来

| 档次 | 能挣的营生 | 每个现实小时，大约挣多少（初定） |
|---|---|---|
| 不入流 | 打零工、跑腿、卖鱼 | 一两 |
| 三流 | 押镖、护院、小悬赏 | 三两 |
| 二流 | 大悬赏、坐镇镖局、师门差事 | 十两 |
| 一流 | 被请去坐镇；大宗的买卖 | 更多，主要靠家业 |

此外还有俸禄（官府、军伍）、门派的月例、产业分红、家将挣回来的钱。

### 4. 钱到哪里去

- 嚼用、药、兵器护具、拜师的束脩、打点、宅子、产业、家将的月钱、丹药。

### 5. 家业：宅邸、产业、家将

- **宅邸**：落脚，存东西，静室可以作地利，家将住在这里。
- **产业**：拿银子入份子，比如船行、茶楼、当铺。按月分红，会出事，要回来处理。
- **家将**：也是第四步的「人」。
  - 按月给月钱；
  - 可以派出去押镖、打探、练功，这是「放着的」玩法；
  - 有忠心，会成长，会受伤，也会死。

### 6. 钱和时间互换

- 钱能买时间：坐船比走路快，丹药让打坐快，请大夫让伤好得快。
- 时间能变成钱：产业、家将。

### 7. 目标（`docs/blueprint.md` 已定）

- 前期手头紧巴巴：挣的钱刚够嚼用，再加一点积蓄。
- 一处小宅子，约要攒一周（现实时间）。
- 一份产业，约要攒两周。
- 拜入门派，门派管吃住，这是前期入门派的一大实惠。

## 九、事：世界里发生的事

**要回答**：任务、路遇、奇遇、差事、世事，怎样统一成一个模型？

### 1. 事只有一种模型

| 项 | 说明 |
|---|---|
| 触发 | 在哪里、什么时辰、什么条件下发生 |
| 人物 | 谁卷在里面；每个人想要什么（第四步的「所求」） |
| 选择 | 玩家能怎样做，要有两难（宪章 P9） |
| 代价 | 每个选择要付什么：时间、银两、伤、人情、名声 |
| 结果写进世界 | 人情、势力的实力和恩怨、传闻、旗标 |
| 余味 | 结局让人回味（宪章 P9） |

### 2. 按玩家的时间分四种

前三种已经在 `docs/blueprint.md` 第二节定下，这里补上第四种。

| 种 | 是什么 | 例子 |
|---|---|---|
| **撞上的** | 即时随机的机遇，只有一次 | 路遇、奇遇、江湖事件 |
| **去找的** | 可以反复做的副本和差事 | 师门差事、悬赏、押镖、秘境、擂台 |
| **放着的** | 允许挂机的长线博弈 | 打坐、闭关、产业、家将派遣 |
| **世事** | 世界自己的大事（第七步） | 势力消长、大事日程 |

### 3. 败局也是事

打输了、被擒了、破产了，都会生出新的事（第五步）。

## 十、故事：一段完整的开篇

**要回答**：剧情在这个世界里干什么？

**定下来**（`docs/blueprint.md` 第五节已定，这里只补上它和前九步的关系）：
- 剧情只做一段完整的开篇，约三小时。
- 开篇的任务，是把前九步一样一样教给玩家：

| 开篇里的一段 | 教会玩家哪一步 |
|---|---|
| 瓜洲夜雨、童年三忆 | 人：根基是怎样来的 |
| 夜袭、江伯之死 | 交手：伤、内力、打不过就逃 |
| 赶往扬州 | 时间与空间：路程、凶险、天黑 |
| 初到扬州 | 势力：门派、漕帮、六扇门、黑风寨，每一家都想要点什么 |
| 住店、典当、找营生 | 经济：一日的嚼用，手头紧 |
| 渡口一战、闭关 | 成长：历练要靠静修来化；第一次下线静修 |
| 江心废墟 | 事：秘境，危险看得见，可以知难而退 |

- 开篇结束时，第一个问题有了答案，更大的谜团浮出来。之后谜团的后续散在世界里，等玩家自己去找。

## 十一、数怎样管，怎样验证

- **数值总表**：所有可调的数，只放在一个地方（`src/content/numbers.ts`），每个数都写清单位和含义。
- **标准人对打**：各档、各派的标准人互相打，检查同档八到十五合、高一档胜率约八成、相克 56% 到 60%、各派实力在窄区间里。
- **模拟玩家**：按几种玩法风格（勤奋、只做主线、只挂机、只刷副本）在江湖历里过上几年，检查第六步的目标曲线和第八步的经济目标。
- **进 CI**：上面这些都写成断言。改了任何一个数，曲线跑偏了，就不让合并。

# 骨干计划：先让扬州的头几个江湖日好玩

负责人 10-09 晚定的方向（`docs/decisions.md` 最后三条）：
- 「游戏要循序渐进，体验要好玩，让玩家有目标……先建立骨干，再慢慢丰满」；
- 「参考网文，主角的成长之路有一定的规律和套路」，玩家要有「值得追求的事业」，与江湖自由不矛盾；
- 「学习马斯克的第一性原理，找出让游戏变好玩的方法是最关键的」。

10-09 晚负责人又定：**不推倒，换中心改造**（保留引擎、内容、存档、测试）。

**北极星**（采纳 ChatGPT 的方案）：从一个没钱、没本事、没人认识的人，成长为有能力、有牵挂、能改变一方局面的人。武功、门派、地图、经济都围绕这个过程设计；玩家最终可以成为剑客、捕快、掌门，也可以成为不善战却能调停两帮纷争的人。留下三种乐趣：
- **自主性**：这是我自己选的路；
- **能力感**：以前做不到的事，现在有办法了；
- **影响力**：有人记得我，世界因为我的行动发生了变化。

**检验标准**：玩家合上手机时，知道自己今天办成了什么，也惦记着江湖里的某个人、某件事。

本文件是这些决定落地的依据。以后开任务，都从这里拆，并在 Issue 里写明出自哪一节。

## 一、方法：好玩是一个循环

从头问「玩家为什么想继续玩」，拆到底是一个小循环：

> **想要**一样东西 → 眼前有几个**选择**，各有代价 → 选了马上看到**后果** → 自己**进步**一点 → 冒出新的想要（中间有**意外**）

缺一环就断：没有想要，玩家乱逛；没有选择，玩家干等；没有看得见的后果，玩家觉得白忙；没有进步，玩家觉得原地踏步；没有意外，玩家觉得像上班。手机上这个循环要转得快：几十秒就该有一次值得做的决定。

ChatGPT 10-09 的评估用一句话说了同一件事，也补上了「痕迹」这一环：**「我自己选了一件事，付出了代价，办出了结果，长了一点本事，也在江湖留下了一点痕迹。」** 每次上线都应有机会完成这样一个小过程。

**怎么量**：每次试玩数三个数，改完再量，变好了才算改对。
1. 有意义的决定：平均多少次点击一个（选了会有不同后果的才算）；
2. 无事可做：玩家只能干等、空点、绕圈的次数；
3. 想关掉：玩家说「想关」的次数和原因。

## 二、证据：五份试玩和两份摸底（10-09 晚）

四个角色在浏览器里真玩（新手、MUD 老玩家、只想变强的玩家、商业制作人），每人 150～350 次点击、江湖十天上下；另有负责人原话台账（255 条）和代码摸底。

**玩得最好的地方，循环五环都齐**：藏经阁破案（看现场、盘问、指认、再选求不求情）；输给屠千山后醒在大明寺、有人指点「变强之道」；闭关两日、回头赢了柳寒舟；小金山观残棋悟出惊鸿剑；卖身葬父。**要保住，别改坏。**

**想关掉的地方，都是循环被我们自己截断**：

| 断在哪 | 现象（试玩原话或摸底数字） | 几份报告撞到 |
|---|---|---|
| 没有选择 | 「江湖上的日子，已经走在现实前头了，这一夜过不去」：夜里歇脚、闭关全灰，历练攒到六百多吃不掉；手上有今日差事时歇脚键消失，只能空点「观察」熬夜 | 4/4 |
| 想要了没有路 | 身上始终三十文上下；治手伤要一百五十到四百五十文；帮工给一个烧饼；来钱全是一次性的；行善的人最穷 | 4/4 |
| 做了没有后果 | 揭了寻人榜找不到要去的东关布庄；小栓的舅舅只在亥子时出现、见闻簿不记；撬锁、来一手是死按钮 | 3/4 |
| 后果在骗人 | 掂斤两读的是此刻气血不是实力（柳寒舟「远不如你」→「远在你之上」）；写「你收了钱」银两 +0；书办说榜贴不出去却揭得到 | 3/4 |
| 进步看不见 | 闭关七日升了两门第二重，结算单一字不提；档次十三天都是「不入流」，名号一栏「—」；没有战力、评语、排名 | 3/4 |
| 失败太重 | 押镖遇伏，镖丢、记过、手和内息二级重伤，出发前不提示内力只剩十二 | 2/4 |

代码摸底的数字说的是同一件事：东西多、接不上（141 门武功 92 门没有入口；22 处条件永远不成立；14 件世事只有 2 件改变世界；原地静修八十日世界不变；悬赏榜交差后不复位能反复领钱）。

## 三、骨干：第一卷

成长照网文和金庸的规律走：一卷一张图、一个压着你的人、一级台阶、一场盛会。卷是梯子不是轨道：每一级台阶有几条路，主线可以不做。

| | 第一卷：瓜洲到扬州 |
|---|---|
| 台阶 | 不入流到三流；拜师入门、升外门 |
| 压着你的人 | 黑风寨屠千山（主线已有）；中途一两个小恶人（如柳寒舟这样可以回头赢回来的对手） |
| 主角独有的 | 寒江家学、参悟断水 |
| 来钱 | 可重复的零工和差事（赏银接单前看得见）、悬赏、走镖 |
| 变强 | 实战、练功、闭关；钱买得到药和兵刃 |
| 被看见 | 评语和战力、离下一档差什么、传闻议论你、第一个名号 |
| 盛会（卷末） | 扬州擂台，有日子可等 |
| 秘密（引出第二卷） | 江心废墟、父亲的遗书 |

## 四、长、中、短期

**长期（愿景，不变）**：一个先于玩家存在、自己运转的金庸江湖；GTA 式的自由和身份；三十派各有立身之道；神兵绝学靠机缘洞察；一卷一卷往上，三个月成宗师。

**中期：小而完整的扬州**（短期做完、试玩数字变好以后开始；先写设计，负责人看过再拆任务）：
- 一条河（运河码头）、三股势力（漕帮、府衙、盐号）、二十个关键人物，各有诉求：想得到什么、害怕什么、依靠谁、手里有什么、办不成会怎么办。诉求相撞自然生事，人会求人、隐瞒、交易、报复，也会自己解决（接 `docs/huo-shijie.md` 第二片）。手写剧情管重要人物和关键转折，世界规则管后果持续存在。
- **新开局**：江伯病了要药，药船被扣在码头，牵涉船主、漕帮和官府；三条路（护送换药钱、求官府接一桩差事、夜里找小路渡河），各有代价。办完：江伯得药、你长一点本事、有人欠你人情也可能有人记恨、码头的收费或通行变了、留下下一件事的线索。保留江伯、寒江家学、身世之谜。
- 门派生活两三派（如丐帮、六扇门在扬州）：本事、归属、负担一起来。
- 一条靠理解的谜链（前后说法不一、桥名与旧诗对不上这类）；失败给新信息，求助欠人情，硬闯惹麻烦。
- 离线时修炼、养伤、小事照常推进；会改变关键人物命运的大事给可理解的预告和介入机会，不让人怕没准点上线。
- 扬州擂台、少年英雄榜、名号；门派内门和藏经阁；江心废墟做成第一个秘境（第一卷的其余部分）。

**短期：把截断循环的地方接上**（现在开始，一件一个 PR，每件做完拿试玩量）：

|---|---|---|---|

**第一轮的验收**（ChatGPT 10-09 的评估提出，维护者采纳；四个角色再玩时逐条打勾）：
1. 到扬州后，能发现两三件事，自由选其中一件；
2. 出发前看得懂路费、时间，和自己办不办得了；
3. 办成一件有辨识或取舍的事，拿到合理的钱、见识或人情；
4. 修炼后看得懂自己长了什么，并在一个熟悉的挑战上（比如柳寒舟）感到差别；
5. 再去找相关的人，听到与结果有关的新回应（在江湖留下了痕迹）。

再加三个数（第一节）：有意义的决定多久一个、无事可做几次、想关掉几次。

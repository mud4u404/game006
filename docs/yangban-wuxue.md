# 武学的层级写法：样板（寒江三门）

依据：负责人 10-09 晚「战斗系统的形式我认可，但文字描述的魅力还可以加强，武功的效果还有提升空间，武学的层级带来的视觉效果差异、描述的层级不一样，这些很重要」。任务见 `docs/renwu-pi1.md` T8。本页是 T8c 成批写作的样板，谁写武功描写都照它。

## 一、四段

| 段 | 境界 | 写法 | 一句话 |
|---|---|---|---|
| **生** | 第一、二重（初窥门径、略有小成） | 招式的样子写清楚，带一点吃力、拘谨 | 形似 |
| **熟** | 第三、四重（融会贯通、炉火纯青） | 快、准、连贯，一招接得上下一招，对手难防 | 利落 |
| **精** | 第五、六重（登堂入室、出神入化） | 意在剑先，会借势、会诱敌；对手明明看见，偏偏挡不住 | 意到 |
| **化** | 第七重以上（登峰造极、返璞归真、天人合一） | 动作反而少了、淡了，看似平常一指，不着痕迹，却无从躲闪 | 返璞 |

## 二、写作守则

1. **四段要看得出是同一招**：招名的意象贯穿四段（「孤帆远影」始终有帆影、天际；「寒潭映月」始终有潭、月、冷光），只是写法一段比一段深。
2. **越高越少**：化段的字数不比精段多，动词更少、更轻。不靠堆形容词显得厉害。
3. **普通招式不写中没中**：出招描写后面，引擎会接对手闪开、架住或中招的话。所以普通招式只写到招式「到了哪里」为止，不写「刺中」「着了一剑」。绝招（`performs`）可以写中，因为绝招本身就是一击。
4. **格式**：普通招式前面引擎会加「你使一招「某某」，」，所以开头不写「你」，直接写动作；绝招整句写，以「你」开头，句中用「」点出招名。可用 `{foe}`（对手）、`{part}`（部位）。不给对手用他、她。
5. 照 `docs/wenfeng.md`：数字写中文，不用现代词、京片子，不以格言收尾，破折号后不跟判语，不写「你的剑」「佩剑」（招式里写「剑」可以，那是这门武功本身的兵器）。

## 三、寒江剑法（普通招式）

现有的 `text` 和 `alts` 作「生」段，不改。下面补熟、精、化三段，每段一句。

**孤帆远影**
- 熟：剑尖斜挑而出，寒光去势极远，看着尚在三尺之外，一眨眼已到了{foe}{part}。
- 精：剑尖只轻轻一送，那点寒光便似顺着江风飘了过去，明明看得见来路，偏偏不知该从哪里去挡，直奔{foe}{part}。
- 化：剑尖不过随手一指，寒光淡得几乎看不出，像天边一片帆影，不知何时已到了{foe}{part}跟前。

**江枫渔火**
- 熟：剑锋连抖，三点星芒一点赶着一点，明灭相接，接连落向{foe}{part}。
- 精：剑锋上三点星芒忽明忽灭，像夜泊时江上的渔火，看不出哪一点是虚、哪一点是实，一齐笼住{foe}{part}。
- 化：剑锋只轻轻一颤，三点星芒竟似同时亮起、同时熄了，{foe}{part}左近，只剩一片说不清来处的寒意。

**寒潭映月**
- 熟：长剑回圈，圈子划得极圆，冷光自下翻起，一闪便到{foe}{part}。
- 精：长剑回了半个圈子，剑身的冷光恰恰映向{foe}双眼，剑锋随即自下撩向{part}。
- 化：剑身似动非动，冷光如潭底月影，轻轻一晃，已贴近{foe}{part}。

**烟波钓叟**
- 熟：剑势放得极缓，似垂钓江上，{foe}才一动念，剑尖已等在{part}前头。
- 精：剑垂身侧，如钓竿闲搁，{foe}抢上一步，正好把{part}送到剑尖跟前。
- 化：持剑而立，目光不落{foe}身上，只似江边闲坐，{foe}稍一动弹，剑尖已候在{part}。

**风雪归舟**
- 熟：剑随身转，冷风扑面，一剑横削{foe}{part}，沉而不滞。
- 精：身子一转，满身风雪都裹在剑上，横削过去，剑还未到，寒气先逼得{foe}{part}一缩。
- 化：转身似收剑归去，一缕风雪随剑势掠向{foe}{part}。

**寒江孤影**
- 熟：人剑贴成一线，一道孤影不偏不倚，刺向{foe}{part}。
- 精：人与剑已分不出先后，一道孤影划过，{foe}眼中只剩这一线寒光，直指{part}。
- 化：不见人动，也不见剑动，江上只像多了一道影子，那影子的尽头，正是{foe}{part}。

## 四、寒江剑法（绝招）

**寒江孤影**（现有一句作「生」）
- 熟：你一招「寒江孤影」，人随剑走，孤影一闪已到{foe}{part}，剑尖一递即收，身形早飘出三步之外！
- 精：你一招「寒江孤影」，人剑化作一道孤影，贴着{foe}身侧掠过，剑尖在{part}一点，人已在三步之外回身而立！
- 化：你一招「寒江孤影」，原地似只微微一侧，{foe}{part}已着了一剑，再看时，人已立在三步之外！

**江枫渔火**
- 熟：你剑锋连颤，「江枫渔火」三点星芒一点紧似一点，前后相接，落向{foe}{part}！
- 精：你剑锋连颤，「江枫渔火」三点星芒明灭不定，像是一点虚、两点实，又像三点都实，接连落向{foe}{part}！
- 化：你剑锋一颤，「江枫渔火」三点星芒同时亮起，同时熄去，{foe}{part}上下三处，同时一凉！

**独钓寒江**
- 熟：你剑尖一颤，「独钓寒江」两道冷光一前一后刺中{foe}{part}，寒气自剑尖直透经脉，{foe}半身登时发僵！
- 精：你剑尖只一颤，「独钓寒江」两道冷光已先后到了{foe}{part}，寒气如江水结冰，顺着经脉一路冻上去，{foe}半身发僵，动弹不得！
- 化：你剑尖只轻轻点了两点，「独钓寒江」{foe}{part}一凉，寒气已封住半边经脉，{foe}立在当地，动弹不得！

## 五、寒江心法（内功硬接）、踏雪无痕（轻功闪避）

见招拆招里用这门武功应对成功时，接在对手出招后面的一句。

**寒江心法 · 硬接**
- 生：你提起寒江心法的内力硬接下来，臂上一麻，好歹接住了。
- 熟：你把寒江心法一运，内力绵绵涌到掌心，稳稳接下这一招。
- 精：内力似江水回流，这一招的力道撞上来，竟被一层寒意化去了大半。
- 化：你并不运劲，寒江心法自行流转，那一招打在身上，倒像石子落进了深潭。

**踏雪无痕 · 闪避**
- 生：你脚下踏雪无痕的步子一错，堪堪闪开。
- 熟：你足尖一点，踏雪无痕的身法使出，身子一偏便让了过去。
- 精：你身形一飘，已在半丈之外，落地处连雪面也未陷下。
- 化：无人看清你如何移步，那一招落下时，你已站在别处，地上一个脚印也没有。

## 六、被动生效时的一句（S7 接进实战以后）

- 护体：你周身的内力一震，卸去了几分力道。
- 身法：你身子一晃，这一下便落了空。（只在被动身法让对手落空时用）
- 回气：你调匀一口气，伤处的疼略缓了些。
- 涨怒：你挨了这一下，心头火起，出手更狠了。

## 七、给成批写作的人（T8c）

- 每门武功：普通招式每招补熟、精、化三段，各一句；绝招每个补三段；内功写硬接四段、轻功写闪避四段（生段如果原来没有，也要补）。
- 先写一门、自己读一遍四段：看得出是同一招吗？越往上是不是越淡越难防？没写「中没中」吧？
- 只改分到你名下的那几门武功所在的内容包，id 不动。

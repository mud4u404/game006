# 前一百个任务（定稿）

主干用 Codex 10-09 的一百项（先验证好玩、三个可玩里程碑），并进 Codex 第二稿与维护者稿的架构要求（统一行动协议、九条不可破坏的规则、最小验证世界），再按负责人定过的事改了几处。架构见 `docs/fangan.md` 第一至三节。

**第一版范围**：一座江南城（扬州）及附近河道、十二个地点、二十个关键人物、三股势力（漕帮、府衙、地方商户）、两条师承、约十二门真能学到的武功。做通生计、战斗、关系、探索、离线成长。

**核心目标**：玩家自由选择一件事，付出代价，得到结果，增长本事，并在江湖留下影响。

**体验的四个观察点**（每次试玩都记）：首次自主选择、首次收益、首次成长、再次回来。另加三个数：有意义的决定多久一个、无事可做几次、想关掉几次。

**改动标记**：※＝相对 Codex 原稿改过，理由写在本行；其余照原稿。

**怎么做**：每项控制在半天到三个人日，过大继续拆；四条工作线（系统、界面、内容、验证）；前置列写主要依赖，据此并行。人手分档见 `docs/liushui.md`：O＝维护者（Opus）、S＝Sonnet、H＝Haiku、小弟按长处。

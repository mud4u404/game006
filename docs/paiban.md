# 维护者按原则定的事

负责人 10-09：「这个你自己思考！原则我已经说过了！」「这种问题也是！」

所以凡是能按负责人定过的原则判断的事，维护者自己定、自己做，写在这里。负责人不同意，直接改这份清单，维护者照改。

依据的原则（原话见 `docs/decisions.md`、`docs/maintainer.md`）：
- **活**：江湖先于玩家存在，事情不等人，不靠任务推着过关。
- **自由**：GTA 式的自由，玩家凭心情逛、凭心情插手。
- **代价**：大多有条件、有代价，极少唾手可得。
- **金庸**：文字是金庸风格的中文武侠世界。
- **手机**：手机上好看、好点、不拥挤。
- **从零**：开局弱，从零练武，节奏慢，成长感比剧情重要。

排期：**甲**＝这一批就做；**乙**＝下一批；**丙**＝排进路线图，要设计和模拟，先写设计卡。

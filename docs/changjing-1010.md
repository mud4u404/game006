# 地点与场景清单（负责人 10-10 第四条）

负责人：「现在地图上的地点减少了，但是同一个地点里堆了太多的场景，且毫无逻辑，这是个问题。」依据 `docs/sheji-youhua-1010.md` 第四条：一个地点像一条街、一座寺、一个码头，从入口走进去一处挨一处，每个地点不超过八处。

## 先说清几个词

- **场景**：一个 `RoomDef`（一处能站的地方，53 处）。
- **地点**：`RoomDef.area` 相同的一组场景。地图上收进同一处的小地方（`ui/maplayout.ts` 的 `hubsOf`）也是这个意思。
- 改前的毛病不是哪个地点超过八处（最多的才 4 处），而是 `area` 乱写：同一条东关街有「扬州城」「扬州城 · 东关街」「扬州城 · 医馆」「扬州城 · 辕门桥」「扬州城 · 东关」「扬州城 · 东关街北」六种写法，瓜洲的小屋、码头、江堤、鱼市、客店各写各的。玩家在顶栏看到的地名和实际的归属对不上，「这一处属于哪里」说不清。
- `area` 只用于顶栏的小字和存档卡上的地名（`ui/shell.ts`、`ui/story.ts`），不进任何判断，改它不影响存档和剧情。

## 方案

1. **归属对齐**：每个地点只用一个 `area` 写法，格式「城 · 地点」。分到哪里按出口走：从哪一处的出口进去，就归哪一处；寺、观、庵、府衙各自成一个地点，不混进街里。
2. **合并**：逐处核对「太相似、没有自己的事」。核对结果是 **没有可并的**：
   - 53 处里没有哪两处同时满足「人和事都重复」。看着像的（官道茶棚/蜀冈官道、枫桥码头/星桥埠头、西津渡/待渡亭、鱼市口/瓜洲镇）都是为了「场景不挤」测试（一处最多五人）当初拆出去的，并回去会再超员。
   - 所以本次并了 0 处。但并的路已经铺好：`src/content/room-alias.ts` 的 `ROOM_MERGED`（旧 id → 新 id），`core/save.ts` 的 `repair` 读档时会把所在、差事交差处、世界状态里指着旧 id 的地方改过去，不升存档版本。以后并，只需要在表里加一行，并改掉人物 `at`、世事 `where`、差事 `at`、出口里的旧 id（`tests/changjing.test.ts` 会查）。
3. **出口**：多数地点已经是「一个入口、几处小去处」的树形。东关街一条街挂着十个出口，但每一处的 `desc`、`road` 都写的是「从东关街拐进去」（观巷、东圈门、东头盐号），改成层层相连要重写十几处文字，并且会让地图上多出五六个地名，和 10-08「地图太乱」的要求冲突。所以出口不动，留一条备忘：以后东关街如果要深挖，按「街口 → 辕门桥 → 琼花观」「街口 → 东圈门 → 盐号」这个次序接，一起改文字。
   龙王庙只有一条出口（10-10 试玩点出的）：它在「运河渡口」这个地点里的位置是对的（运河堤下，渡口往东），出口怎么补由闭环摸底那一路管。
4. **测试**：`tests/changjing.test.ts`——每个地点不超过八处、同一地点不跨地区、被并掉的 id 在旧档里映射得过去。

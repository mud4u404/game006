# 活的江湖

> **10-09 补：本文的世事、打听、传闻部分，由《活的江湖 · 第二版》（`docs/huo-shijie.md`）接替。** 手写世事留作「本」，新内容写「人、模板、小事」；打听改成问这个人知道什么。导航不剧透那一条（第三节第四条）照旧。


负责人 10-08：

> 一个活的、完整的武侠江湖世界，这个东西应该先行存在。在这个江湖上，有值得探索冒险的大量剧情和故事，等待玩家去发现和参与，这一点很重要。
> 然后玩家的角色，自由自在地体验这个世界，像 GTA 一样，应该是这种感觉，而不是各种各样的任务推着玩家去过关，一切看玩家心情。

这份文档写怎样把这种感觉做出来。它管所有内容的写法：门派据点、新城池、身份、奇遇，都按这里写。

## 一、病根：现在是「任务推着走」

10-08 摸底时，江湖里有 31 个地点、101 个人物、7 条任务、35 张剧情卡、29 个路遇。玩起来像过关，原因是：

- **人站着不动。** 谁在哪儿，一天十二个时辰都一样，等着你去点。
- **世界不自己变。** 你不去，事情就停在那儿等你；传闻是一张固定的单子。
- **处处指路。** 任务簿写着下一步去哪，地图标着「当前目标」，江湖页顶上挂着任务横幅。
- **每个人能做什么都是手写的。** 能偷谁、能打谁，全看写内容的人有没有想到。

这些都是骨架上的事，不是内容多少的事。照现在的写法，再写一百条任务，玩起来还是过关。

## 二、GTA 的感觉从哪里来

1. **世界不等你。** 路人有自己的事，帮派火并，警察追人；你不看，这些事也在发生。
2. **走到哪都有事。** 一条街上同时有好几件事，可以看、可以插手、可以走开。感觉来自密度，不来自任务的数量。
3. **对谁都能动手，世界的反应有统一的规矩。** 任何人都能打、能抢，然后通缉的星级就涨上来。玩法来自规则，不来自剧本。
4. **没人指路。** 你知道哪里有意思（听说的、看见的），去不去由你。
5. **做过的事留下痕迹。** 人记得你，传闻传开，地方变了样。

## 三、五件要做的事

### 1. 世事：江湖自己转（`engine/shishi.ts`，`ContentPack.shi`）

一件江湖上的事是一条时间线，分几步走。每一步写清楚四样：

- 眼下怎样（`now`，见闻簿上的一句）；
- 传开的话（`news`）；
- 不管它的话，几天后自己走到哪一步（`next`）；
- 走到这一步时世界上变了什么（`do`）。

```ts
{ id: 'ss_matou', name: '码头空出来以后', region: 'yz', start: { flag: 'boss' }, first: 'qi',
  steps: {
    qi:      { now: '……', news: '……', next: { days: 2, to: 'duizhi' } },
    duizhi:  { now: '……', where: 'dukou', next: { days: 3, to: 'huobing' } },
    huobing: { now: '……', next: { days: 2, to: 'xiduo' } },
    xiduo:   { now: '……（没人管时的结局）', do: [/* 世界变了 */] },
    dongduo: { now: '……（玩家帮东舵守住的结局）' }
  } }
```

- **世界不等你。** 玩家不插手，事情照样走到结局，写进传闻，世界随之改样：码头换了主人，船钱涨了，人物说的话也变了。不插手不是罚，只是另一种结局，往往还会生出新的事。
- **插手的路不止一条。** 插手写在人物的动作和剧情卡里。条件用 `{ shi: { id, at: ['duizhi'] } }`，效果用 `{ type: 'shi', id, to: 'dongduo' }`，把事情推到另一步。
- **玩家知道的和世界上发生的分开记。** 见闻簿只写玩家知道的那一步。玩家知道一件事有四条路：
  - 人在那个地区时听到传开的话；
  - 走进事情发生的地点（`where`）；
  - 向人打听；
  - 自己插手。
  隔久了没去打听，见闻簿上写的就是旧消息。
- **同一时间，江南道上总有几件事在走。** 每个城池至少一件。机器检查：每件事的每一步都有路走到（不插手的那条路，加上每一种插手）。

### 2. 作息：人在不同的时辰在不同的地方（`NpcDef.at` 可以写多处）

```ts
at: [{ room: 'cheng', if: { hour: { from: 8, to: 17 } } },
     { room: 'cheng_tavern', if: { hour: { from: 18, to: 22 } } }]
```

- 说书人白天在东关街，夜里在望江楼；卖花姑娘天黑就回家；更夫只在夜里出来；小贼只在夜里出没。
- 同一个地方，早上、晌午、夜里去，看到的人和事不一样。人不在的时候，地点的描写要交代他去了哪儿。
- 开店的（`service`）不跟作息走，一天十二个时辰都找得到。约人、派差事的人，在约好的地方也一直找得到（机器检查）。

### 3. 对谁都能做的事：通用动作

每个人能做什么不再全靠手写。人人都有一套：

| 动作 | 做什么 | 状态 |
|---|---|---|
| 打听 | 问这一带的事：先说你还不知道的世事，再说你知道的那件后来怎样了，都没有就说些闲话传闻。一个人一天只问一回 | 这一步做 |
| 典当 | 开当铺的都收 | 已做 |
| 赠礼 | 送对了关系升一级 | 已做 |
| 动手 | 打谁都行，后果有统一的规矩：恶名、苦主的亲友记仇、官府追缉（武侠的「通缉星级」） | 和六扇门一起做 |
| 偷 | 看身法，失手了也算进恶名 | 和六扇门一起做 |
| 盘问 | 六扇门的人才有 | 和六扇门一起做 |

手写的动作只留给有故事的人。

### 4. 见闻簿：不推人走，但说清楚

负责人 10-09 补了一句：「剧情多，任务多，非常需要一个可追踪的任务导航系统……至少玩家知道自己进度在哪，卡在哪，哪怕做不成也知道。」随后又定：「这个任务导航只是方便玩家知道自己的进度，但不能剧透！更不能出戏地在那讲解！」所以见闻簿上的心事，写的是主角自己心里有数的事（`src/engine/daohang.ts`）：

- 走到哪：这一步写什么、在哪儿、多远；做过的收在「前情」里，后面的步骤不露。
- 心里的盘算：一句话，写成主角自己的念头，不挂「能做、卡住」的签，不打勾打叉，不报数。
- 卡在哪：只说玩家自己掂量得出的——钱、根基、火候、身上带的东西、时辰（「入夜以后再去」「还差：凑够二两银子」）；剧情上的门槛（还没查到的线索、还没见过的人）一概不点破，只说「这事还缺些眉目，再四处走走、打听打听」。
- 找谁：只有标题、盘算里已经点了名的人，才写他什么时辰在哪；还没查出来是谁的，不提。
- 做不成了：写为什么（玩家亲眼见过的事），归进「未竟」；记挂着的，横幅放下，动态记一笔。
- 写法：每一步的 `who`、`hint`、`need`、`fail` 写在 `QuestDef` 里，只抄推进分支里真有的条件；`hint` 只写到这一步为止人物已经对主角说过的话。机器玩家每推进一步，都核对这一步的门槛真成立（`tests/zoubian.test.ts`）；「不剧透」也有测试（`tests/daohang.test.ts`）。

江湖上的事（世事）照旧不指路，只写你知道的那一步。玩家没到过那一带、也没听说的事，停在起头那一步等着，不白白错过；没插手就了结的，写「这一回你没赶上」。

- 任务簿改叫「见闻」，分三块：
  - 江湖上的事：知道的世事，写到你知道的那一步；
  - 心事：主线和别的私事；
  - 了结的。
- 开篇（序章和第一回）照旧有横幅带路，这是负责人定的「一段完整的剧情」。开篇以后，横幅只挂玩家自己在见闻簿里选了「记挂」的那一件；不选，就什么也不挂。
- 地图上不标「当前目标」，只标你自己选了的那一件。

### 5. 一次上线玩什么：用机器量「密度」（`tests/xianguang.test.ts`）

机器玩家加一种「闲逛」打法：不追任何任务，在一个城池里随便走、随便打听、随便等，走三天。从第二天起数它碰上几件「新鲜事」：

- 知道了一件世事，或一件事往前走了一步；
- 碰上一个前一天在这里没见过的人；
- 撞上一次路遇。

数到的「每十步几件」写进测试，过不了就变红，跟基础设施检查一样。内容稀了，CI 会先发现。

## 四、内容怎么写（给协作者）

- **先写世事，再写人。** 一个新城池，先想这里眼下正在发生哪两三件事，不管的话各自怎样收场；再想这些事牵扯到谁，他们白天、夜里各在哪儿。
- **不要写「去某处找某人」的任务。** 写一件正在发生的事，让玩家听说、撞见，自己决定插不插手。
- **每件事至少三个结局：** 没人管的一个，插手的至少两个（帮这边、帮那边、报官、趁火打劫……），而且结局之间世界的样子看得出不同。
- **结局要写进世界：** 地点的描写、人物的话、传闻，至少改一处。

## 五、和开发顺序的关系

这一层排在门派内容和苏州前面。顺序是：

1. 引擎：世事、作息、打听、见闻簿、闲逛指标；
2. 扬州示范：「码头空出来以后」「东关街夜里闹贼」两件世事，加上扬州人的作息，放进试玩预览，请负责人先玩；
3. 六扇门特权，做成引擎的第一个用户：
   - 通缉犯住在江湖里，有作息；
   - 靠打听、盘问去找；
   - 恶名高了，捕快来拿的是你；
4. 给协作者的苏州和第二批门派据点，按第四节的写法派。

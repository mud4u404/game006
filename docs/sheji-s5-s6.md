# 骨干 S5、S6 规格：战力与评语、失败有缓冲

对应 `docs/gugan.md` 第四节 S5、S6，`docs/renwu-100.md` 第 049、044 项的一部分。依据 `docs/sheji-001-003.md` 第 003 项「失败」「成长」。

## S5 战力与评语（第一版）

**玩家价值**：知道自己多强、离下一档差什么、江湖上认得的人谁强谁弱（负责人愿景第 12 项）。只写真的，算法一致：掂斤两、交手、人物页用同一套（`src/engine/person.ts` 的 `tierCont`、`tierOf`、`realmAt`、`gongliAt`）。

人物页「斤两」一块，四样：

1. **战力数**：`round(tierCont × 100)`，旁边写档次，例如「战力一百三十七：三流之上，二流未满」。数随实际变，闭关、学艺、受伤后（受伤不降战力数，另起一句「眼下带伤」）都对得上。
2. **离下一档差什么**：写成两样看得见的门槛，照 `tierOf` 的判法：
   - 最高的一门武功要到第几重（现在第几重）；
   - 功力要几年（现在几年）。
   - 到了宗师不写。不报百分比。
3. **一句评语**：按路数（偏外功、偏内功、偏轻功、均衡，看 `outer / neigong / qinggong` 谁高）和档次各写一句，拼成一句话，例如「剑走轻灵，内力尚浅」「掌力沉雄，身法还嫌笨重」。四种路数 × 六档，二十四句，金庸笔法，维护者审。
4. **认得的人谁强谁弱**：只列交过手的人（`foeLog`）和掂过斤两的人，按 `tierCont` 分「强过你」「相仿」（差不到三分之一档）「不如你」三栏，每栏最多三个，写人名不写数。没有就不显示这一块。

**验收**：
- 战力数与 `tierCont` 一致；
- 闭关升重后，人物页的「差什么」跟着变；
- 评语二十四句齐、过文风检查；
- 认得的人只含交过手、掂过的。

## S6 失败有缓冲

**玩家价值**：失败要有代价，但不清空积累；会失手的事先告诉你；输了知道为什么、下回怎么补（第 003 项）。

1. **出发前提示**：揭榜、接镖、接差事、出远门（赶路超过一个时辰）的确认处，按玩家眼下的状态加一行：
   - 带伤（写哪处，手伤影响兵刃、腿伤影响身法、内伤影响内力）；
   - 气血不到一半；
   - 内力不到三成；
   - 身上的钱不够这趟的嚼用或船钱。
   - 都没有就不写。只提示，不拦。
2. **败仗只减益、不清空积累**：先把现在打输以后的全部后果列一张表（钱、物、伤、差事、关系、历练、熟练、修为），对照第 003 项：
   - 历练、熟练、修为、武功一样都不扣；
   - 伤按强弱封顶（已有）；
   - 丢镖不叠加重伤；
   - 差事头一回误了只记一过（已有）；
   - 失物有赎回的路。
   - 不合的改掉，表写进本文件末尾。
3. **输了写明为什么、下回怎么补**：败仗结算卡加一行，从这几样里挑最主要的一条写：档次差多少、带伤、内力耗尽、对方的重招你没接住（哪一种：力、速、巧）。下回怎么补也写一句（养好伤再来、练到第几重、换一门克它的功夫、找人帮手）。不说教，只写事实。

**验收**：
- 带伤时揭榜看得到提示，满状态看不到；
- 打输一场后历练、熟练、修为不变（测试）；
- 败仗卡有「为什么」一行，且和实际原因一致（构造带伤、档次差两种测试）。

### 二、出发前提示怎么出

- 位置：人物详情里，这个人有揭榜、接镖、接差事的动作（动作的分支带 `job` 效果，或者就叫「揭榜」）时，动作按钮下面一行小字；地图点地名的「去某处」确认卡上，路上超过一个时辰（一百二十分钟）时同样加一行。
- 内容：「出发前：手上带着重伤，使兵刃要吃亏；腿上带着轻伤，身法要打折扣；内息带着重伤，内力运不顺；气血不到一半；内力不到三成；身上的钱不够这趟的船钱和店钱（要几文，眼下只有几文）。」说到哪样写哪样，都没有就整行不出。
- 钱：这趟路的船钱，加上赶到时已过了半夜的一夜店钱（客栈一日一百文，`LODGING.inn`）。
- 代码：`src/engine/chufa.ts`；测试：`tests/shibai.test.ts`。

### 三、败仗卡的「败在哪里」

四样各算一个分，取最高的那一条写，下回怎么补也跟着这一条走（`src/engine/jiesuan.ts` 的 `loseNote`）：

| 缘故 | 什么时候是最主要的 | 下回怎么补 |
|---|---|---|
| 档次差 | 对手比你高出小半档以上，分数按差几档算 | 最高的一门功夫练到第几重再来；他的性质写明了就提「换一门克他某路的功夫」；这一场有备战没用上就提「把底细打听清楚、帮手请来」 |
| 带伤 | 开打前带着伤，一级记零点三五分 | 有重伤：先找郎中看了伤、服了药；只有轻伤：养上一日再来 |
| 内力耗尽 | 打完时内力低于一成五（护体失效的那条线） | 内力养回来再来，硬接、抢攻都耗内力 |
| 重招没接住 | 没接住的重招按他那一招的路数（力、速、巧）记次数，一回记零点二分，两回起每回零点三分 | 力沉的靠内功硬接，快的靠轻功闪开，巧的靠外功拆开，各练深一重 |
| 都不到 | 四样都不显著 | 养足气血再来，多看一眼他出重招前的架势 |

验收（`tests/shibai.test.ts`）：满状态无伤时揭榜没有提示，带伤时有；每个对手打输、逃、认输后历练、熟练、功力、根基、师门不减；构造「三处重伤去打相仿的人」，所有败仗卡写的都是带伤；构造「满状态去打高出两档的人」，写的都是档次差。

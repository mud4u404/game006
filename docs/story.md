# 开局与主线

## 一、主角

- **姓名**：沈孤舟。名字可以改，但「沈」姓不能改，它是身世线索。
- **身份**：二十岁，瓜洲渡渔家的养子。养父江伯从小教他一套「剑法」，却从不说这套剑法从哪里来。
- **初始状态**：
  - 武功：寒江剑法、寒江心法略有小成；踏雪无痕融会贯通，是江伯从小逼着在船上练出来的。
  - 序章结束时，从江伯的遗物里得到绝技「断水」的残篇。
  - 属性：基础值之上，由开局的「童年三忆」加成。
  - 人物修为：不入流，到第一回结束时大约三流。

## 二、背后的真相（设计者可见，玩家逐步揭开）

二十年前，寒江派掌门**沈沧澜**，也就是主角的生父，与两淮巡盐御史暗中联手，追查一桩惊天私盐案：
- 两淮盐银借漕运北上，最后流进了藩王私养的军队。
- 主谋是**黑水盟**，成员有东厂督主曹无咎、两淮盐运使、苍梧剑派掌门顾长风，以及几位大盐商。

黑水盟先下手为强：
- 给寒江派扣上「通倭谋逆」的罪名。
- 某个雨夜，东厂番子和雇来的江湖高手一起血洗了江心的寒江渚。史称「寒江夜雨」。
- 内应是寒江派大弟子**柳元直**，也就是柳寒舟的父亲。
- 沈沧澜战死，佩剑「寒江」被夺，绝学「断水」失传。
- 老仆江伯抱着襁褓中的少主逃出，在瓜洲渡隐姓埋名，一躲就是二十年。

沈沧澜死前，已经把查到的**盐银账册**一分为三，托付出去：
1. **第一份**：巡盐御史藏进了扬州府案牍库，夹在当年结案卷宗的夹层里。对应**朝廷线**。
2. **第二份**：落到了顾长风手里。他留着这份账册，是为了将来要挟同党。对应**江湖线**。
3. **第三份**：随一船私盐沉在运河某处，漕帮的老帮主知道下落。对应**漕运线**。

二十年后，黑水盟察觉江伯露了行迹，派人追杀。故事从这里开始。

账册是所有人都想要的东西：
- 黑水盟要销毁它。
- 朝中清流要拿它弹劾。
- 锦衣卫想用它扳倒东厂。
- 漕帮想用它洗清冤名。

所以在任何一条线上，玩家都会遇到好几方势力的拉拢和阻挠。

## 三、序章「瓜洲夜雨」（目标：15 分钟内把玩家送进开放世界）

### 1. 标题
雨夜江面上浮现书法「江湖夜雨」四个字，点「新的江湖」开始。

### 2. 童年三忆（用剧情的方式完成角色创建）
三段回忆，每段三选一，决定属性加成，以及武功的初始倾向。这些选择会直接影响之后见招拆招的成算。

| 回忆 | 选项 | 加成 |
|---|---|---|
| 七岁，江伯第一次带你出船，风浪骤起 | 死死抱住桅杆 | 体魄 +2，根骨 +1 |
| | 学着江伯的样子撑篙 | 身法 +2，踏雪无痕熟练 +50 |
| | 盯着浪头，默数它的节奏 | 悟性 +2 |
| 十二岁，镇上恶少欺负卖鱼的阿婆 | 抡起扁担冲上去 | 胆魄 +2 |
| | 绕到后面绊他一跤 | 身法 +1，悟性 +1 |
| | 去叫来巡检，当面对质 | 根骨 +1；侠义 +5；巡检记住了你，后续可借力 |
| 十六岁一个雨夜，你看见江伯独自在江边练剑，剑光如寒江 | 躲在暗处偷学 | 悟性 +1；寒江剑法熟练 +80 |
| | 走出去，求他教你 | 胆魄 +1；寒江剑法熟练 +40；江伯多教你一招 |
| | 回屋后彻夜难眠，跟着他的呼吸打坐 | 根骨 +1；寒江心法熟练 +80 |

三段回忆结束后起名。默认名「孤舟」，姓「沈」固定，旁白交代：「江伯说，你本姓沈。」

### 3. 瓜洲渡（教玩家探索）
- 傍晚，江伯咳得厉害，让你去镇上的药铺抓药。
- 在瓜洲镇，一步步学会三件事：
  - 场景页：此处有谁、去处。
  - 点人交谈。
  - 买东西。
- 茶摊上能听到两句闲话，埋下伏笔：
  - 「最近江上来了几条生船，不打鱼，专打听人。」
  - 「扬州那边黑风寨又劫了漕船。」

### 4. 夜袭（教玩家战斗）
- 回到家，门开着。三个黑衣人正在翻找屋子，江伯倒在地上。
- **第一战**：对一个普通黑衣人。教玩家认识自动对拆和主动招式「寒江孤影」。
- **第二战**：对黑衣首领，打不过是剧情安排。
  - 他出重招时，第一次出现见招拆招，教玩家看成算。
  - 打到一半，江伯拼尽最后的力气出手，使出一剑「断水」，绝招题字第一次出现。
  - 首领负伤退走。他腰牌上有一个「厂」字，这个细节会被玩家看到。

### 5. 江伯之死（10-09 改：江伯生死未卜，序章重写见 `docs/kaipian.md`）
江伯临终交给你两样东西：
- **半块玉佩**：刻着「沈」字，还有半个「寒」字。
- **一页油布包着的剑谱残页**：绝技「断水」，初窥门径。

他的遗言是：「去扬州……大明寺……找了尘……别信……官府的人……」

之后：
- 你掩埋了江伯，房子已经烧了。
- 天亮时搭上一条去扬州的船。
- 画面出现「第一回 · 扬州」，开放世界从这里开始。

### 6. 进入开放世界
- 船靠岸，你到了瘦西湖畔，就是原型现在的起点。
- 主线横幅：「寻访大明寺了尘大师」。
- 同时，江湖传闻里已经出现几条身份线的入口：
  - 漕帮被劫
  - 威远镖局招镖师
  - 六扇门缉拿「草上飞」
  - 边关招兵
- 玩家可以先办正事，也可以先去混口饭吃。

## 四、主线章回

### 第一幕 · 扬州
| 回目 | 内容 | 推进方式 |
|---|---|---|
| 序章 · 瓜洲夜雨 | 见上文 | 固定流程 |
| 第一回 · 渡口一剑 | 寻访了尘大师，渡口大战屠千山，结识漕帮，发现湖畔石碑上的「沈」字。屠千山是开局第一道真正的门槛：刚进扬州的少年单挑必败，要先在扬州走一走。 | 单挑（寒江剑法约炉火纯青）；或者做准备，可以叠加：**知彼**，看出他左臂的旧伤，船夫才肯说来历，他的刀慢半分；**帮手**，侠义够了，漕帮管事违了帮主的令带兄弟截住喽啰，代价是管事丢了差事；**掠阵**，和柳寒舟切磋交好，他来渡口掠阵，事后问起你的剑法，埋下他身世的线 |
| 第二回 · 石碑旧事 | 了尘大师说出你的身世：生父沈沧澜，寒江派，寒江夜雨。玉佩另一半在寒江渚。 | 对话和回忆。用过去时态的「说书」形式，演出当年那一夜 |

### 第二幕 · 寒江渚
| 回目 | 内容 |
|---|---|
| 第三回 · 江心废墟 | 前往镇江江心的寒江派旧址。这是一个探索型场景：机关、伏兵、残碑剑痕。在剑冢里找到另一半玉佩，以及父亲的遗书。遗书里说，账册分成了三份。柳寒舟也出现在这里，目的不明，可以合作，也可以动手。 |

### 第三幕 · 三条线（顺序随意，每条线两回）
| 线 | 回目 | 怎么拿到这份账册 | 关联的身份线 |
|---|---|---|---|
| 朝廷线 | 案牍 · 扬州府 | 投身六扇门，凭官身调阅卷宗；结交知府师爷；或者夜闯府衙盗出来，但会被通缉。东厂和锦衣卫都会插手。 | 六扇门、锦衣卫 |
| 江湖线 | 论剑 · 苍梧山 | 拜入苍梧剑派做卧底，升到内门后找机会；在苍梧论剑大会上公开挑战；或者借掌门之女顾清漪的帮助。 | 门派 |
| 漕运线 | 盐路 · 运河 | 和漕帮联手去打捞沉船；押一趟镖混进盐枭的船队；或者独自追查。会发现盐银一路流向北方军镇，引出第四幕。 | 帮会、镖局 |

三条线每走完一条，世界都会有反应：
- 黑水盟对你的追杀会升级。
- 说书人会多出新段子。
- 相关势力对你的态度会改变。

### 第四幕 · 九边
- 回目：北上 · 大同
- 盐银养的是藩王私兵，伪装成边军。
- 玩家可以投军，从小卒一路干起；也可以混进私兵营里做卧底。
- 本幕有两场大型战役，都是全程文字演出的战场。
- 结义兄弟雷大鹏的故事线在这里收束。

### 终章 · 京城夜雨
- 三份账册凑齐，进京。
- 揭开全部真相：黑水盟盟主曹无咎；柳元直当年的苦衷；父亲的佩剑「寒江」下落何处。
- 最后的选择决定结局。

## 五、结局

| 结局 | 触发条件（大致） | 内容 |
|---|---|---|
| 沉冤得雪 | 朝廷线声望高，把账册交给锦衣卫或朝中清流 | 寒江派平反，黑水盟伏法。你可以入朝为官，也可以辞官回到江湖 |
| 快意恩仇 | 亲手了结主要仇人 | 江湖震动。侠义高时你是一代大侠，恶名高时你是人人畏惧的煞星 |
| 重开寒江 | 自立门派，或门派线走到深处 | 在寒江渚重建寒江派，你成为开派宗师 |
| 归隐江湖 | 与红颜或兄弟的关系达到顶点，最后放下仇恨 | 一叶扁舟，从此江湖与你无关，但你仍是传说 |
| 黑水之主 | 接受黑水盟的招揽，并取而代之 | 你成了新的黑暗，说书人从此不敢再提你的名字 |

结局之后可以继续自由游玩，世界会按结局改变：谁掌了权，哪个门派兴盛，江湖传闻怎么说你。

## 013 行动协议

**一句话**：玩家和人物做任何事，都走同一条路：提出行动 → 检查条件 → 定下代价与结果 → 一次结算（要么全成，要么全不成）→ 记一条事件 → 通知相关系统 → 给玩家看实际结果。

### 类型（`src/engine/xingdong.ts`，新文件）

```ts
/** 谁要做什么 */
interface ActionReq {
  who: 'player' | string;     // 人物 id
  verb: string;               // 交谈、交差、买、学艺、赶路、出手……
  target?: string;            // 人物、物件、地点、差事 id
  at?: string;                // 地点
  key?: string;               // 防重复领取的凭据；有奖励的行动必须带（见下）
  cause?: string;             // 由哪条事件引起（连锁用）
}
/** 规则定下的代价和结果，执行前给界面看 */
interface ActionPlan {
  ok: boolean;
  why?: string;               // 不行的原因，原样给玩家看
  cost: Effect[];             // 必须付得起：钱、物、历练、贡献、时间
  gain: Effect[];             // 成了才给
  minutes: number;            // 预计耗时
}
/** 记进存档的一条事件 */
interface EventRec {
  n: number;                  // 流水号
  day: number; min: number;
  who: string; verb: string; target?: string; at?: string;
  cost: Effect[]; gain: Effect[];
  key?: string; cause?: number;
}
```

`plan(req)` 只算不改；`act(req)` 先 `plan`，`ok` 才结算。界面上的按钮标价、灰掉、写原因，全读 `plan` 的结果（许诺和实付同一依据，规则二）。

### 事先定死的五件事

1. **耗时的行动**：开始时检查条件、扣**预付**的代价（如船钱），时间一次走完（第一版不中途打断）；到了再检查**完成条件**（如要找的人还在）。完成条件不成立时，退还标了「可退」的代价，时间不退，并写明为什么。
2. **条件不成**：什么都不扣。**执行中失败**（如打输了）：只扣已经花掉的时间和事先写明的代价，奖励不给。钱不够就不让做，不再「扣到零照样给」。
3. **重复点击、读档**：有奖励的行动必须带 `key`（例：差事交差用「差事 id + 揭榜的那一日」）。事件记录里已有同一个 `key` 就拒绝结算（规则三、八）。存档在结算之后写一次。
4. **连锁上限**：一次行动引出的后续事件，深度最多三层，一次结算最多十条效果链；超了截断，并在事件记录里记一笔。
5. **人物自己行动**：同一个 `act`，`who` 填人物；代价从人物的持有物里扣（人物资源在第 022 项做），时间占人物的作息（第 023 项）。第一版先做入口，第 024 项再接。

### 事件记录

- 存档新增 `log: EventRec[]`，只留最近三百条（再早的归档成摘要，第 015 项定）。
- 见闻簿「你在这里做过的事」、人物「记得你做过的事」、传闻的来处，都读它（第 048、049、036 项）。
- 复现：同一个开局、同样的行动记录和随机种子，重放结果一字不差（规则九，第 019 项）。

### 怎么接到现有代码上

- 内容照旧写条件和效果。分支执行处（`src/engine/world.ts` 的动作执行、`dsl.ts` 的 `run`）改成先 `plan` 再 `act`：效果按类型自动分成代价（钱、物、历练、贡献的扣减，`time`）和结果（其余的）。
- `run()` 保留，作为 `act` 结算的内部一步；**界面和内容不再直接调 `run`**（测试里检查）。
- 先改三类：交差、买卖、学艺（第 024 项），它们正好是「说的和给的不一样」「反复领钱」的老毛病出处。

### 验收（第 013 项）

- 单元测试：钱不够不让买、什么也不扣；同一个 `key` 结算两次只成一次；连锁超过三层被截断；`plan` 给的价和 `act` 实扣一致。
- 存档测试：旧档读进来 `log` 为空，照常玩；新档存读后 `log` 一致。
- `npm run check` 全绿。

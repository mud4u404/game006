# 试玩记录

负责人 10-08：「我希望你真实试玩一下游戏，找出不合逻辑或者体感差的地方。」

维护者在浏览器里（手机尺寸）从「新的江湖」开局，一步一步点，玩了大约两天半的江湖时间：

- 序章打了两场；
- 了尘交代主线；
- 揭榜抓河贼，输了一次，第二晚拿住；
- 跟着黑影找到偷药的阿七，替他赔了钱；
- 在武当拜了师，学太和心法；
- 坐船去苏州，路上跳江救人。

一共记下四十条。下面是每一条和处理结果。

标记：**修了**（这次的 PR 里改了，测试或浏览器里核过）；**等定**（牵涉设定或数值，等负责人拍板）；**记下**（小毛病，以后顺手改）。

## 一、明摆着不合逻辑

| # | 问题 | 处理 |
|---|---|---|
| 1 | 江伯还活着，小屋门口就有「南 · 江伯坟」，走过去「新坟……是那天清晨你用刀刻的」，胆魄之眼说「你在这里跪过多少回」，还能祭拜；进一次人情就改成「阴阳两隔」 | **修了**：这里改叫「江堤老柳」，序章里只是江伯补网坐的老柳；坟、祭拜、人情、两条根基之眼都只在序章以后 |
| 2 | 河贼输给我后「扑通跳进运河，明晚还得上岸」，回到渡口他还在盐包后头，马上能再打 | **修了**：新效果 `away`（这几个时辰哪儿都见不到他）；我先逃跑的，另写一个结局「你退开了」，不再说他跳了河 |
| 3 | 屠千山刚骂完「滚远点」，打听他就「凑近了些」讲华山掌门 | **修了**：有「动手」的人不自动加「打听」；打听的开口样子从四种加到十二种 |
| 4 | 东关街子时写着「店铺都上了门板」，药铺掌柜在拨算盘、胡婶守着烧饼炉、孙彪收份子钱；府衙半夜九个人一个不少；渡口夜里「吆喝搬盐包」 | **修了**：`RoomDef.nightQuiet`，入夜（亥时到寅时）没写作息的人都回家。照旧在的有三种：住店看病的，有约在这儿等你的，写了 `night` 的（牢头、值夜衙役、牢里的账房、武馆学徒）。东关街、渡口、瘦西湖、府衙、镖局、武馆、辕门桥、镇江大市口、打铁巷写了夜景；大明寺、琼花观也补了夜景。CI：写了 `nightQuiet` 没夜景的变红 |
| 5 | 回春堂掌柜开口「惊澜来了」，人情却是「素不相识」 | **修了**：开局就是点头之交 |
| 6 | 序章里第一次进瓜洲镇，动态写「老街还是老样子」 | **修了**：这句只在序章以后 |
| 7 | 阿七那段写「第二天一早……」，出来还是半夜、人在东关街 | **修了**：时辰走到第二天早上 |
| 8 | 战报「尖刀尖刀乱扎」「尖刀一脚踹翻了个箩筐」：154 条花样里 139 条是自成一句的，前面又拼了兵器名 | **修了**：不拼兵器名；内容指南写明花样自成一句 |
| 9 | 战报里刚使过「江枫渔火」，按钮上同名的绝招却写「略有小成可用」灰着 | **修了**：跟绝招同名的招，不当普通招式使 |
| 10 | 海捕文书（一张纸）有「交谈」 | **修了**：改成观察、细看 |
| 11 | 自己跳江救人，动态写「一位公子跳进江里把人救了上来」 | **修了**：「你跳进江里把他拖了回来」 |
| 12 | 童年三忆「叫来巡检，当面对质」给根骨；「回屋……跟着他的呼吸打坐」（人在屋里，江伯在江边） | **修了**：改给悟性；改成「学着他平日的吐纳打坐」 |
| 13 | 童年的根基长进标「突破」「（江湖经历）」 | **修了**：标「收获」「（少年往事）」 |
| 14 | 结算页「气血恢复至三成」：打完时本来就不止三成也这么写 | **修了**：真回了血才写 |
| 15 | 师门差事误了，结算写「地位降一级」（其实扣的是门派贡献） | **修了** |
| 16 | 卢馆主、清和道长说同一句「东关街的后生，十个里有三个去盐号当了打手」 | **修了**：清和道长换了说法 |

## 二、体感差

| # | 问题 | 处理 |
|---|---|---|
| 17 | 路遇「卖身葬父」只剩「走开」：给钱要五十文（我有二十五），细看要悟性二十三（我二十二），都藏着；路人都扔一两个铜板，我一个也给不了，还被记一笔「你没帮她」 | **修了**：钱、根基、侠义、恶名、火候这类条件够不着的选项，灰着露出来，写明差什么（「要 50 文（身上 25 文）」）。旗标、任务、世事这类剧情条件照旧藏着，免得剧透。卖身葬父多一条「摸出几文钱，放在草席边上」 |
| 18 | 接下的差事不进见闻簿；顶上写「三日后，周捕头在扬州府衙等你」，读起来像三天后再去，交差也不在周捕头 | **修了**：见闻簿顶上一栏「差事」，带「去」的按钮；写成「三日之内：……（到扬州府衙的悬赏榜交差）」 |
| 19 | 攻守之势写「你压制对手 83%」，下一合我气血归零 | **修了**：气血不到四分之一时，气血条闪，战报提醒一句「攻守之势再好……该吃药，或者走」 |
| 20 | 序章头一场怒气涨到 100，「杀招：没有杀招」 | **修了**：没有杀招的不摆怒气条和杀招按钮 |
| 21 | 赏钱两套说法：书办嘴上「赏银十文」「一百文」，到手是另一个数；剿匪「赏银五十两」实给五十文 | **修了**：书办不报数，到手多少看「交差」那一行；剿匪尽数拿送的人头钱改成说一致的四百六十文 |
| 22 | 书办说「四张榜尽管揭」，可手上有差事时揭不了，也没说 | **修了**：书办说清「一回只揭一张」 |
| 23 | 镖局「不收生人」，不知道怎样才不算生人 | **修了**：赵老镖头点一句「找个镖局里的人替你说句话，铁衣成天泡在望江楼」 |
| 24 | 坐船从扬州到苏州一文不花 | **修了**：`RoomDef.fare`，运河客船二十文、过江渡船十文、江南运河客船四十文；钱不够的替船家撑篙抵账，路上多耗一个时辰 |
| 25 | 伤叠得太快：两场小仗落下手伤二级、足伤一级、内息伤三级，一级三日，要闭关十八天；铁律只许闭关九日；治一级一百五十文，一张悬赏八百文 | **等定**：伤的算法是地基第三版定的（挨重招占气血几成，落几级），动它要重跑模拟。可选：一级两日；或一场最多落两级；或赢了的那场少落一级 |
| 26 | 府衙挤了九样，三块榜各管一套（告示=草上飞、悬赏榜=河贼、海捕文书=钱三，书办另管四张） | **等定**：要不要合成一块榜、由书办统一登记 |
| 27 | 扬州到苏州半天就到 | **记下**：赶路的分钟数是地图上定的，等阶段三铺开江南道时一起看 |
| 28 | 屠千山的快船「团团围住」渡口，客船照样来去 | **记下** |
| 29 | 序章首领「这人比刚才那个强得多。撑住！」，两三下就被江伯救场 | **记下**：可以让救场晚一两合 |
| 30 | 没取名时顶上已写「沈孤舟」 | **记下** |

## 四、做得好的

- 黑影→跟上去→草棚里的孩子和病娘→三种处置：有条件，有代价，有人味。
- 武当拜师，「站桩或接三十招」二选一。
- 打不过河贼，第二晚可以再来。
- 地图的「东关街一带」收得清楚，点了照样自动赶路。

## 五、这次试玩以后多了的机器把关

- 写了 `nightQuiet` 的地点要有夜景（`tests/shishi.test.ts`）。
- 入夜人回家、有约的照旧等、`away` 到点回来（同上）。
- 坐船付船钱、不够就撑篙（`tests/jichu.test.ts`）。
- 机器玩家盯世事时，也去找递线索的人（文朝奉说了，严捕头那里才有「报线」）。了结了还有没走过的路，从头再起一回。

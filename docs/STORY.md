# 《烬龙誓约 Emberoath》剧情设定

> 本作全部角色、世界观与剧情均为原创。

## 一、世界

**瑟兰迪亚大陆**。三百年前，灭世黑龙「冥烬」自地底苏醒，灰烬覆盖天空长达七年。
赤龙伊格娜与七名人类骑士立下 **「烬龙誓约」**：赤龙以自身为锁，将黑龙封入烬火山的心脏；
骑士们则世代守护封印与赤龙的沉眠。骑士的后裔组成了 **赤鳞骑士团**。

誓约留下了两样东西：

- **守印巫女的血脉**：封印的「锁孔」，以巫女之血可以加固，也可以打开封印。
- **六片龙鳞残片**：赤龙交给骑士们的信物，散落各地。集齐六片，誓约便能在**不牺牲赤龙**的情况下重新缔结（真结局条件）。

| 势力 | 说明 |
| --- | --- |
| 洛斯坦王国 | 主角的祖国。老王卧病，摄政公爵 **埃德蒙** 把持朝政。 |
| 赤鳞骑士团 | 守护东境 **赤鳞要塞**，团长 **阿尔贝里克**，副团长 **巴尔德**。 |
| 维尔加帝国 | 东方的军事帝国。名将 **格雷戈**、黑骑士 **西格**。皇帝已被教团的「灰烬之言」蛊惑。 |
| 灰烬教团 | 崇拜黑龙的教团。大主教 **摩尔迪斯**、魔女 **薇丝珀**。目标：以巫女之血解开封印，让黑龙「净化」这个世界。 |
| 诺斯加德王国 | 北方的雪国，天马骑士团的故乡，已被帝国攻陷。 |

## 二、角色

| 角色 | 定位 | 一句话 |
| --- | --- | --- |
| 雷恩 | 主角 / 见习骑士 | 被骑士团收养的孤儿，颈侧有鳞状胎记——第一位誓约骑士的直系后裔。 |
| 艾莉西亚 | 修女 | 要塞礼拜堂的修女，**守印巫女最后的血脉**，教团追捕的目标。 |
| 巴尔德 | 副团长 / 圣骑士 | 雷恩的师父，冷幽默。第五章为掩护众人死守霜脊之桥。 |
| 洛伊 | 骑兵 | 雷恩的挚友，乐天，嘴硬。 |
| 格伦 | 佣兵 / 战士 | 独眼，只认金币，却从不对弱者出手。 |
| 菲娜 | 弓手 | 林边猎户的女儿，父亲被教团的山贼所杀。 |
| 卢卡斯 | 魔法师 | 魔导学院学生，追查恩师的失踪——而恩师正是摩尔迪斯。 |
| 琪雅 | 盗贼 | 白鸥港的小偷，养着一群孤儿，讨厌贵族。 |

| 西格 | 黑骑士 | 帝国黑骑士，巴尔德的儿子。第七章由雷恩说服倒戈。 |

**反派**：摩尔迪斯（前魔导学院院长，相信只有灰烬能让世界重生）、薇丝珀（教团魔女，摩尔迪斯捡回的孤女，对他绝对忠诚）、格雷戈（帝国名将，重荣誉，最终醒悟）、埃德蒙（摄政公爵，与教团交易以夺取王位）。

### 龙鳞残片（6 片）

1. 第一章：路旁古碑（隐藏宝物，在碑旁待机）
2. 第二章：林边村落的老人（拜访村庄）
3. 第三章：领主宅邸的宝箱
4. 第四章：海岸沉船（隐藏宝物）
5. 第六章：神殿深处的宝箱（需要盗贼或钥匙）
6. 第八章：王城宝库的宝箱

### 结局

- **普通结局**：伊格娜以生命重新封印黑龙，雷恩在烬火山立碑，骑士团重建。
- **真结局**（六片龙鳞）：六片龙鳞化为新的锁，伊格娜不必牺牲。黑龙被彻底焚尽，誓约以「人与龙并肩」的形式重新缔结。

## 四、主题

**誓约不是枷锁，而是选择。** 三百年前的誓约要求一方牺牲；本作的结局让主角们选择「一起承担」。
巴尔德与西格、卢卡斯与摩尔迪斯、琪雅与雷文——每一组关系都是「被留下的人如何面对离开的人」。

## 0. 一句话结论

**现在的江湖是一本写好的书，翻到哪页算哪页；要的是一座有人住的城，书由城里的事自己长出来。**
病根不在内容少，在世界**没有可以被改变的东西**：没有势力、没有地盘、没有物价、人没有所求、话没有来处。所以后果只能写成旗标，事件只能一件件手写，打听只能从池子里抽，玩家只能被写好的事推着。
补法是加一层**世界状态**、一层**人**、一层**传闻**、一个**导演**；事件改成「模板 + 世界里的真人真地」。原型在扬州跑了八个江湖、各六十日：东关街白天的样子从 **1 种变成 20 种**，两个人知道的事从**完全一样（1.00）降到重合两成半（0.24）**，玩家闭关一月回城，平均看得见 **9 到 10 处**后果，每一处都说得出为什么。

## 1. 诊断

### 1.1 你的五个判断，逐条核实

#### (a)「世事是写死的时间线」——**核实，而且更糟：没人管的结局永远是同一个**

- `src/engine/shishi.ts:78-83`：往下走只看一件事，`now - st.since >= nx.days * DAY`。日子到了就走，跟世界上别的任何东西都无关。
- 我把「码头空出来以后」分别从第 0 日、第 3 日起头，各跑十四日，两条时间线一字不差：
  `qi duizhi duizhi duizhi huobing huobing xiduo xiduo …`
- 玩家在扬州境内待三十日不插手：五件世事走完四件，结局**每一回都是「没人管」的那一个**：钱三逃往苏州、白七郎逃往杭州、码头归西舵、阿七挨板子。没有一件会因为东舵这阵子强些、府衙这阵子闲些而换个走向。
- 「内容量 = 作者的工作量」也核实：全江湖 14 件世事、82 步，起头条件全是旗标或任务（14/14），能年年再来的只有 1 件（鲥鱼汛）。
- **补一条你没说的**：10-09 定下的「没到过、没听说的事停在起头等你」（`shishi.ts:68-77`），是给这个病根打的补丁。手写的事贵，所以错过就是浪费；可是**让世界等你，恰恰就是不活**。玩家在瓜洲待三十日，扬州的五件事只起了三件头，**一件也没往下走**。负责人的两个心愿（「世界不等你」和「别白白错过」）在手写内容的框架里是打架的；换成生成的事，这个矛盾就没了（见第六节问题一）。

#### (b)「世界没有共享的状态量，后果只是旗标」——**核实**

我数了全部内容包写状态和读状态的次数：

| 状态 | 写 | 读 | 说明 |
|---|---|---|---|
| 旗标 `flag` | 419 处 | — | 一个全局的布尔，名字自拟，后果全靠它 |
| 关系 `rel`（玩家对人） | 53 处 | **3 处** | 写了几乎没人读 |
| 恶名 `eming` | 23 处 | 6 处 | 一个总数，不分谁记的账 |
| 势力、地盘、治安、物价、通缉 | **没有** | **没有** | `GameState`（`core/state.ts:19-115`）里根本没有这些字段 |

最好的例子：码头归了西舵，结局写着「过一回船先交二十文」（`shishi-yangzhou.ts:36`），可运河渡口的船钱（`RoomDef.fare`）是死的，玩家一文也不多交。后果只活在文字里。`docs/paiban.md` B08 打算「给 fare 写条件」，那又是一处补丁：码头每换一次主人，作者就得去改一处条件。**状态量缺了，后果就不能连锁**：西舵得了码头 → 有钱 → 收份子 → 药价涨 → 穷人偷药，这条链今天写不出来，因为中间每一环都没有地方存。

#### (c)「人没有目标、记忆、关系、知识，打听是从全局池抽」——**核实**

- `NpcDef` 出现过的字段，全部内容合起来只有这些：`id name ini tone brief look verbs actions night obj icon count at altName hint gift likes service`。没有所求、性情、帮派、行当、记性，也没有对别人的好恶。
- 人除了旗标，没有一点自己的状态：伤了、坐牢了、走了，都只能靠作者写 `if: { notFlag }` 把他从地点里拿掉。全江湖只有两处用了 `away`。
- `hearsay()`（`shishi.ts:112-128`）**不读是谁在说**：本地区的世事先说，再从 `NEWS` 里随手抽。我让玩家在扬州一天之内问遍在场的人：**55 个人说了 23 到 24 种话，其中 23 到 27 句说的是扬州以外的事**（苍梧论剑、武当下山、苏州范家）。卖花姑娘讲少林长老，牢头讲论剑，就是这么来的。
- `NEWS` 216 条，**没有一条写了「谁知道」**：`NewsDef` 只有 `if`、`text` 两个字段（`types.ts:610`）。
- 作息：扬州 77 个人里，**只有 10 个**写了随时辰变的作息。

#### (d)「玩家没有自发的游戏循环」——**部分推翻**

循环是有的，而且做得不差：历练 → 静修 → 境界（`lilian.ts`、`shiguang.ts`），身份 → 差事 → 银子（`shenfen.ts`、`JobDef`），师门 → 贡献 → 武功。老玩家给成长循环打了 6.5 分，没说它缺。
**真正的毛病是：这些循环和世界不咬合。** 走镖不改变路上的治安，揭榜不来自城里真出过的事，攒的钱除了买刀、住店没处花在人身上。府衙照壁五张悬赏，**四张挂着 `PENDING` 不能揭**（`xuanshang.ts:11-18`），因为每张都要作者手写线索和对手。所以玩家的循环转起来，世界不动；世界的事走起来，玩家的循环不受影响。「想干什么、为什么干」答不上来，是因为世界不给玩家**理由**：没有人求你，没有人恨你，没有东西因为你变贵变便宜。

#### (e)「事件靠手写，扩不动」——**核实，但要分开说**

- 扩不动：上面的四张空榜就是证据；14 件世事用了两三天的协作者产能。
- **手写本身不是病。** 扬州的世事文字是全游戏最好的部分（阿七「二十板子，一声没哭」）。病在**手写的单位太大**：一件事从起因、角色、地点、步骤到结局整块写死，拆不开、换不了人、不能重组。
- 已经有自发长出来的模板：`liushanmen.ts:22-34` 的 `wanted()` 函数，三个人犯共用一个结构，只换文字。说明「模板 + 填人」是这个项目自己会走到的路。

**修正后的判断**：要的不是「模拟替代手写」，而是**模拟管因果，手写管文字**。纯模拟（像矮人要塞）会出一堆没人愿意读的流水账；纯手写（现在）出不了量，也接不上因果。走的是十字军之王、Wildermyth 那条路：**作者写「局」的骨架和文字，世界挑人、挑时候、定结局。**

### 1.2 你漏掉的五个根本问题

#### (f) 玩家是「跳」着看世界的，世界却按「走」来设计

时间铁律（`shiguang.ts`）：下线一小时算江湖一日，一次最多十六日；在线半小时只走一两日江湖。**玩家大半的江湖日子是闭关、下线时跳过去的。**所以「活」主要在两个时刻被感到：**出关读邸报**、**回到熟地方**。
现在这两处都是假的：
- 邸报：`jingxiu()`（`shiguang.ts:157-165`）把听到的世事写完，**不够就从全局传闻池随手抽几条补上**。我在扬州连着静修六回、每回十日，四局合计 64 条传闻，**19% 是随手抽的，说到玩家自己的 0 条**。地基第十条明明写着「邸报里的每一条，都是你自己从前做的事引出来的」。
- 回到熟地方：东关街六十日里白天**只有 1 种样子**（下一条细说）。
世界的设计必须把「跳」当成头等大事：跳过去的日子里发生了什么、玩家凭什么知道、回来时在哪儿看得见。

#### (g) 世界没有「看得见」的那一层

地点描写是作者按条件写死的几种（`RoomDef.desc: Branch[]`）。**没有一条通道能让任何系统往一个地方写一句「这里出过事」**。我量了：玩家不插手，六十日里每天上午十点、夜里十点各看一眼：

| 地点 | 「上午 + 夜里」的样子有几种 | 上午的样子变过几回 |
|---|---|---|
| 东关街 | 2（就是白天、夜里） | **0** |
| 运河渡口 | 4 | 3（码头一件事） |
| 望江楼 | 2 | 0 |
| 瘦西湖畔 | 1 | 0 |

没有痕迹，世界就算真动了，玩家也看不见。

#### (h) 玩家的行动进不了世界的因果

「对谁都能动手」（`docs/huojianghu.md` 第三节第三条）至今没有：全部内容只有 22 处写了「动手」、2 处写了「偷窃」，其余的人点「偷窃」得一句默认的推托（`world.ts:202`）。更根本的是：**没有「谁看见了」**。你在暗巷里杀了人，和在府衙门口杀人，恶名一样涨，因为恶名是全局总数，不是「谁知道了什么」。所以通缉、仇家、名号都长不出来。老玩家给自由度打 6 分，说「坏人路线基本是假动词」。

#### (i) 随机数不归种子管

`hearsay()` 用 `core/util.ts:3` 的 `pick`，背后是 `Math.random`。机器玩家、闲逛测试都定了种子，可打听这一步种子管不到：我前后两次跑同一个摸底脚本，打听的结果不一样（23 种 / 23 句外地事，又一次 24 种 / 27 句）。世界层一旦接上传闻和导演，**一处漏网的 `Math.random` 就能让 CI 时红时绿**。这件事必须在第一片就立规矩。

#### (j) 消息没有价值，所以打听没有策略

武侠的骨子里是消息：谁在哪、谁要动手、风声漏没漏。现在问谁都一样，所以「问谁」不是一个选择；知道了也没用，因为结局不看谁知道什么。原型里有一幕：周捕头要清剿西舵，风声叫西舵的人听到了，官兵扑了个空，府衙丢了脸；苦主到府衙告状，周捕头多知道了两件事，下一回就拿住了人。**消息成了能换东西的东西。**这是武侠最该有、而我们完全没有的玩法。

#### (k) 量「活」的尺子量错了东西

`tests/xianguang.test.ts` 是对的方向，可它数的「新鲜事」里：每十步 1.28 件，42 件里 **21 件是「地方变了样」**，就是同一个地方白天、夜里的描写换了一换；「新的人」也多半是作息轮转。**一半的「活」是钟在走，不是世界在走。**尺子不对，CI 就会护着假象。

### 1.3 根因的先后和因果

```
R1 世界没有可改变的状态（势力、地方、人的处境）
 ├─→ 后果只能写成旗标（b）──→ 后果不连锁、看不见（g）
 ├─→ 事件只能整块手写（a）（e）──→ 内容量 = 工作量 ──→ 只好让世界等你（「未闻不走」）
 └─→ 世界给不出玩家理由（d）──→ 只能靠任务推

R2 话没有主人（传闻不属于任何人）
 └─→ 打听是抽签（c）──→ 消息没价值（j）

R3 「跳着过日子」没被设计进世界（f）
 └─→ 邸报靠填充，回城看不出变化

R4 玩家的行动没有目击者（h）
 └─→ 名声、通缉、仇家长不出来

R5 工程：随机不归种子（i），尺子量错（k）
 └─→ 改了也验不出来，验出来也不可信
```

**R1 最根本，R2 最疼（老玩家第一条），R3 最影响手机上的体感，R4 决定 GTA 感，R5 决定改得动改不动。** 修的顺序也照这个来，但第一片要把 R1、R2 一起做薄薄一层，因为只做 R2（让人说自己的话），说出来的也还是死的事。

## 2. 「活」是什么，怎样量

### 2.1 三十分钟的「活」

一个玩家在手机上拿起游戏三十分钟，觉得江湖是活的，是这样一串感受：

1. **出关时**：「我不在这十日，扬州出了这几件事」——每一件都是真的，都在我常去、我认识的人身上，有一两件说到我。
2. **走进熟地方**：「这里变了」——船钱涨了，药铺上了门板，街口多了一块木牌；我能问到为什么。
3. **问人**：「他说的是他的事」——船夫说船钱，脚夫说没活干，叫化子什么都知道一点；同一件事，在场的人说得清，隔了三手的人说得走了样。
4. **起意**：「这事我想管」——不是任务簿让我管，是阿七的娘病着、焦五占了码头、药贵了我自己也买不起。
5. **插手**：「我做了，世界记得」——东舵的人记着我，西舵的人恨我，说书的把这一段编进了书。
6. **不插手**：「我不管，事情也有个下文」——而且不是作者写好的那一个，是这一回江湖里的势力强弱定的。
7. **下回**：「这回的扬州和上回不一样」——换个种子、换种玩法，码头可能是东舵的，阿七可能没被抓。

### 2.2 十条指标

| # | 指标 | 怎样量 | 现状（main 实测） | 原型（8 个江湖 × 60 日） | 上线目标 |
|---|---|---|---|---|---|
| K1 | **各有见闻**：作息不在一处的两个人，知道的事重合几成 | 两人已知事件集合的 Jaccard | **1.00**（`hearsay()` 不读是谁） | **0.24** | ≤ 0.5 |
| K2 | **话有来处**：问一圈，答话的来处是他常待的地方、他的帮、说得出听谁说的，或他自己的日子 | 逐句判来源 | **0%**；扬州一天 55 人里 23–27 句是外地事 | **98%**；外地事 2%，只出自船夫和外乡人 | ≥ 80%；外地事 ≤ 15% |
| K3 | **一事多因**：同一类事，起头的起因有几种 | 导演挑它时，分最高的那一项 | **1**（一个旗标） | 2–3 种（夜盗 3：药价、娘病、外乡飞贼） | 每类 ≥ 2 |
| K4 | **每回不同**：两个江湖的事件（模板 + 人 + 结局）重合几成 | 两两 Jaccard | **1.00** | **0.51** | ≤ 0.6 |
| K5 | **我不在也有事**：闭关三十日回城，这期间了结的事，回城看得见几处后果 | 回城时比对势力、地方、人的状态和痕迹 | 境内 4 件，结局八局一样；**境外 0 件** | 每局了结大事 9.3 件，回城看得见平均 **9.6 处**、最少 6 处 | ≥ 3 处，且都问得到缘故 |
| K6 | **同地异日**：东关街、渡口白天的样子，六十日里有几种 | 在场的人 + 痕迹 | **1 / 3** | **20 / 20** | ≥ 8 |
| K7 | **事出有因**：由前一件事引出来的事占几成；最长的因果链几环 | 起因里的人、势力出自哪件已了结的事 | **0**（链是作者写死的：钱三→白七郎→熊大） | **56%**，最长 12 环 | ≥ 40%，链 ≥ 3 |
| K8 | **不疏不密**：一城同时在走的大事 | 每日计数 | 开局 2 件 | 平均 1.3（**被人数卡住**，见 5.4） | 2–4 件；一日了结的小事另算 |
| K9 | **邸报说真话**：出关邸报里，真事（玩家在场、在他人脉里、或说到他）的比例 | 逐条判来源 | 81%（19% 随手抽），说到玩家 0 条 | （原型没做邸报） | 100%，每回 ≥ 1 条和玩家有关 |
| K10 | **世界记得你**：玩家一件耸动的事，七日后城里几成人知道；说到时走了几成样 | 传闻扩散 | 只有作者写了带旗标的 `NEWS` 的才有 | （原型的传播已验：说书人一夜传满座） | 七日 ≥ 50%，走样 ≥ 20% |

还要两条**反指标**，防止为了「活」而吵：
- **重复**：一次上线里同一句话听到两回的比例 ≤ 5%（原型里垫底小事「入了梅」三十日出现三回，超了，见 5.4）。
- **空话**：问十个人，七个以上说「没什么新鲜事」就算冷场；冷场率 ≤ 20%。

### 2.3 怎样让机器量

- **新测试 `tests/huo.test.ts`（活的江湖体检）**：不开界面，只跑世界，扬州 8 个种子 × 60 日，算 K1、K3、K4、K6、K7、K8 和两条反指标，过不了门槛就变红。再加几条不变式：一个人同一时段不在两处；死了、走了的人不说话；每个结局都留下一处痕迹和一条传闻；一个模板每一段都有三种说法。
- **改 `tests/xianguang.test.ts`**：开局时把每处白天、夜里两种描写都先记下，昼夜轮换不算新鲜；新鲜事只数四种：世界状态变了（主人、船钱、物价跨档）、看见新的痕迹、碰上处境变了的人（伤了、回来了、新来的）、问到一件没听过的事。再加 K2（问一圈，话有来处的比例）。
- **改 `tests/zoubian.test.ts`**：机器玩家的「盯世事」打法改成「盯局」，每种插手各走一遍，核对世界状态真的变了。
- **工程规矩**：`engine/` 下不许出现 `Math.random`（CI 用搜索查），世界的每一次随机都出自 `seedOf(世界种子, 第几日, 用途, 谁)`。

一天怎么走（`tickWorld`，跨过一个江湖日就跑一次，静修十日就跑十次）：
1. **慢变**：势力的据点养人，实力慢慢回到本来；治安、物价慢慢回常；伤好了，牢坐满了；痕迹到期擦掉。
2. **在走的局**：到日子的推一段，写状态、写痕迹、生传闻（在场的人就是目击者）。
3. **导演**：在走的大事不够就挑一件起头；够了就看分数掷骰；什么都不急，就起一桩街坊小事垫底。
4. **传话**：白天、夜里两个时段，同处一地的人互相说；帮里的人夜里互通；说书人在酒楼说给满座；叫化子什么都往分舵报；不耸动的事十来日就忘。

### 3.3 人物层：轻量的「人」

**不是每个人都要活。** 开店的、物件、背景人不写；一城挑二三十个「有事的人」写一个 `life` 块。原型用了 16 个人就跑出了因果；要把同时在走的事撑到两三件，扬州要三十个上下（见 5.4）。

**此刻在哪**（改 `world.ts` 的 `present`）：事件打断（`at`）＞ 处境（坐牢在府衙大牢，伤了在家，走了、死了哪儿都没有）＞ 作息（`NpcDef.at`）。人不在常待的地方，地点描写底下由引擎补一句交代（「济生堂掌柜挨了打，在家养伤，铺子上了一半门板」），这正是 `huojianghu.md` 第三节第二条要的，原来要作者一处处写。

### 3.4 信息层：传闻

**一件事的一段，生一条传闻。** 文字不进存档：传闻只记（哪件事、哪一段、哪日、在哪、多耸动、牵涉谁），说的时候按模板现拼，所以存档小（原型六十日后精简存法 7.7 KB）。

```ts
export interface RumorInst {
  id: string;
  /** 出自哪件事、哪一段：文字从模板里取 */
  ev: string;
  ph: number;
  day: number;
  place: string;
  /** 多耸动（0–1）：越耸动传得越快、记得越久。火并 0.85，街坊小事 0.3 */
  juice: number;
  /** 牵涉的人、势力：说话的人就是其中之一时，用他自己的说法（「我」） */
  subj: string[];
  /** 机密：只在这几股势力里传，每传一手有两成半走漏 */
  secret?: string[];
  /** 外地的事：只有跑码头的（船夫、镖师、外乡人）带得进来 */
  far?: true;
  /** 说的是你 */
  about?: 'you';
}
```

**传播**（原型 `spread()`，一日两个时段）：
- **同处**：同一时段在同一处的人，嘴碎的把自己知道的最耸动的一两件说给旁人；几率 = 嘴碎 ×（0.35 + 耸动 × 0.6）；每传一手有 22% 走一档样。
- **人脉**：帮里的人夜里互通，牵涉本帮的事帮内都知道；叫化子什么都往分舵报（丐帮的立身之道「打探」，`lizu.md`，就这么落地）。
- **枢纽**：说书人夜里在酒楼，把最耸动的一件说给满座的人（一半走样）。茶馆、码头、府衙是天然的枢纽。
- **忘**：过了 8 + 耸动 × 30 日就忘。所以老事会淡，大事记得久。
- **走样三档**：原样（「焦五带西舵的人占了码头北头」）、走了样（「渡口来了一伙生面孔，怕是要出事」）、面目全非（「听说有人要在渡口放火烧船」）。作者写三种说法，引擎挑。

**打听 = 问这个人知道什么**（原型 `ask()`，替换 `dating()`/`hearsay()`）：
1. 从他知道的事里，挑**你还不知道的**（或者你知道的版本更走样的）；
2. 按耸动、离他近（事发在他常待的地方 +0.4，牵涉他的帮 +0.4）、新鲜（每过一日 −0.03）排；外地事 −0.3；
3. 用他的声口开口：`{名}{开口前的样子}，道：「{说法}」`（文风第一条：先写说话人，再用「道」）；他就是当事人，就用「我」；说到自家吃亏的，替自家找补一句（立场）；
4. 是听来的，就带一句「（听说书的张瞎子说的）」，玩家就知道顺着去问谁；
5. 什么都没有，说他自己的日子：`voice.idle` 按世界状态挑（船夫说船钱，掌柜说药价，脚夫说有没有活）。**同一个人，隔几日问，话跟着世界变。**
6. 关系管说多少：素不相识的只说传开了的事；相谈甚欢以上，机密也说；请一顿酒、给几个钱，多说一件（代价）。
7. 一人一日问一回（现规矩不变）。

**`NEWS` 池怎么办**：216 条不删，分三类：说到扬州具体人事的，改写成那件事的传闻，挂到知情人身上；外地的事，标 `far`，只交给跑码头的人；写了旗标条件、说玩家事迹的，改成玩家行动生出的传闻。`NewsDef` 加 `who?: string[]`（行当或势力）、`far?: true`，CI 查：没标的不许进池。效果 `{ type: 'news' }` 废弃。

**玩家也是传闻的主角**：玩家每一件耸动的事（打赢焦五、放走钱三、在府衙门口拔刀），由效果 `rumor` 生一条传闻，在场的都是目击者。**名声 = 多少人知道关于你的事**（`w.you.fame`，按地区算）；名号从知道的人最多、最耸动的那条里长出来（「渡口一剑」），地基第四条「名声靠人传」「名号从传言里长出来」就这么落地。官府的追缉也只从目击者、告状的人那里来：你在暗巷里做的事，没人看见就没人知道（原型里「告状」这一模板就是这条路）。

### 3.5 导演（说书人）

**它的职责只有五条：**

1. **读局势**：每个模板写「什么样的世界适合发生我」，导演每日扫一遍，拿到一串候选，每个带分数和起因。
2. **选真人真地**：模板的角色从世界里挑（最强的帮、最窘迫的人、刚丢了码头的那一边），同一个人不同时卷进两件局。
3. **排节奏**：一城同时在走的大事保持在两到四件；少于两件就一定起一件，空着时一日可起两件；多了就不起；同一个模板隔五日、同一班人隔二十日才再起（原型测过的取舍见 5.4）；什么都不急，就起一桩街坊小事垫底，让街上有人在过日子。
4. **保证有下文**：每个结局必须留一处痕迹、一条传闻，大的还要留「后手」（下一件局的种子）：丢了码头的会记仇，被抓的人家里有病人，赢了的帮会伸手。原型里六成的事是前一件事引出来的。
5. **写大事记**：每一段一句，邸报、见闻簿、说书都读它。

**几条硬规矩：**
- **生成的「势」不等人，手写的「本」照旧等你听说**（见第六节问题一）。
- **远近有别**（性能，也是叙事）：玩家所在的地区和相邻的地区全模拟；远处的地区只做「慢变」，每七日由导演挑一件大事粗跑一遍，结果写进那里的大事记，玩家到了才看到痕迹、问到缘故。
- **下线时走慢一半**（`paiban.md` G24 已定）：静修十日，导演按五日的节奏起事。
- **出关保底**：出关时，玩家所在地区若没有一处看得见的变化，导演当场挑一件已经了结、玩家还不知道的事，让它的痕迹留到玩家回去。邸报里**只写玩家能知道的**：他在场的地区里传开的、认识的人（相谈甚欢以上）托人带的话、说到他的；不再从池子里抽（K9）。
- **玩家插手优先**：玩家正在插手的局，导演不让它被别的局打断（卷进去的人不被别的局挑走）。

**和现有系统**：
- `ShiDef` 留着，作为「本」：固定角色、固定步骤的手写局。导演可以给「本」排期（加 `when`，世界到了这个样子才起头），但不改它的步骤。现有十四件里，码头、闹贼两件改写成模板，做示范；海捕文书一系列（`wanted()`）改写成「缉凶」模板，人犯从外乡人池里挑。
- 路遇（`encounter.ts`）：几率不再只看路程，乘上这段路的治安（治安 20 的官道翻倍，80 的减半）；正在官道上走的「劫道」局，本身就是一种路遇。
- 见闻簿：「江湖上的事」显示玩家知道的局，写到他知道的那一段，下面一行小字写起因（「听说是因为药价涨了」），起因也是玩家能知道的才写。

### 3.6 事件模板：协作者写得了、机器验得了的格式

```ts
export interface EventTpl {
  id: string;
  name: string;
  /** 局：几日、有结局、留后手；小事：一句话的场面，一日了结（导演垫底用） */
  kind: '局' | '小事';
  region?: string[];
  /** 角色：从世界里挑真人真地 */
  roles: Record<string, RoleSpec>;
  /** 显著性：每一项成立就加分；分最高的那一项是「起因」，写进大事记和见闻簿 */
  when: { if: Cond; score: number; why: string }[];
  /** 合计至少多少分才起 */
  min?: number;
  cool?: { tpl?: number; cast?: number };
  phases: PhaseTpl[];
  /** 没人插手时，结局怎样判：按两边实力、按几率、按某个角色的处境 */
  resolve: ResolveRule;
  endings: Record<string, EndingTpl>;
}
export interface RoleSpec {
  kind: 'faction' | 'person' | 'place';
  /** 角色的条件。人物角色可以写行当、性情、帮派、处境、所求；地方角色写 tags */
  if?: { trade?: string[]; traits?: string[]; notTraits?: string[]; faction?: string | '无'; tags?: string[]; st?: string[]; need?: { atLeast: number }; owner?: string; w?: Cond['w'] };
  /** 有几个合格的时挑谁 */
  pick?: 'strongest' | 'weakest' | 'neediest' | 'random';
  /** 和哪几个角色不能是同一个 */
  not?: string[];
}
export interface PhaseTpl {
  id: string;
  /** 这一段走几日（取区间里的一个数） */
  days: [number, number];
  /** 谁在哪：'@place' 是地方角色；这几日他就在那里（玩家去了就碰得上） */
  stage?: { role: string; at: string; slot?: 'day' | 'night' }[];
  do?: Effect[];
  mark?: { at: string; k: string; text: string[]; days: number };
  /** 传开的话：三档说法各写两三种；self 是当事人自己的说法 */
  rumor?: { juice: number; text: [string[], string[], string[]]; self?: Record<string, string[]>; secret?: string[]; witness?: ('在场' | '更夫' | string)[] };
  /** 玩家插手：挂在某个角色身上的动作，和现有 verbs/actions 是同一套 */
  hooks?: { on: string; verb: string; if?: Cond; text: string[]; do: Effect[] }[];
}
export interface ResolveRule {
  by: 'power' | 'chance' | 'role';
  /** 按实力：a 赢的几率 = 1 / (1 + e^(−(实力a − 实力b + 加减) / k)) */
  a?: string; b?: string; k?: number;
  /** 加减：玩家帮了谁、更夫看没看清、风声漏没漏 */
  mods?: { if: Cond; side: string; amt: number }[];
  /** 判出的结局 id：a 赢、b 赢 */
  win?: string; lose?: string;
}
export interface EndingTpl {
  do?: Effect[];
  mark?: PhaseTpl['mark'];
  rumor?: PhaseTpl['rumor'];
  /** 后手：了结以后，过几日、几成机会起哪一件局，谁接着当哪个角色 */
  after?: { tpl: string; cast: Record<string, string>; inDays: [number, number]; p: number }[];
}
```

**机器校验**（`tests/content.test.ts` 新增「模板」一节，协作者交活前自查）：
- 每个角色有人选得上（在开局的扬州里至少有一个合格的）；每个 `$角色` 都定义过；`{占位}` 都填得上；
- 每一段的传闻三档都写了、每档至少两种说法；每个结局都改了至少一个世界状态、留了一处痕迹、生了一条传闻；
- 每种插手都推得到一个结局或改了一边的力；机器玩家每种插手各走一遍，核对世界真的变了；
- 文风规则（`tests/style-rules.ts`）照样查填好角色以后的文字；占位后面不许接死数（「赏钱五百文」写 `{shang}`，数由状态算）；
- 不变式：不会武的（没帮派、性情里没有「狠」）不去堵人；死了的人不当角色；一个人不同时在两件局里。原型里就出过「济生堂掌柜去堵老管事」这种怪事，加了这条角色约束才没了，所以它必须写成 CI。

**谁写什么**：模板的**骨架和第一种说法**由维护者写（用 opus，金庸文字把关），后面的说法、声口、闲话、小事交给协作者写，机器先审，每日一审再审。

### 3.7 玩家的后果：做了事，世界怎样回来

```
玩家的动作 ─→ 谁看见了（在场的人 + 痕迹）─→ 传闻（会传、会走样）
          └─→ 状态（势力的实力、地方的主人、某人的处境）
传闻 ──→ 各帮对你的账（w.fac.you）、官府的追缉（heat）、人对你的好恶（rel.you）、你的名头（fame）
这些 ──→ 回过头改世界怎样待你：
   · 价钱：西舵记你的仇，过渡口多收你一倍；东舵当你是自己人，不收
   · 门：盐号的账房见了你就关门；丐帮的人肯替你盯梢
   · 局：寻仇的局把你当「x」角色挑（焦五来堵你）；官府清剿的局把你当目标（海捕文书上是你的画像）
   · 差事：悬赏榜上的榜从局里来（东关街闹贼，府衙贴告示，你才揭得到）
```

**通缉（GTA 的星）**：只有官府、门派有 `heat`。零：没事。一：盘问（进城门、府衙一带，捕快拦你问话，要么说得过去，要么花钱）。二：海捕（照壁上贴你的画像，赏金猎人的路遇会来）。三：围拿（城里白天走动，捕快带官兵来拿，打得过可以跑，打不过就进大牢）。**消法**：躲出去（每七日降一档），花钱打点（按档次，贵），投案（坐几日牢），立功（替官府拿了别人）。原来的恶名不删，变成「江湖上对你的总印象」，由各帮的账汇总算出来。

**动手、偷窃对谁都能做**（`huojianghu.md` 第三节第三条，这里给出统一的规矩）：
- 动手：看人家的档次（`person.ts`），打赢了照常处置（放、送官、杀），在场的人都是目击者；苦主的帮记账，至亲（`rel ≥ 60`）记仇，可能起「寻仇」。杀人另记一笔「人命」（`paiban.md` B34 已定的分量表）。
- 偷窃：看身法和对方的眼力；得手了这人窘迫加深；失手了，在场的人都看见。
- 看得出人家不会答应、不能动手的，按钮灰着，写一句缘故（老玩家痛点 8）。

### 3.8 玩家的自发循环：想干什么、为什么

挑三个，**全都由世界喂料、反过来改世界**；别的推后。

| 循环 | 玩家想什么 | 世界喂他什么 | 他做了，世界变什么 | 接上的现有系统 |
|---|---|---|---|---|
| **立身**（钱和地位） | 「我要活下去、要买那口好刀、要在本行里升上去」 | 差事从局里长出来：闹贼 → 府衙悬赏；劫道 → 镖局多一趟护送、价钱随治安涨；码头换主 → 东舵请人护船 | 拿了贼，东关街治安回升；护镖成了，官道上客商多了，物价回落 | 身份、`JobDef`、嚼用 |
| **恩怨**（人和人） | 「焦五打伤了大牛，大牛是我朋友」「他害过我，我要他还」 | 人记得你，仇家找上门（寻仇局把你当角色）；被你放走的人还你一回人情 | 两帮对你的账变了，门开了或关了；仇解了或结深了 | 关系阶梯、胜负以后的处置、约与心魔 |
| **扬名**（名头） | 「我要江湖上都知道我」 | 说书人编你的段子；名号从传闻里长出来；有人慕名来挑战 | 名头高了，乌合之众闻名而逃（地基 C4），东家给的价码高了，也招仇家 | 侠义、说书、江湖谱（推后） |

**这三个为什么够**：立身是手机上「每次上线做一件」的骨架（地基第十条）；恩怨是武侠的魂，也是 Nemesis 那种「这个敌人是我的」的感觉；扬名是 GTA 的星的反面，让好人路线也有看得见的奖励。三者互相咬：扬名招来恩怨，恩怨影响立身的门路。
**推后**：立帮、收徒、置业、家将、婚嫁。它们都是「玩家自己的一股势力」，等势力这一层跑稳了，是顺手的事（问题四）。寻亲（主线身世）照旧是手写的「本」。

**三十分钟的一个样子**（原型种子 1，第 31 日玩家出关）：
- 出关邸报：「你闭关这些日子：渡口火并，码头归了西舵，过船二十文（老船夫说的）。东关街的铺子都在交份子钱，药价跟着涨了。官道上有客商叫人劫了。」
- 去渡口：真的交了二十文；脚夫大牛不在，「在家养伤」；问老船夫，他说的是火并和船钱。
- 去东关街：铺子门口钉着木牌；问济生堂掌柜，他说「我到府衙击鼓，告了西舵的焦五一状」；阿七在街上跑腿（他娘的药钱又涨了；这个江湖里，他第三十六日就会去偷）。
- 玩家起意：帮东舵夺回码头（打焦五），或者把掌柜知道的事递给周捕头、让下一回清剿别再扑空，或者赶在阿七动手以前替他娘抓几副药。三条路都是世界当场长出来的，没有一条是任务簿派的。
- 做了以后：说书人当夜就在望江楼说你的事，七日后半城人知道；西舵记你的仇，下回过渡口要你双份船钱，一个月后焦五出了牢来堵你。

### 3.9 守不守原则

| 原则 | 怎样守 |
|---|---|
| 活 | 世界有状态、有人、有传闻、有导演；不插手的事也有下文，而且每回不同 |
| 自由 | 不指路：局只有「你知道」才进见闻簿；插手的路挂在真人身上，按钮看得见、点得到 |
| 有条件、有代价 | 打听要关系、要钱；插手就结账（这边恩，那边怨）；通缉、仇家、物价都是代价；名头也招祸 |
| 金庸 | 文字由作者写，模板只填人名地名；三档说法、立场、自称让话有人味；CI 查文风 |
| 手机 | 痕迹每地最多两条，写在描写底下；邸报「你不在时」最多五条；数不进人物的嘴（文风第四条），船钱、药价只在按钮和账上 |
| 存档 | 第五版只加 `w`；迁移由旗标推出世界（见 4.1）；样本进 `tests/fixtures/saves/` |
| 确定性 | 世界的随机全出自 `seedOf(w.seed, 日, 用途, 谁)`；`tickWorld` 只在跨日时跑，跑多少次结果一样；玩家的动作是输入，同样的输入出同样的江湖 |
| 性能 | 原型 16 人 9 个模板一日 0.3–0.4 毫秒（Node）；四城、每城三十人、远处粗跑，估一日 2–3 毫秒；下线十六日补跑约 50 毫秒，手机上按五倍算也不到三分之一秒 |

**原则**：每一片都能合并、测试全绿、玩家当场看得出变化；先在扬州做透，再铺开；不搭空框架。每一片标「绿档 / 黄档 / 红档」（`decisions.md` 10-09 的合并规则）。

### 第一片：「扬州的人说自己知道的事，码头的主人是真的」（黄档，存档第五版）

**做什么**（没有导演、没有模板，只把现有的扬州接上状态和传闻）：
1. **世界状态的最小一层**：扬州六股势力（东舵、西舵、府衙、汪家盐号、丐帮分舵、黑风寨残部）；十处地方的 `life`（治安、繁荣、物价、主人、船钱表）；痕迹通道进 `roomDesc`（描写底下最多两行）。
2. **人的最小一层**：扬州二十个「有事的人」写 `life`（行当、性情、嘴碎、声口、闲话）；`PersonState` 只先做处境（伤、牢、走）和知道的传闻。
3. **传闻**：现有扬州五件世事的每一步，从 `news` 生一条传闻实例（目击者 = 此刻在 `where` 的人 + 那一带的枢纽），之后沿同处、帮内、说书人传；打听改成 `ask()`；`NEWS` 标 `who`/`far`，外地的事只给跑码头的人。

5. **邸报不再从池子里抽**：只写玩家能知道的（K9）。
6. **随机归种子**：`hearsay`、`dating` 的 `pick` 换成种子随机；CI 查 `engine/` 下没有 `Math.random`。

### 5.4 原型没证明的，和它暴露的问题

1. **密度被人数卡住**。同时在走的大事平均只有 1.3 件，低于目标的两到四件。我试了导演冷却的四种取舍：

| 同模板冷却 / 同一班人冷却 | 同时在走的大事 | 两个江湖重合 | 六十日里同一模板同一班人重演 |
|---|---|---|---|
| 8 日 / 30 日 | 1.06 | 0.48 | 33% |
| **5 日 / 20 日（选定）** | 1.28 | 0.51 | 38% |
| 3 日 / 12 日 | 1.48 | 0.49 | 46% |
| 2 日 / 6 日 | 1.74 | 0.50 | 56% |

   调松冷却，事多了，重演也多了（焦五和老管事来回争四回码头）。**密度只能来自更多的人和模板，不能靠导演催。** 估一城要三十个上下有事的人、十五个上下的模板，第二片验这个估计。
2. **垫底小事会重复**。六桩小事、六日冷却，「入了梅，济生堂掌柜晒药材」三十日里出现三回。上线前每城要二十桩以上、按节令挑（梅雨、鲥鱼汛、端午），一次上线里不许重复。
3. **怪事**。早一版里「济生堂掌柜去堵老管事」：不会武的人去寻仇。加了角色约束（没帮派、不狠的人只告状）才没了。所以角色约束必须进 CI。
4. **文字是平的**。原型的说法是我按金庸口吻写的骨架，一种说法用到底；真做时每档两三种、当事人另有说法，且要金庸编辑审。原型证明的是**因果和差异**，不是文字。
5. **没做玩家插手**。插手（助拳、调停、告官）在模板里只留了口子（`help` 加力），原型里的玩家只看、只问。第二片由机器玩家把每种插手走一遍。
6. **没做远处地区、没做邸报**。

## 6. 要负责人拍板的六件事

**问题一：生成的事不等人，手写的事照旧等你？**
- A（推荐）：导演生的「局」不等人，错过了有下文、有痕迹、问得到；手写的「本」（主线、现有世事里的大事）照旧「没听说就停在起头」。理由：手写的贵，错过是浪费；生成的不贵，错过就是江湖本来的样子，而且它会长出下一件事。
- B：全都等人（世界只在玩家到场的地区走）。安全，但扬州以外永远是死的。
- C：全都不等。手写的大事也会被错过。

**问题二：每个玩家一个江湖，还是大家一个江湖？**（决定了以后异步多人怎么做）
- A（推荐）：每个玩家一个江湖（开局的种子不同，之后各自分岔）；别的玩家的事迹以「外地传闻」进你的江湖、上江湖谱。免费后台做得到，单机也完整。
- B：全服一个江湖，世界在服务器上跑，大家改的是同一个扬州。最像 MMO，可是后台必须免费（`decisions.md`）、手机要能离线，做不到。

**问题三：犯了事，代价做到多重？**
- A：只记账：恶名、各帮的恩怨、涨价、不让进门、仇家。
- B（推荐）：再加官府追缉（零到三档：盘问、海捕、围拿），打不过会被拿进大牢；坐牢做成一段玩法（托人、花钱、越狱、在牢里认识人），不是罚站。理由：GTA 的自由来自「做什么都行，但世界有统一的反应」，没有追缉，坏人路线就是假的。
- C：再加上「被废武功」这一级。太狠，不推荐。

**问题四：玩家自己的一股势力（立帮、收徒、置业、家将）进不进上线版？**
- A（推荐）：上线版只做人情网：结交的人替你打听、替你说话、替你办一件事（各有代价），立帮收徒推到上线以后。理由：先让别人的势力活起来，玩家的势力才有对手、有意思。
- B：上线版就做立帮，玩家的帮也是一股势力，能争码头。量大，会把第五片以后的工作量翻倍。

**问题五：内容的写法从「一件件世事」改成「人、模板、小事」？**
- A（推荐）：改。以后派给协作者的是：一城的势力和二三十个人的 `life`、模板的说法变体、街坊小事。现有十四件世事保留为「本」，码头、闹贼、海捕文书三件改写成模板做示范。这会改 `huojianghu.md` 第四节「先写世事，再写人」，所以要你点头。
- B：两种并行，协作者照旧写世事，维护者另做模板。省事，但两套东西会越走越远。

**问题六：开局的扬州每局都一样吗？**
- A（推荐）：开局一样（屠千山刚倒，码头空着，周捕头当捕头），之后按种子分岔。开篇的剧情要靠固定的开局。
- B：开局就随机（谁占码头、谁当捕头都不定）。重玩价值高，但开篇剧情要为每种开局各写一套。

## 8. 我按原则自己定了的事

| 定了什么 | 依据 |
|---|---|
| 一城同时两到四件大事；少于两件必起；垫底小事不计 | 活、手机（一次上线有事可遇，又不吵） |
| 冷却：同模板五日、同一班人二十日 | 原型取舍表；再紧重演过半 |
| 传闻三档走样，每传一手两成二走一档；忘的日子 = 8 + 耸动 × 30 | 活（传言会走样、会淡）；原型验过 |
| 外地的事只从船夫、镖师、外乡人嘴里出来 | 活（话有来处）；金庸（一地有一地的声音，文风第十二条） |
| 打听仍是一人一日一回；关系管说多少；请酒、给钱多说一件 | 代价 |
| 数不进人物的嘴：治安、实力、好恶不显示；船钱、药价只在按钮和账上 | 文风第四条；手机 |
| 痕迹每地最多两行；邸报「你不在时」最多五条 | 手机（不挤） |
| 物价封顶 50 到 200 | 代价有，但不失控（经济模拟 M1–M5 要用新物价重跑） |
| 有事的人一城二三十个，开店的、背景人不写 `life` | 手机性能；场景不挤（一处最多五人照旧） |
| 不会武的人不去堵人，只告状；角色约束进 CI | 金庸（人要像人）；原型的教训 |
| 下线时导演按半速起事 | `paiban.md` G24 已定 |
| 远处地区每七日粗跑一件大事 | 性能；活（远处也在变，到了看得见） |
| 世界的随机全出自种子，引擎里禁 `Math.random` | 确定性（测试靠种子重放） |

## 附：参考了谁，取了什么

| 参考 | 取其神 | 不照搬的 |
|---|---|---|
| 十字军之王（Crusader Kings） | 事件 = 条件 + 从世界里挑角色；人物有性情、好恶；一件事的后果改关系，关系生出下一件事 | 不做全天下每个人的谱系和继承 |

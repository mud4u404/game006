# 开发全景图

从现在到「武侠 MUD 里的 GTA」完整版的开发顺序。每个阶段都写明维护者做什么、协作者批量做什么、怎样算验收。原则见 `docs/charter.md`，已定的事见 `docs/decisions.md`。

## 排序的三条依据

1. **先建会影响全局的规则，再铺内容。**
   - 养成节奏（P7）决定了武功、神兵怎样获得。
   - 探险解谜（P8）决定了它们藏在哪里、怎么拿到。

   这两套规则没定，大量内容写出来以后都要返工。
2. **质量体系越早建越便宜。** 宪章、试玩员、回归测试要先于大规模开发。
3. **单机核心先跑通，再做多人。** 存档格式稳定以后再上云，免得反复迁移。

# 武功搭配、纸娃娃与道具（设计卡）

负责人的反馈：

> 武功系统，是不是应该能够自由装备武功呢？武功还分主副手？这个有点不合理了吧，除非左右互搏。
> 道具系统也是一样，似乎互动有问题，最好能开发个纸娃娃系统。

## 一、为什么要改

- **主手、副手不合理**：武侠里，一个人同一时间只使一门外功。双手各使一门，是周伯通「左右互搏」那样的奇功，不是人人都会。
- **武功要能自由装备**：现在学会武功以后自动放进槽位，玩家自己换不了。
- **兵刃武功要有兵器**：剑法要拿着剑才使得出来，现在不讲这个。
- **道具许诺的动作做不到**：
  - 杏花写着「可以送人」，花雕写着「自己喝也好，请人喝也好」，黑风断首刀写着「能卖个好价钱」，可这些动作都不存在；
  - 身上的青锋剑是页面上写死的一行字，不是真正的装备。
  - 这违反宪章：说了能做的事，就要做得到。

## 二、武功搭配：五个位置

| 位置 | 放什么 | 见招拆招里负责 |
|---|---|---|
| 内功 | 内功 | 硬接 |
| 轻功 | 轻功 | 闪避 |
| 拳脚 | 拳法、掌法、指法、爪法、腿法、手法 | 空手时的拆招、抢攻 |
| 兵刃 | 剑法、刀法、枪法、棍法、杖法、鞭法、斧法、锤法、奇门 | 手里有对得上的兵器时的拆招、抢攻 |
| 绝技 | 绝技 | 怒气满时的杀招 |

- **出手用哪一门**：手里拿着兵器、兵刃位的武功又和兵器对得上（剑法配剑，刀法配刀……），就用兵刃位的武功；否则用拳脚位的武功。
- **缴械**：兵器脱手，改用拳脚位的武功，直到兵器拿回来。这比「伤害打六折」更有画面，也让拳脚有用武之地。
- **左右互搏**：奇遇得来的杂学，门槛极高（悟性要高，还要心无旁骛）。学会以后，拳脚和兵刃同时出手：
  - 两门武功的绝招都能用；
  - 抢攻改由另一只手的武功负责。
- **自由装备**：
  - 武功页上方是「搭配」，五个位置一字排开；点一个位置，列出能放进去的武功，以及换上以后各项成算的变化。
  - 战斗中不能换。
  - 学会新武功时，对应的位置空着才自动放进去。
- **内功为根照旧**（`docs/menpai.md` 第七节）：外功的绝招要用本门内功来使。

**旧存档迁移**（存档版本 2 → 3，不丢任何进度）：
- 原来主手、副手里的武功，按门类分进拳脚位或兵刃位。两门同类时，主手那门留下，另一门照样学会，只是不在位置上。
- 原来的寒江剑法（主手）加惊鸿剑（副手）：寒江剑法放进兵刃位，惊鸿剑留在武功页，随时可以换上。
- 青锋剑变成真正的兵器，放进背包，并装备在身上。
- 迁移前后，见招拆招里硬接、闪避、拆招三项的成算不变；抢攻改由出手的那门武功负责。fixtures 加一份测试存档。

## 三、纸娃娃：六个装备位

人物页最上方是一个水墨人形，六个装备位绕在四周，空位写「空」。点一个位置，列出背包里能放进去的东西；点一件装备，看它的说明，可以卸下。

| 装备位 | 放什么 | 主要作用 |
|---|---|---|
| 兵器 | 剑、刀、枪、棍、杖、鞭、斧、锤、奇门兵器 | 决定兵刃武功能不能用；伤害加成；长短（一寸长一寸强） |
| 冠 | 斗笠、头巾、发冠 | 少量护体或身法 |
| 衣 | 布衣、皮甲、软猬甲 | 护体 |
| 靴 | 布鞋、快靴 | 身法 |
| 佩 | 玉佩、香囊、腰牌 | 内力、属性，有的带身份（例如六扇门腰牌） |
| 饰 | 指环、手镯、护腕 | 属性，或者一点特效 |

- 装备分品级（凡品到神品），数值有上限，由测试校验，和武功一样不许顶格。
- 装备的数值，比同级的武功小得多：**武功是根本，装备锦上添花**。一件神兵不能让三流高手打赢一流高手。
- 兵器的类型、长短，接进见招拆招的长短克制（`docs/wuxue.md` 第三节）。
- 信物类的佩饰（例如主角的半块玉佩）可以戴，但没有数值，只有剧情作用。

## 四、道具：分类与动作

| 类 | 例子 | 能做什么 |
|---|---|---|
| 药 | 金疮药 | 服用（战斗中也能） |
| 酒食 | 花雕 | 饮用（回一点内力，壮胆）；请人喝（算赠礼） |
| 装备 | 青锋剑、黑风断首刀 | 装备、卸下；典当 |
| 信物、线索 | 半块玉佩、断水残页、铜牌 | 细看（文字可以随剧情变化）；不能卖、不能丢 |
| 杂物 | 杏花、飞蝗石 | 赠人；飞蝗石在战斗中打出 |

- **赠礼**：点人物的「赠礼」，从背包里挑一件送。人物可以写「喜欢什么」（`likes`），送对了关系升得快，送错了只是客气收下。
- **典当、售卖**：当铺、杂货铺这类人物有「典当」动作，按道具的价钱收；信物、线索不收。
- **细看**：每件道具都能点开看说明；线索类可以随剧情写不同的文字（和人物的「观察」一样带条件）。
- **规矩**：道具的说明里写了能做什么，就必须真能做到。内容校验检查这一条，例如说明里写「可以送人」，就要能赠礼。

## 五、数据格式（维护者实现）

- `ItemDef` 新增：
  - `kind`：药、酒食、装备、信物、杂物；
  - `use?: Effect[]`：服用、饮用的效果；
  - `equip?: { slot, weapon?, reach?, stats }`：装备位、兵器类型、长短、数值；
  - `price?`：典当价，单位文；
  - `look?: Branch[]`：细看时随条件变化的文字。
- `NpcDef` 新增 `likes?: string[]`：喜欢的道具。
- `GameState` 新增 `gear`：装备位到道具 id 的对应。搭配槽位改为 `neigong`、`qinggong`、`fist`、`weapon`、`ult`，存档版本升到 3，附迁移和测试存档。

## 六、实施顺序

1. **时间看得见**（已做）：每个动作都花时间，交谈十分钟、请教半个时辰；顶栏显示到「刻」；天色转换时记一句见闻。
2. **武功五位**（已做，10-08）：槽位、迁移、搭配界面、见招拆招、战斗按钮。左右互搏留到奇遇内容里做。
3. **道具与纸娃娃**：引擎、界面、迁移由维护者做；装备和道具的内容（兵器谱、衣饰、各地商铺）拆成任务交给协作者。

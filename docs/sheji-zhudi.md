# 门派驻地：师门不再是地图上一个点

## 为什么

真实玩家 10-10：「这个师门、丐帮啥的，能不能有个总部啥的，带点功能，比如练功桩啥的。感觉就一个小点，有点寒酸。」

现状：门派在地图上一个点、一个师父。拜了师以后，除了「请教」「考校」「讨差事」，师门没有别的用处，也没有别的人，归属感出不来。原有的「住处三选一」里的「回师门住」只省一百文店钱，玩家几乎感觉不到（`src/engine/shiguang.ts` 的 `zhuOf`）。

依据的原则：
- **活的江湖**：入了门要有个落脚的地方，那里有人、有事、有日子。
- **有条件有代价**：驻地的好处只给门人；好处里带着规矩和负担。
- **变强的速度受限**（宪章 P7）：练功桩只让门人练得更划算，不突破每日修为的额度（`allowance`）。

## 每派一张自己的小地图（负责人 10-10：「每个门派需要有个单独的地图，我昨天也说过的」）

照 `docs/design.md` 的四层地图（天下 → 道 → 地点 → 场景）：门派是一个**地点**，下面挂自己的几处**场景**。
- 数据上：驻地各处是 `RoomDef`，`area` 写成「扬州 · 丐帮总舵」这样的地点名，`exits` 彼此相连，只从城里一处入口进出（例：丐帮总舵从扬州城外的破庙进，六扇门校场从府衙后门进）。
- 界面上：地图页**进了这个地点，就只画这个地点的小地图**（几处场景按 `map` 坐标排开，像北大侠客行里的门派地图），出去再回到城里的大图。现在的地图页按道画全图，门派只是其中一个点，这正是玩家说的「一个小点、寒酸」。
- 参考：北大侠客行等武侠 MUD 的门派布局（山门、正厅、练功房、木人巷、梅花桩、厨房、休息室、藏经阁），研究笔记见 `docs/zhishiku/mud-xiakexing.md`。

## 驻地有什么（每派三到五处，样板派先做丐帮、六扇门）

| 处 | 有什么 | 用处 | 门外的人 |
|---|---|---|---|
| 正堂 / 总舵 | 师父或长老 | 拜师、考校、请教（原有） | 照旧能进 |
| 练功场 | 练功桩、木人、沙袋（各派各样：丐帮在破庙后院打桩，六扇门在衙门校场射箭、使铁尺） | **练桩**（见下） | 看得见，用不了（「这是本帮兄弟练手的地方」） |
| 住处 | 通铺、伙房 | 回师门住：不花店钱；**闭关打坐加一成**（客栈一成不加，露宿打八折） | 进不去 |
| 执事处 | 管事的门人（一位，有声口） | 讨差事（原有的师门差事）、打听本门消息、领本门的规矩 | 不理 |
| 门人二三 | 同门师兄弟（有作息、有声口） | 交谈、切磋（打赢涨熟练、打输掉体力）；会说本门近来出了什么事 | 一般的路人 |

## 练桩（新动作）

- **谁能用**：本门门人，人在练功场。
- **一回**：两个时辰，每天一回（`again` 一日）。
- **得什么**：拿历练换本门武功的熟练度，比自己静修**划算两成**（换算率 ×1.2）。只算进当日修为额度之内的部分；额度用完了，桩照打，只养筋骨不长功夫。结算时照 `TIELV_TEXT` 的说法写明。
- **代价**：时辰；体力降一些；历练照扣（只是换得多一点）。
- **玩家看得见的**：结算写清这一回练了哪门、熟练长了多少（照现有的突破卡和闭关邸报，不另造界面）。

## 负担（门人要守的）

- 每旬有一回值夜或杂役差事（原有的师门差事框架），长期不应卯，贡献会掉（后做，先记下）。
- 门规照旧：叛出、恶名、命债（`docs/decisions.md`「恶名能洗、命债不能」）。

## 做法与分工

1. **引擎**（一件，给 Codex，排在 #308 之后、#313 之前）：
   - 新效果「练桩」：本门、本处才能做；一日一回；按 `jingxiuPlan` 的换算率 ×1.2，受 `allowance` 限。
   - 驻地「住处」闭关加一成：`zhuOf(s) === 'home'` 时，`jingxiu` 的 `eff` ×1.1。
   - 「门外的人用不了」统一写成条件；补测试。
   - 地图页：人在某个门派地点里时，只画这个地点的小地图（按 `area` 筛场景、按 `map` 坐标排）；出了地点回到大图。
2. **内容**（两件，依赖引擎那件）：
   - 丐帮扬州总舵（Trae：带地方味的场景和路人）；
   - 六扇门校场（Qoder：衙门、兵的声口）。
   - 每件写三到五处、一位执事、两三个门人（有作息、有声口、会说本门近事），练功场的描写和练桩的结算文字。
3. **验收**：机器玩家（`tests/zoubian.test.ts`）走得到每处；新加一个从拜入丐帮到在总舵练一回桩的走通测试；见闻簿记一笔「师门在哪」。
4. 其余各派照样板分批做，排在每日巡视里。

## 采纳的参考（`docs/zhishiku/mud-xiakexing.md`，侠客行系源码研究，10-10）

维护者定，依据「有条件有代价」「变强的速度受限」：
1. **练桩要有门槛、时辰、区间**（侠客行梅花桩）：基本功太低上不了桩（硬上摔一跤、伤体力）；只在白天长功夫，夜里只养筋骨；本门武功不得超过基本功的一倍半。并进 #330。
2. **木人是「你自己的影子」**：练功场的木人照玩家当下的本事拷一份，势均力敌；一日打三到五回就「打坏了，明日再修」；打赢涨熟练（受额度限），打输掉体力。并进 #330（引擎）和各派驻地（换壳：丐帮打狗桩、六扇门铁尺靶）。
3. **执事派差有名额**：每日两三个名额；同一人连着接会被换一桩；当班差事占一个时辰、擅自离岗算失败；可以自愿去（不给钱、涨人缘）；低火候只派跑腿送信。并进各派驻地的执事。
4. **山门「对账」**：回驻地时门口的人看你离开期间恶名、命债变没变，三档口气；作恶的罚几日不能练桩、不能领差（不是死）。另起一件，排在驻地之后。
5. **晋升要过人、有身份物**：外门→内门→真传，除了贡献，还要切磋赢一位同门、一位大师兄，长老问「愿不愿意」；升了加一个看得见的身份物（丐帮加布袋、六扇门换腰牌）；叛出扣回。另起一件，排在驻地之后。

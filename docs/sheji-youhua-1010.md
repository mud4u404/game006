# 已有内容先改好玩：负责人 10-10 七条

负责人 10-10：「你应该先把已有部分优化改良，让它变好玩，再去开发后面的空中楼阁！」随后给了七条，优先做。新系统、新地方、新门派的任务已全部挂「暂缓」（152 件）。

下表是七条各自怎么做、谁做、怎么算做完。「我定了什么」一栏按 `CLAUDE.md` 第二节，依据写在后面。

## 一、剧情和任务都跑得通，每件事都有收场

- **要的**：任何一条剧情、差事、世事，玩家走到哪一步都有路往下走；多结局可以，悬着不行。
- **做法**：
  1. sonnet 先摸底，出一张「悬而未决清单」。机器手段：走遍检查（`tests/zoubian.test.ts`）、线索检查（`tests/xiansuo.test.ts`）。人工手段：逐条读心事、差事、世事的每个阶段，问三个问题：走到这里有没有下一步可做；做砸了有没有退路；结局有没有交代。
  2. 清单每条写成一件「内容·修订」任务派给协作者，按长处分。
  3. 新增一条机器检查「每件心事、差事都有收场」：每个阶段至少一条出路（下一步、失败收场或放弃），收场写进见闻簿。进 CI，存量登记、只许减。
- **验收**：清单清零；新检查进 CI。

## 二、地图当主力，主界面不再重复列去处

- **要的**：负责人说常用右下角的地图，主界面的「去处」和它重复，切来切去麻烦；地图画得潦草。
- **我定了**：地图页成为主要的走法。主界面的「去处」一节缩成一行，只留「主线要去的那一处」和一个「打开地图」按钮，其余去处都到地图上点。地图上点一个地点，直接显示那里有什么人、什么事、要走多久，再点「去」就赶路，不用先切回主界面。依据：手机上好用，少一次切换。
- **地图画得精致些**：
  - 地点用有层次的圆点加名字，主线目标、有事的地点、去过的地点各有标记；
  - 路线画成水路、陆路两种线；
  - 当前所在处加一圈高亮；
  - 按 `docs/design.md` 的四层地图，在城里看到的是城内小图；
  - 配色走现有主题色，深浅两种模式都看得清；
  - 390 宽不横向滚动。
- **谁**：sonnet 一件「主界面与地图改版」，和第三、六条同在一个 PR（都改 `src/ui/views/jianghu.ts`，分开做会互相冲突）。Codex 的驻地 PR #537 也动地图，谁先合，另一个就先合最新 main。

## 三、主界面醒目地展示角色

- **要的**：战力、称号、武学评价一眼可见，有存在感。
- **我定了**：主界面顶上放一张角色卡，每次进主界面都在最上面：
  - **名字和称号**：称号从玩家做过的事来，先用现有的名号（如「渡口一剑」），没有就显示身份（「游侠」「丐帮记名弟子」）；
  - **战力**：一个数字，取自现有战力评估，变了要有提示「战力 812 → 860」；
  - **武学评价**：一句话，如「剑法初成，内功尚浅」，按现有的武功火候生成；
  - **气血、内力、银两**：小字一行。
  依据：玩家合上手机前要知道自己今天变强了没有（北极星的检验标准）。

## 四、地点里场景太多、没有逻辑

- **要的**：地点少了，一个地点里堆了太多场景，毫无逻辑。
- **做法**：sonnet 先出一张表：每个地点有哪些场景，哪些放错了地方（不该在这个地点）、哪些太相似可以并成一处。我按表定调整方案，写成内容任务派给协作者。只改场景的归属和出口，不删内容。
- **原则**：一个地点下的场景要像一条街、一座寺、一个码头那样有顺序，从入口走进去，一处挨一处；每个地点不超过八处。

## 五、NPC 有活人感

- **要的**：主要人物会主动打招呼、引出话题、跟玩家有互动；要适当。
- **我定了**：给人物加「迎面」：玩家走进场景，场景里的主要人物可能先开口。
  - 一句话，带一个可点的话头，比如「了尘抬头：『施主，江老三的事有眉目了？』」，点了就进对应的交谈。
  - **适当**：同一个人一天最多主动一次；同一场景一次只一个人开口；只在有话可说时开口（关系、心事、世事走到某一步、玩家刚做过与他有关的事）。
  - 由谁开口、说什么，写在人物数据里，内容由协作者照声口写。
- **谁**：引擎（迎面的规则、一天一次、和现有交谈接上、测试）交 sonnet；先给十个关键人物写迎面的话，派给协作者（Qoder 写衙门和僧道，Trae 写码头和市井）。

## 六、玩家不知道先做什么

- **要的**：不再漫无目的、沦为街溜子。
- **我定了**：主界面角色卡下面放一条「眼下要紧」，永远只有一件，用动宾句写清楚去哪、找谁、做什么，例如「去运河渡口，会一会屠千山」。
  - 点它，先赶路，到了地方再把要找的人和要做的动作高亮出来；不再只弹一个「就在此处」。
  - 选哪一件：主线有下一步就是主线；主线卡住了（要等、要变强），就显示「为什么卡住」和一件能帮上的事，比如「屠千山刀法老辣，先去闭关练到小成」。
  - 再往下是「也可以」，最多两件：差事、零工、门派差事，只列真正在附近的。
  依据：试玩报告第 3、4 条（首屏三屏长、没有一句先做这个；主线到了地方点不动）。

## 七、战力提升要有渠道

- **要的**：现在变强只有闭关和学艺两条路，还看不见。
- **我定了**，四条路都要看得见、走得通：
  1. **闭关**：按钮上直接写预估，如「闭关一日：剑法熟练 +X，战力约 +Y」；出关写「战力 812 → 860」。
  2. **门派练功**：练桩、木人，在 Codex 的 #330 里，正在做，优先合。
  3. **切磋**：同门、武馆、熟人可以切磋。打赢涨熟练（受每日额度限），打输不伤命。先查现有切磋（`spar`）够不够用，不够只补最小的一块。
  4. **打赢有收获**：战后结算写「历练 355 → 365」，够闭关一日时提示「可去闭关」。
  - 武学页最上面加一块「变强的路」，列出眼下走得通的几条和各自的代价。
- **谁**：闭关预估、战后结算、「变强的路」并进第二、三、六条那件 sonnet 改版；切磋另起一件给 sonnet；#330 让 Codex 先做完。

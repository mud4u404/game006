# 参考笔记：侠客行系和炎黄的随机事件与房间小事

> 三行总结
> 1. 大事钉在**挂历**上，小事钉在**门口**。炎黄全年只有五件日历大事（`adm/daemons/event/` 就五个文件），每件自己排自己的下一场——钱塘潮写成「明年八月十八涨潮，提前一天预告」，触发完再排来年，永不断档；而扬州广场的门口小事是每进一次门掷一次骰，和你的身份、你身上带着什么挂钩。
> 2. 日历大事的规矩是「**在场才有奖，传闻自动写**」：潮水只给站在江边的人看，感悟只给经验够格的人涨，事后系统自动把「八月十八某、某等人在钱塘江观潮」编成传闻发出去——大事自己生成自己的江湖谈资。
> 3. 世界**不管有没有人看都在转**：事件按游戏钟触发，不按在线人数；NPC 随机走动、天气按季节每天抽一张表。奇遇和常事的分工也清楚——奇遇是**手工埋的点、一人一次**（旗标记账），常事是**可以无限重复的轻事件**；全服大事一年五件，密不密的活儿全交给门口的小事和闲话。

写于 10-10，为 #597 而读。对照 `src/engine/encounter.ts`（路遇冷却与 `once`）、`src/engine/shishi.ts`（世事 `again`）和 `docs/zhishiku/sandbox-rimworld.md`（环世界讲**节奏**：保底、间隔、分级；侠客行系讲**挂历**：大事钉日子、小事钉门口——同一件事的两头）。

## 〇、看了什么、怎么看的

三家源码都在仓库外临时目录，只读文本，没有运行。出处路径各相对自己仓库根。没读的：天气表（`/adm/etc/nature/`）的逐行内容、入侵战的数值细节、各事件的完整台词。

## 一、它怎么做的

### 1.1 日历大事：事件是文件，自己排下一场（炎黄 `adm/daemons/eventd.c`）

- 每件大事是 `adm/daemons/event/` 下的**一个文件**：钱塘潮信、峨眉金顶、天池、无量山、皇帝驾崩，全年五件。
- `eventd` 每个游戏小时心跳一次，把到点的事件触发掉；事件自己用 `at_when / at_after(年, 月, 日, 时)` 在游戏历上**排下一场**——潮信写的是「明年八月十八，提前一天先发预告」（`event/qiantang.c` 的 `create_event`），触发完再排来年，**永不断档，也不靠人补**。
- 分阶段：预告（STATUS_PROMPT）→ 发生（START）→ 结束（END）。
- **奖惩只给在场的人**：潮来时扫一遍房间，在场的都看到潮水的描写；经验够万的再得一份「若有所悟」（经验、潜能、内功各按随机数涨）；事后自动生成一条传闻——「八月十八，某某、某某在钱塘江观潮」，**参加大事会进江湖谈资**。

### 1.2 全服大事：外敌入侵（炎黄 `adm/daemons/invasion/invasiond.c`）

- 全服警报开路：「异族联军攻入北京」，开一个专门的频道直播战况；
- 敌人按等级成套生成（等级越高攻防越硬），打退有赏——**一件大事就是一份按实力缩放的差事**。

### 1.3 天时：季节播报 + 每天抽一张天气表（炎黄 `adm/daemons/natured.c`）

- 游戏历走到 3/21、6/22、9/23、12/22，全服播一句换季；
- **每天按当月季节抽一张天气表**（春天在雨、晴、风三张里抽）——天气不只改描写，还按表改小账（冷天伤身、雨天路滑之类，落在角色数值上）。

### 1.4 门口小事：进门掷骰，只找对的人（侠客行2001 `d/city/guangchang.c`）

扬州广场的 `init()` 里挂着两件小事，都是**每进一次门掷一次**：

- 带着红镖进广场：三分之一概率被人撞一下，再对半掷——要么镖被扒走（差事物品直接销毁，身上记一个「失镖」的旗标），要么扒手露了行藏落荒而逃。**不掷骰的人毫无感觉**：这场骚扰只找带镖的。
- 所有人：十分之一概率触发「蒙面人」事件的后手（代码里一半还注释着——又是想到没做完的）。

### 1.5 奇遇与常事的分工

- **奇遇是手工埋的点、一人一次**：平一指看见你带着手脚就开口买、李文秀的问话树、藏经阁二楼要推荐信——全靠旗标记「这一号这人已经遇过了」。
- **常事是可以无限重复的轻事件**：押镖、守山门、师门任务、门口掷骰、闲话——量极大、单次极轻。
- **数量级**：日历大事五个文件对几百间房——大事极少而重，小事极多而轻；让江湖不安静的从来不是大事的频率，是小事的存在。

### 1.6 玩家不在场时

照转。事件按游戏钟触发（潮信不等人）；NPC 有随机走动（`inherit/char/npc.c` 的 `random_move`，精力过半才走）；天气每天自己抽。**在场的拿奖励和传闻，不在场的错过了就是错过了**——没有补发，也没有「因为你不在所以世界停了」。

## 二、我们能借什么

- **世事 `again` 的两极分工**：极少数世事钉日历（潮汛、庙会、擂台赛），大多数转成门口小事（掷骰路遇）。我们现有 32 条路遇只有冷却是缺「掷骰的身份门」；14 件世事只有一件 again 是缺「挂历」。
- **在场才有奖励 + 传闻自动写**：事件结的奖励只发场景里的人，结完了自动生成一条「某某等人如何如何」的传闻——奖励和谈资一次结清。
- **小事带身份门**：同一条路遇，对带镖/带伤/带恶名的人概率不同——比纯冷却更能防腻，也更像「江湖专挑你下手」。
- **和环世界那份对照**：环世界用「保底 + 间隔」把节奏摊匀，侠客行系用「挂历 + 门口」把密度分层——我们的导演可以两头取：保底保下限（不安静），挂历造高点（有盼头）。

## 三、不借什么、为什么

- **全服频道的警报和直播**：我们没有多人和频道，入侵那套广播改成府衙告示与传闻即可。
- **按现实秒的心跳**：我们的世界按行动推进，心跳式掷骰改写成「进场景掷骰」「过时辰掷骰」，语义一样、实现更省。
- **攻城战的数值规模**（按等级成套刷敌人）：单机不养这么大的战斗；借它的「警报—到场—按实力拿赏」三段即可。
- **注释掉的半成品**：蒙面人事件写一半停了——我们每个掷骰事件都要能被机器玩家走到（zoubian 兜底），不留只能人肉触发的事件。

## 四、建议进设计的三到五条

1. **挑两三件世事钉在游戏历上，提前一天给预告。**
   出处：炎黄 `adm/daemons/eventd.c`、`event/qiantang.c`（`at_after` 自排下一场、预告阶段）。状态：新。落到 `src/engine/shishi.ts` 的 `again` 规格（设计层面，动引擎另起单）与 `docs/huojianghu.md`。
2. **事件结只发在场的人，并自动生成一条传闻。**
   出处：炎黄 `event/qiantang.c` 的 `do_bonus`（在场过滤、经验门槛、随机量、`MAP_D->record_rumor`）。状态：新。落到 `docs/huojianghu.md` 传闻与世事结算。
3. **路遇加「身份门」：同一条路遇对不同身份的人不同概率。**
   出处：侠客行2001 `d/city/guangchang.c`（带镖才掷、三分之一的撞、对半的成败）。状态：新。落到 `src/engine/encounter.ts` 的条件与概率（规格层）与路遇写法。
4. **季节换一次天时，天时改一点小账。**
   出处：炎黄 `adm/daemons/natured.c`（四季播报、每天按季节抽天气表）。状态：新。落到 `docs/huojianghu.md`（我们已有时辰，加月与季）。
5. **大事一年五件的密度当作上限来守。**
   出处：炎黄 `adm/daemons/event/`（五个文件对几百间房）。状态：新。落到 `docs/fenxi-codex-10-09.md` H1 的回应与世事规划：日历大事宁可少而重，密度交给门口小事和迎面闲话（见 `mud-yingmian.md`）。

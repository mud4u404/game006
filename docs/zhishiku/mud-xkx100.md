# 参考笔记：侠客行 100 的门派驻地布局、门禁和门人日常

> 三行总结
> 1. 五个门派的「驻地」其实都是**一座山 + 几间功能房**：武当 155 个文件、峨眉 160 个文件，九成是上山的石阶、松林、盘道，真正的功能房只有十几间，全挂在一条主轴上——「路要远，堂要近」，走到山门后的体验是三五步一间、间间有用。
> 2. 门禁有四种做法，全是**用世界说话而不是用弹窗**：帮众才能钻的香案洞（钻的时候广播「运起缩骨功」）、对上暗号才开五秒的木门、伪装成城市角落的分舵入口、进门就翻档案的戒律院。外人不是「不许进」，是**进得来但处处被认出来**。
> 3. 最值得开发者 agent 学的是几个小机关：数字出口的「总机式枢纽」、落脚点被戒律院劫持（被审期间下线再上也醒在牢里）、门派出生点直接设在分舵里、每个分舵口坐一个有名有姓的头目、帮主藏在暗道尽头而不是大堂。

写于 10-10，为 #336 而读。丐帮分舵、武馆、门派任务的大框架上一份笔记（`mud-xiakexing.md`）已经写过，本份补齐 xkx100 里五派的具体布局和门禁细节，专收「有意思的设定」。**开发者 agent 用法：每一节末尾都标了我们自己的落点；引用机制前先查 `docs/sheji-zhudi.md` 是否已采纳，别重复提。**

## 〇、看了什么、怎么看的

`git clone --depth 1 https://github.com/mudchina/xkx100 /tmp/xkx100`（仓库外临时目录），GBK 编码，逐文件 iconv 转码读文本，**没有运行任何东西**。五派各拆到房间级：文件数（.c）少林 302、峨眉 160、武当 155、华山 109、丐帮 51；下面写的每间房都有出处（`d/<派>/<文件名>`，相对仓库根）。没读的：战斗数值、武功招式、上山路的逐间描写。

## 一、五派的布局

### 1.1 丐帮（`d/gaibang/`，51 个文件）——没有大殿，全是门

```
扬州城南 土地庙（丐帮出生点，卢长老+彭长老+大弟子）
 ├─ 西 兽舍（狐狼虎狮）   ├─ 东 蛇园（五种蛇）
 └─ 香案下的洞（帮众运缩骨功钻入）→ 破庙暗道 → 密室 ←→ 储藏室 ←─┐
                                                                │
扬州中央广场老槐树 树洞内部（守洞帮众+留言板「富人地狱，穷人天堂」）
 └─ 对暗号 → 木门开五秒自动关 → 树洞下【总机枢纽：0～9 数字出口】
      ├─0 井底密道(岳阳)  ├─1 谷场槐树边  ├─2 草堆下面(无锡)…
      └─ 每条暗道两段，尽头是一个分舵入口，口上坐一位头目
         （北京 街边狗洞=全冠清、成都 破床底下、福州 大榕树下、
          泉州 铁枪庙下、少林 屋角边、华山 舍身崖下、雪山 雪坑小洞…）
城外 林间小屋（西通暗道）——洪七公住这儿，不在大堂
```

要点：**总舵不存在**。「总部」是关系网+暗号+一张暗道图；十四个分舵入口全部伪装成城市的破烂角落，知道暗号的人才用得了。丐帮弟子出生在土地庙（`valid_startroom`），路上随时可能「从洞里钻出来一个同门」。

### 1.2 少林（`d/shaolin/`，302 个文件）——主轴挂功能房

```
山门（知客僧虚通、虚明）→ 石阶×11 → 广场（钟楼七层/鼓楼七层分列东西）
→ 大雄宝殿 → 广场群（五片）→ 戒律院（玄痛+僧兵×3，不可动手）→ 监狱×2
侧挂：练武场×4、斋厅×2+厨房×2、藏经阁（楼下经卷/楼上是另一层）、
     东西侧殿、防具库、达摩洞（竹林深处，达摩本人在里面坐关）
外围：竹林×14、松林×14（护法松林，擅入记罪）、八卦阵×8、万古寒潭
```

要点：钟楼**一层一间共七层**，顶层有撞钟的僧人——垂直的塔用七间房堆出来。达摩洞里真的坐着达摩，**镇派的不是值钱货，是一个见不到的人**。

### 1.3 武当（`d/wudang/`，155 个文件）

```

→ 磨针井/榔梅园（沿途小景）→ 紫霄宫大门 → 武当广场
→ 三清殿（总堂）→ 东厢走廊 → 练功房、茶室 | 西厢走廊 → 藏经阁

要点：「**解剑岩**」——上山先解剑，一块石头就是一条门规；金顶在最高处，**地理高度=辈分高度**。

### 1.5 华山（`d/huashan/`，109 个文件）

```
山脚 玉泉院 → 青柯坪 → 苍龙岭 → 金锁关（一线天险，过了才算上山）
→ 三峰分流：朝阳峰（主峰）/ 玉女峰（玉女祠）/ 落雁峰

## 二、有意思的设定（开发者 agent 重点读这节）

每条一个机关，写明在哪、怎么运作、我们哪里用得上：

1. **总机式枢纽**（`d/gaibang/undertre.c`）：树洞下用 `0～9` 编号出口各通一条暗道，选号「拨接」。比十个方向词好记，比列表菜单有画面。我们做「帮会暗道」「地窖网络」时可借：扬州总舵的地下用编号出口，外人进来了也不知道拨几号。
2. **对暗号的门会自动关**（`d/gaibang/inhole.c`）：说对两句暗号之一，墙开一道小木门，`call_out` 五秒后自动关上——**门是临时的，暗号才是永久的**。对不上暗号的外人只得到一句「阁下光临敝帮有何贵干」。落点：扬州丐帮总舵入口（`docs/sheji-zhudi.md` 备选已记，做总舵时实现）。
3. **帮众专属的物理通道**（`d/gaibang/pomiao.c`）：香案下的洞只许帮众钻，钻的时候向在场所有人广播「某某运起丐帮缩骨功，一弯腰往洞里钻了进去」——门禁动作本身是**一次身份展示**。落点：各驻地帮众专用近道可以照此写一句广播。
4. **落脚点劫持**（`d/shaolin/jlyuan.c`）：进了戒律院被审，`startroom` 被改成戒律院——**审问期间下线，再上线人还在大殿里跪着**。惩罚跟着人走，不跟着房间走。落点：若做「关半日」类惩罚，落地为「下线再上仍在受罚地」，写进设计稿即可，不必新增系统。
5. **guilty 三档对账**（同文件）：离寺期间在外杀人越货 = 罪一；擅闯护法松林 = 罪三；**惩恶扬善但伤了人命 = 罪二——表彰一句、训诫一句、销案放行**。审问流程是「大喝 → 跪 → 僧兵三应『弟子在』→ 判词」。三档判词=三种江湖道理，值得整段借（机制上一份笔记已写，本份补的是流程细节：判词按档案念，僧兵应名三次，每次间隔随机一两息）。
6. **门派出生点设在分舵里**（`pomiao.c` 的 `valid_startroom`）：丐帮弟子睁眼就在土地庙，门外就是蛇园兽舍。我们的开局是瓜洲，但**每个师门包可以给「入门当天」一个从驻地醒来的瞬间**。
7. **分舵口坐有名有姓的头目**（`underbj.c` 街边狗洞=全冠清）：十几个分舵，个个有本地头目一名。**地方的名字靠人记**，不是靠房间描写。落点：驻地第二批分舵（若做）每人一间一位。
8. **帮主藏在暗道尽头**（`gbxiaowu.c` 林间小屋只有一条西向暗道通外面）：洪七公不住大堂。**权力的可见度**是设计出来的：越往里越偏，见帮主要过三道暗道。
9. **地名写门规**（华山）：解剑岩、回心石、有所不为轩、舍身崖——**规矩刻在山上**，不写在帮助文件里。落点：我们驻地的路口、岔道命名可以照这个思路（如六扇门「自新石」、少林「面壁处」）。
10. **地理高度=辈分高度**（武当金顶、峨眉金顶、华山三峰）：最尊贵的人住在最高处，玩家一路爬升的体感就是地位的体感。落点：驻地布局排布时把「长老所在」放在动线尽头最高/最深处。

## 三、门外的人进来会怎样（四派四种答案）

| 做法 | 例子 | 机制 |
|---|---|---|
| **动作拦** | 丐帮香案洞 | `do_enter` 查门派，非帮众钻不进，帮众广播缩骨功 |
| **口令拦** | 树洞木门 | 说对话才开门，开五秒即关；说错只给一句场面话 |
| **地点拦** | 少林戒律院/护法松林 | 外人踏进去直接触发审问流程，非本派一律治罪 |
| **无人拦** | 峨眉山门、武当玄岳门 | 知客迎客，前厅对香客开放；拦人的是更里头的地点和NPC |

共同点：**没有一处用系统弹窗**。外人始终「进得来」，只是走到该被认出来的地方，被认出来。

## 四、门人日常（这版看到的）

- **值守**：戒律院常驻僧兵三名+知客小童一名；玄岳门知客道长+道童两名；报国寺山门知客。值守是**站岗的人+他的位置**，没有复杂的排班系统。
- **门规惩罚**：少林一条链（戒律院审 → 杖责 → 僧监拘押三月 → 「非洗心悔改不得释放」「意图越狱罪加一等」），判词分三档，见第二节第 5 条。武当、峨眉未见同等强度（后山禁地以地形拦）。
- **师兄带师弟**：丐帮土地庙配「大弟子」（`first`）一名，陪着两位长老——**新人的引路人是一个常驻 NPC 位**。练功场的同门群像（`lianwu*.c` 各有若干弟子）是氛围，不是机制。
- **同门切磋**：本版没细查切磋闸门的代码（上一份笔记的练功闸门通用规律可沿用），如实记一句，不编。
- **吃饭睡觉**：斋厅、厨房、禅房、修习室各派齐备；位置固定在主轴两侧，与上一份笔记「安全房/睡房/练功房三分」一致。

## 五、对照我们的原则

| 我们的原则 | xkx100 做对了的 | 不学的 |
|---|---|---|
| 活的江湖 | 每个口上有一个有名的人；门禁动作带广播 | 人是站桩的（我们有作息） |
| 有条件有代价 | 暗号、档案、禁地层层设闸 | 迷阵×8、盘道几十间——走路的税 |
| 金庸风格 | 解剑岩、回心石、有所不为轩：地名写规矩 | 杖责三百的酷刑描写 |
| 手机上好用 | 主轴三五步一间功能房 | 160 个文件九成是山路；找洪七公要过三道暗道 |
| GTA 式自由 | 外人处处进得来，被认出来才拦 | 无 |

## 六、建议进设计的三到五条

1. **驻地的「地方戏」用编号枢纽或暗号门做一处**。扬州丐帮总舵入口对暗号（已列备选）；若做分舵网络，枢纽用 0～9 编号出口。出处：`d/gaibang/inhole.c`、`undertre.c`。落到 `docs/sheji-zhudi.md` 丐帮总舵一节。
2. **门禁动作要有「身份广播」**：帮众走帮众道（钻洞、进内院）时向在场的人广播一句「某某运起缩骨功/出示了腰牌」，外人走外人道。一句广播就是身份系统的展示层。出处：`d/gaibang/pomiao.c`。落到各 `shanmen-*.ts` 驻地入口（内容层，不改引擎）。
3. **地名写门规**：驻地内的路口、险处、岔道起「解剑岩/回心石/有所不为轩」式的名字，规矩不写在告示里、刻在地上。出处：`d/wudang/xuanyuegate.c`（解剑岩）、`d/huashan/`（回心石、有所不为轩）。落到驻地第二批的房间命名（`docs/sheji-zhudi.md` 补一段命名约定）。
4. **「见不到的人」当镇派之物**：达摩在达摩洞坐关、洪七公藏在暗道尽头——掌门/祖师不要坐在大堂等人，让「见到他」本身是一件要走门路的事。出处：`d/shaolin/damodong.c`、`d/gaibang/gbxiaowu.c`。落到 `docs/sheji-zhudi.md` 的「晋升要过人」配套：真传一层放「掌门所在」，平时不在。
5. **判词按档案念**：戒律院对账三档的完整流程（念档案 → 僧兵应名 → 分档判词 → 有时限的拘押）上一份笔记已建议采纳；本份补充实现细节——判词要引你做过的事（「你离寺仅有数日，却在外杀人越货」），**不是一句「你犯了门规」**。出处：`d/shaolin/jlyuan.c`。落到未来「山门对账」的任务规格里（挂 `docs/sheji-zhudi.md` 采纳参考第 4 条）。

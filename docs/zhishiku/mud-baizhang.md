# 参考笔记：侠客行系和炎黄怎么给「打输」定价

> 三行总结
> 1. 打输分两档走两套流程：**昏迷**（眼前一黑、手脚被封、气血清零，体格越高醒得越快，醒来自动被挪出人堆；只记下「谁打晕的你」）和**死亡**（扣经验百分之一、潜能减半、存款超一万贯的部分减半、武功各掉一级；**新手只扣二十点经验**——低经验时死亡几乎不疼）。
> 2. 疗伤是明码标价的买卖：扬州药铺柜台上贴着价目——金创药五十两、蛇药二十两、养精丹一两。而新手一日工钱「只有几两」，**一味创伤药等于十几天的工钱**；打输的真代价不在惩罚公式里，在这张药价签上。
> 3. 「输了还能再来」靠三道结构性的门：**切磋与真打是两个命令**（切磋点到为止、只耗体力不受伤）；**擂台挂免死牌**（no_death 的房间里死亡自动降级成昏迷）；**昏迷本身是保护**（倒下就脱战，不补刀到死）。记仇的机制反而很轻——大多只是记一笔「谁打晕过我」。

写于 10-10，为 #596 而读。出处：论剑第一轮 #593「输一场要白干三天」；对照 `src/engine/shang.ts`（轻伤过一日自愈、重伤一次治一级）、`src/engine/jiesuan.ts`、看伤价（葛郎中/宁大夫一级 150 文）。

## 一、打输了会怎样

### 1.1 昏迷（侠客行2001 `feature/damage.c`）

- 气血、精神、精力全部清零，身上挂「昏迷不醒」的牌子，什么都做不了；
- **醒来的时间按体格算**：`random(100 − 体格) + 30` 秒——筋骨强的人爬得快，弱的多躺一会儿；
- 醒来自动挪一步（若倒在人身上，被挪到那人所在之处的上一层），不欠任何人；
- 系统记下「最后打晕你的人」一笔（`last_fainted_from`），这是后续记仇、报一箭之仇的钩子；
- 打晕你的人拿到的是 `winner_reward`（胜方奖励），**你不掉东西**——昏迷本身不罚。

### 1.2 死亡（侠客行2001 `adm/daemons/combatd.c` 的 `death_penalty`）

| 扣什么 | 数额 |
|---|---|
| 经验 | 减 1%，上限 5000 点；**经验不足 50 的只扣 20 点** |
| 潜能 | 减一半 |
| 存款 | 一万贯以内不动，**超出部分减半**（有一条保底线） |
| 声望（善恶） | 减 5% |
| 武功 | 各掉一级（`skill_death_penalty`：炎黄的版本里，可作招架/轻功/内功的秘学直接追回，其余压回一百，知识类不动——见 `feature/skill.c`） |
| 累犯 | 「死亡次数」超过经验门槛后才开始记（一万×次数），门槛内不加重 |

**新手保护是明写的两条**：低经验死亡只扣二十点经验；死亡次数的累进门槛按经验抬高。老玩家才真的怕死。

### 1.3 免死房：擂台（`d/city/leitai.c`、`d/quanzhou/leitai.c`）

比武招亲的擂台挂着 `no_death` 牌：**在这些房间里，死亡自动降级成昏迷**（`damage.c` 的 die() 第一段就查这面牌子）。比武、论剑这类「不该死人的场合」，用房间属性一刀切死。

## 二、受伤和疗伤

- **伤分两层**：气血掉了可以回，**气血上限被打掉（伤）恢复极慢**，靠内功疗伤加速（`inherit/char/npc.c` 里每拍挂一次内功「行气」）、靠药。
- **扬州药铺的价目**（`d/city/yaopu.c` 柜台广告）：金创药五十两白银、蛇药二十两、养精丹一两，「其他神药与老板面议」。散落的丹药也这个量级：玉真散标价八千文、百草丹四千文（`d/dongtinghu/obj/`）。
- **对照新手收入**：守山门这类差事的新手工钱「只有几两银子」（`kungfu/class/wudang/zhike.c` 的工钱分档，上一份笔记 `mud-xiakexing.md` 拆过）。

**代价 ÷ 新手一日收入**：

| | 一次治伤 | 新手一日收入 | 倍数 |
|---|---|---|---|
| 侠客行2001 | 金创药 50 两（重伤一剂） | 守山门约几两 | **约十倍到二十倍** |
| 我们 | 看伤一级 150 文，跌打酒 60 文、内伤药 80 文（`jichu.ts` 葛郎中/宁大夫） | 杂役类正收入多为一笔 1～20 文（各内容包 `silver` 正项统计） | 一级伤约七倍上下，重伤二级连治两次就到「白干三天」 |

两边惊人地一致：**老 MUD 和我们都把治伤定在「新手几天的收入」上**。区别在他们把死亡罚得再重也不收钱（钱只从药上赚），我们把昏、死换成了「伤要花钱治」——钱的出口更清楚，但也就更容易让人在药铺门口心灰。

## 三、切磋和真打：两个命令、一面免死牌

- `fight` 与 `kill` 是两个指令（`cmds/std/fight.c`）：讨教切磋「点到为止，只会消耗体力，不会真的受伤」；真打才可能死。切磋输了代价只是耗掉的体力，外加身上记一笔「谁打晕过我」。
- 擂台的 `no_death` 是给「规矩场合」的：台上生死有命是不许的，比武招亲打死了要吃官司。
- 我们已有同构物：`FoeDef.spar` 的考校切磋（输了「收手认输」，无惩罚）——方向一致，不用改。

## 四、输了还能再来靠什么

- **没有冷却**：醒来就能再战，血条是唯一的门。
- **仇人记但不深**：昏迷记「谁打晕过我」一笔（`damage.c`），炎黄的门派仇人簿有容量上限、满了挤掉最轻的（`docs/daemons/familyd.md`，`mud-yanhuang.md` 拆过）——记仇会过期，不会滚雪球。
- **真正的门槛是药钱**：输多了不是系统罚你，是药铺账单罚你。这既是它「有代价」的优点，也是把人逼走的暗门（试玩里两次想关游戏，正对应这个）。

## 五、建议进设计的三到五条

1. **新手减震写在明处**：他们的低经验死亡只扣二十点、累犯门槛按经验抬；我们的败仗惩罚（体力、时辰、药钱）也可以按「入门头几日减半」给一条明文的减震，让第一次惨败不劝退。出处：侠客行2001 `adm/daemons/combatd.c` `death_penalty`（经验 50 以下只扣 20）。状态：新。
2. **给治伤留一条「不花钱的慢路」**：他们的气血伤靠内功行气慢慢回，药是加速不是唯一；我们的重伤「自己不会好」可以补一条极慢的自愈（比如重伤养七日自动轻一级，闭关加倍），让没钱的人有路，有钱的人买时间。出处：侠客行2001 `inherit/char/npc.c`（内功行气挂每拍）。状态：新。落到 `src/engine/shang.ts` 的设计（动引擎另起单）。
3. **药价分级，别把最重的伤定成天价**：他们的药铺一等一家（金创药五十两治重伤、养精丹一两养精神），贵的药治重的病，便宜药管日常；我们一级 150 文对轻伤合理，**重伤连治几次的总账**要在设计里算给玩家看（伤势面板写一句「还差几级、大约几文」）。出处：侠客行2001 `d/city/yaopu.c` 价目。状态：新。落到看伤对话与伤势提示（内容层）。
4. **败仗记账不记恨**：他们只记「谁打晕过我」，记仇簿还会挤掉旧账；我们打输的仇（河贼、屠千山）适合做成**可了结的事**（去报仇了结、官府剿了），而不是永久的属性减益。出处：侠客行2001 `feature/damage.c`（`last_fainted_from`）；炎黄 `familyd` 仇人簿的容量淘汰。状态：新。落到 `docs/gugan.md` 的仇怨设计。
5. **免死牌挂在该挂的场合**：擂台 `no_death` 让比武场合天然不死人；我们的考校、切磋已用 `spar` 表达，将来英雄榜、擂台一类设计里保留这条「场合免死」的明文，别让切磋出人命。出处：侠客行2001 `d/city/leitai.c`（`no_death`）、`cmds/std/fight.c`（切磋点到为止）。状态：新。

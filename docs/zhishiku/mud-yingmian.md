# 参考笔记：侠客行系的 NPC 怎么主动开口

> 三行总结
> 1. 主动开口分两层：**迎客**（`init()` 里登记一个「玩家进门」的钩子，隔一拍再开口，开口前先验人还在不在；说什么按身份分档——本门、门下童子、善客、恶客四档换四副脸色）和**闲话**（每个心跳掷一次骰，中了就从话池里抽一句；平时和打架是两套池子、两个频率，打架时绝不说闲话）。
> 2. 「看人说话」有三种深度：**看你是谁**（门派、性别、称谓换一口气）、**看你带着什么**（萧府的贺客看见来人带着凶刀，寒暄当场变成拿人）、**记得你问过什么**（问话树用旗标记「他问过第一句」，第二问的答案就变了）。
> 3. 通用模板出奇地克制：只对**真人**开口（NPC 走过不停）、**不打架时**开口、先 `remove_call_out` 再 `call_out` 一拍（防叠加、让场景描写先落地）。频率中位数是「每秒一掷、百分之五中」——大约二十秒一句，吵不起来的关键不是话少，是**池子小、频率低、分场合**。

写于 10-10，为 #595 而读。对照 `src/engine/yingmian.ts`（迎面：一人一江湖日最多一次、同一场景同一时辰段只挑一人、只挑条件成立的、挑人先看来往再看好坏）和 `docs/sheji-youhua-1010.md` 第五条。

## 一、它怎么做的

### 1.1 迎客：进门一拍之后再开口

三家的模板一模一样（例：炎黄 `d/gaochang/npc/liwenxiu.c`、侠客行2001 `kungfu/class/wudang/zhike.c`）：

- 房间或 NPC 的 `init()` 里：只挑**真人**（interactive；NPC 进出不理会）、**不打架的**，先 `remove_call_out("greeting")` 再 `call_out("greeting", 1, 玩家)`。
- 一拍的延迟有两个用处：**场景描写先落地，话随后到**；开口前再验一遍「这人还在这个房间里吗」（`environment(me) != environment()` 就闭嘴）——延迟期间人走了，话就不说。
- 同一钩子重复触发也不叠加：`remove_call_out` 在前，先来没说完的招呼直接作废。

### 1.2 打招呼看身份：一个知客，四副脸色

武当知客道长（侠客行2001 `kungfu/class/wudang/zhike.c` 的 `greeting`）按来人身份分四档：

| 来人 | 反应 |
|---|---|
| 本门弟子 | 「这位道姑/道兄辛苦了！」（称谓随性别变） |
| 本门道童 | 「还要继续努力啊！」 |
| 没带恶名的 | 作个揖，欢迎来武当山 |
| 恶名重的 | 「唰」地抽剑：满脸杀气，不是来敬香就请回 |

同一家还有**看你带着什么**的（`d/forest/npc/banhe.c`）：来人身上带着那把凶刀，寒暄当场变成「好你个小贼，竟敢混入我萧府行凶」并直接动手；空手来的照样行礼道喜。还有**只认人的**（`d/jiaxing/npc/shashou.c`）：他的目标一进门，别的都不说，喊一声名字就动手。嘉城客栈的店小二最简单，两句迎客话随机抽一句（`d/city/npc/xiaoer.c`），外加问路表（`inquiry`：问哪个门派答哪个门派）。

### 1.3 闲话：每个心跳掷骰，平时和打架两个池子

机制在 `inherit/char/npc.c`（侠客行2001）：

- 每个心跳掷一次：`random(100) < chat_chance` 才开口，中了就从话池 `chat_msg` 里随机抽一条。
- **打架时自动换池**：查的是 `chat_chance_combat` 和 `chat_msg_combat`——没设战斗话池的 NPC，打起来就闭嘴。
- 话池里的元素可以是**句子，也可以是函数**：函数型的能看当场情况说话（京城街头闲人说完话顺手 `random_walk` 溜达一步；下棋的叹气找对手，遛鸟的吹口哨——话和动作排在一个池子里轮流出）。
- 全库频率抽样：`chat_chance` 取 2 到 20，最多的是 5（约每二十秒一句），其次是 10、6、15。**没有超过 20 的**——最吵的人也是十秒一句。

### 1.4 记得你：问话树用旗标

炎黄 `d/gaochang/npc/liwenxiu.c` 的问话链是「记得聊过什么」的样板：

- 问「苏普」，她答完在玩家身上记一面小旗（temp 旗标）；
- 再问「父母」，**查到这面旗**，答案就从一句冷话变成掏心窝的仇情，并记下第二面旗，故事往下走一层；
- 没问过第一句就问第二句，只得到「父母之仇，不共戴天」一句门面话。

侠客行100 `d/kunlun/npc/mingjiao_shouwei.c` 是另一路防重复：同一件事**问过一遍就不再答**（「你不是已经问过了吗？」），用进门即清的临时旗标挡住车轮问话。同一文件里还有一段被**注释掉**的「夜间值守话」——按门内时辰换词，写好了没开。**时辰条件是最先被砍的**：没有验收兜着的话头，活着活着就没了。

## 二、我们能借什么（对照迎面的规矩）

我们的迎面已经定了节制的骨架：一人一江湖日最多一次、同一场景同一时辰段只挑一人、只挑条件成立的、挑人先看来往再看好坏、独立随机数不碰世界的骰子。侠客行系能往骨架里填的：

- **身份分档的口气**（武当知客四档）：我们 `greet` 的 `if` 条件本就吃关系和身份，写内容时按「本门／熟人／生客／恶名」四档起句，一人一套，不共享句式。
- **闲话和战话分池**：打架中不出迎面话（我们的迎面挑人时可以明写「战斗中不挑」，虽然单机战斗即切场景，写明这条能防以后被破坏）。
- **话头带事**：条件吃旗标——办完他家差事的人，迎面先提那件事（banhe 看刀、李文秀记问的机制，搬到我们的 `if` 旗标上）。
- **延迟与验人**：进场景先画景、话隔一拍，开口前确认人还在——我们重画即挑的流程天然满足，但「时辰段中途人离场就不推话头」值得写成明文。

## 三、不借什么、为什么

- **每秒掷骰的心跳闲话**：单机不需要常驻喋喋不休；我们一天一次、一场景一人，比它安静得多，也更像「活人偶然搭话」而不是「收音机」。
- **见面即动手的硬编码**（杀手见目标、萧府见凶刀直接 `kill_ob`）：我们的敌对走条件与恶名系统，不在迎面里藏战斗。
- **NPC 对 NPC 的帮派喊话**（知客道长见毛贼就摇人上）：我们没有同门群战，这句气质可以留给传闻，不进迎面。
- **把闲逛混进话池**（说完话顺手 random_walk）：移动和说话在我们是两套系统，不混。
- **想到没开的时辰条件**（明教守卫的夜间话）：借的是教训——每个带时辰条件的话头都要有测试兜着，不然维护时最先被砍的就是它。

## 四、建议进设计的三到五条

1. **打招呼按「本门／熟人／生客／恶名」四档起句，一人一套。**
   出处：侠客行2001 `kungfu/class/wudang/zhike.c`（`greeting` 四档、称谓随性别）。状态：新。落到 `docs/sheji-youhua-1010.md` 第五条的写法规格、`NpcDef.greet` 条件吃 `rel` 与门派。
2. **迎面话头可以吃旗标，把「你办过的事」说出口。**
   出处：侠客行2001 `d/forest/npc/banhe.c`（见凶刀翻脸）、炎黄 `d/gaochang/npc/liwenxiu.c`（问话树记旗）。状态：新。落到 `docs/content-guide.md` 迎面写法一节：交完差的 NPC 迎面先提那件差。
3. **战斗中不出迎面，写成明文。**
   出处：侠客行2001 `inherit/char/npc.c`（`chat_chance` 与 `chat_chance_combat` 分池，打架自动换池）。状态：新。落到 `src/engine/yingmian.ts` 的规格注释（现在的实现已天然满足，写明防回归）。
4. **开口前验人还在、先景后话。**
   出处：侠客行2001 `kungfu/class/wudang/zhike.c`（`init` 先 `remove_call_out` 再隔一拍，`greeting` 开头验 `environment`）。状态：新。落到 `docs/sheji-youhua-1010.md`：时辰段中途离场的人不推话头。
5. **问过就不再答；问话有先后，后一问吃前一问的旗。**
   出处：侠客行100 `d/kunlun/npc/mingjiao_shouwei.c`（问过即挡）、炎黄 `d/gaochang/npc/liwenxiu.c`（旗标推进问话树）。状态：新。落到 `docs/content-guide.md` 交谈一节：引路式问答加一次性旗标，多问一人身上只记一面。

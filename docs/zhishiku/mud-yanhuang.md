# 参考笔记：炎黄 MUD 怎么做师门任务、门派贡献和叛师

> 三行总结
> 1. 炎黄把「替师门办事」做成一条**资格闸门越走越窄**的路：经验一万才派活、十万以前只送信；要领杀人任务，先得办过「出师」（师父当面赠图册、给一个出门的记号），江湖阅历不够的一律打发回去继续历练。派什么活是**师父的性格**定的：正派师父派你杀恶人，邪派师父派你杀大侠，同一套系统两种江湖。
> 2. 它有四个数各管一摊：**门派贡献**（花在绝招和奖励物上，叛师清零）、**威望**（取消杀人任务就扣）、**江湖阅历**（一堆资格闸门的钥匙）、**门派声望**（整个门派的数，按历史地位定基础值）。奖励到里程碑不白送——师父拿东西出来**报个贡献价，你答「要」才扣**，全程是兑换不是发糖。
> 3. 叛师罚在**关系**上而不只在数值上：武功废掉、贡献清零之外，还记一个「离开过某派」的档案，**记了档案的门派永不回收**，叛过任何一派的名门也拒收。这个「档案」比「扣两百贡献」狠得多，也省事得多。

写于 10-10，为 #335 而读。对照 `docs/decisions.md` 的门派贡献一行（差事攒贡献、升地位要贡献门槛、学武功另扣贡献）和 `docs/sheji-zhudi.md`「采纳的参考」第 3、5 条（执事派差有名额、晋升要过人）。上一份笔记 `mud-xiakexing.md` 读过炎黄的任务门槛和声望概况，本份把这几块拆细。

## 一、师门任务：一条越走越窄的路（questd.c）

### 1.1 谁能领、领什么

师父（`can_quest` 的 NPC）面前「要活」，闸门一层层：

| 闸门 | 条件 | 不过怎么说 |
|---|---|---|
| 经验 | 实战经验一万起 | 「就你那点水平，我实在没法给你派任务」 |
| 类型 | 十万以前**只派送信** | — |
| 阅历 | 送信要江湖阅历二十；杀人要一百 | 「可惜你的江湖阅历太差」 |
| 出师 | 杀人任务要 `out_family` 记号：经验五万 + 阅历一百，师父当面办一场小仪式，赠一本**地图册** | 「待你外出历练段时间后再说吧」 |
| 善恶相冲 | 邪派弟子找正派师父（或反过来） | 师父大怒赶人：「你居然误入歧途，还敢来见我」 |
| 同时一件 | 身上有活没交，不给第二件；帮别人做事没做完也不给 | 「先办妥了再说」 |

### 1.2 送信（低经验的活）

收信人是一个生成的 NPC，**按师父的功夫拷一份**，扔在远方片区（大理、关外、星宿海、天山、终南山、西域……），信是**写着你和收信人名字的实物**，交给玩家，送到、取回执、回来交差。全程无战斗，考验的是跑图和打听。

### 1.3 杀人（出师以后）

- 目标是**照玩家当下实力整个拷出来的生成 NPC**，再按难度级（完成数累积升级，零到九级，级越高攻击防具加成越多）往上加码——**永远打得过但永远不好打**。
- 目标扔在哪按玩家经验分档：五十万以前扔在远片区，八十万以后才扔在近处。
- **师父的善恶决定任务的性质**：正派师父的目标是「作恶多端的败类」，邪派师父的目标是「屡次和我派作对的大侠」，中立的师父连理由都懒得给。同一套代码，两种江湖。
- 目标会**随机移动**、可能**带帮手**、玩家**逃走过几次**都记着，交差时按这些调整奖励（有帮手而你照样办成，额外加赏）。

### 1.4 交差的奖励

一发六样：经验、潜能、实战体会、威望、江湖阅历、门派贡献，都带随机浮动，随难度级和转世次数上浮。三个特例值得记：

- **超时交差**（过了一天）：奖励**砍半到砍到四分之一**——不是不给，是打折。
- **无门派游侠**：所有奖励加随机五成。它用奖励差价补偿「没有师门」的玩家，而不是用惩罚逼人拜师。
- **休整机制**：完成过五十件后，每回交差有百分之一的机会触发「师父不派了」，**要去做几件门派外的散活才恢复**——游戏自己伸手按住刷任务的玩家。

### 1.5 里程碑：兑换，不是白给

连做到三十、五十、一百……一千件，师父拿出**对应档次的物品**（丹药、好东西），**明码标价扣贡献**（十五、二十五、五十……五百点），玩家答「要」才成交，贡献不够师父直接说「相信你也用不到」。第一千件的物品池还按玩家经验再分五档。**每个里程碑都是一次自愿的交易**。

### 1.6 取消与做砸

| | 杀人任务 | 送信任务 |
|---|---|---|
| 师父口气 | 「你干不了就算了，让别人做吧」 | 「连这点小事都干不了？算了吧」 |
| 扣什么 | 威望（按任务难度分档：最简单的双倍扣，高难度的反而免扣）、贡献、实战体会（「疲于奔命，难以消化」，向已消化的部分衰减） | 江湖阅历 |
| 连做记录 | **清零**——但按福缘掷骰，福气好的师父说「看在你忠心耿耿的份上，这次不重罚」 | 不清零 |

超时交差不算失败，是奖励打折；**主动取消才伤关系**。罚什么和任务难度挂钩，高难度的活取消不扣威望——**难活办砸了不重罚，是在鼓励人接难活**。

## 二、贡献、威望、阅历、声望：四个数各管一摊

| 数 | 归谁 | 涨 | 掉/花 | 上限衰减 |
|---|---|---|---|---|
| 门派贡献 `gongxian` | 个人对师门 | 交师门任务；个别机缘 | **花**：学本门绝招（每招明码标价五十、八十、二百……）、领里程碑物品；**清零**：叛师、改投、被逐 | 没看到上限和衰减 |
| 威望 `weiwang` | 个人在江湖 | 交任务（幅度随难度） | 取消杀人任务按难度扣；改投别派清零 | 未细查 |
| 江湖阅历 `score` | 个人 | 交任务、散活 | 取消送信扣；是一堆资格闸的钥匙（送信二十、出师和杀人一百） | 可扣到零 |
| 门派声望 | 整个门派 | 按历史地位定基础值（少林一千万最高，武当八百万、丐帮七百万……逐级往下） | 门派间的恩怨事件 | 上限十亿 |

学绝招是贡献花得最重的地方，而且**贡献不是唯一的闸**（武当问震山掌绝招那一问的完整检查）：已学过的不重教；非本门弟子不教；**基础武功没学的不教**；贡献不够不教（「你为我武当派效力还不够」）；**侠义值不够不教**（名门要求弟子德行）；基础武功等级不到四十、内力不到两百的让回去再练。全过了才传，传完扣贡献。**「贡献要看人品」在这里是五道闸里的一道，不是一句空话。**

另外有个「非嫡传不教」：同一门派，你不是这位师父的亲传弟子，他只说「虽为我门下弟子，却非我嫡传，去找你师父学吧」。**师父的身份比门派的身份更细一层**。

门派声望旁边挂着**仇人簿**：每个门派记自己的仇人，上限一百个，满了删掉仇怨最轻的十个——连「记仇」这件事都有容量和淘汰。

## 三、辈分：拜谁为师，你就是什么辈分

炎黄没有另做一套「职位晋升」，**辈分就是职位**：收徒时你的辈分 = 师父的辈分 + 一，头上顶着「第 N 代弟子」的名号。想升，就去**拜辈分更高的师父**——而每位高辈师父有自己的收徒门槛：梅庄、昆仑这些派查三样——**离开过本派的（`detach/某派` 有记录）不收；叛过本派的不收；叛过任何门派的不收**；武当收徒还要悟性三十、侠义八千（「名门正派，对弟子要求极严」）。所以「升辈分」不是攒够一个数就自动发生，是**下一位师父肯不肯收你**。称号（title）挂在身上，别人一眼看得见；逐出师门，称号当场变回「普通百姓」。

## 四、叛师：罚在关系上

三种走法，代价一层比一层重：

| | 流程 | 代价 |
|---|---|---|
| 自愿脱离（detach） | 必须当着**自己的师父**（找同门长辈，他让你去找师父）；要确认两回；师父叹口气，「走之前你得把学到的武功留下」，一指点在穴道上，人昏过去 | 本门秘学**整个追回**（可作招架、轻功、内功用的武学直接删）；其余武学一百级以上压回一百；知识类不动；`detach/某派` 记档案；贡献清零；任务清空；称号变「普通百姓」 |
| 被逐出（expell） | 师父开口逐出 | 同上 |
| 改投别派（betrayer） | 拜师时系统先警告「判师很可能遭到严厉惩罚」，确认两回；拜师礼上明写「跪下磕了四个响头」 | 威望清零、贡献清零、`betrayer/某派` 和总次数记档；帮助文件言明原门派的人可能**追杀**，失手被抓住就废功加基本武功折半 |

**能不能回头：不能。** 各派收徒的第一道检查就是翻档案：`detach/本派` 或 `betrayer/本派` 有记录，当面拒收（「亏你还有脸回我昆仑山」）；`betrayer/times` 大于零（叛过任何一派），别的名门也不收（「我梅庄虽小，也不接纳背信弃义之徒」）。唯一的后门是「转世」特权可以免废功脱离前世门派一次——**豁免是稀缺资源，不是常规出路**。

## 五、对照我们的原则

| 我们的原则 | 炎黄做对了的 | 做错了的（我们不学） |
|---|---|---|
| 有条件有代价 | 任务有五道资格闸；绝招五道闸 + 明码标价扣贡献；里程碑是兑换；取消有分档罚则 | 转世的各样加成把「有条件」冲淡 |
| 活的江湖 | 师父善恶决定派什么活；「非嫡传不教」；休整机制 | 任务目标凭空生成、扔在野外等玩家 |
| GTA 式自由 | 无门派游侠奖励加五成，不拜师也能混 | 杀人任务本质还是「系统派活」 |
| 金庸风格 | 出师赠地图册；叛师要当着师父、磕头、点穴废功 | 「提头来见」的割人头交差 |
| 手机上好用 | 里程碑一键领 | 目标随机移动全图找人的折腾 |

## 六、建议进设计的三到五条

**1. 差事资格用「办过几件差」当钥匙，不用战斗数值。**
炎黄所有闸门里最值钱的是「江湖阅历二十/一百」这道：它数值上小，语义上是「你在江湖上走过、办成过事」。我们的师门差事已有火候门槛，可以再加一道**阅历闸**：新入门只派送信跑腿；送过几封信、办妥过几件杂差，执事才肯派护送、巡山这类见血的活。出处：questd.c 的 score 检查（「可惜你的江湖阅历太差」）与 out_family 出师仪式。落到 `docs/sheji-zhudi.md` 执事一节和各 `shanmen-*.ts` 的讨差事分支。

**2. 里程碑奖励做成「兑换」，不做成「发放」。**
连办几件差，师父（执事）拿出一件好东西**报个贡献价**，玩家选「要」才扣贡献成交，不够就明说。这与「唾手可得的东西极少」严丝合缝，还把「贡献有什么用」变成看得见的场景。出处：questd.c `special_bonus`（答 Y 才扣十五到五百贡献）。落到 `docs/decisions.md` 门派贡献一行（补一句「里程碑兑换」）和将来驻地执事的对话。

**3. 差事罚则分档：难活办砸不重罚，取消才伤人情。**
炎黄把「超时交差」（奖励打折）和「主动取消」（扣威望、扣贡献、连做清零）分开，且高难度任务取消反而免扣威望。我们的差事失败已有「这一趟不算」，可加两档：**超时**——贡献照给一半，师父念一句；**中途撂挑子**——清掉「连续办差」的小加成，同门念叨你几天。出处：questd.c `cancel_quest` 与 timeover 分支。落到 `docs/sheji-zhudi.md` 差事一节、`src/engine/shenfen.ts` 的 JobDef 失败语义（设计层面，动引擎另起任务）。

**4. 「连办有赏、连办有休」：小加成 + 强制歇脚。**
连做里程碑给的是**兑换资格**而非数值暴涨；且完成五十件后有个百分之一的「师父今日不派活」，去做点门派外的散活才恢复。前者防「白给」，后者防「刷」。我们的差事可设：同一执事连办五件，第六件他说「你也歇歇」，隔日再来；歇脚期闲逛照常有世事。出处：questd.c 里程碑表与 `quest/freequest` 休整。落到 `docs/sheji-zhudi.md`、`docs/linggan.md`（已记）。

**5. 叛师记档案：离开过的师门永不回收，改投过的名门都要多问一句。**
我们已有「一人一师门」「叛出按 `pastSect` 拦一道」，但炎黄的狠处在**档案跟着人走、别的门派也看**：本派 `detach` 记录 → 永不收；`betrayer` 总次数 → 所有名门提高门槛。我们可以落三句：叛出的门派永不收（已有，保持）；**改投过的人，新师门收徒时加一道「你为何离开旧师」的当面盘问**，答完才谈考验；叛出时贡献清零、师门差事资格清、长老当面收回本门外门以上的功法（不折半、不清基础）。出处：`meizhuang.h`/`kunlun.h` `permit_recruit`、`feature/master.c` `attempt_detach`。落到 `docs/decisions.md`（补「叛师」一行）和将来改 `shanmen-*.ts` 拜师分支时。

### 顺带记两笔小东西

- **「非嫡传不教」**：同门的高辈师父不教别支弟子的绝招，一句话就写出门派的纵深。出处：`feature/master.c` `prevent_learn`。以后山门包的「请教」可以借。
- **仇人簿有容量**：记仇也只记最重的九十几个，满了忘掉最轻的。「门派记得谁害过它」这件事若做，得先定「记几条、忘哪些」。出处：familyd.md 仇恨清理。

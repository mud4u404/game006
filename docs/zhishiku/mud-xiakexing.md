# 参考笔记：侠客行系武侠 MUD 怎么做门派驻地和练功

> 三行总结
> 1. 侠客行系把门派做成「一串有名字的房间 + 每间一两个管事的人 + 门口的门禁」，真正有功能的房间只有七八种：山门、大殿、练功场（木人、桩）、藏经阁、斋厅（伙房）、休息室（睡房）、执事处（掌门、长老）、戒律处；其余大半是路和迷阵。
> 2. 练功的所有路子都靠同一套闸：不能在睡房和安全房练、先看基本功、再看实战经验的三次方上限、再看内力精力的瓶颈；**没有一样东西是白涨的**，这和我们的「有条件有代价、不能速成」同路。
> 3. 门派生活的骨架是「辈分 + 贡献/忠诚 + 门规惩罚 + 叛师代价」；我们能借的是机制的形状（对账、门禁、三关晋升、每日名额），不借的是杀人任务、千次连做的奖励、玩家间仇杀。

写于 10-10。起因：真实玩家说「师门就一个小点，寒酸，能不能有个总部，带点功能，比如练功桩」，负责人补充「每个门派需要有个单独的地图」。本笔记为 `docs/sheji-zhudi.md` 提供参照，不替代它。

## 一、门派驻地的地图布局

### 1.1 少林（侠客行2001 `d/shaolin/`）

全目录近二百个文件，但**有功能的只有三十间上下**，其余是：台阶十一级、竹林十四间、松林十四间、罗汉堂九间、般若堂九间、五行迷阵、暗道、客栈镇子。主轴是一条南北线，两侧挂功能房：

| 房间 | 里面有什么 | 功能 / 门禁 |
|---|---|---|
| 山门殿 → 台阶（碑林东西各一）→ 天王殿 | 守门僧、香客 | 过了山门才算进寺；东西侧殿有杂役僧 |
| 广场（钟楼在东、鼓楼在西） | 香客、僧兵两名、一位清字辈的僧人 | 钟楼七层，每层一间，顶层有个撞钟的小和尚，第一层有扫地僧 |
| 大雄宝殿 | 一位僧人、香客 | **不能打架**，可作下线落脚点 |
| 勤修场、精进场 | 勤修场是空场，精进场有一位僧人、僧兵两名 | 两块广场当「纵深」，勤修场西通斋厅、东北通戒律院，精进场往北是后殿 |
| 斋厅 + 厨房 | 摆好的素斋三四盘、清水葫芦 | 进门就有吃的喝的，不收钱；厨房往里是烧饭僧 |
| 戒律院 | 执法长老一位、僧兵三名 | **不能打架**；非弟子或有案在身的人一进来就被拿下审（见 3.3） |
| 后殿 | 一位僧人 | 可作下线落脚点；往北是练武场 |
| 练武场（三片，东中西） | 每片一个**木人**，十来个僧人在练 | 木人是练功器械（见二、2.5）；东边是僧房 |
| 方丈楼（一楼、茶室、方丈室） | 知客僧 → 茶室僧 → 方丈 | 一层层往里走；**要进方丈室，佛学（buddhism）得到三十**，不够的被茶室僧拦下——拦的是学问，不是身份 |
| 达摩院（练武场三号往北） | 两位老僧 | **双重门槛**：本寺弟子辈分不够的被拦；没通过十八罗汉阵（一场连环比武，通过了身上记一个标记）的也被拦 |
| 罗汉堂 | 九间禅房，老僧入定参禅 | 描写里说不少绝世武功是在这里悟出的，是「高阶武学的来处」，不是闯关处 |
| 藏经阁（一楼、二楼） | 一楼一位老僧、佛经几卷；二楼一位僧、几部武学秘本 | 一楼自由进；**二楼要有推荐信**才让上（被守阁僧拦下） |
| 白衣殿、地藏殿 | 各有一个木人 | 小殿也摆练功器械 |
| 武器库、防具库、药品库 | 一位管库僧 | 门人领装备和伤药的地方，不是给外人逛的 |
| 监狱 | 狱卒、佛经 | 被罚的人关在这里，有时限；也可作下线落脚点 |

**怎么连**：南进北出的单线，两侧是「廊」（走廊房，单纯的连接）。越往里越要资格。所有门禁都用一个思路：**守着的那个人在场，门就拦；他不在场，门就松**（例：武当知客道长不在时，守山门的活被人「趁机溜走」）。

### 1.3 丐帮（侠客行2001 `d/gaibang/` + 扬州树洞；侠客行100 的丐帮更完整）

丐帮**根本没有「一座总部」**，这是它最值得借的地方。侠客行100里是这样的：

- **土地庙**（扬州城边的破庙）：门人的落脚点，有路长老、彭长老、一位大弟子；往东是**蛇园**（五种蛇）、往西是**兽舍**（狐、狼、虎、狮），丐帮人驯养它们。庙里有个入口往下通暗道。
- **暗道** → **林间小屋**：洪七公在这里，屋里放着竹棒、狗肉、酒袋、鸡腿。
- **扬州广场老槐树的树洞**：另一个入口。树洞里有守洞的人，**要对上暗号才开门**，对的是「天堂有路你不走呀」「地狱无门你进来啊」，外人说这句话只会被问「阁下光临敝帮有何贵干」。门开三秒又关上。
- **树洞下**：一个暗道枢纽，**十几条暗道**各通一座分舵，分舵的入口全都是伪装：北京的狗洞、成都的破床底下、福州的大榕树下、泉州铁枪庙下、少林的屋角边、无锡的草堆下、岳阳的井底、星宿海的沙丘小洞、雪山的雪坑小洞。每座分舵地下室有一位当地的头目。
- **青竹林**（七间迷阵）：土地庙往南，外人进去会转晕。
- 丐帮的「家」不在房子里，在**关系和暗号里**。另外丐帮弟子**随地能睡**（别派必须到睡房），是它特殊的身份福利。

### 1.4 衙门和兵营（侠客行2001 `d/city/`；这里不是门派，是官府）

衙门大门（四个衙役）→ 衙门正厅（提督、师爷）→ 东厅、西厅、内宅；旁边是**牢房**；兵营另在西大街，兵营大门（四兵）→ 兵营（武将、四兵、牢房）→ 兵器库。没有练功房、没有睡房，**官府的功能是「差事」**：找提督要工作，就当上**巡捕**，身上挂上名牌，领一份通缉名单去抓人。有门槛：经验够五万；杀人记录多、经验却低的人自己上门「找工作」，会被他按机关掉进牢里，身上东西没收。同时在岗的巡捕有人数上限，满了就说「本府现在不缺人手」。

### 1.5 武馆（侠客行100 `d/wuguan/`）和天鹰教练武场

- **武馆**是扬州城里一座**站满各门各派小弟子的大院**（取个热闹）：武馆大门（两个门卫）→ 大院（两进）→ 大厅；北、南各两片练武场；两间**习武堂**（不能打架，里面是教头）、学堂、书房、账房、饭厅、物品房、休息室（睡房）、厨房、马房、柴房、水房、菜地、后院。教头**收学费**才教（收的钱有最低额），而且**经验超过五万的人他不教**：「你的武功应该历练江湖才能再长进，不能埋没在这里了」。
- **天鹰教练武场**（侠客行2001 `d/tianying/lianwuchang.c`）：一句话描写——场上排着木桩和木人，弟子在击打，有人蹲马步；**每月一次比武检查教众进度**。

### 1.6 共同规律（和我们的驻地对照）

1. **层层往里，越里越要资格**：山门（谁都进）→ 广场（谁都进）→ 功能房（看身份）→ 内院（只有门人）→ 最里（只有高辈）。我们的驻地是三五处，缩成三层：门口（外人能看）、练功场与执事处（门人）、住处（门人，进去才算家）。
2. **安全房与练功房分开**：茶室、丹药房、大殿、习武堂、戒律院都「不能打架」；练功场不是睡房，睡房也不能练功。这是个小而重要的规矩：**休息的地方不长功夫，长功夫的地方不能睡觉**。
3. **每间房一两个有名字的人**，而不是十来个同质的人。知客、管库、茶童、教头各一位，就够让地方有人气。
4. **器械放在场景里**：木人、竹剑、蒲团、桩，**玩家看得见、摸得着，是场景的一部分**，不是菜单里的一行。
5. **房间自带坐标**：侠客行100 每间房写了 `coor/x`、`coor/y`、`coor/z`，地图靠这个排，与我们的 `map` 字段同构。
6. **无关的路与迷阵占了大半**：我们不学。手机上走五步到练功房是折磨，三五处场景一屏看完才对。

## 二、练功的方式

先说共同点：**所有练功命令的头几行都是同一组闸门**：不能在睡房、不能在「不能打架」的房间、不能在忙、不能在战斗中、不能骑着马。这些闸门是**位置和状态的条件**，不是数值。数值上限另有一层。

| 命令 | 做什么 | 消耗 | 上限 / 瓶颈 | 对门人的限制 |
|---|---|---|---|---|
| **练 practice**（`cmds/skill/practice.c`） | 把已经装备（enable）的那门武功练一遍，提高熟练度 | 气和内力（由各武功自己的 `practice_skill` 决定） | **本门武功的等级不得超过基本功的一倍半**（基本功不够就说「火候未到，先打好基础」）；招架不能靠练；一次练多少遍可以重复 | 不分门人外人，只看你学没学会 |
| **学 learn**（`cmds/skill/learn.c`） | 向师父请教，**学得最快** | **潜能**每次扣一点、**精**扣一些（悟性越高扣得越少，第一次学加倍）；**师父也要耗精**，太累就教不了 | 学到的不得超过师父的等级；**武学类的等级三次方除以十不得超过实战经验**（经验不够「怎么也领会不了」） | 必须是师父亲传，或师父愿意收；非嫡传的同门，师父只肯教到自己水平的三分之一以内（侠客行系的通例）；炎黄更严：同门但非嫡传的，一概不教，让你去找自己的师父 |
| **读书 study**（`cmds/skill/study.c`） | 读秘籍、典籍 | **精**，书越难、悟性越低花得越多，最低十点 | 书有**最高可学等级**（高了就是「太浅」）；要先识字；要有最低实战经验；武学类也受三次方上限 | 有些书只给特定的人（例：九阴真经只给「被允许」的人） |
| **打坐 dazuo/exercise**（`cmds/skill/exercise.c` 与 `dazuo.c`） | 练内力 | 每一刻花**气**，换内力；精要在七成以上 | **内力上限有天花板**：和内功等级、根骨挂钩；到顶就提示「瓶颈」；内力满了才涨上限 | 要先选好内功心法（enable）；不分门派 |
| **吐纳 tuna/respirate**（`cmds/skill/respirate.c`） | 练精力 | 花**精**，换精力 | 同样有按内功等级和根骨算的瓶颈；气要在七成以上 | 同上 |
| **睡觉 sleep**（`cmds/std/sleep.c`） | 恢复气、精、精力、内力 | 时间（睡到随机醒） | **睡过一觉后，短时间内再睡恢复变少**（有个「刚睡过」的状态按时间衰减）；某些房间要天黑才让睡 | **非丐帮的人必须在睡房才能睡**；丐帮随地能睡 |
| **打木人**（少林 `d/shaolin/npc/mu-ren.c`） | 与木人切磋 | 同切磋 | **木人把你的技能、属性整套拷过去**，等于跟自己打；**被打若干次就「坏了」**，不让再打 | 不分门人外人 |
| **梅花桩**（峨嵋 `d/em/meihua*.c`） | 上桩走桩，练轻功 | 每走一圈花精和精力 | 要**轻功基本功够三十**才跳得上去（不够摔一跤伤气）；**基本功在三十到一百之间才长**，过了就不长；**只在白天的时辰有效**；要走满七处才算一圈 | 不分门人外人，但在峨嵋的地界 |
| **石碑领悟 lingwu**（全真 `d/zhongnan/wusezhai.c`） | 对着碑文、木人悟一门鞭法 | 要有拂尘，内力精力各三十 | **该武功一百五十以上才能悟，五百封顶**；等级三次方不得超过经验的十倍；**每次只有一成的几率有进步** | 全真的地界 |

### 借什么

- **「学」比「练」快，且耗的是别人的精神**。师父今天教累了就不教，这天然是**一日一次的额度**，与我们的「每日修为额度（`allowance`）」同构。我们的「请教」可以写成：师父每日肯教的次数有限，说「今日乏了，明日再来」。（出处：`learn.c` 对师父精的检查）
- **练功有两道闸：位置（不是睡房、不是安全房）+ 基本功（练的武功不能比基本功高太多）**。我们的「练桩」可以只对「基本功比本门武功高出一截」的人长功夫，这样练桩有天花板，不会越练越溢出。（出处：`practice.c`）
- **器械要有门槛、有时辰、有区间**：梅花桩三个条件齐全才长功夫，这对我们的练桩是现成的模板。（出处：`d/em/meihua1.c`）
- **木人是「你自己的影子」**：属性技能全拷自玩家，所以永远是势均力敌，不会被刷。再加「被打坏」的次数上限，既有练功的手感，又不会成为刷熟练的捷径。（出处：`mu-ren.c`）
- **睡房不长功夫、练功场不能睡**：直接借。

### 不借什么

- **打坐练内力的无限循环**（一直挂着练）：和「变强的速度受限」冲突，我们已有每日额度，不再叠一层。
- **「勤加练习」靠重复指令刷**：一次练若干遍的写法在命令行很合理，在手机上就是狂点按钮。我们的练桩已经是「两个时辰一回、一日一回」，不增加。
- **石碑的百分之十几率**：随机的小进步在手机上是挫败感。我们若做碑，用确定性的「读一遍涨一点，一日一次」。

## 三、门派生活

### 3.1 门派任务（师门任务）

两个仓库各做了一套，**形状一样**：向本门的掌门、长老「要活」，条件不够不给。

- **侠客行100 的四类**（`inherit/char/manager.c`）：取本门失落的**秘籍**、杀本门的**叛徒**（系统造一个拿着本门武功的叛徒放到外面）、拿别派的**奸细**（别派混进来的探子）、杀指定的人。每类有**时限**（叛徒这类限时大约八分钟，叛徒本身二十分钟后自己跑掉）、**限制同时一件**、误了期被师父骂并扣一成气血、做满一轮（十来件）有额外奖励。门槛是实战经验（叛徒要一万以上，秘籍要一千以上）。
- **炎黄的版本**（`adm/daemons/questd.c`、`cmds/usr/quest.c`）：经验不足一万不派；一万到十万只让你**送信**（把信送到某人手里，取回执）；十万以上派**杀人**，要先去**外出历练**（师父说「待你外出历练一段时间后再说」）、阅历够一百；**善恶相冲**的不派（邪派弟子找正派师父领活，被骂一顿）；完成一件**得一点门派贡献**，连续完成多少件有加成，到三十、五十、一百件有额外奖励，**奖励拿贡献换**（贡献够才能领某件东西，答「要」才扣）。
- **取消和失败有代价**：时限内没交差被师父骂；中途取消会让「连续完成」的记录清零（运气好有几率免罚）。

**借**：
1. 「师父分派 + 限时 + 同时一件 + 交差」的框架（我们已有师门差事，对得上）。
2. **「先出去历练，师父才给活」**：门人的经验和阅历没到，师父直接说「你的火候不够，先去闯荡」。这是「有条件」的好写法，且不推着玩家走。（出处：炎黄 `questd.c` 的 `accept_ask` 里「历练」一节）
3. **送信**：低经验的活是送信、取回执，不要杀人。符合金庸风格，也是我们已有的「差事」里最容易写成故事的。

**不借**：
1. **杀人和砍人头的活**（「割下人头回来交差」）：和「恶名/命债」的设计（`docs/decisions.md`）打架，且不是金庸风格的「任务」。
2. **连做上百件的奖励阶梯**：炎黄做到一千件还有奖，这是刷任务；我们的「世界不推着玩家」不要这个。
3. **系统凭空造出一个「叛徒」放到地图任意处**：随机刷怪式的任务，没有人物的来龙去脉。

### 3.2 值守（守山门）

武当的**守山门**是整个仓库里最像「门派日常」的一件事（`kungfu/class/wudang/zhike.c`）：

- 找知客道长要活，他说「守卫一天」；**自愿守也可以，没有报酬**。
- 接了活，身上挂上「山门守卫」的名牌；**必须站在岗上，一次五分钟**，擅自走开就算失败，记一次失败。
- **名额有限**：道长手里同时只有两个名额，满了说「今天的活儿都分派完了」（原版是同时名额，没有按日重置，我们的「每日」是自己改的）；同一人**频繁接活会被换到别的活**（「这两天山门平安无事，你去帮制香道长砍树吧」）。
- **工钱按你的经验分档**：新手只有几两银子，之后随经验涨，发的是真银子，外加一点点经验。
- 值守时**有时（约五次一回）冒出山贼**，守着的人要出手，守得住有一点点经验。
- 武当还有第二件：**制香道长要人砍树**（松、柏），再第三件是敬香；这三个人是同一个小生态。

**借**：「站岗」做成一个**占用时辰**的差事（一个时辰守一回，守的过程中可能来事），每日名额有限，自愿守无报酬但涨「人缘」。
**不借**：现实时间五分钟的守候；失败要靠玩家挂在那里不动。

### 3.3 门规与惩罚：少林的「出入对账」

这是我最想借的一套（`d/shaolin/guangchang1.c` 等，戒律院 `jlyuan.c`，监狱 `jianyu.c`）：

- 弟子离寺时，系统**记下**他当时「杀过多少人」「善恶值多少」。
- 回山门，守门僧**对账**：杀人数没变 → 「师兄辛苦了，请进」；杀人数多了、善恶值掉了 → 记为「有过」，**带去戒律院**；杀人数多了、善恶值反而涨了（做的是惩恶扬善）→ 记为「情有可原」，老僧**训诫一番**放人（「你伤人命乃僧家重罪，下次定不轻饶」）；
- 「有过」的：执法长老喝问，僧兵齐声应「弟子在」，**杖责关进监狱**，监狱里有**带时限的状态**（原文设成六十个单位，折合多久我没查），时限内醒来就在牢里，**不是死，是被关**。
- 擅闯禁地（护法松林）也同样被拿下。

武当的做法更轻：**非门人在要地被拦住说一句**，不动手。

**借**：驻地的门口有一个「对账」的人，回山时核一下你离开期间的恶名、命债变化，**分档给口气**——没事、训诫、关起来（一个时辰到半天，不是死刑）。这和我们已定的「恶名能洗、命债不能」配得上，而且是**门派真有规矩**的最直观表现。
**不借**：杖责昏过去之类的惩罚动画；监狱里无法行动的长时限（手机上的卡死感）。

### 3.4 叛师

三个仓库的规矩一脉相承，**代价逐层加重**：

| 做法 | 侠客行2001 | 侠客行100 | 炎黄 |
|---|---|---|---|
| 另投别派 | 评价清零、记「叛徒」次数加一（帮助文字说技能折半，但我没在这段代码里找到执行处） | 经验超过一万**不能改投**；改投的人被记「离开过某派」，**那一派以后不收你**；忠诚清零 | 离开要先过掌门，掌门当面**废掉你的武功**才放行 |
| 被逐出（开除） | 技能折半、评价归零，头衔清除 | 同 | 同 |
| 自己退出（向掌门请求） | 少林僧人还俗：向自己的师父求，师父再三确认，逐出师门，发一件布衣（`kungfu/class/shaolin/dao-jue.c`） | 掌门**基本功折半、其余武功全部清除**，昏过去，头衔变成「普通百姓」，**记下你离开过这一派**；经验不到一百万的，掌门只冷笑一句不理 | 师父当面废掉武功（折损多少在 `skill_expell_penalty`，我没细读），再记下离开过这一派；有「转世」特权的人可免 |
| 杀同门 | NPC 厉声说「你我本同门」 | **自动被逐出师门**，忠诚清零 | 玩家互杀同门不影响门派声望 |
| 丐帮特例 | 退帮要在执法长老面前说「接受」，**扣回升袋时加过的经验**（每级一千五乘以级数减一），摘掉布袋 | — | — |

**借**：
1. **「离开过的门派不再收」**：记一个「曾离某派」的标记；这让换门派不是白换的，也让「回头」成为一个故事。
2. **「经验到了一定程度不能改投」**：我们的版本可写成「内门以上改投，先过掌门一关」。
3. **杀同门 = 逐出**：简单、清楚、不需要额外界面。

**不借**：技能折半这类「数值惩罚」（玩家会觉得被罚了一天的功夫）。我们若罚，罚在**位置和人情**上：地位降、贡献清、旧同门见了不理你。

### 3.5 贡献与忠诚

- **侠客行100 的 `family/fealty`（师门忠诚）**：做差事涨；**教绝招时要扣**：每个门派绝招写明要多少忠诚、什么武功多少级、内功多少级、内力多少、**善恶值要正（或要负）**，条件齐全才教，教完扣掉忠诚（`inherit/char/master.c` 的 `teach_perform`）。
- **炎黄的 `gongxian`（门派贡献）**：每件师门任务得一点；兑换师门的物品时扣；退派时清零。
- **武当的「奉献」**（`wudang/offerring`）：以**入门日数（年龄）**为尺子，奉献数低于年龄，制香道长当面训斥（「你疏于敬奉，离被逐出山门不远了」），再高一档是「勤勉奉献，要加强努力」，再高是「尽职，众道长很满意」，最高是「楷模」。**同一个数，四种口气**。杀同门扣奉献。
- **炎黄的 `familyd`**：每个门派一个**声望数**，按天快照；玩家间仇杀会让声望此消彼长；每个门派记一份**仇人簿**（上限百人，满了先去掉最轻的十个），仇人被杀时门派给奖励。

**借**：
1. 我们已有「贡献换功法」（`docs/decisions.md` 10-08），所以**不重复**。
2. **「同一个数，四种口气」**：NPC 的话按贡献/入门日数的比值分档，是零成本的活人感，且是**声口**而不是新数值。
3. **贡献要看人品**：高阶传授除了贡献，还要正邪（善恶值）合格，符合金庸里「名门正派不传恶人」。
4. **门派的仇人簿**：门派记得谁害过它。放在以后，单机里只用「某派对你的态度」一个数就够。

**不借**：门派声望按玩家互杀此消彼长（我们没有玩家间的对抗）。

## 四、让玩家有「家」的感觉的小东西

| 小东西 | 侠客行怎么做 | 我们借不借 |
|---|---|---|
| **伙房 / 斋厅** | 少林斋厅**随便吃**（几盘素斋，清水葫芦）；武当茶室茶点随便吃，**但不许带出门**，被茶童拦下；丐帮有狗肉、鸡腿、酒袋 | **借**：驻地吃饭**不花钱但不带走**（回到「家」的第一个好处就是不用花饭钱）；带出去要拦，写一句声口 |
| **睡觉** | 门人在睡房睡，**男女分房**；睡房不能练功；丐帮随地睡；睡过一觉短时间内恢复变少 | **借**：回师门住不花钱（已定）；**不借**男女分房（手机上多一层麻烦） |
| **药房** | 武当丹药房：门人来领，**一人一种一次（以本次上线计）**，场上同类药太多就不给 | **借**：门人每旬可领一次本门的伤药，量少，不是白送 |
| **同门的话** | NPC 有随机话（武当道长每隔一会儿说一句：香火练制不易、玄岳门是出入门户不可松懈、山门前松林里有人参果……）；**欢迎词按来人身份分档**（本门的「辛苦了」、有道童称号的「继续努力」、善人「欢迎来到武当山」、恶人「满脸杀气，不是来敬香就请回」） | **借**：同一位执事对本门人、路人、恶人三种口气 |
| **门派频道** | `menpai` 频道只发给同门；喊话前缀是门派名，NPC 也会喊「各位同门，有人在这里撒野，大伙儿一起上」（仅作气氛，只有三处代码用） | **借其精神**：单机里变成「执事处的告示」：本门近来出了什么事，一天换一两条 |
| **象征物** | 丐帮**布袋**，一袋到九袋，披在身上，别人一眼看出辈分；每升一级要**亲手绑一只新袋**；退帮要摘。少林**法名**按辈分字改名（入清字辈，名字改成「清×」） | **借**：身份有一个**外显物**（袋、腰牌、法号），在界面上看得见、升级有仪式的一句话 |
| **门匾、碑文** | 房间里挂「藏经阁」木匾、碑林、石碑刻着断云鞭要义，可「看」 | **借**：场景里有可看的物件，一句话 |
| **钟楼、早晚** | 少林钟楼七层有撞钟僧，但**我没找到按时辰撞钟的代码**（只搜了「早课」「晚课」两个词，没有命中；其余没细查）| **我们自己做**：用我们已有的时辰系统做早晚，这是「活的江湖」比他们强的地方 |
| **门派地位的称呼** | 「某派第三十九代弟子」「丐帮五袋弟子」 | 已有「外门、内门、真传」 |
| **晋升的仪式** | 丐帮**青竹令**三关（见下） | 见下一节五条 |

**丐帮升袋的三关**（`kungfu/class/gaibang/promote.h`、`jian.c`），是我在这些仓库里见过**最好的「晋升」设计**：
1. 向执法长老**领一块青竹令**（要有一千以上经验）；
2. **战胜一位同辈的师兄弟**，他在令牌背后签名；
3. **战胜同辈的大师兄**，他也签名；
4. 带着令牌找执法长老，**检查：经验够不够（有公式，每级一个线）、身上布袋还在不在**；够了问「你愿意晋升吗」，答「愿意」才升，**升级加一笔经验，退帮扣同一笔**。

## 五、对照我们的原则

| 我们的原则 | 侠客行系做对了的 | 做错了的（我们要避开） |
|---|---|---|
| **活的江湖** | 每间房有名字的人；NPC 对不同身份的人口气不同；欢迎词分档 | 人是站桩的，没有作息（我们有）；钟楼不敲钟 |
| **GTA 式自由** | 非门人也能进外层，只在要地被拦；睡觉、吃饭不强迫 | 任务由系统硬派；连做奖励推着玩家刷 |
| **有条件有代价** | 学艺耗潜能和师父的精；绝招要贡献 + 善恶 + 前置武功；叛师代价逐层加；器械有门槛、有区间 | 个别惩罚是纯数值（技能折半） |
| **金庸风格** | 师徒辈分、推荐信、青竹令、暗号入帮、少林「师兄辛苦了」 | 割人头、杖责三百一类的动画 |
| **手机上好用** | 少数几个器械各司其职 | 迷阵、十几间的竹林、走五步到练功房 |
| **变强的速度受限** | 三次方上限、瓶颈、师父会累、睡后恢复变少 | 打坐、练功靠重复刷；千件任务阶梯 |
| **不能速成** | 学了要练、练了要悟、悟了要有经验，层层闸门 | 个别地方（如炎黄的奖励）可以白给 |

## 六、建议进 `sheji-zhudi.md` 的五条

**1. 驻地门口放一个「对账」的人（山门、执事处），回山时核账，分三档给口气。**
- 内容：门人每次回驻地，门口的人看一眼你**离开期间的恶名和命债有没有变**：没变 →「师兄辛苦了」；变了但是除恶（恶名没涨、命债是恶人）→ 训诫一句放人；变了且是作恶 → 带去见长老，罚一件杂役或关半日（用「几日之内不能练桩、不能领差」表示，不是死）。非门人想进内层，被门口的人拦一句，但**不动手**。
- 出处：侠客行2001 `d/shaolin/guangchang1.c`（离寺前后的杀人记录和善恶记录比对、`guilty` 标记分档）、`d/shaolin/jlyuan.c`（戒律院审问）、`d/shaolin/jianyu.c`（监狱用一个有时限的状态）；武当 `d/wudang/hd_zoulang.c`（非门人被拦）。

**2. 木人做成「你自己的影子」，打若干次就「坏了」，隔日修好。**
- 内容：练功场的木人切磋时，对手拷自玩家当下的武功和体力，所以永远势均力敌；每日可打三到五次，之后「木人被你打坏了，明日再修」。结算沿用我们的切磋：打赢涨熟练（受每日额度限制）、打输掉体力。不同派的「木人」可换壳：丐帮是打狗桩、六扇门是铁尺靶。
- 出处：侠客行2001 `d/shaolin/npc/mu-ren.c`（`accept_fight` 里拷贝技能属性、`fight_times` 累计到一定次数标记 `damaged`）。

**3. 练桩要有门槛、有时辰、有区间（梅花桩三件套），且练功场不是睡房。**
- 内容：①**门槛**：基本功低于某值的人上不了桩，硬上要摔一跤（伤体力）；②**时辰**：只在白天的时辰长功夫，夜里桩照练，只养筋骨不长；③**区间**：本门武功不得超过基本功的一倍半，基本功本身在某区间内才长，过了就不长（避免它成为一直刷的出路）；④练功场、睡房是两个地方，住处练不了功，练功场睡不了觉。这四条一起，把「练桩比自己静修划算两成」的收益收在**有来历的闸门**里，而不是一个孤零零的 1.2 倍。
- 出处：侠客行2001 `d/em/meihua1.c`（跳上桩要轻功三十、只在白天时辰、基本功三十到一百才长、耗精和精力）；`cmds/skill/practice.c`（本门武功不得超过基本功的一倍半；睡房和安全房不能练功）。

**4. 执事处的差事按「每日名额 + 当班不得离岗 + 工钱按火候分档 + 可自愿」来写，低火候只派送信类的活。**
- 内容：执事每日只有两三个名额，满了说「今日的活都分完了」；同一人连着接，执事让他换一桩别的；当班是**占一个时辰的差事**（站岗、巡夜），站岗期间可能来一件小事（路人闹事、山贼探路），能处理好有额外人缘；擅自离岗算失败，记一次；也可以**自愿**去，没有工钱，但涨本门的人缘。工钱和贡献按火候分三档。低火候（新入门）只派送信、跑腿，**师父说「你火候不够，先出去闯荡再说」**，不派杀人、不砍人头。
- 出处：侠客行2001 `kungfu/class/wudang/zhike.c`（`guard`/`volunteer`、同时名额 `stock`、`worker` 记录防连续接活、工钱按经验分档、离岗算失败）；炎黄 `adm/daemons/questd.c`（`accept_ask` 的「历练」门槛、低经验只派送信）。

**5. 晋升要「过人」，不光攒够贡献：学丐帮的青竹令三关，门人身上带一个外显的身份物。**
- 内容：外门→内门→真传，除贡献门槛（已定），还要**赢一位同门（切磋）+ 赢一位同辈的大师兄（切磋）**，两人各在你的凭证上落款，再拿凭证找长老，长老**核贡献、核火候**后问「愿不愿意」，答「愿意」才升；升了是一句仪式（丐帮是加一只布袋，六扇门是换腰牌，少林是改法号）；**退出时同样一笔账要扣回去**。身份物在界面上看得见，别人一眼知道你的辈分。
- 出处：侠客行2001 `kungfu/class/gaibang/promote.h`（两关由同辈NPC考验、令牌上记赢了几场）、`kungfu/class/gaibang/jian.c`（经验线公式、核布袋、说「愿意」才升、加一笔经验，退帮扣回）；少林 `kungfu/class/shaolin/dao.h`（凭推荐信越辈拜师、先得方丈令牌才能挑战）。

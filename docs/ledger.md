# 总账：负责人的需求、游戏的全貌、接下来的顺序

负责人：「今晚的开发比较繁杂，我也给到你非常多的需求和指令，但是我希望你汇总整理归纳，对整个游戏要保持高质量的把控能力，继续创意策划和设计。」

这份总账就是做这件事的。维护者每次开工先读它，每日审查时更新「状态」一栏。

和其他文档的分工：
- 宪章 `charter.md` 管原则；
- 决策 `decisions.md` 管已经定下的事；
- 全景图 `roadmap.md` 管阶段；
- 清道夫 `audit.md` 管每一处是否有意义；
- 本文件把四份串起来，回答三件事：负责人要过什么、游戏现在长什么样、下一步先做哪件。

## 一、五根支柱：每个改动都要服务其中一根

| 支柱 | 一句话 | 落在哪里 |
|---|---|---|
| **成长从江湖上来** | 没有白给的：本事来自实战、指点、准备和历练，闭关只是消化 | 历练（`engine/lilian.ts`）、备战（`engine/beizhan.ts`）、境界伤害、内功成长 |
| **门派是身份也是限制** | 拜谁为师决定你会什么、不能做什么、怎样立足江湖 | 七种打法相克（`docs/menpai.md`）、师承前置（`engine/shicheng.ts`）、立身之道（`docs/lizu.md`） |
| **每件事都有人、有两难、有余味** | 不论大小，不做跑腿、杀怪、送东西 | 宪章 P9，示范见 `caoshangfei.ts`、屠千山的三条路 |
| **世界记得你** | 做过的事留在人物的嘴里、传闻里、说书里 | flag、人情备注、传闻、战后说书、名号 |
| **金庸的文字，点按的手感** | 文笔看齐金庸，全程点按，手机竖屏 | 文风规则（`tests/style-rules.ts`）、D「素白卡片」 |

**改动之前过三道问**：
1. 它服务哪根支柱？哪根都不服务，就不做。
2. 清道夫四问：这是什么、有没有意义、没有它会怎样、改了会不会更好。
3. 能不能让机器查？能，就写进 `tests/`。

## 三、玩家旅程：游戏的全貌与缺口

按玩家的时间线看游戏。每一段写玩家该有的感受、现在靠什么做到、还缺什么。缺口就是创意策划的方向。

| 阶段 | 玩家该有的感受 | 现在靠什么 | 缺口 |
|---|---|---|---|
| **第一刻钟**：序章 | 家破人亡；一个不入流的渔家少年；心里留下一剑「断水」的念想 | 序章、童年三忆（定根基）、两场剧本战 | 基本够了 |
| **第一个时辰**：初到扬州 | 江湖很大，自己很弱，处处有事 | 扬州十个地点、六件事；了尘的劝诫；单挑屠千山必败 | 地方太少，走完就空了 → **路遇、地图铺开**（进行中） |
| **第一天**：渡口一剑 | 靠打听、结交、借势，以弱胜强，第一次扬名 | 历练、备战、战后说书、名号 | 银两没什么用处；没有能反复做的营生 → **活计**（悬赏、镖单、漕运） |
| **第一周**：江南道 | 自己挑路：投军、入六扇门、拜师、走镖、跑漕运，每条路立足的方式都不同 | 身份线的入口散在各处（镖局邀请、募兵、六扇门榜文）；立身之道的设计 | **拜师的入口**；身份线框架；六扇门示范 |
| **第一个月**：门派中人 | 门规管着你；本门武功一层层传给你；同门、敌派有恩有怨 | 师承前置引擎；打法相克；对战模拟 | **门派武功还上不了实战**（五个位置、战斗内核）；门派日常与师门任务 |
| **三个月**：宗师 | 一招一式都有来历；名号、恩怨，江湖记得你 | 修为、名号、说书、人情 | 养成节奏模拟（M3）；神兵秘籍谜链（M4）；江湖榜（M6） |

**从这张表看出的两个最大缺口**：
1. **门派还上不了实战**。七十多门武功、平衡模拟都做好了，玩家却一门都学不到，学到了也用不上。这是「门派是身份也是限制」这根支柱的地基。所以五个位置、战斗内核、拜师入口要连着做。
2. **第一周以后没有能长期做的事**。路遇和活计让江湖一直有事；身份线让玩家有长期的去处。

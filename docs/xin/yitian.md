# 一天怎么过（负责人 10-11 答六问，维护者据此定细节）

## 一、负责人定的
| 问 | 答 |
|---|---|
| 时间怎么走 | 做事花时辰；下线后世界也慢慢自己往前走 |
| 一个游戏日多久 | 十几分钟，差不多上线一次就是一天 |
| 吃住 | 「自动花少量钱就可以了，会有一些文字描述，但是不要过多干扰玩家；如果没钱，会影响战力」 |
| 打工 | 「挂机赚钱，消耗时间和体力／精力，过程可能会有事，一些随机的收获或者考验」 |
| 钱 | 紧巴巴的，初期赚钱难 |
| 夜里 | 能做的事和白天不同，风险大收获大；「那时间系统要容易观察和理解」 |

## 二、由此定的细节（维护者）
1. **时间**：一天十二时辰。每个动作先写明要花多久（「约半个时辰」），点了才走。下线后世界按慢速往前走：各人照作息过日子，没人管的事照自己的走向推进；你自己的练功、打工离线打折（`docs/xin/wugong.md`）。回来第一屏只说两件事：你长了什么，镇上谁、哪件事变了。
2. **吃住**：每天自动扣一点嚼用（吃住在草棚最便宜，住小客店贵些、伤好得快），一行字带过，不弹窗。**没钱时**：饿着肚子，气血和内力上限打折，打架吃亏；人物卡上明写「饿着」和打了几折，不让玩家猜。
3. **精力**：一条每天用、睡觉回的条，打工、练功、读书都耗它（和气血、内力并列，替代北侠的「精」）。
4. **打工就是挂机**：选一处、选多久（一个时辰、半天、到天黑），时间和精力照扣，钱按做完的结算。过程中偶尔遇事：
   - **收获**：多给的赏钱、捡到的东西、听到的一句话、认识一个人；
   - **考验**：有人闹事、有人塞给你东西、要你看见当没看见。遇到考验就停下来让你选，选完接着挂。
   频率不高，一次挂机最多一两件，不打扰。
5. **钱**：开局几十文。一天打工挣的钱，够吃住还能剩一点；一把像样的刀、请郎中治一次重伤，要攒好几天。
6. **夜里**：铺子关门（地图上灰掉），码头有暗船，芦苇滩、土地庙有人，弓兵巡街，亥时后在街上走会被盘问。
7. **时间要一眼看懂**：
   - 顶上常驻时辰和天色（卯时、天亮），一圈刻度显示今天过了多少；
   - 地图上每处标开门时辰，快关门的提前提醒；
   - 天黑后整个界面跟着暗下来，不靠玩家自己算；
   - 人不在时写他什么时候回来（「陆七卯时在院里打拳」）。

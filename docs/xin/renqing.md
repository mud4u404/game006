# 人与人（负责人 10-11 答七问，维护者据此定细节）

> 依据：档案 H02、H03、R01～R03、W02；「世界只能依据真实发生且被知晓的事反应」；「让人物记得一件具体共同经历，比每次见面重复一句好感增加更有分量」；「容貌打开机会，不决定结果」。

## 一、负责人定的
| 问 | 答 |
|---|---|
| 关系怎么给玩家看 | 数字（条）和一句话都给 |
| 分几样 | 信任、敬重、情分、恩怨，分开算 |
| 首版感情线 | 要，淡淡的少年情愫，人选是沈三的女儿 |
| 恩怨记多久 | 分轻重：小过节会淡，大仇记一辈子 |
| 消息怎么传 | 谁看见谁知道，经爱说话的人一点点传开，越传越走样 |
| 镇上的人多主动 | 有事才来找你 |
| 他们之间有没有关系 | 有；得罪一个，他的朋友也会冷淡你 |

## 二、由此定的细节（维护者）
1. **看一个人的关系**：四条小条（信任、敬重、情分、恩怨），一句话（「陆七对你另眼相看，却还不信你」），再列他记得的事，最多三件，用他的口吻（「那夜你替沈三拨开了镣铐」）。
2. **四样怎么动**：信任看你说话算不算数、替不替他守秘密；敬重看你的本事和骨气；情分看一起经历过的事、你待他的好；恩怨看你帮过他、害过他。一件事可以同时让敬重涨、信任跌。
3. **恩怨分轻重**：小过节（顶撞、抢了生意）几天后慢慢淡；大仇（伤了他的人、害了他的亲人）不淡，还会传给他的朋友和同伙。一次救命不一定解开一桩大仇（档案 R03）。
4. **记得的事**：每个要紧的人记着和你有关的具体事件，见面时的态度、话里会带出来；同一句不重复说。
5. **消息**（负责人问：「消息传播跟我有什么关系？」所以它必须落到玩家手里的五样上，落不到的不做：①**藏**：没人看见的事没人知道，玩家会掂量在哪做、何时做；②**扬名**：有人围观，名声才传开，镇上的人待你不同；③**放风**：在茶棚故意说一句假话，让两拨人扑空或撞上；④**打听**：离源头越近越准，花钱问韩嫂是传了几手的，亲眼去看才是真的；⑤**封口**：给钱、吓唬、或他本是你朋友）：每件事记下谁亲眼看见。看见的人照自己的立场说给别人听；韩嫂这类爱说话的人传得快，传一手可能走一点样（「拨开了镣铐」传成「劫了囚车」）。地图上能看到「镇上在传什么」。
6. **有事才来找你**：一个人会在「他记得你的某件事」加上「他眼下需要什么」时主动找你：黑鳅请你喝酒（想要账册），顾老爹病重托付你，陆七某天叫住你。来找你的时候都有理由，一天不超过一两回。
7. **人和人之间**：首版画一张小关系图，例如陆七和韩嫂是旧识，黑鳅和葛彪暗里有往来，顾老爹和陆七年轻时一起撑过船。你对一个人做的事，会按这张图波及他的朋友和对头。
8. **容貌**：只影响第一面的起点（情分、店家的脸色），往后看共同经历。

## 三、感情线：沈蘅
沈三的独女，十五六岁，寄住在私塾先生家，识字，性子倔。那一夜之前她不认得你；那一夜之后，她爹是死是活、是谁害的、你做了什么，决定她第一次看你的眼神：感激、恨，或是将信将疑。往后靠一起经历的事慢慢走近，也可能走远。她有自己的心事和主意，不因为你救过谁、长得好看，就一定喜欢你（档案 R01）。

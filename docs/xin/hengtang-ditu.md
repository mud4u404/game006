# 横塘的地图（第三版，维护者 10-11 定，负责人可改）

> **第三版的收法**（负责人看第二版笑说：「这也太完善了，这个小镇莫非是宇宙中心？」）：按真实的江南水码头小镇收，样样缺一点；首版明面上只开十二处左右，藏着的只留与账册、陆七有关的几处。第二版的完整设想保留在下面，标了「以后」的不进首版。真实感从「缺」里来，缺了才想往外走。

> 负责人 10-11 提了五个关注点：①基础设施完善，有商店、书店、医馆这些公共服务；②有地方打工赚钱、练武功；③两大势力的地盘，和它们交锋的地方；④职业体验，比如镖局、杀手、官府；⑤值得探险解密的地方，解开后出现新地点。另要维护者补「没想到的妙想」。

## 二、按五个关注点

### ① 公共服务（中间地带，谁的人都来）
| 处 | 能做什么 |
|---|---|
| **茶棚** | 吃饭；花钱打听；两边的人都来吃面，是镇上的消息集散处 |
| **客栈** | 住宿（比草棚好，伤好得快，要钱）；来往的江湖人在这落脚 |
| **医馆** | 治伤、买药；郎中收学徒 |
| **书铺** | 买书、租书、学认字；偶尔有人拿旧书来卖（秘籍线索的入口） |
| **杂货铺** | 干粮、油灯、绳索、蓑衣，出门办事的零碎 |
| **铁匠铺** | 买刀剑、修兵器 |
| **当铺** | 当东西、收来路不明的货 |

### ② 打工和练武
| 打工 | 在哪 | 顺带 |
|---|---|---|
| 摆渡 | 横塘渡 | 你的本行；会遇到各色客人 |
| 扛包 | 漕帮码头 | 练膂力；听脚夫闲话 |
| 拉风箱 | 铁匠铺 | 练膂力 |
| 抄书 | 书铺 | 练悟性、识字 |
| 抓药 | 医馆 | 认药，以后会治伤 |
| 跑堂 | 客栈 | 见江湖人，听外面的事 |
| 趟子手 | 镖局 | 跟镖出镇（短线），见真刀真枪 |

| 练武 | 在哪 | 条件 |
|---|---|---|
| 拳、基本功 | 陆七小院 | 他肯教 |
| 刀、棍 | 镖局练武场 | 进了镖局，教头教 |
| 刀、弓 | 巡检司校场 | 当了帮役 |
| 野练、切磋 | 石桥下的空地 | 谁都能去，常有人约架 |
| 站桩、打坐 | 草棚、客栈房里、土地庙 | 有个地方坐下就行 |

### ③ 两大势力的地盘
- **漕帮**：码头、货栈、鱼市。黑鳅的人守着，外人在这里多问一句就有人盯你。
- **官府**：巡检司、校场、榜文墙。弓兵夜里巡街，过了亥时在街上走要被盘问。
- **交锋的地方**：
  - **横塘渡的税卡**：漕帮的船要过，巡检司要查。查多查少，看银子到没到。你天天在这撑船，两边的脸色都看得见。
  - **驿前街**：白天两边的人擦肩而过，互相不搭理；出了事，第一个打起来的地方。
  - **茶棚**：中立，谁也不在这动手，但谁都在这听。
- 地图上用两种底色标出两家的地盘，交锋处画在中间。

### ④ 职业体验（首版能入门的）
| 职业 | 从哪入门 | 体验到什么 |
|---|---|---|
| 船家 | 开局就是 | 摆渡、熟悉水路、两边的秘密都从你船上过 |
| 镖局趟子手 | 镖局 | 押短镖去对岸，路上可能遇劫 |
| 巡检司帮役 | 巡检司 | 查船、巡街、拿人；看见官面上的规矩和不规矩 |
| 漕帮脚夫，后来帮众 | 漕帮码头 | 扛包、跑腿，慢慢被拉进帮里的事 |
| 医馆学徒 | 医馆 | 认药、治伤，救人也能结人情 |
| **杀手**（藏着的） | 当铺的暗柜 | 要先有人引荐。接一单，钱多，后果也重 |

一个人同时只能走一条明面上的路；暗地里的那条（杀手、线人）可以另外有，但被发现就两头不是人。

### ⑤ 探险和解密（解开才出现在地图上）
| 藏着的 | 怎么找到 | 解开后 |
|---|---|---|
| **货栈的暗仓** | 夜里跟踪漕帮的人，或者在码头扛包时多看一眼 | 地图上多出暗仓：私盐就藏在这里，是账册之外的第二件证据 |
| **芦苇滩深处的沉船** | 撑船进芦苇荡，需要水性（天资「水性好」的人更容易） | 沉船里有旧物，牵出一段多年前的事 |
| **土地庙神像后的暗格** | 在庙里过夜时听见响动，或者沈三的话里漏出来的 | 沈三藏过的东西，或者别人藏的 |
| **当铺的暗柜** | 当铺掌柜看你顺眼，或者有人引荐 | 杀手的门路 |
| **石桥桥洞里的刻字** | 撑船从桥下过时，抬头看 | 陆七年轻时的旧事 |

## 三、补充的几个想法
1. **地图会被你改写。** 账册交给巡检司，码头对你关门（地图上码头变成「不欢迎你」）；你把货栈的暗仓捅出去，巡检司来查封，货栈贴上封条，黑鳅的人换了地方。你做过的事，留在地图上。
2. **白天和夜里是两张地图。** 白天铺子开门、码头卸货；夜里铺子灰掉，码头有暗船，芦苇滩有人，土地庙才是人来的时候。
3. **跟着人走，就能找到地方。** 有些地点不靠打听，靠跟踪：跟着黑鳅的人走一夜，地图上就多出他们去的地方。
4. **两面墙，两种声音。** 巡检司的榜文墙贴告示和悬赏，码头的柱子上漕帮贴招工和「规矩」。同一件事，两面墙的说法不一样，看两面墙就知道镇上在斗什么。
5. **江上的点会动。** 漕帮的夜船、巡检司的巡船，在江上是会移动的点，撑船时要避开，或者故意去撞上。
6. **地图边上的远方。** 苏州城、太湖、对岸的镇子，画在边上，写明为什么暂时去不了（要路引、涨水、没有盘缠）。路已经在那里，等以后放开。

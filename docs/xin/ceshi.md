# 武侠测试（维护者 10-11 定，负责人可否决）

> 依据：负责人定「玩家自己定」加「掷三次挑一、宿命感」（`docs/xin/renwu.md`）；档案「开片要有电影感、迅速把人笼罩在武侠气氛中」；原创不照搬。

## 定法
- **七道题**，都是江湖处境，不是性格问卷。每题四个答案，暗中各偏一项：刚猛→膂力、灵动→身法、聪慧→悟性、坚韧→根骨。答案顺序每题打乱。个别答案暗带一点定力。福缘不受测试影响。
- **结果**：一句「你是怎样的人」（例：「你遇事先动手，后动脑」）。答得散的归「中庸」，不偏。分类不拿金庸人物来套。
- **偏的幅度**：主项期望约 24，其余三项分剩下的；掷骰时上下浮动，总数始终 80，每项 10～30。测试定方向，掷骰定命。
- **测试可以重做，掷骰不能。**

## 题目初稿（文字以后按 `docs/wenfeng.md` 再磨）
1. 雨夜渡口，船家不肯开船，身后有人追来。——抢过竹篙自己撑／跳上邻船／跟船家讲条件／伏进芦苇等天亮
2. 师父只肯教你一样。——碎石的硬功／一步三丈的轻功／一本看不懂的拳谱／站桩吐纳
3. 有人当街羞辱你。——当场还手／一笑走开，记下他的样子／一句话把他噎回去／忍了，回去练功
4. 一场明知打不过的架。——拼了／跑／找他的破绽／挨着，等他力竭
5. 你最怕什么。——被人小看／被困住／被人骗／半途而废
6. 得了一笔钱。——买把好刀／买匹快马／买几本书／先存着
7. 有人说你一辈子成不了高手。——打到他改口／不理／问他凭什么／用十年证明

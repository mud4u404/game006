# 武侠测试（维护者 10-11 定，负责人可否决）

> 依据：负责人定「玩家自己定」加「掷三次挑一、宿命感」（`docs/xin/renwu.md`）；负责人 10-11：「无非是测试玩家是那种类型的侠客，只不过问题不要那么傻那么硬，巧妙一点，聪明一点」；档案「开片要有电影感」；原创不照搬。

## 定法
- **场子**：雨天茶棚，邻座相士说你骨相有意思，随口问几件小事。不是问卷，是开场戏。
- **掷三次挑一接在戏里**：相士替你抽三支签，挑一支，就是你的命。
- **问题只问注意到什么、本能怎么做**，不问性格；答案无对错，看不出对应哪项。
- **一个答案可以同时偏几项**（膂力、悟性、根骨、身法，暗带定力）。福缘不受测试影响。
- **结果**：相士一句话（例：「你这副骨头，是挨得住打的」），不报类别名。答得散的不偏。
- **偏的幅度**：主项期望约 24，总数始终 80，每项 10～30；掷签时上下浮动。测试定方向，抽签定命。
- **测试可以重做，抽签不能。**
- 每个答案偏多少，和 Codex 用模拟校，保证没有人人都选的「最优答案」。

## 题目（文字以后按 `docs/wenfeng.md` 再磨）
1. 「伸手给我看看。」——伸左手／伸右手／先缩了一下
2. 邻桌两人争一枚铜钱，你先看到的是——钱上的字／两人的手／谁先撑不住／谁在说谎
3. 雨停，门口一摊积水——跨过去／绕过去／一脚踩进去／站着等它渗下去
4. 常做的梦——在屋顶上奔跑／在水底睁着眼／被压在石头底下／在一屋子书里找不到门
5. 檐下漏水，数到第几滴心烦——不到十／二三十／一百开外／没去数
6. 相士递来的酒里漂着一只小虫——一口喝下／弹掉再喝／放下不喝／问他这是什么意思
7. 「你这一生，是想被很多人记住，还是只想记住一个人？」——不偏天赋，记下来，以后的故事可能用到

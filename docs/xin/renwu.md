# 人物底子（第一版，负责人 10-11 与维护者讨论定）

> 从头开始的第一个问题：人物由什么构成、怎么来。根据：`docs/dangan-1011.md` 第一、三章，北大侠客行一系的经典设定（xkx100 公开源码 `feature/attribute.c`、`adm/daemons/logind.c`）。**借鉴设定结构，不抄代码和文字。** 具体数值先照北侠的比例，以后靠模拟和负责人的手感校。

## 一、已定的

| 项 | 定法 | 谁定 |
|---|---|---|
| 骨架 | 参考北侠的经典设定，按我们的理解改 | 负责人：「为什么不参考北大侠客行现成的经典设定，稍微根据我们的理解优化一下」 |
| 先天四项 | 膂力、悟性、根骨、身法。总点数 80，每项 10～30 | 照北侠 |
| 后天 | 后天 = 先天 + 对应基本功的十分之一（拳脚→膂力、读书识字→悟性、基本内功→根骨、基本轻功→身法），基本功一直有用 | 照北侠 |
| 容貌 | 看得见，与生俱来；要复刻并发扬光大（见第三节） | 负责人：「容貌系统我也觉得很重要……颜值就是正义」 |
| 隐藏的 | 福缘（机缘）、定力（心性稳不稳，抵得住容貌和诱惑）。只这两样 | 负责人：「福缘肯定要」「定力同意加」 |
| 天资 | **核心的一层**，不是点缀。分凡、良、奇、绝四品，品级越高越贵、越少见；掷天命时一起掷出一池候选，用有限的「天资点」挑；挑定不可撤销（细节见第四节） | 负责人：「天资决定是 roll 出来的，且不可撤销……宿命感」「这个相当重要……越高级的天资花费越多」 |
| 怎么来 | 先做**武侠测试**，答案定你是哪一类人（刚猛、灵巧、聪慧、坚韧……），类别决定 80 点往哪边偏；再**掷三次挑一**，挑定不改，「这就是命」 | 负责人提 A、B 两法，维护者建议串起来，负责人同意 |
| 缺陷换点 | 可以收下缺陷（体弱多病、胆小如鼠、天生口吃……）换天资点。同一个「绝」，有人拖着病体换来，有人白白掷到 | 负责人同意 |
| 天资点与福缘 | 福缘高的，开局天资点多一点。福缘是暗的，玩家只觉得「这次运气不错」 | 负责人同意 |
| 角色数 | 每建一个角色掷三次；一个账号最多建三个角色 | 负责人选乙 |
| 次数记在哪 | 记在云账号上，清本地数据不能重掷 | 维护者（技术办法交 Codex） |
| 性别 | 玩家自己选，不掷 | 负责人 |
| 显示 | 属性显示数字。中文评价只用在「看」一个人时：容貌一句（生得眉清目秀）、武学整体一句（武功看来平平） | 负责人 |
| 不要的 | 出身（渡口帮工、药铺学徒……）：「网络小游戏感，过时了」。北侠其余隐藏属性（胆识、灵性、耐力……）不放 | 负责人 |

## 二、每一项都要答得出「能做什么」

规矩：答不出「它让我能做什么、看出什么、扛住什么」的属性，不设。

| 属性 | 打架 | 打架以外 |
|---|---|---|
| 膂力 | 出手重 | 推门拔闩、扛包挣钱、负重 |
| 悟性 | 学招、读谱快 | 识字、学手艺、看出别人的破绽和旧伤（看出来要能接到后续动作上） |
| 根骨 | 气血多、恢复快、内力上限 | 挨打不倒、赶远路、扛伤病 |
| 身法 | 躲得开 | 翻墙、追人、逃跑、偷东西 |
| 容貌 | 对定力低的异性有震慑 | 第一印象、传闻、某些门槛、惹眼的代价 |
| 福缘 | — | 奇遇来不来、险时有没有转机（暗的，玩家只觉得「运气」） |
| 定力 | 不被激怒、不被容貌所动 | 抵诱惑、审问不松口 |

## 三、容貌怎么发扬光大

1. 第一面：店家殷不殷勤、肯不肯多说、讨价还价，异性好感的起点。
2. 江湖记得你：传闻里「那个俊俏的少年」，名声传得快。
3. 有的门派、师父收徒看相貌。
4. 代价：惹眼，难隐姓埋名；招嫉妒，也招不怀好意的人。
5. 会变：重伤破相、衣着打扮和易容暂时改观、年纪。
6. 边界：**容貌打开机会，不决定结果**。NPC 有自己的意愿，喜不喜欢你，还要看共同经历（档案 R01）。

## 四、还没定的（下一步讨论）

- 武侠测试：已定，见 `docs/xin/ceshi.md`。
- 容貌、福缘、定力的范围，是否计入 80 点（倾向：不计入，单独掷）。
- 天资的清单、各品出现的概率、天资点的具体数目。
  - 候选例子（每个都要答得出「能做什么」）：凡（水性好、夜眼、海量）；良（过目不忘、铁骨）；奇（天生神力、百毒难侵、心如止水）；绝（武学奇才、左右互搏、天生异脉：有的武学只有你练得成）。
- 气血、精、内力三样资源要不要照北侠全留。
- 「看」一个人时武学评价的档次说法。

## 五、洞察：不同的人看见不同的东西（负责人 10-11：「这个设计我觉得还不错，可以保留」）
规矩（档案三之 3，「看出来又如何」）：看见的东西必须能接到一个动作或结果上；同样的信息也能靠打听、经历拿到，属性高只是更早、更省事。横塘的样例：
| 谁看得见 | 看见什么 | 能拿来做什么 |
|---|---|---|
| 膂力高 | 扛包时觉得粮包沉得不对 | 知道粮里夹着别的，牵出货栈暗仓 |
| 悟性高 | 沈三说「我没杀人」时眼神不躲，说「我不干净」时躲了 | 判断他哪半句是真；也能看出对手的破绽和旧伤，战斗里接得上 |
| 身法高 | 脚步声里多了一个人 | 发现被跟踪，能甩开或反跟 |
| 定力高 | 白先生客气话里的那一下停顿 | 不被他稳住，留个心眼 |
| 天资「水性好」 | 芦苇滩那片水底下有东西 | 能下水，找到沉船 |
| 天资「夜眼」 | 夜里码头那条船上的人影 | 夜里行动不必点灯 |

## 六、Codex 审查（#642）后定的（维护者 10-11，负责人可否决）
1. **三个终身槽位**：一个账号一辈子最多建三个角色；删角色不返额度；没挑完就退出的，下次接着挑同一组三支签，不重掷。首次抽签前明说次数和不可撤销。
2. **每项能力只有一个来源**：身体能力、基本功的稳定性、具体武学的打法、内力资源分开算，后天加成不重复计；取整和上限的口径由实现时定死，玩家看得见「练了却还没跳」的进度。
3. **天资防独大**：每项天资写清楚能做什么、在什么场合、要什么条件、和哪些不能同时选。高品的确实强，但不能在战斗、成长、生活三方面全面压过其余的。稀有度按整套建角流程（三选一、三个槽）报数，不只报单次概率。
4. **福缘只管开局点数**这一件（以后奇遇另算），不顺手提高高品出现率。
5. **缺陷要真咬人，但不替玩家做决定**：每个缺陷写明何时发作、改变什么、怎么缓解、最多叠几个、返几点。还没有对应玩法的（比如口吃，交涉规则未定）先不放进池子。挑定前可以先试组合，最后一次确认才锁定。
6. **容貌和定力只在有人在场、有相关情境时起作用**（第一面、交涉、某些人），不变成对所有异性的永久战斗加成；先天容貌和当前观感（伤、衣着、易容）分开。
7. **测试**：首次抽签后测试方向冻结；查有没有某个答案在所有目标下都更优；「伸哪只手」这类题要有身体或习惯上说得通的依据。
8. **技术**：沿用同一套云账号登录，新游戏另开自己的表和数据库函数（建角、确认都由服务端做，客户端改不了次数）；新旧存档分开，本机存储用 `xin-` 前缀；正式建角要联网，游客试玩用不占名额的演示角色；新网址 `/game006/xin/`。

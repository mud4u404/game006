# 人物底子（第一版，负责人 10-11 与维护者讨论定）

> 从头开始的第一个问题：人物由什么构成、怎么来。根据：`docs/dangan-1011.md` 第一、三章，北大侠客行一系的经典设定（xkx100 公开源码 `feature/attribute.c`、`adm/daemons/logind.c`）。**借鉴设定结构，不抄代码和文字。** 具体数值先照北侠的比例，以后靠模拟和负责人的手感校。

## 一、已定的

| 项 | 定法 | 谁定 |
|---|---|---|
| 骨架 | 参考北侠的经典设定，按我们的理解改 | 负责人：「为什么不参考北大侠客行现成的经典设定，稍微根据我们的理解优化一下」 |
| 先天四项 | 膂力、悟性、根骨、身法。总点数 80，每项 10～30 | 照北侠 |
| 后天 | 后天 = 先天 + 对应基本功的十分之一（拳脚→膂力、读书识字→悟性、基本内功→根骨、基本轻功→身法），基本功一直有用 | 照北侠 |
| 容貌 | 看得见，与生俱来；要复刻并发扬光大（见第三节） | 负责人：「容貌系统我也觉得很重要……颜值就是正义」 |
| 隐藏的 | 福缘（机缘）、定力（心性稳不稳，抵得住容貌和诱惑）。只这两样 | 负责人：「福缘肯定要」「定力同意加」 |

## 二、每一项都要答得出「能做什么」

规矩：答不出「它让我能做什么、看出什么、扛住什么」的属性，不设。

| 属性 | 打架 | 打架以外 |
|---|---|---|
| 膂力 | 出手重 | 推门拔闩、扛包挣钱、负重 |
| 悟性 | 学招、读谱快 | 识字、学手艺、看出别人的破绽和旧伤（看出来要能接到后续动作上） |
| 根骨 | 气血多、恢复快、内力上限 | 挨打不倒、赶远路、扛伤病 |
| 身法 | 躲得开 | 翻墙、追人、逃跑、偷东西 |
| 容貌 | 对定力低的异性有震慑 | 第一印象、传闻、某些门槛、惹眼的代价 |
| 福缘 | — | 奇遇来不来、险时有没有转机（暗的，玩家只觉得「运气」） |
| 定力 | 不被激怒、不被容貌所动 | 抵诱惑、审问不松口 |

## 三、容貌怎么发扬光大

1. 第一面：店家殷不殷勤、肯不肯多说、讨价还价，异性好感的起点。
2. 江湖记得你：传闻里「那个俊俏的少年」，名声传得快。
3. 有的门派、师父收徒看相貌。
4. 代价：惹眼，难隐姓埋名；招嫉妒，也招不怀好意的人。
5. 会变：重伤破相、衣着打扮和易容暂时改观、年纪。
6. 边界：**容貌打开机会，不决定结果**。NPC 有自己的意愿，喜不喜欢你，还要看共同经历（档案 R01）。

## 四、还没定的（下一步讨论）

- 武侠测试的题目和类别（几类、每类怎么偏）。
- 容貌、福缘、定力的范围，是否计入 80 点（倾向：不计入，单独掷）。
- 天资：①收缺陷（体弱多病、胆小如鼠、天生口吃……）换天资点，加不加；②天资点多少与福缘挂不挂钩；③清单和各品出现的概率。
  - 候选例子（每个都要答得出「能做什么」）：凡（水性好、夜眼、海量）；良（过目不忘、铁骨）；奇（天生神力、百毒难侵、心如止水）；绝（武学奇才、左右互搏、天生异脉：有的武学只有你练得成）。
- 气血、精、内力三样资源要不要照北侠全留。
- 「看」一个人时武学评价的档次说法。

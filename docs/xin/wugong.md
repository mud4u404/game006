# 武功怎么来、怎么长（负责人 10-11 答六问；维护者在北侠骨架上优化）

> 负责人 10-11：「有没有可能不要完全照抄北侠，我们优化一下呢」。骨架参考北侠（档案第九章 M1～M6），改掉手机上成了苦役、玩家看不懂的地方。

## 一、负责人定的
| 问 | 答 |
|---|---|
| 一门入门拳初学到小成，现实多久 | 两三天，每天玩一会儿 |
| 练功、打坐能否离线挂 | 能，但离线效率打折 |
| 拜几个师父 | 一个；改投别派算叛师，有代价 |

| 秘籍、奇遇首版出不出 | 出一两样，很稀有 |
| 生死相搏死了 | 鬼门关走一遭，掉经验和潜能，复活 |

## 二、保留北侠的
- 两层：基本功（基本拳脚、刀法、剑法、内功、轻功、招架、读书识字）＋具体武学；具体武学挂在基本功上，有效等级＝基本功一半＋具体武学。
- 五条路：跟师父学（最快，要师承）、读秘籍（要识字）、自己练熟（慢，耗体力）、打坐（涨内力）、实战（攒经验和潜能）。
- 潜能是学艺的本钱；武功等级受实战经验压着，只苦练练不上天。
- 气血、精神（学和读要耗它）、内力三样资源。
- 一个师门，叛师有代价。
- 境界由有效武功、内力修为、实战经验合成，约十档，看人、战斗共用一个口径（`docs/xin/zhandou.md`）。

## 三、优化的（维护者定，负责人可否决）
| 北侠 | 问题 | 我们 |
|---|---|---|
| 练功敲命令刷几百次，打坐刷屏 | 手机上是苦役 | 定方向就挂着练；在线偶有「喂招」「领悟」点一下；离线打折结算 |
| 潜能、经验黑箱 | 不知道卡在哪 | 变强的路上明说缺什么：实战、师父点拨、内力、识字 |
| 经验压等级，撞上只能干刷 | 卡住无趣 | 瓶颈是事件：真打过几场、见识过某种对手，某一刻想通，破关有演出（档案 G06） |
| 招式升级只换描述加威力 | 门门打起来差不多 | 保留按等级解锁新招，另给每门武学一种性子（刚猛、灵巧、阴柔、沉稳），决定它多出哪种特殊应对（档案 C02） |
| 基本功只是门槛 | 普通功夫无尽头 | 基本功练到极高也有化境（档案 G02） |
| 门派刷贡献换武功 | 师徒成了买卖 | 师父是一段关系：会考你、看你做人、态度会变；贡献照有，肯不肯教不只看数字（档案 G01） |
| 天赋只管学得快慢 | 天资没有宿命感 | 天资与武学相合：某些天资练某些武功特别快，有的武功非某种天资练不成（档案 G05） |
| 死了掉经验潜能，还掉武功 | 一次失手几天白练 | 掉经验和潜能，武功等级不掉 |

|---|---|---|
| 01 | 浅色，街道小地图在主屏 | 人在地图上标「在场」「可找活计」；按钮一主一次 |
| 02 | 人物立绘 | 当前武功「桥头拳 · 初学」带进度和「练拳」；伤处连到身体 |
| 03 | 深色，眼前一幕 | 去处标动作：「可讨教」「可听闻」「可帮工」 |

| 06 | 街巷图 | 已到过、未探索、暂不可达（写明原因）；选了先看描述再「前往」 |

# 门派设计总纲：打法、相克、定位

负责人原话：

> 门派和武功系统绝对不是滥竽充数、换字换皮的把戏，必须是专业策划，严格数值，差异性和平衡性绝佳的产物。我不希望玩家轻易发现什么门派都一样，或者一下子就发现哪个门派最无敌，其它根本无必要，这对游戏都是灭顶之灾。

门派之间的差异分三层：**打法**（怎么打，本文件第二、三节）、**门规**（能学什么，本文件第七节）、**立身之道**（靠什么在江湖上活下去，见 [lizu.md](lizu.md)）。

本文件是所有门派、武功内容的上位设计。`docs/wuxue.md` 管单门武功怎么写，本文件管**门派之间为什么不一样、谁也不能独大**。写武功之前必须先读。

## 一、两条红线

1. **门派之间打法不同**：同样练到出神入化，少林弟子和星宿弟子打起来应当是两种游戏，不能只是招名不同。
2. **没有最强的门派，只有更合适的对手**：每个门派都有打得过的对手、打不过的对手，也有势均力敌的对手。换门派、换搭配是为了应对不同的敌人，而不是为了追某一个「版本答案」。

两条都由机器把关：「打法」由内容检查管，「谁也不能独大」由对战模拟管。

## 二、七种打法与相克环

**打法**就是一套取胜的思路。每种打法有自己的招牌效果，也有天生的软肋。

| 打法 | 怎么赢 | 招牌效果 | 可用效果 | 软肋 |
|---|---|---|---|---|
| **刚猛** | 蓄势一击，打穿对手 | 破绽 `break`、震慑 `fear` | `break` `fear` `rage` | 调息长、耗内力大，没有控制，也不会自保 |
| **浑厚** | 根基扎实，越拖越稳 | 护体 `guard`、疗伤 `heal` | `guard` `heal` `rage` `fear` | 伤害平平，靠时间磨赢 |
| **阴毒** | 下毒放血，慢慢耗死 | 中毒 `poison`、灼烧 `burn`、流血 `bleed` | `poison` `burn` `bleed` `chill` `weaken` | 起效慢，怕对手速战速决 |
| **绵柔** | 借力打力，对手越猛越吃亏 | 卸力 `weaken`、护体 `guard` | `weaken` `guard` `chill` | 主动伤害低 |
| **迅捷** | 快剑连环，身法取胜 | 身法 `haste`、多段连击（`hits` ≥ 2） | `haste` `bleed` `break` | 单下轻，碰上卸力，每一下都被削减；中毒以后身法减半 |
| **擒拿** | 缠、拿、点、锁，让对手出不了手 | 点穴 `busy`、缴械 `disarm` | `busy` `disarm` `chill` `weaken` | 伤害低，定身之后调息很长 |
| **吸纳** | 吸人内力为己用 | 吸内力 `drain` | `drain` `guard` `weaken` | 对内力浅的对手收益低 |

**相克环**：七种打法排成一圈，每种都**克前面两种、被后面两种克**，和剩下两种势均力敌。

```
刚猛 → 浑厚 → 阴毒 → 绵柔 → 迅捷 → 擒拿 → 吸纳 → （回到刚猛）
```

| 打法 | 克 | 理由 | 被克 |
|---|---|---|---|
| 刚猛 | 浑厚、阴毒 | 一击打穿护体，不等毒发就分出胜负 | 擒拿（蓄势时被定住）、吸纳（内力被吸，大招放不出） |
| 浑厚 | 阴毒、绵柔 | 疗伤压过毒伤；对方伤害低，磨不动 | 刚猛、吸纳（内力被吸，护体疗伤失效） |
| 阴毒 | 绵柔、迅捷 | 毒伤不吃卸力和护体；对方单下轻，又没有自保 | 刚猛、浑厚 |
| 绵柔 | 迅捷、擒拿 | 每一下连击都被卸掉；太极粘连专破擒拿 | 浑厚、阴毒 |
| 迅捷 | 擒拿、吸纳 | 身法闪开控制；招式快而省，内力吸不着 | 阴毒、绵柔 |
| 擒拿 | 吸纳、刚猛 | 吸功、蓄势都要时间，一点就断 | 绵柔、迅捷 |
| 吸纳 | 刚猛、浑厚 | 吸干内力，大招和护体都用不出来 | 迅捷、擒拿 |

在打法之外，还有一层**性质相克**：柔克刚、刚克阴、阴克阳、阳克柔（`docs/wuxue.md` 第三节）。所以同一种打法的两个门派，因为性质不同，碰上的对手也不同。

`江湖` 散学是天下流传的寻常功夫，不挂打法：品级最高上品，绝招、杀招、合璧、被动都不带效果，只比真功夫。它是谁都能学的底子，所以不能有招牌，否则人人都去练它，门派就白分了。轻功的身法被动例外。

数一数：刚猛 4、浑厚 3、阴毒 4、绵柔 4、迅捷 4、擒拿 4、吸纳 2。吸纳天下罕见，门槛最高。

## 四、机器怎样把关（`tests/menpai.test.ts`）

定位写在 `src/content/skills.ts` 的 `SCHOOL_STYLE`（由维护者维护）。检查以门派为单位，运行 `npm run menpai` 可以看到每个门派的体检结果。

1. **先定位，后写武功**：门派不在 `SCHOOL_STYLE` 里，就不能写它的武功（江湖散学除外）。
2. **只用本门可用的效果**：一个门派所有武功的绝招、杀招、合璧、被动里出现的效果，必须在「主打法的可用效果」和「副打法的可用效果」的并集里。
   - 例外：轻功的被动可以用身法 `haste`，而且不算招牌。
3. **三连击是迅捷的专长**：主打法、副打法里都没有迅捷的门派，绝招最多两击。
   **蓄势是刚猛的专长**：`charge` 只能用在带刚猛的门派、一击的绝招上。
4. **招牌要立得住**：
   - 主打法的招牌效果，全门派至少出现三次。迅捷的「多段连击」（两击以上的绝招）每个算一次。
   - 副打法的招牌效果，全门派至少出现一次。
   - 主打法的招牌不能比副打法的少，不然主次就颠倒了。
5. **性质**：门派里拳脚、兵刃、内功的性质，至少三分之二要落在性质倾向里。
6. **门派之间不能雷同**：把一个门派的武功里每种效果出现几次（多段连击也算一项）排成一列数，任意两个改造完的门派，这列数的相似度（余弦）不能超过 0.9。主打法相同的门派，要靠副打法和招牌的侧重拉开距离，例如一个多用破绽、一个多用震慑。
7. **江湖散学**：最高上品，不带效果。
8. **师承与前置**（第七节）：
   - 门派武功都要写 `teach`，品级和传授方式对得上；
   - 绝品以上要有同门前置（奇遇武功可以用属性门槛代替）；
   - 内门、真传的武功，顺着前置要能找到本门的入门或外门武功；
   - 有绝招的武功，要有一门上品以下、能给它打底的内功；
   - 前置不能绕成圈、不能比本身品级高，这一条对所有门派（包括待改造的）都是硬性的。

还没改造完的门派列在 `STYLE_PENDING` 里，暂时只提醒、不报错。改造一个，就从名单里删一个，名单清空为止。新门派不许进这个名单。

## 五、相克靠什么成立（战斗规则约定，武学 B 阶段实现）

光有相克表不够：战斗规则里必须有对应的机制，相克才是真的，而不是写在纸上。下面每一条规则都只为一两组相克服务，B 阶段写进 `src/engine/combat.ts`，再由第六节的对战模拟验证。

| 规则 | 内容 | 成就哪组相克 |
|---|---|---|
| 破绽抵护体 | 对手身上的破绽先抵消他的护体，每 1% 破绽抵 2% 护体，抵完剩下的才加伤害 | 刚猛克浑厚 |
| 蓄势 | 刚猛的重手绝招写 `charge: true`（只能是一击）：先蓄势一合，蓄势那一合算进调息，出手时伤害加两成。蓄势时被点穴、缴械，这一招落空，内力照扣。杀招不用蓄势。只有带刚猛的门派能写 | 擒拿克刚猛 |
| 内力见底 | 内力不够，绝招放不出来；内力低于上限的一成半时，内功的被动（护体、回血、怒气）失效 | 吸纳克刚猛、吸纳克浑厚 |
| 毒不吃减伤 | 中毒、灼烧、流血每合掉的血，不受护体、卸力影响 | 阴毒克绵柔 |
| 毒不叠加 | 同一种持续伤害再中一次，取数值大的那个、刷新合数，不叠加 | 防阴毒独大 |
| 疗伤驱毒 | 绝招、杀招里的疗伤，顺带让身上的中毒、灼烧、流血各少两合。被动的每合回血不驱毒，否则带回血内功的门派对毒完全免疫 | 浑厚克阴毒 |
| 毒滞身法 | 中毒或寒气在身时，身法减半 | 阴毒克迅捷 |
| 卸力按击算 | 被卸力的人，伤害先按比例降低，每一击再减去卸力值那么多点 | 绵柔克迅捷 |
| 粘劲 | 被卸力的人施展点穴、缴械，得手的几率减半 | 绵柔克擒拿 |
| 身法闪控 | 身法不光能闪开伤害，也能闪开点穴、缴械（每招只判一次） | 迅捷克擒拿 |
| 解穴免疫 | 穴道解开、兵刃拿回以后，一合之内不会再被点穴、缴械，防止两门武功交替点穴把人锁死 | 防擒拿独大 |
| 吸功要接实 | 吸内力要绝招打中才算，最多吸走对方现有的内力；迅捷、擒拿的绝招本来就省内力，被吸也伤不了根本 | 迅捷克吸纳、擒拿克吸纳 |
| 速战 | 不用专门的规则：毒伤要好几合才见效，刚猛的爆发先分出胜负 | 刚猛克阴毒 |
| 久战 | 打满三十合不分胜负，按剩下的气血比例判输赢，相差不到 2% 算平手。护体最多 50%，叠护体拖时间不是万能打法 | 浑厚克绵柔 |

**通用结算约定**：
- 一招里的效果，只要有一击打中就施加一次，三连击不会上三次流血。
- 身法、护体都有上限（50%）。
- 寒气在身：出手一定落在后面，身法减半（和中毒一样），但不拖慢调息。对战模拟发现「寒气连调息也减半」会让带寒气的门派对谁都赢九成以上，所以不采用。
- 可调的规则参数集中在 `src/engine/combat.ts` 的 `TUNE`，改了要跑 `npm run balance`。

**打法的数值侧写**：同样的预算，不同打法花在不同地方。B 阶段把它写成对战模拟里的配招规则，也作为写绝招时的参考。

| 打法 | 耗内力 | 调息 | 连击 | 特点 |
|---|---|---|---|---|
| 刚猛 | 高 | 长 | 一击 | 单击伤害最高 |
| 浑厚 | 中 | 中 | 一到两击 | 内功被动最强 |
| 阴毒 | 中 | 中 | 一到两击 | 一大半伤害在持续掉血里 |
| 绵柔 | 低 | 中 | 一到两击 | 主动伤害低，靠卸力和护体 |
| 迅捷 | 低 | 短 | 两到三击 | 单击最轻 |
| 擒拿 | 低 | 长 | 一击 | 伤害低，定身之后要调息 |
| 吸纳 | 吸来的补回去 | 中 | 一击 | 越打内力越足 |

**内功的被动**也按打法分：刚猛用怒气 `rage`；浑厚用护体 `guard`、疗伤 `heal`；绵柔、吸纳用护体；迅捷用身法 `haste`（内功的身法算招牌）。阴毒、擒拿暂时没有合适的被动，B 阶段补上专属的被动（例如阴毒的「毒身」：打中你的人自己中毒）。在那之前，这两种打法为主的门派，内功被动从副打法里挑，挑不出就不写。

## 六、对战模拟（武学 B 阶段）

内容检查只能保证「不一样」，保证不了「谁也不能独大」。B 阶段有了战斗模型以后，加一项对战模拟（`tests/balance.test.ts`）：

- **同等投入**：分前、中、后三期，每期规定境界和品级额度。每个门派按第七节的师承规则，配出这一期的最优搭配。
- **对打**：两两对打，固定随机种子，结果可以重现。
- **出招策略**：所有门派用同一个评估器，只是本门招牌效果的权重略高。另做一次「权重全拉平」的复跑，各派胜率变化不超过三个点，证明策略没有偏心。

| 检查 | 标准 |
|---|---|
| 镜像对局 | 同门派对打，胜率 50% ± 3%（证明模拟本身公平） |
| 不能独大 | 中期每派总胜率 40% 到 60% |
| 相克成立 | 按打法汇总，克的一方胜率不低于 56% |
| 没有废门派 | 每派至少有两个胜率过半的对手 |
| 分期有界 | 每一期每派总胜率 35% 到 65%；同一门派后期和前期相差不超过 20 个点 |
| 混搭不独大 | 最优混搭总胜率不超过 60%，而且比同根基的纯修高不出五个百分点 |

- 改造完的门派不少于六个、覆盖四种主打法以后，这些检查才进 CI 硬性把关。在那之前，只出报告。
- 待改造的门派只出报告，不断言。
- 不满足时，先调数值和第五节的规则，不动相克环。
- `npm run balance` 打印完整的胜率矩阵，每对一千场。CI 里每对两百场，二十秒以内跑完。

**实现**：
- 战斗内核在 `src/engine/combat.ts`，第五节每条规则都有单元测试（`tests/combat.test.ts`）。
- 搭配在 `src/engine/build.ts`：同一时期所有门派境界、气血、内力相同，能用哪些武功由 `teach` 决定，奇遇武功按品级分期。
- 对打和矩阵在 `src/engine/sim.ts`。

## 七、师承与前置：门派是一种约束

武侠世界里，门派不只是招式的出处，更是一种约束：拜谁为师、学到哪一层、能不能兼修别派，都有规矩；上乘武功要先打好根基。这些约束本身就是平衡的一部分——它让「把各派最强的武功拼在一起」这条路走不通，门派之间的差异才不会被混搭抹平。

### 1. 一人一师门

- 同一时间只能有一个师门（`S.sect`）。拜师以前，只能练江湖散学和奇遇武功。
- 门内地位：记名弟子 → 外门 → 内门 → 真传。
- **出师**：做到真传、师父点头，所学全部保留，从此不再受门规约束，也不能再向本门学新武功。
- **叛门**：门派追杀；本门武功的境界就此封顶，不能再往上练。

### 2. 门内地位决定传授（`teach`）

| `teach` | 谁能学 | 品级 |
|---|---|---|
| 入门 | 记名弟子以上 | 凡品、良品 |
| 外门 | 外门弟子以上 | 良品、上品 |
| 内门 | 内门弟子以上 | 上品、绝品 |
| 真传 | 真传弟子 | 绝品、神品 |
| 奇遇 | 不靠师门：山洞石壁、前辈遗刻、家传、残谱 | 不限，禁品只能是奇遇 |

江湖散学不写 `teach`，谁都能学。主角的寒江一脉是江伯家传，都算奇遇。

### 3. 前置武学（`requires`、`needAttr`）

- 上乘武功要先把根基练到某一重才能学，写在 `requires` 里，例如：
  - 六脉神剑：一阳指练到登堂入室；
  - 太极剑：太极神功练到炉火纯青；
  - 独孤九剑：华山剑法练到炉火纯青，悟性也要够（`needAttr`）。
- 每派因此形成一棵**武学树**：入门 → 进阶 → 镇派。
- 规则（机器检查）：
  - 绝品以上的武功必须有同门的前置；奇遇武功可以改用属性门槛代替。
  - 前置的品级不能高于本身，不能绕成圈。
  - 内门、真传的武功顺着前置往下找，必须能找到本门的入门或外门武功，树是连通的。

### 4. 内功为根（`roots`）

参照北大侠客行的做法：

- **门派的绝招、杀招、合璧，要用本门内功来使。** 内功换成别派的，这门外功只剩普通招式。
- 有渊源的门派，用 `roots` 写明可以通用的内功 id，例如逍遥、灵鹫宫共用小无相功。
- 少数奇遇武功不挑内功，`roots` 写「任意」，例如独孤九剑「无招胜有招」。这种武功必须有高前置。
- 江湖散学不挑内功。
- **外功的境界，不能比你最高的那门内功高出一重以上。** 到了这一步，熟练度照涨，但突破要等内功跟上；内功一突破，卡住的外功跟着突破，不会白练。
- 因此每个有绝招的门派，都必须有本门的内功，而且要有入门级的，不能只有神品内功。

### 5. 门规的宽严

| 门规 | 在门期间能学什么 | 回报与代价 |
|---|---|---|
| 严 | 只能学本门和江湖散学，别派的奇遇武功也不行 | 回报：同源加成加倍，师父指点涨熟练更快（M10 实现） |
| 宽 | 可以兼修别派（奇遇、他人传授），门规「禁修」的打法除外 | 兼修的别派外功只有普通招式（内功为根） |
| 邪 | 什么都能学 | 恶名、正派追杀；吸来的内力太杂会反噬（日月神教） |

宽严写在 `SCHOOL_STYLE` 的 `discipline`，禁修的打法写在 `forbid`，例如丐帮禁修阴毒、吸纳。

### 6. 品级的天花板

- 每派的顶级武功至少到绝品，没有「先天就弱」的门派。
- 神品只能是真传或奇遇；禁品只能是奇遇，而且门槛和代价都高。
- 前期强、后期强的门派可以有，但由对战模拟按前、中、后三期分别把关。

### 7. 混搭还剩什么空间

- 能混：内功定了根基门派，外功可以带别派的，但只有普通招式；江湖散学、「任意」内功的奇遇武功不受限制。
- 混的代价：绝招、合璧、同源加成都没了；严门弟子根本不能混。
- 所以最优混搭的搜索空间是「一个根基门派 × 别派外功的普通招式 × 江湖散学 × 少数奇遇武功」，对战模拟可以穷举，保证它不压倒纯修。

## 八、写武功时怎么用

1. **先找门派**：在第三节的表里找到这门武功所属的门派，看它的主打法、副打法、招牌。
2. **只用本门可用的效果**：效果要从本门可用的效果里挑。想用别的效果，先在 Issue 里提出来，等维护者调整定位，不要自己绕过去。
3. **每门武功都有自己的分工**：一个门派里的几门武功分工不同，例如一门主攻、一门控制、一门护身，合起来才是这个门派的打法。
4. **数值落在区间里**：见 `docs/wuxue.md` 第五节。调完数值运行 `npm run retune` 看看有没有不合规的。
5. **写完跑体检**：`npm run menpai`，本门派那一栏没有问题才算完成。
6. **写清师承**：每门武功写 `teach`（怎么传授）；绝品以上写 `requires`（前置）；跨门派通用的内功写 `roots`。见第七节。
7. **描写和机制对得上**：写了点穴就要带 `busy`，写了三剑就是三击，写了下毒就要带 `poison`。反过来，机制改了，描写也要跟着改。

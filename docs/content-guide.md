# 内容编写指南

本文写给编写游戏内容的协作者，包括地点、人物、对话、支线、对手和剧情。所有内容都是数据，写在 `src/content/packs/` 下的内容包文件里，不写逻辑代码。

格式的权威定义在 `src/content/types.ts`。可以参考的现成例子：
- `packs/yangzhou.ts`：扬州的地点、人物、对手、第一回任务
- `packs/guazhou.ts`：序章的瓜洲渡
- `packs/prologue.ts`：序章的剧情卡片和剧本战
- `packs/core.ts`：物品和江湖传闻

---

## 一、文风

整体向金庸看齐：白描为主，用动作和细节说话，节奏干净。

| 要 | 不要 |
|---|---|
| 短句，动词有力：「刀光一闪，桌角应声而落。」 | 长串形容词堆砌 |
| 用细节暗示：「伞沿滴水不沾衣」暗示身负武功 | 直接说破：「他武功很高」 |
| 对白贴合身份：船夫说船夫的话，老僧说老僧的话 | 所有人一个腔调 |
| 对白用「」，对白里再引用用『』 | 英文引号 `"` `'`，或中文弯引号 `“”` |
| 数字用中文：三船盐、二十文 | 阿拉伯数字（界面上的数值除外） |
| 符合明代风物：银两论文和两，时辰论辰时、酉时 | 现代词：OK、系统、任务、经验值、技能、玩家 |
| 江湖人的口吻：少侠、客官、施主、阁下 | 网络用语 |

**篇幅参考**
| 内容 | 字数 |
|---|---|
| 场景描写（desc） | 2 到 3 句，60 到 90 字 |
| 观察（look） | 30 到 60 字 |
| 一次对白 | 一般不超过 80 字 |
| 剧情卡片 | 每段不超过 60 字，每张卡片 2 到 5 段 |

**名字**
- 人物名两到三个字，有古意。
- 地名可以用真实的扬州、江南地名。
- **武学以金庸群侠为底**：金庸的武功、门派都可以用，前代侠客的事迹可以写进武功介绍、传闻、典故；但书中人物**不作为 NPC 出场**，测试会检查 NPC 和对手的名字，名单见 `tests/forbidden-names.ts`。

## 二、内容包

每个文件默认导出一个 `ContentPack`，系统会自动收录，不需要改别的文件：

```ts
import type { ContentPack } from '../types';

const pack: ContentPack = {
  rooms: [/* 地点 */],
  npcs: [/* 人物与物品 */],
  foes: [/* 对手 */],
  quests: [/* 任务 */],
  stories: [/* 剧情卡片 */],
  items: [/* 物品 */],
  news: [/* 江湖传闻 */]
};
export default pack;
```

文件名用英文小写，与内容相关，例如 `huafang.ts`、`dongguan-tavern.ts`。

**id 规则**
- 小写英文、数字、下划线，例如 `huafang_genü` 不行，`huafang_singer` 可以。
- 同一类内容里，所有内容包之间不能重名。
- id 一旦发布就不要再改，存档里存的是 id。

## 三、地点（RoomDef）

**新地点先回答清道夫四问**（`docs/audit.md`）：这是什么、有没有意义、没有它会怎样、改了会不会更好。维护者在 Issue 里答好，协作者照着写，PR 描述里抄一遍。答不出「有没有意义」的地点不做，不做空场景。

```ts
{ id: 'yz_fuya', name: '扬州府衙', area: '扬州城', region: 'yz', t: 10, map: [30, 86],
  desc: '朱漆大门两旁蹲着一对石狮，照壁上贴满了告示。两个衙役拄着水火棍，打着哈欠。',
  npcs: ['fuya_yayi'],
  exits: [['东', 'cheng', '西']],      // 第三项「西」：自动给东关街补一条往西回到府衙的出口
  road: '你沿着城墙根往西走，衙门的鼓楼渐渐近了……' }
```

| 字段 | 说明 |
|---|---|
| `region` | 所属区域，地图按区域显示。扬州是 `yz`，瓜洲是 `gz` |
| `t` | 赶路分钟数。两地之间取双方的较大值，常用 5 到 30 |
| `map` | 在地图上的位置，横纵坐标都是百分比，范围 5 到 95。不要和已有地点重叠 |
| `desc` | 可以写成字符串，也可以写成分支列表，见第五节 |
| `npcs`、`objs` | 写 id，或写成 `{ id, if: 条件 }` 表示只在条件成立时出现 |
| `exits` | 出口必须往返相通，测试会检查。新地点连到已有地点时，写上第三项回程方位。方位写一个字，显示在圆圈里：东西南北，也可以是「舟」「岸」「楼」「门」这类 |
| `onEnter` | 进入时触发的分支，常用来开一段剧情 |

## 四、人物与物品（NpcDef）

```ts
{ id: 'fuya_yayi', name: '衙役', ini: '衙', tone: 'blue', brief: '打着哈欠',
  look: '皂衣歪戴，腰牌上的漆掉了一半，一看就是混日子的。',
  verbs: ['交谈', '观察', '打赏'],
  actions: {
    交谈: [
      { if: { flag: 'boss' }, text: '「哟，渡口那位少侠！您找周捕头？在后堂呢。」' },
      { text: '「看什么看？告示在墙上，自己看去。」' }
    ],
    打赏: [
      { if: { silver: 10 }, text: '衙役把铜钱往袖子里一揣，脸色立刻好看了：「少侠有什么吩咐？」（银两 −10 文）',
        do: [{ type: 'silver', delta: -10 }, { type: 'flag', flag: 'yayi_tipped' }] },
      { text: '你摸了摸钱袋，空空如也。' }
    ]
  } }
```

**字段**
| 字段 | 说明 |
|---|---|
| `ini`、`tone` | 头像上的单字和配色，配色可选 red、jade、amber、gray、blue、purple |
| `obj: true` | 表示物品，比如石碑、残棋、门。物品要写 `icon`，可选 stele、go、boat、door |
| `count` | 头像右下角的人数角标，例如三个佩刀汉子 |
| `hint` | 选中时显示在右侧的一句提示；不写时显示 `brief` |
| `altName` | 条件成立后改用另一个名字，例如「青衫书生」报上名字后变成「柳寒舟」 |
| `at` | 把这个人物放进已有地点，例如 `at: { room: 'cheng' }`，也可以加 `if` |
| `service` | 基础服务的标签：`医`（看伤）、`宿`（住店）、`兵`（卖兵器）、`当`（典当）、`杂`（杂货），例如 `service: ['医']`。只是标签，服务本身写在动作里；CI 按它查各地齐不齐、名副其实（见下面「基础服务」） |
| `gift` | 收到杏花等礼物时的反应 |
| `verbs` | 可以点的动作，按显示顺序排列 |

**可用的动作**
- 常用动作：交谈、观察、请教、切磋、赠礼、偷窃、购买、打赏、动手、细看、抓药、推门。
- 也可以自拟两个字的动作名，例如「斗酒」「打听」「求情」「赎身」，写进 `verbs` 和 `actions` 即可。
- 「观察」先显示 `look`。如果写了 `actions.观察`，会在后面接上第一个条件成立的分支，还可以带效果，例如细看出线索时设一个 flag。条件变了，看到的细节也跟着变。
- **带条件的动作**：`verbs` 里的一项可以写成 `{ verb: '求情', if: { flag: 'cangjing_solved' } }`，条件成立才出现这个按钮。真相揭开以后才有的动作，一定要这样写，免得按钮先剧透。
- 地点的 `onEnter` 分支里写的 `text`，会记进见闻；最近几条里已经有同一句的，不会重复记。
- **关系称谓**只用关系阶梯里的词：素不相识、点头之交、相谈甚欢、知交、结拜兄弟、情缘；心存芥蒂、有隙、仇敌；特殊的相依为命、师徒、阴阳两隔（`src/engine/renqing.ts`，CI 检查）。
  - 想写出味道，用 `rel` 效果的 `note`，写一句「为什么记得这个人」，人物页的人情里会显示。例如 `{ type: 'rel', npc: 'liu', value: '相谈甚欢', from: ['素不相识', '点头之交'], note: '湖畔切磋，不打不相识' }`。
  - 人情页只列有意义的人：素不相识、点头之交的人收在「萍水相逢」里。所以值得玩家记住的人，要让关系往上走，或者写进恩怨。
- **根基检定**：根基现在都有实际作用（`src/engine/gengu.ts`）。写检定时按它的本意用：
  - 体魄：斗酒、扛重、熬夜；
  - 根骨：硬扛内伤、运功；
  - 身法：攀爬、追人、脱身；
  - 悟性：看出破绽和线索、解谜；
  - 胆魄：威吓、对峙、劝人。
  - 常人的根基各是二十（上限五十）。**检定看后天**：先天加上武功练出来的（内功长体魄、根骨，轻功长身法，外功长悟性、胆魄，每重两点）。刚到扬州的玩家后天在二十二到二十五之间；门槛定在二十三到二十六算有一点要求，三十以上要练过几重。
  - 先天只有奇遇和剧情里的经历改得了（`{ type: 'attr' }`），一次给两三点，不要多给。
  - 每个检定都要有过不了的那条路，不能卡死。
- **银两口径**：一两等于一千文。日常开销用文（一壶花雕三十文、一顿饭十来文），悬赏、大买卖用两。玩家前期身上一般三十到一百二十文。
- **基础服务**（示范 `packs/jichu.ts`）：医馆、客栈、兵器铺、当铺、杂货铺的人标上 `service`。`tests/content.test.ts`「基础设施」查：扬州五样都有，瓜洲、镇江至少有医馆和客栈；「医」要有治伤（`cure`）或回气血（`heal`）的分支，「宿」要有同时回气血、过时辰的分支，「兵」卖的是兵器（带 `equip`），「当」收东西给钱，「杂」卖东西。
  - 价钱照这个口径：看伤一级一百五十文（三处九级全治一千三百来文），回满气血五十文，金疮药六十文；住店一百文一宿，睡到次日卯时；兵器三百到八百文；当铺死当，给买价的三到五成。小地方可以便宜些。
  - 每个铺子都要有没钱时的回应、没伤时的回应；不卖没有用处的东西。
- 「赠礼」「请教」「切磋」「偷窃」不写 actions 时有默认回应。其他动作必须写。
- 按钮配色：「偷窃」为危险色，「动手」「推门」为醒目的红色，「切磋」为主色。

## 五、分支、条件、效果

几乎所有会变化的文字，都用**分支列表**表达：从上往下，找到第一个条件成立的分支，显示它的 `text`，并按顺序执行它的 `do`。

**最后一个分支必须不带 `if`**，保证玩家无论如何都会得到回应，测试会检查。

### 条件（Cond）

一个条件对象里写的所有项必须同时满足：

| 写法 | 含义 |
|---|---|
| `{ flag: 'boss' }` | 标记 boss 已设置 |
| `{ notFlag: 'paid' }` | 标记 paid 未设置 |
| `{ quest: { id: 'main1', is: 1 } }` | 任务 main1 正好在第 1 阶段 |
| `{ quest: { id: 'main1', atLeast: 2 } }` | 任务进度不小于 2；`below: 2` 表示小于 2 |
| `{ silver: 20 }` | 银两不少于 20 文 |
| `{ item: { id: 'flower' } }` | 身上有杏花；`atLeast: 3` 表示至少 3 枝 |
| `{ noItem: 'jade' }` | 身上没有玉佩 |
| `{ wounded: true }` | 身上有伤（手、足、内息任一处）；`false` 表示没伤。看伤的分支用它分有伤、没伤 |
| `{ tired: true }` | 气血或内力不满；`false` 表示两样都满。调养、喝药这类只回气血的，先写一支 `tired: false` 的「用不着」，免得满血也收钱 |
| `{ rel: { npc: 'liu', is: ['相谈甚欢', '知交'] } }` | 关系在列出的几种之中；`not` 表示不在其中 |
| `{ learned: 'jinghong' }` | 已学会惊鸿剑；`notLearned` 表示没学会 |
| `{ realm: { skill: 'jh_taizu', atLeast: 1 } }` | 某门武功练到第几重（0 起，1 是略有小成）；`below` 表示还没练到 |
| `{ canLearn: 'gb_lianhua' }` | 学得了这门武功：师门、地位、前置、门规都满足。教门派武功的分支必带，见「拜师」 |
| `{ sect: { school: '丐帮', rank: '外门' } }` | 是丐帮弟子，地位不低于外门；不写 rank 只要在门中 |
| `{ noSect: true }` | 眼下没有师门（出过师、叛过门的也算没有）。拜师的分支用它 |
| `{ attr: { key: '体魄', atLeast: 24 } }` | 后天根基不低于某值，例如斗酒看体魄、识破骗局看悟性（常人二十） |
| `{ yue: 'liu_again' }` | 今天是这个约的约期，约还没了结。赴约的那一条分支用它 |
| `{ shenfen: 'biaoshi' }` | 现在的营生是这个身份（游侠 youxia、镖师 biaoshi……），而且没被辞退 |
| `{ job: 'bj_gz' }` | 正在办这件差事（接下了，还没交差） |
| `{ jobOpen: 'bj_gz' }` | 这件差事眼下接得：身份对、手上没有别的差事、上回办完已经隔够了日子。「接」的动作用它 |
| `{ xia: 20 }` / `{ eming: 10 }` | 侠义或恶名不低于某值 |
| `{ hour: { from: 19, to: 5 } }` | 时辰在 19 点到次日 5 点之间，可以跨午夜，常用于入夜才有的事 |
| `{ chapter: 1 }` | 当前在第一回 |
| `{ any: [条件A, 条件B] }` | 满足其中任意一个 |

### 效果（Effect）

| 写法 | 作用 |
|---|---|
| `{ type: 'flag', flag: 'x' }` | 设置标记 |
| `{ type: 'quest', id: 'main1', stage: 2 }` | 设置任务进度。只升不降：已经到了更高阶段时，这条不起作用，所以开启任务的效果可以放心写在会重复触发的地方 |
| `{ type: 'track', id: 'side_x' }` | 把顶部横幅切换成追踪这个任务 |
| `{ type: 'feed', tag: '传闻', text: '……' }` | 在场景卡片里加一条见闻，标签可选：传闻、出关、主线、江湖、突破、收获 |
| `{ type: 'toast', text: '……' }` | 屏幕顶部弹出一句提示 |
| `{ type: 'silver', delta: -20 }` | 增减银两 |
| `{ type: 'item', id: 'jcy', delta: 1 }` | 增减物品 |
| `{ type: 'rel', npc: 'liu', value: '知交', from: ['相谈甚欢'] }` | 改关系；写了 `from` 时，只有当前关系在列表里才改 |
| `{ type: 'prof', skill: 'hanjiang', amount: 50 }` | 增加武功熟练度，满了会自动突破 |
| `{ type: 'lilian', amount: 60 }` | 给历练，闭关时化成功夫。用在高人指点、奇遇、看人比武这类「长见识」的地方；打架、了结任务由引擎自动给，不用另写 |
| `{ type: 'learn', skill: 'jinghong', prof: 120 }` | 习得武功。前置、师门、门规不满足时学不成；门派武功的分支要带 `canLearn`，见「拜师」 |
| `{ type: 'sect', school: '丐帮', rank: '记名' }` | 拜入门派，或在本门升到某个地位（只升不降）；身在别派时不起作用 |
| `{ type: 'leaveSect', how: '出师' }` | 离开师门：出师所学全留；`'叛门'` 本门武功的境界就此封顶。人物页的「师门」写进来历 |
| `{ type: 'attr', key: '悟性', delta: 2 }` | 改先天根基（奇遇、剧情里的经历），一次两三点 |
| `{ type: 'xia', delta: 5 }` | 改侠义 |
| `{ type: 'eming', delta: 5 }` | 改恶名。恶名与侠义是两条独立的值，不互相抵消 |
| `{ type: 'title', value: '渡口一剑' }` | 设置名号 |
| `{ type: 'time', add: 30 }` | 时间往后推 30 分钟；`set: 1110` 表示设为当天 18:30，若已过则到第二天 |
| `{ type: 'weather', value: '大雨' }` | 改天气 |
| `{ type: 'heal', hp: 200 }` | 回复气血；`'full'` 为回满（算歇了一夜，顺带让最重的伤缓一级，住店用它）；`hpAtLeast: 0.4` 表示至少回到四成，`hpAtLeast: 1` 是只回满气血、不碰伤 |
| `{ type: 'cure', levels: 1 }` | 治伤：从最重的那处起，一共减 `levels` 级；不写 `levels` 是全治。治完自动记一条见闻。收钱治伤的分支要带 `if: { wounded: true }`，没伤的另写一句「没伤」（CI 查） |
| `{ type: 'move', to: 'hu' }` | 把玩家移到某处 |
| `{ type: 'news' }` | 随机抽一条江湖传闻写进见闻，文字里可以用 `{news}` 引用 |
| `{ type: 'fight', foe: 'xxx' }` | 开打 |
| `{ type: 'yue', id, npc, at, inDays, text, miss }` | 定约：`npc` 约你 `inDays` 日后在 `at` 见；过了那一日还没了结，执行 `miss`，再生一层心魔。见下面「约」 |
| `{ type: 'yueDone', id }` | 了结一个约（赴约的分支里写） |
| `{ type: 'xinmo', delta: -1 }` | 化解一层心魔（还诺、赔罪、了却一件事）；`delta: 1, why: '…'` 是做了违背信条的事 |
| `{ type: 'shenfen', id: 'biaoshi' }` | 换营生（入伙、赔罪回来），地位从新进做起 |
| `{ type: 'standing', delta: 1 }` | 本行里的地位升降（立功、违了行规）；降到零被辞退，做回游侠 |
| `{ type: 'job', id }` / `{ type: 'jobDone', id }` / `{ type: 'jobFail', id }` | 接差事、交差领钱、差事办砸（地位降一级）。见下面「身份与差事」 |
| `{ type: 'story', id: 'xxx' }` | 打开一段剧情卡片 |

### 文字里的占位符

| 占位符 | 含义 |
|---|---|
| `{given}` | 主角的名，默认「孤舟」 |
| `{name}` | 主角全名，默认「沈孤舟」 |
| `{story}` | 最近一次首领战的战后说书 |
| `{news}` | 本次 `news` 效果抽到的传闻 |

## 六、任务（QuestDef）

```ts
{ id: 'side_huafang', name: '支线 · 画舫夜宴', stages: [
  { title: '打听画舫上的事', to: 'hu' },
  { title: '入夜后登上画舫', to: 'huafang' },
  { title: '画舫夜宴 · 完' }
] }
```

- 阶段从 0 开始。最后一个阶段一般不写 `to`，表示已经完成。
- 推到最后一个阶段时，引擎自动给历练，每个阶段 100。大事、小事不相称时，用 `lilian: 400` 另定。
- 任务靠效果推进：`{ type: 'quest', id, stage }`。
- 要让顶部横幅追踪某个任务，用 `{ type: 'track', id }`。主线进行中时，支线一般不要抢走横幅。

## 七、对手（FoeDef）

对手和玩家是同一种「人」（`src/engine/person.ts`）。**写对手只写档次和路数，不写气血、伤害**：气血、出手、重招的强度都由交手引擎（`src/engine/duel.ts`）算出来，实战和模拟器用同一套。

**档次（`rank`）和路数（`build`）**
| 档次 | 是谁 | 玩家刚到扬州时（练了几天）的胜率 |
|---|---|---|
| `0` 不入流 | 地痞、护院、盐丁、拦路的飞贼 | 五五开到七成（看路数） |
| `1` 三流 | 有点名头的好手、小帮派的头目 | 两成以下 |
| `1.5` | 三流里拔尖的：屠千山 | 一成；备战做满四成 |
| `2` 二流 | 一派里的中坚、黑道上叫得响的 | 打不过，要靠剧情 |
| `3` 一流 / `4` 绝顶 / `5` 宗师 | 一方人物 / 名动江湖 / 一代宗师 | — |

- 档次可以带小数；差一档以内胜负主要看应对，差一档以上会被压着打。
- `build`：`outer` 外功见长（出手重）、`inner` 内功深厚（耐打）、`light` 轻功见长（快、难打中），不写为均衡。
- `weak`（0 到 1）：不是练家子（饿急了的孩子写 0.1）、喝醉了、点到为止的切磋，气血和出手都乘这个数。练家子不写。
- 写完用 **武学试算台**（`npm run dev` 以后打开 `/lab.html`）看胜率：选「套用内容里的对手」，调玩家的搭配和境界，下面直接给出用实战引擎打两百场的胜率。

**重招（`tells`）**
- 每一招写 `dom`：这一招主要是哪一项。`li` 力（沉猛，硬接最难）、`su` 速（快，闪避最难）、`qiao` 巧（变化多，拆招最难）。强度不用写，由档次算。
- 至少两招，主项不同，玩家才有「以己之长」可选。
- 二流以上的对手会使虚招（引擎按档次定），预兆的文字不用分虚实。

**结算（`results`）**
- `win` 必须写；会输的战斗必须写 `lose`；切磋（`spar: true`）建议写上 `yield` 和 `flee`。
- `story: '@compose'` 表示由引擎根据战况生成战后说书，一般只给首领用。
- 奖励标签由 `do` 里的效果自动生成；打完的历练也由引擎按档次自动算。

**胜负以后（`results.win.after`）**：打倒有名有姓的对手，由玩家定他的下场。每条路都要写明后果**在哪里回来**：
```ts
after: {
  plea: '孩子跌坐在泥里，抱着脑袋直哆嗦：「别打了……」',  // 对手倒下以后说的话
  opts: [
    { label: '给他几个铜板', sub: '银两 −10　以后在渡口', if: { silver: 10 },
      say: '你摸出十文钱，丢在他跟前。',                  // 战斗记录里的一句
      title: '十文钱', story: '……',                         // 换掉结算的标题和叙述（可不写）
      do: [{ type: 'flag', flag: 'ly_xiaozei_fed' }],      // 后果
      later: '他说会还你。往后去渡口，留心那双草鞋。' },   // 结算页上的「以后」
    { label: '下杀手', sub: '恶名 +3', say: '……', do: [...], later: '城里会传开这件事。' }
  ]
}
```
- 至少两条路。每条路写下的旗标，**一定要有地方读**：一条路遇（`encounters`）、一句传闻（`news`）、人物的一句话。只写旗标、没人读，玩家就看不到后果。
- `if` 可以让某条路只在条件成立时出现，例如事情已经了结过（`notFlag: 'cw_done'`）就不再有。
- 示范：`luyu-demo.ts` 的小毛贼（三条路各接一条后续）、`chuanwu.ts` 的水鬼（和他身上的「报官、通帮、放过、勒索」是同一件事）、`huafang.ts` 的汪家护院。

**备战（`prep`）**：强敌要给弱小的人留出路。打听底细、找帮手、占地利，每一条写成一项准备：
```ts
prep: [
  { if: { flag: 'tu_scar' }, atk: 0.85, big: 0.85,          // 知彼：对手出手打折，最多八五折
    text: '你记着船夫的话，专往屠千山左边走。',              // 开打时的叙述
    story: '少年早从船夫口中探得他左臂有旧伤。' },           // 战后说书里的一句
  { if: { flag: 'tu_allies' }, text: '……',
    ally: { name: '漕帮', share: 0.25, at: [2, 7, 12],       // 帮手：一共替你打掉两成半气血，在第 2、7、12 合出手
      say: ['盐包后头一声呼哨……', '漕帮管事抡起铁锚链……', '……'] },  // 每次出手的叙述
    win: [{ type: 'flag', flag: 'tu_with_allies' }] }        // 带着这项准备打赢的后果、代价
]
```
- 帮手在战斗里看得见：每次出手是一条单独的记录，结算页的「援手」写明谁来了、打掉几成。
- `share` 在 0.1 到 0.3 之间；一个对手的帮手加起来最多四成半。
- 准备要从内容里挣来（看出破绽、交好某人、侠义够了），每一项都要有代价或后果，不能白拿。示范见 `src/content/packs/yangzhou.ts` 的屠千山。

## 七之一、约

武侠里的时间是用约定标出来的：三月之后嵩山之巅，十年之约。守约就是「信」（docs/foundation.md 第三节第三条）。

- 下线就是静修，现实一个钟头算江湖一日。**静修碰到约期，会在约期那天一早出关**，玩家不会因为下线误了约。
- 约要少：一件事里最多一个，不要做成每天签到。
- 一个约要写三处，CI 会对账（`tests/content.test.ts` 的「约」）：
  1. 定约：`{ type: 'yue', id, npc, at, inDays, text, miss }`。`text` 写约的是什么；`miss` 写失约的后果（关系降一级、一句见闻……）；
  2. 赴约：在那个人的动作里加一条带 `if: { yue: id }` 的分支，写在最前面；
  3. 了结：赴约的分支里写 `{ type: 'yueDone', id }`。守约要有回报，最好是只有守约的人才看得到的东西。
- 失约另外生一层心魔：静修打八折，四十来日才淡；重了会走火。心魔可以用 `{ type: 'xinmo', delta: -1 }` 化解（赔罪、还诺）。
- 示范：`yangzhou.ts` 的柳寒舟。切磋输给他，他约你三日后湖畔再见；守约，他把赢你的那几剑拆给你看，成了知交；失约，他在湖畔等你一整天。

## 七之一之二、身份与差事（JobDef）

钱来自替人办事，不来自打怪（docs/foundation.md 第三节第六、八条）。每件差事都在某个身份之下：游侠揭府衙的悬赏榜，镖师走镖。

- **报酬不写**：由身份和差事的档次算（`engine/shenfen.ts` 的 `jobPay`）。镖师三流一趟一两出头，宗师约九倍；游侠少些，够过日子。难办的差事写 `k`（零点五到二倍）。
- **对手结算里不要再给大笔银两**：钱从差事来。随手打架得的钱，一场不超过一百文。
- **身份的义务就是约**：接下差事，系统替你定一个约（交差的人、地点、几日之内）。过了期限没交差，就是误事：差事作废、地位降一级、生一层心魔。降到零被辞退。
- 一件差事写四处，CI 会对账（`tests/content.test.ts` 的「差事」）：
  1. 差事本身，写进内容包的 `jobs`：`{ id, shenfen, tier, title, npc, at, days, again?, k? }`。`npc` 是交差的人，要在 `at` 这个地点；
  2. 接：发差事的人身上加一个带 `if: { jobOpen: id }` 的动作，分支里写 `{ type: 'job', id }`；
  3. 路上的凶险：一个对手（`fight`），打赢了交差，打输了 `{ type: 'jobFail', id }`；
  4. 交：交差的人身上加一个带 `if: { job: id }` 的动作，或者写在对手的胜利结算里：`{ type: 'jobDone', id }`。
- 交差的人可以只在差事进行时出现：`at: { room: 'gz_town', if: { job: 'bj_gz' } }`（例如押车先到的趟子手）。
- 同一件差事能反复接，路上的人别每次都说一样的话：第一回给个「胜负以后」，放了、送官，下一回走这条路就不一样。
- 示范：`biaoju.ts`。威远镖局（试镖入伙、走瓜洲、走镇江、赔罪回来），府衙的悬赏榜（游侠拿河贼），兵器架上三十两的好刀、房牙子手里二百两的小院（盼头）。

## 七之一之三、根基之眼（EyeDef）

交手以外，每种根基读到不同的东西（docs/foundation.md 第三节第一条）。后天根基够了，场景描写下面、观察人物时，多出一行带根基名的话。

| 根基 | 看得出什么 |
|---|---|
| 悟性 | 话里的破绽、碑文诗句的意思、线索 |
| 胆魄 | 谁色厉内荏，可以压一压；谁在怕什么 |
| 身法 | 能攀、能借力、能跟上的路；谁随时准备跑 |
| 体魄 | 伤势，谁带着伤，谁快撑不住了 |
| 根骨 | 谁是练家子，内力深不深 |

- 写在自己内容包的 `eyes` 里，不必改别人的文件：`{ npc 或 room, attr, atLeast, if?, text, do? }`。
- 门槛：二十五是刚到扬州就可能看得出的（童年选择偏了这一项）；二十九要练上几重；三十三是出类拔萃。常人二十，上限五十。
- **一处至少写两种根基**，偏科的人也总有自己看得出的那一层。只写在关键场面上，不要每个房间都写。CI 会查。
- 写具体的细节（「他左臂总比右臂慢半分，袖口下露出一截发黑的旧疤」），不写「你觉得他不简单」这类空话。
- 看出来的可以是一条路：人物身上的眼可以带 `do`，观察时执行，通常写一个旗标，解锁别处的做法。示范：体魄好的人看得出屠千山左臂有旧伤（写下 `tu_scar`），不必去问船夫，备战照样生效。挂在地点上的眼只是描写，不带效果。
- 示范：`genji-yan.ts`（渡口、瘦西湖畔、大明寺、望江楼、府衙、盐号、茱萸湾、镖局）。

## 七之一之四、拜师（门派）

门派是身份，也是限制（`docs/menpai.md` 第七节）：一人一师门，按门内地位传授（记名 → 外门 → 内门 → 真传），上乘武功有前置，门派的绝招要用本门内功来使，门规分严、宽、邪。规矩由引擎把关（`src/engine/shicheng.ts` 的 `canLearn`），内容只管写人、写事。

写一派的山门，写下面五样。示范见 `src/content/packs/baishi.ts`：丐帮扬州分舵（讨一顿饭入帮）、六扇门（周捕头举荐，教头考校）、军伍（名册画押，什长考校），还有不用拜师的广陵武馆。

1. **拜师的动作**：师父身上一个「拜师」（也可以叫「投效」「投军」）。分支从上往下排：
   - 不收的人先拦下：恶名太高、做过对不起本门的事（读已有的旗标，例如杀过讨饭孩子的人丐帮不收）；
   - 写 `noSect: true` 的分支才往下走，一人一师门。身在别派的，最后那个不带 `if` 的分支正好说清楚；
   - 举荐和门槛写在条件里：任务进度、旗标、侠义、关系。
2. **入门考验**：一场切磋（`spar: true` 的对手，胜利结算里拜入），或者替师门办一件小事（开一个小任务，回来复命时拜入）。照宪章 P9 写：考验本身有两难，至少两种过法，例如根基检定过得去的直接过，过不去的挨一顿打。
3. **拜入**：`{ type: 'sect', school, rank: '记名' }`，同时写一个旗标（「拜师」按钮的条件、传闻读它）。**拜入的那一刻把门规告诉玩家**，再用 `feed` 写进见闻，玩家随时翻得到。门规的宽严看 `SCHOOL_STYLE` 的 `discipline`：严门在门期间只学本门和江湖散学，宽门禁修 `forbid` 里的打法。
4. **传艺**：师父身上的「请教」，**一门武功一个分支**，先内功，再轻功，再外功：
   ```ts
   { if: { sect: { school: '丐帮' }, canLearn: 'gb_lianhua', notLearned: 'gb_lianhua' },
     text: '……', do: [{ type: 'time', add: 120 }, { type: 'learn', skill: 'gb_lianhua', prof: 60 }] },
   ```
   - 教门派武功的分支**必须带 `canLearn`**，地位、前置、门规由它把关；剧情选项里教也一样。对手的结算里没有条件可写，不在那里教门派武功；
   - 都教完了、地位不够的，各写一个分支说清楚还差什么，最后一个不带 `if` 的分支留给外人；
   - **内功为根**：门派的绝招要本门内功来使，入门就要传本门内功，不然弟子的外功只剩普通招式；
   - 学艺花时辰（`time`）。学会的武功，对应的搭配位空着就自动放进去，占着的要玩家自己去武功页换，文字里可以提一句。
5. **升地位**：「考校」之类的动作，条件写清：入门武功练到第几重用 `realm`，侠义用 `xia`，办成过的事用旗标。效果 `{ type: 'sect', school, rank: '外门' }`。条件不够的，分开说缺哪一样。

江湖散学不用拜师：武馆交学费、花时辰就教。分支照样带 `canLearn`，钱不够、底子不够的另写分支（示范：广陵武馆的卢馆主）。

CI 的检查（`tests/menpai.test.ts` 的「拜师」）：
- 内容里拜得进的门派，`teach` 为「入门」的武功每一门都要有地方教；教了带绝招的外功，就要教得到给它打底的内功；
- 门派传授的武功只在带 `canLearn` 的分支、选项里教；
- 从扬州起走一遍：拜师、学入门武功、换上搭配，绝招使得出，交手引擎打得完一场。

要留意的：
- 严门（军伍、六扇门、少林、武当……）的弟子在门期间学不了别派的武功，奇遇也不行。拜入时一定要说。
- 丐帮没有入门的内功（混天气功是上品，外门才传），扬州分舵的记名弟子使不出丐帮的绝招，升了外门才行。
- 镇派绝学（`teach` 为「内门」「真传」的绝品、神品）不在分舵、下院教。

## 七之二、武功（SkillDef）

武功写在内容包的 `skills` 字段里，一个文件一批，例如 `src/content/packs/skills-gaibang.ts`。格式、数值预算、文风和示范都在 **[docs/wuxue.md](wuxue.md)**，写之前必读。

- 文笔看齐金庸，分类和机制参照北大侠客行，鼓励创新。
- 每门武功要有辨识度：性质、绝招效果、杀招演出，至少有一样让人记得住。
- 数值超出品级预算时，`npm run check` 会直接指出超了多少。

## 八、剧情卡片（StoryDef）

用于开场、转折、抉择。每张卡片有标题、几段文字和若干选项：

```ts
{ id: 'huafang_night', cards: [
  { tag: '支线', title: '画舫夜宴',
    paras: ['……', '……'],
    choices: [
      { label: '出手相救', sub: '侠义 +5', do: [{ type: 'xia', delta: 5 }, { type: 'fight', foe: 'huafang_guard' }], next: -1 },
      { label: '袖手旁观', result: '你转过身去。身后的哭声，被丝竹声盖了过去。', next: -1 }
    ] }
] }
```

| 字段 | 说明 |
|---|---|
| `next` | 选完之后去第几张卡片。不写为下一张，写 `-1` 为结束 |
| `result` | 选完后先显示的一段结果，玩家点「继续」后再跳转 |
| `do` 里有 `fight` 或 `story` | 当前剧情会立刻结束，转去战斗或另一段剧情 |
| `sub` | 选项下方的小字，用来提示后果，可以不写 |
| `if` | 条件成立才出现，例如 `{ attr: { key: '悟性', atLeast: 23 } }`、`{ silver: 50 }`、`{ item: { id: 'huadiao' } }`。每张卡片至少留一个不带 `if` 的选项，CI 会查 |

## 八之二、路遇（EncounterDef）

赶路时在路上遇到的事，系统在 `src/engine/encounter.ts`。路遇是江湖「一直有事」的来源，也是反复挣历练的地方。示范见 `src/content/packs/luyu-demo.ts`，写之前先读一遍。

```ts
encounters: [
  { id: 'luyu_maishen', region: ['yz'], to: ['cheng', 'dukou'], once: true, story: 'ly_maishen' },
  { id: 'luyu_tongchuan', region: ['gz'], to: ['gz_kechuan'], once: true, weight: 0.5, if: { hour: { from: 18, to: 6 } }, story: 'ly_tongchuan' }
]
```

| 字段 | 说明 |
|---|---|
| `region` | 走进这些地区的地点时可能遇到 |
| `to` | 只在走进这些地点的路上遇到。不写为地区里任何一段路。地点必须在 `region` 里 |
| `if` | 条件：时辰、侠义、恶名、flag、任务进度…… |
| `weight` | 同时有几条可遇时，按分量抽，默认 1。稀罕的奇遇写小些 |
| `once` | 一生只遇一次。不写的，同一条七天内不再遇 |
| `story` | 遇到时打开的剧情卡片（第八节） |

**引擎的规矩**（写内容时不用管，知道就行）：
- 一段路遇上事的几率是路程分钟数除以 150，最多四成。
- 一趟路最多遇一次；两次路遇之间至少隔两个时辰；序章里不遇。
- 剧情读完后自动接着赶路；路遇里开了打，打完停在原地。

**质量要求**（宪章 P9，和任务一样不能潦草）：
- **人物要有动机**：拦路的孩子是饿的，卖身葬父的姐弟是被盐号逼的。不写「一个山贼跳出来」。
- **选择要有两难和代价**：至少两条路，后果不同。用选项的 `if` 让根基、银两、物品各有用处，比如悟性看出破绽、胆魄吓退对方。
- **世界要记得**：
  - 用 flag 记下玩家的选择；
  - 写带 `if` 的传闻（news）；
  - 需要的话，用另一条 `once` 路遇在别处接上，例如那个孩子后来在渡口的样子。
- **历练上限**：
  - 奇遇（`once`）一条路最多给 200；
  - 能反复遇的最多 40；
  - 打架的历练由引擎自动给，不要另写。
- **命名**：路遇 id 用 `luyu_` 开头，剧情 id 用 `ly_` 开头。

## 九、设计原则

1. **至少两种解法**：手工设计的支线，至少提供两种解决办法，从武力、人情、计谋、银两、潜行里选。不同解法的后果要不同。
2. **后果要持久**：用 `flag`、`rel`、`xia` 记下玩家的选择，让 NPC 之后的回答随之变化。
3. **提示靠世界**：线索通过交谈、观察、传闻、告示交给玩家，不要在文字里直接写「去某某地」。
4. **每个人物都值得点**：至少写交谈和观察，重要人物要随剧情变化给出不同的回答。

## 十、提交前自查


- 分支列表缺少兜底
- 人物没有放进任何地点

# 《炎龙骑士团》系列玩法研究简报

> 本文为本项目的玩法调研笔记，只总结游戏机制，不涉及原作剧情、角色和美术。
> 《烬龙誓约》复刻的是**玩法结构**；世界观、剧情、角色、美术和音乐全部为原创。
> 可信度标注：【确认】= 多源一致；【社区】= 单一攻略/论坛来源；【不确定】= 未查证。

## 系列概览

| 作品 | 年份 | 关键系统 |
|---|---|---|
| 1 代《邪神之封印》 | 1994 DOS | 线性章节；20 级自动转职；HP 由防具决定；魔法在商店购买、按次数使用 |
| 2 代《黄金城之谜》 | 1995 DOS | 关间村庄（旅馆/武器店/道具店/教会）；教会手动转职；道具解锁隐藏职业；隐藏要素极多，被视为系列巅峰【确认】 |
| 外传《风之纹章》 | 1998 DOS | 系统接近 2 代；光明/黑暗两系转职 |

## 已确认的核心机制

- 方格地图，回合顺序为我方阶段 → 敌方阶段，另有第三方 NPC 阶段；每关回合上限 255【确认】
- 地形按百分比修正攻防，例如树林攻击 −5%、防御 +10%；各兵种移动消耗不同；飞行单位无视地形【社区】
- 不能穿越敌方单位，"卡位堵路口"是核心战术【确认】
- 射程由武器决定，部分武器自带射程 +1；受物理攻击时持武器者会反击，空手不能反击【确认】
- 命中约等于攻方 HIT 减守方 EV，敏捷同时影响两者；伤害约为攻击减防御，带小幅浮动；暴击率和毒击率是武器的隐藏属性【确认/社区】
- 本回合未行动的单位按等级回复 HP（"以逸待劳"）；敌人判断"打不动"时放弃攻击、只贴身卡位【确认】
- 攻击时切换到全屏斜视角战斗画面，背景随地形变化；可以关闭战斗动画【确认】
- 经验：每 100 点升一级。按造成伤害占敌方 HP 的比例获得经验，最后一击拿满，并按等级差修正；治疗、辅助也给经验【确认】
- 2 代：20 级以上可在教会手动转职，转职后等级重置；持有特定道具可转为隐藏高级职业【确认】
- 魔法用 MP，按职业和等级自动习得；大多数魔法只能原地施放，移动后不能用；作用范围分单体、十字、大范围【社区】
- 无永久死亡：阵亡者在关间教会付费复活；主角阵亡即失败；可招募角色若在招募关卡阵亡则永久错过【社区】
- 永久属性道具：HP、MP、移动、攻击、防御、敏捷提升【确认】
- 战场宝箱；停在特定格子待机可获得隐藏宝物；部分敌兵会抢走宝箱后逃跑【确认】
- 隐藏角色招募条件可量化（回合数、某人存活、到达某处等）；跨章节收集道具决定是否解锁真结局【确认】
- 关间村庄设施：旅馆（存档）、武器店、道具店、教会；另有需要特殊操作才能打开的秘密商店【确认】

## 《烬龙誓约》的取舍

| 原作机制 | 本作做法 |
|---|---|
| 方格、阶段制、地形百分比攻防、移动消耗、不可穿越敌人（卡位） | 原样保留 |
| 物理反击；空手不能反击；魔法不被反击 | 保留 |
| 未行动者按等级回复 HP | 保留 |
| "打不动就不打"的 AI；伤害可以为 0 | 保留，伤害为 0 时显示"无效" |
| 武器的暴击、毒击、附加法术 | 保留，但在界面上明确显示 |
| 全屏战斗画面 | 在 3D 战场上做镜头特写演出；可选完整、简略、关闭 |
| 教会转职；道具解锁隐藏职业 | 保留。为配合 11 章的篇幅，改为 Lv10 起可转职、每阶段上限 Lv20，"早转还是晚转"的取舍依然存在 |
| 魔法按职业和等级习得；大型魔法只能原地施放 | 保留 |
| 教会付费复活，不设永久死亡；主角阵亡即失败 | 保留 |
| 隐藏宝物格、宝箱、抢宝盗贼、村庄拜访与劫掠 | 保留 |
| 隐藏角色招募；跨章节收集决定真结局 | 保留：收集六片"龙鳞残片"决定结局 |
| 关间村庄（旅馆、武器店、道具店、教会）；秘密商店 | 改为营地，功能相同；秘密商店需要隐藏操作才能打开 |
| 每人 8 格共用背包 | 现代化为：武器、防具、饰品各一格，另加 4 格道具和公共仓库 |
| 连续多场、中间不能补给的战役 | 终章前为连续战役，只提供行军营地（整备与存档） |
| （新增）营火夜话与羁绊 | 增强剧情沉浸感与队伍养成：并肩作战积累羁绊，解锁对话与相邻加成 |

主要来源：中文维基百科与百度百科的系列条目、游民星空和巴哈姆特等攻略站、PTT Dynasty 版、bilibili 专栏（通过搜索摘要查阅）。

# 灵感本

谁有想法都记一笔：负责人、维护者、Codex、协作者、三个审查角色、调研笔记。每日巡视挑最好的三条，变成设计或任务。

每条一行：日期｜来源（谁、出自哪份笔记或哪局试玩）｜想法（一句话）｜对着北极星的哪一点（自主、能力感、影响力、惦记）｜状态（新 / 采纳→#N / 搁置：原因）

## 想法

## 保持灵感的几种做法

1. **从金庸原著倒推**：挑一个名场面（侠客岛腊八粥、聚贤庄、华山论剑、绝情谷），问「玩家要亲身走一遍这一幕，游戏里得有什么」。
2. **玩家故事**：机器玩家和真实玩家身上发生过的有意思的事，记进 `docs/ledger.md`。哪类故事多、哪类没有，就往那个方向加深。
3. **每周一次灵感会**：三个审查角色加 Codex，各提「如果……会怎样」五条，维护者挑三条给负责人一页纸。
4. **调研**：见 `docs/zhishiku/`。没有急活时，协作者从调研任务里领。

## 一、玩家是谁

一个十几岁、身负谜团的少年，从瓜洲渡走进江湖。

- **弱**：一开始不入流，谁都打不过。
- **慢**：功夫靠勤奋和机缘一点点长。走完开篇的剧情，大约三流；二流要下苦功，或者撞上机缘；宗师是几个月以后的事，而且可遇不可求。
- **自由**：拜师学武、投身官府、经营产业、行侠或作恶，都是玩家自己选。
- **被世界推着走**：江湖不等他。势力消长、大事发生，他不出手，事情照样发生。

下面的一切，都要让玩家感到这四件事。

## 二、玩家怎样度过时间：三种玩法

从玩家的角度，时间只分三种：**撞上的**、**去找的**、**放着的**。

### 1. 撞上的：即时随机的机遇挑战

| | |
|---|---|
| 玩家感受 | 「江湖处处有事，说来就来。」没有预告，当场就要决定：出手还是走开，信还是不信，冒险还是退。 |
| 什么时候 | 赶路、进门、夜里、交谈中，随时 |
| 特点 | **只有一次，不能重来**；结果写进世界（人物记得、传闻传开、后来再遇上） |
| 收获 | 历练、人情、侠义或恶名、奇遇的线索；稀有的奇遇给武功 |
| 代价 | 受伤、破财、结仇、错过 |
| 现有系统 | 路遇（已做）；奇遇谜链、江湖事件（要做） |
| 数值要管的 | 每个时辰撞上几次；一条机遇最多给多少；按地区、时辰、侠义恶名、门派调整几率 |

### 2. 去找的：可以反复进行的副本与差事

| | |
|---|---|
| 玩家感受 | 「我知道去哪儿能变强、能挣钱，每次去都不完全一样，越难的给得越多。」 |
| 什么时候 | 玩家自己决定去 |
| 特点 | **能反复做**；目标明确，有难度等级；每次的布局、对手、事件有变化；同一件事做多了收获递减，或者要隔一阵才能再做 |
| 四类 | **师门差事**：巡山、送信、同门切磋、清理门户，换门派贡献，升地位，学武功。<br>**江湖活计**：悬赏缉拿、押镖、漕运，换银两、声望。<br>**秘境副本**：多层的封闭场景，有机关、伏兵、宝物，危险看得出来，每一层都能知难而退，换历练、残谱、材料。<br>**擂台切磋**：和各派好手过招，换历练。 |
| 现有系统 | 切磋、历练的递减（已做）；其余要做 |
| 数值要管的 | 每一类每个时辰给多少；难度和收获的比例；递减和冷却 |

### 3. 放着的：允许挂机的漫长博弈

| | |
|---|---|
| 玩家感受 | 「我做了一个决定，过些天回来看结果。有赚有赔，看我押得准不准。」 |
| 什么时候 | 现实时间流逝，离线也算，但有上限 |
| 特点 | **长线**、**有风险**、**要分配有限的东西**（银子、家将、时间） |
| 四类 | **闭关**：选修哪门、闭多久。时间越长，消化越多，也有走火入魔的风险；按现实时间累积，有上限。<br>**产业**：投银子买份子（船行、茶楼、当铺……），选经营方针，按月分红；会出事，要回来处理。<br>**家将派遣**：派家将去押镖、打探、练功，回来带着收获，也可能带着伤，或者回不来。<br>**门派与势力**：门派贡献、官府职位、江湖声望随时间消长；世界大事按时间推进，玩家站哪一边、投多少，影响结果。 |
| 现有系统 | 闭关（按游戏内天数，要改成现实时间加上限）；其余要做 |
| 数值要管的 | 每现实小时最多长多少（不能速成，宪章 P7）；风险的概率与损失；投入产出比 |

### 4. 三种玩法怎样咬合

```
撞上的（机遇）──给独一份的东西：奇遇武功、人脉、线索、仇家
      │
去找的（副本差事）──给稳定的资源：历练、银两、门派贡献、声望
      │
放着的（挂机博弈）──把资源随时间变成实力和财富：历练→功夫、银两→产业收益、家将→收获
      │
      └──实力和财富又打开更难的副本、更大的博弈、更深的机遇
```

一个都不能少：
- 只有「撞上的」，成长靠运气；
- 只有「去找的」，就成了刷怪；
- 只有「放着的」，就成了挂机。

## 三、数值模型：游戏就是数值

### 1. 一切都换算成「玩家的时间」

所有数值最终回答同一个问题：**玩家花多少时间，得到什么**。先定目标曲线，再反推每一个数。

| 目标 | 认真玩家 | 只做主线 | 只挂机 |
|---|---|---|---|
| 走完开篇剧情 | 约 3 小时，三流 | 约 3 小时，三流 | 不可能（剧情要人走） |
| 二流 | 约 2 周 | 到不了（缺历练） | 到不了（闭关只能消化历练） |
| 一流 | 约 1～2 个月 | — | — |
| 宗师 | 3 个月以上，而且要机缘（奇遇、高人） | — | — |

经济、战斗同理：
- **经济**：前期的少年手头紧巴巴。每小时能挣的，刚够衣食住行加一点积蓄；一处宅子要攒约一周；一份产业约两周。
- **战斗**：同一档次的对手，八到十五合分出胜负；高一档的胜率约八成；高两档基本碾压（设计文档 4.3 节）。

### 2. 数值总表：所有的数只在一个地方

- 新建 `src/content/numbers.ts`，把散在各处的数收进来，按类分好，每个都写单位和含义：
  - **时间**：每个动作的分钟、赶路、一天合多少现实时间；
  - **成长**：每重境界要的熟练、历练的来源和上限、闭关速率；
  - **战斗**：伤害基线、境界系数、气血内力的来源；
  - **经济**：物价、工钱、收入、开销；
  - **机遇**：频率和奖励上限；
  - **副本**：难度和奖励；
  - **挂机**：速率和风险。
- 现在这些数散在 `skills.ts`、`lilian.ts`、`gengu.ts`、`state.ts`、`fight.ts` 写死的随机数、`encounter.ts`、各内容包的对手里，彼此没有对照。改一个，不知道会动到哪里。
- 内容包里的数（对手气血、奖励、价钱）也要落在数值总表定下的档次里，CI 检查。

### 3. 用模拟证明曲线

- **模拟玩家**：写一个不用界面的「玩家」，按几种玩法风格（勤奋、只做主线、只挂机、只刷副本）玩上几十个小时，记下修为、银两、声望随时间怎样长。
- **数值体检进 CI**：上表的目标曲线写成断言，改了任何数，曲线跑偏就不让合并。现在的门派对战模拟，是这套体检的一部分。

## 四、门派武学：三十派，又多又平衡的数学模型

### 1. 难在哪里

门派越多，越容易出两种毛病：
- 有的门派换了个名字，其实一样；
- 有的门派明显最强，大家都去拜它。

三十派两两对打就是四百多对，靠手调不可能，必须有模型。

### 2. 模型的四层

**第一层：单门武功的价值**（已有，要写清楚）
- 一门绝招值多少，换算成「期望伤害当量」：
  - 伤害 × 连击 × 命中；
  - 每种效果折成当量（点穴一合值多少伤害，流血每合值多少……）。
- 效率 = 当量 ÷（耗内力 + 调息的代价）。品级决定效率落在哪个区间。
- 境界线性放大：一重一成。

**第二层：门派的「打法指纹」，用来量差异性**
- 把一派在某一期能用的全部武功，算成一个向量，有九个维度：
  - 爆发、持续输出、控制、削弱、持续伤害、生存、资源（吸内力、省内力）、怒气杀招、身法先手。
- 两派指纹之间的距离就是差异：
  - 任意两派的距离不能小于一个下限，否则就是换皮；
  - 每派在自己的招牌维度上，必须排在所有门派的前列。
- **选新门派也看指纹**：在九维空间里找没人站的位置，新门派站过去。这样加到三十派，每一派都有自己的位置，而不是凭感觉挑名字。

**第三层：强弱，用胜率矩阵拟合每派的「实力值」**
- 对战模拟（已有）打出胜率矩阵。用一个公式拟合：
  - P（甲赢乙）= σ（甲的实力 − 乙的实力 + 相克修正）
  - 由此得到每派一个实力值，和七种打法之间的相克强度。
- 断言：
  - 每派实力值落在一个窄区间里，总胜率约 45% 到 55%；
  - 相克修正要明显，克的一方约 56% 到 60%；
  - 前期、中期、后期分别成立，没有前期无敌或后期独霸的门派；
  - 最优的混搭不比纯修本门强出一个小量。

**第四层：战斗以外的分量**
- 立身之道：特权、帮手、生计、差事、软肋。这些不进战斗平衡，但要让每派的日子过得不一样（见 `docs/lizu.md`）。
- 门规的宽严、禁修，是限制，也是特色。

### 3. 三十派从哪里来

- **现有二十五派**：武功数据和定位已有，十九派由 zcode 改造过一轮。
- **新增至少五派**：用指纹找空位以后定名单。候选：嵩山、衡山、恒山、崆峒、青城、唐门（唐门要先让暗器能上阵）。
- **主角的寒江一脉**：不算在三十派里，是玩家自带的。
- **每派要有**：
  - 一棵完整的武学树：入门、进阶、镇派，前置连成线；
  - 在江南道能拜的引荐人或师父；
  - 师门差事；
  - 从记名到真传的地位台阶。
- **拜得到**：江南道是首发地区，远处的门派用「分舵、下院、云游的长老、引荐信」进入江南道，不用等地图铺到中原。

## 五、剧情：一段完整的开篇，然后世界自己转

- **只做一段完整的剧情**：《寒江旧案 · 开篇》，从瓜洲夜雨到江心废墟，三小时左右。有头有尾：
  - **开头**：家破人亡，身负谜团；
  - **中间**：初入扬州，在剧情里一件件见识江湖：
    - 门派（大明寺、各派弟子）；
    - 帮会（漕帮）；
    - 官府（六扇门）；
    - 绿林（黑风寨）；
    - 江湖规矩（人情、侠义、恶名）；
    - 武学（拜师、历练、闭关）；
  - **结尾**：江心废墟里找到父亲的遗书，第一个问题有了答案，更大的谜团浮出来。
- **剧情的任务**：让玩家理解这个武侠世界，并且把三种玩法都教会。剧情结束时，玩家已经撞上过机遇、做过差事、闭过关。
- **之后**：没有「下一章」等着点。世界按时间运转：势力消长、大事发生。谜团的后续藏在各处，等玩家自己去找：奇遇谜链、线索簿。

## 六、先做什么，后做什么（由上面推出来）

数值是地基，所以先做；门派是负责人最看重的，又最难，所以紧跟着做；三种玩法的系统做好了，内容才有地方放；剧情最后收口，因为它要把前面的系统都教给玩家。

| 阶段 | 做什么 | 怎样算做完（可以量出来的） | 估计 |
|---|---|---|---|
| **一、数值地基** | 数值总表；目标曲线写进 `docs/numbers.md`；模拟玩家；数值体检进 CI | 所有可调的数都在数值总表里；模拟玩家跑出成长、经济曲线，CI 检查 | 2 天 |
| **二、门派武学** | 打法指纹和实力值模型；拜师、地位、传授、师门差事系统；新增五派以上；三十派全部过体检 | 三十派都能拜；任意两派指纹距离达标；实力值、相克、分期、混搭的断言全过 | 4 天（zcode 同时写各派内容） |
| **三、三种玩法** | 机遇：奇遇谜链、江湖事件。副本：秘境、差事、活计、擂台的框架。挂机：闭关改现实时间，产业，家将派遣，势力消长 | 每类至少一个能玩通的示范；模拟玩家的三种风格都有路可走 | 4 天 |
| **四、经济与人生的路** | 衣食住行、宅邸、物价工钱；纸娃娃与道具；官府这条路（六扇门） | 经济曲线达标：前期紧巴巴、宅子约一周、产业约两周 | 2 天 |
| **五、开篇剧情** | 石碑旧事、江心废墟（秘境副本）、线索簿；剧情里教会三种玩法 | 新玩家三小时走完开篇，自然学会三种玩法，到三流 | 2 天 |
| **六、试玩与上线** | 模拟玩家加真人试玩、清道夫大审、调数 | 上一节的曲线全部达标，冒烟和乱点测试通过 | 2 天 |

合计约 16 天，按 10-08 开始算，10-24 前后上线。每个阶段结束交一个 PR，写清「怎样算做完」的每一项有没有做到。

**和已经做完的东西的关系**：
- 武功五个位置、实战接内核（今天的 #90）：是阶段二的一部分，提前做了。
- 历练、路遇、备战、从零练武：是阶段三、阶段一的雏形，会被数值总表收编。
- 已经写好的扬州、瓜洲内容：是开篇剧情的一部分，保留。

**不进上线版**：感情、婚姻；江南道以外的地区；多人。上线后按周更新。

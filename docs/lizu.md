# 立足江湖：门派的立身之道（设计卡）

负责人的点子：

> 不同的门派，立足江湖的方式很可能是不一样的。六扇门是官府中人，他们能够调动官兵，缉拿，关押，本身可能不怎么能打，但是身边有强力保镖。我只是举个例子，抛砖引玉。

门派之间的差异分三层：

1. **打法**：怎么打架，见 `docs/menpai.md` 第二、三节。
2. **门规**：能学什么、不能做什么，见 `docs/menpai.md` 第七节。
3. **立身之道**（本文件）：这一派靠什么在江湖上活下去，能调动什么，平时做什么，怕什么。

前两层决定你**打起来**像谁，第三层决定你**活成**谁。一个六扇门捕快和一个丐帮弟子，在扬州街头遇见同一件事，能做的事完全不同：捕快亮腰牌、调官兵、把人押进大牢；丐帮弟子派小叫花子盯梢，三天后就知道那人睡在哪座破庙。

## 一、立身之道由五样东西组成

| 组成 | 是什么 | 例子 |
|---|---|---|
| **特权** | 只有本门、到了某个地位才能做的动作 | 六扇门「亮腰牌」「缉拿」「搜查」「提审」 |
| **帮手** | 能叫来一起打、一起办事的人或物 | 六扇门的官兵和保镖，丐帮弟子，少林武僧，古墓的玉蜂 |
| **生计** | 怎么挣钱、怎么过日子 | 六扇门俸禄加赏金，丐帮讨饭和卖消息，漕帮跑船分红 |
| **差事** | 本门特有的、能反复做的活儿 | 六扇门缉拿通缉犯，漕帮押船，丐帮打探 |
| **软肋** | 这条路天生的代价 | 六扇门受律法和上司管，不能私刑；恶名高了要丢差事 |

**平衡的原则：强在哪里，就弱在哪里。**
- 单打独斗（擂台、切磋、对战模拟）只比个人武功，帮手不能上场。所以六扇门这样「本身不怎么能打」的门派，在对战模拟里允许落在 40% 到 45% 的低段。
- 帮手只在本门势力范围、办本门差事时才叫得来，而且要付代价：令牌、人情、银两，或者事后的麻烦。
- 门派之间的特权会互相冲突，这正是江湖：漕帮夹带私货，六扇门要搜船；明教被官府通缉，六扇门要拿人；丐帮的消息卖给所有出得起钱的人。

## 三、要做哪些系统

1. **身份与地位**（拜师的最小版本，M10 之前先做）：拜入门派、地位升迁，已在 `docs/menpai.md` 第七节定好数据。
2. **特权动作**：
   - 人物和地点上的按钮，按「你是哪一派、什么地位」出现，复用带条件的按钮（`verbs` 的 `{ verb, if }`，条件 `sect`）；
   - 内容里写清这一派用了特权以后发生什么。
3. **帮手**：
   - 战斗里多一个或几个己方的人，有自己的气血和招式（复用战斗内核的 Kit）；
   - 叫帮手要满足条件、付代价；擂台、切磋、对战模拟不带帮手；
   - 对手也可以有帮手：六扇门的人身边跟着保镖，这才是「本身不怎么能打，但身边有强力保镖」。
4. **生计与差事**：
   - 每派一份「差事簿」，按模板生成能反复做的活儿（`docs/design.md` 的差事系统），报酬是本派的生计；
   - 差事的文字也要有人物、有缘由，不是「杀十只狼」。
5. **门派冲突**：特权之间的冲突写成事件，例如漕帮的私货撞上六扇门的搜查，玩家站在哪一边，两边的人都记着。

## 四、第一步：做一个示范

先把一派从头到尾做透，再铺开。示范选**六扇门**，理由：

- 负责人点了它的名；
- 扬州府衙、周捕头、缉拿草上飞已经在了，是现成的入口。草上飞那一案里，「劝他自首」这条结局，正好可以让他以后成为六扇门的线人；
- 它的特权（缉拿、关押、提审、海捕文书）和帮手（官兵、保镖）最能说明「立身之道」和「单打独斗」不是一回事。

示范的范围：
- 周捕头收你做捕快（记名）；
- 腰牌能盘问、搜查；
- 打败的人可以押进府衙大牢，以后提审出线索；
- 一份海捕文书，三个通缉犯，各有来历；
- 办差时叫得来两个官兵、一个保镖；
- 恶名过高，腰牌被收回。

做完以后，按同样的框架交给协作者，铺到其他门派。

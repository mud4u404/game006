# 第一批设计 001～003：产品目标、体验指标、规则边界

对应 `docs/renwu-100.md` 第 001、002、003 项。后面的设计和开发都以这三页为准；改它们要负责人点头。

---

## 001 产品目标

**一句话**：一部在手机上点着玩的金庸江湖。你从瓜洲渡口一个没钱、没本事、没人认识的渔家少年起步，成长为有能力、有牵挂、能改变一方局面的人。

**玩家从哪里开始**：瓜洲渡口。江伯的渡船、半块玉佩、一根竹篙。第一夜一个独臂镖师求渡，你要定渡不渡；三日后旧债上门，江伯生死未卜（`docs/kaipian.md`）。

**第一版里能过的生活**（一座城、一条河、十二个地点、二十个人、三股势力、两条师承、约十二门真能学到的武功）：

| 生活 | 每天做什么 | 往上走是什么 |
|---|---|---|
| 渡口和码头讨生活 | 撑船、扛包、帮工、跑腿 | 有自己的船、在码头说得上话 |
| 走镖 | 接镖、押运、路上取舍 | 镖师、镖头 |
| 办案（六扇门） | 查访、求证、拘捕或调停 | 捕快、有官身 |
| 拜师（两派选一） | 功课、出力、学艺 | 外门、内门 |
| 追旧事 | 打听、求证、找人 | 江伯下落、寒江旧案的第一层 |

这几样生活共用同一批人、同一条时间、同一份钱和名声；走哪条、走几条，玩家自己定。

**三种乐趣**：自主性（这是我自己选的路）、能力感（以前做不到的事，现在有办法了）、影响力（有人记得我，世界因我而变）。

**第一版怎样算好玩**：
- 玩过半小时，玩家记得一个人，想弄明白一个问题，并且有一个自己决定去做的目标。
- 合上手机时，知道今天办成了什么，也惦记着江湖里的某个人、某件事。
- 隔一天回来，第一屏就有让他想接着玩的东西（熟人怎样了、自己长了什么、有什么变了）。

**第一版不做**：别的城、三十派、多人实时、产业帝国、家将派遣。

## 002 体验指标

每次试玩（真人或试玩助手）都记下面四个观察点和三个数，改了东西再量，变好才算改对。

**四个观察点**（记点击数、游戏内时间、屏幕原文）：

| 观察点 | 什么时候算到了 | 目标 |
|---|---|---|
| 首次自主选择 | 玩家第一次在两条以上都说得通的路里自己挑了一条 | 开局五分钟内（第一夜「渡不渡」） |
| 首次收益 | 第一次靠自己办事拿到钱、人情或本事，而且看得出来 | 十五分钟内 |
| 首次成长 | 第一次看见自己变强了，并在一个熟悉的挑战上感到差别 | 半小时内 |
| 再次回来 | 离开以后回来，第一屏有让他想接着玩的东西 | 每次回来 |

**三个数**：
1. 有意义的决定：平均多少次点击一个（选了会有不同后果的才算）。目标：二十次以内。
2. 无事可做：只能干等、空点、绕圈的次数。目标：一小时零次。
3. 想关掉：试玩者说「想关」的次数和原因。目标：一小时零次。

**怎么量**：试玩助手照固定路线玩（新手、老玩家、只想变强、走镖办案各一条路线），日志写游戏内时间、点击数、屏幕原文；Haiku 汇总成表，和上一次比。

## 003 规则边界

六样最容易让人不痛快、或者被钻空子的事，先把规矩和保护措施定死。

### 时间
- 现实一小时，江湖一日。
- **只限成长，不限行动**（宪章 P7，10-09 改定）：任何时候都能逛、能打、能办事、能挣钱、能歇、能住店、能闭关。只有长修为（消化历练、长功力）受额度管：开局十日，现实每小时添一日，上限二十六日。额度外的闭关日子只养伤、不长修为，结算写明。
- 行动耗时预先写在按钮上（赶路、零工、闭关），实际耗时和预告一致。

### 失败
- 失败要有代价，但不清空积累：差事误了记过（头一回只记一过），丢镖不叠加重伤，输一场的伤按强弱封顶。
- 每个失败都写明为什么、下回怎么补。
- 不在玩家看不见的地方失败：会误约、会失手的，先告诉他。

### 死亡
- **主角不会死**（不做永久死亡）。打输了是重伤、失物、被人救走或被擒；犯了事是追缉、坐牢，可以救、可以花钱、可以越狱（10-09 定）。
- 别的人会死。重要的人死了，是世界真实的后果，写进人物处境和传闻，不可撤回。

### 离线
- 下线就是静修：离开的现实小时算成静修日子，一次最多十六日，受修为额度管。
- 离线时，修炼、养伤、小事照常推进；**会改变关键人物命运的大事，不在玩家离线时结局**：先给预告（见闻簿、传闻、有人来找），留至少一个现实日的介入机会。没赶上的，结局照样发生，回来时有人告诉你。
- 回来先看一页：自己长了什么、熟人怎样了、哪里变了。

### 秘密
- 玩家知道的和世界的真相分开存；界面只显示玩家知道的。
- 导航不剧透：见闻簿写主角心里有数的事，不挂状态签、不报数；秘密不用任务标记带路。
- 谜可以错解，错了给合理的反馈；常见的失误不永久锁死，可以求证或付代价补救。
- 解谜时允许输入答案，这是全程点按的唯一例外。

### 成长
- 成长从江湖上来：实战、了结一件事、高人指点攒历练；闭关把历练消化成功夫；学新武功拿历练换。
- 每一次长进都看得见：升重、升档、习得都有醒目的突破；战力和评语随实际变化。
- 境界有瓶颈，突破要机缘，而且不止一条路（经历、技艺、师长认可）。
- 节奏参考：开篇约三流；二流要下苦功或撞上机缘；宗师三个月上下。是参考，不是硬卡（宪章 P7）。
- 不能速成：同一件事不能反复领好处（悬赏复位、防重复领取、读档不重复结算，见 `docs/fangan.md` 的九条规则）。

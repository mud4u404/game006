# 文风规范

负责人 10-09：「我对文字要求很高，金庸风格的中文武侠世界。」

这份规范由两份全稿文字审查合成（扬州与序章一带、外地门派武功，10-09）。凡是写进游戏的字：地点描写、人物对白、剧情卡、世事、武功介绍、招式、战报、界面说明，都照这里写。写完先自己对一遍第一节的十二条，再跑 `npm run check`（`tests/style-rules.ts` 会拦下一部分）。审查角色见 `.claude/agents/jinyong-bianji.md`。

## 一、十二条

1. **先写说话人，再用「道」引出对白。** 不用「插入式对白」（翻译腔）。
   - 反：「那伤落了根。」他磕了磕烟锅，「他那口刀……」
   - 正：他磕了磕烟锅，又道：「那伤落了根，他那口刀……」
2. **用动作和物件说话，旁白不下判语，段尾不放格言。**
   - 反：帮里的账干净，人不干净——他心里有一杆秤。
   - 正：他的算盘框上缠着一圈红绳；问起来，只说：「记个数。」
3. **「不是 X，是 Y」一个人物只许说一回，一座城不超过三回。** 不用它收尾；看出来的东西直接写成细节。讲武理的可以（「其实不是快，是断」）。
   - 反：这不是学出来的利索，是打小在马背上长出来的。
   - 正：他上马不扶鞍，脚尖一点便上去了，落地的步子还是马背上的步子。
4. **规矩、数值、条件不进人物的嘴，数值归界面。** 一级、略有小成（当数值讲）、学费、经验、任务、属性、贡献多少，人物都不说。
   - 反：「练到略有小成，再攒够一百的贡献，我考校你升外门。」
   - 正：「三样都打熟了，再替我把这几户人家的药送熟了，我再考你。」
5. **用旧白话，不用今人口语。** 不写效率、问题、情况、安全、系统、成功、选择、压力、心态、挺好、够意思、搞定。
   - 反：挺好、今天没空
   - 正：也好、今日没工夫
6. **一类人一副嗓子，每派每人一套话，不填空。** 扬州、镇江人不说京片子（今儿个、您、门儿清）；苏州人话里点一两个吴语字；门派声口见第二节。
   - 反：四家都说「X 不受两家香火」。
   - 正：少林说「佛门不受两家香火」，华山说「剑只认一个主」。
7. **称谓随身份、随亲疏。** 主角是瓜洲渡口打鱼长大的后生：街坊叫「小哥」「江伯家的」；商贾、官面、帮会才叫「公子」「少侠」「客官」。
8. **武打写招、写势、写应变，兵器各有声响，不写光效。** 招式先写身法和对手的反应；比喻三招里最多用一回，不套「如 X……{foe}{part}」的模子。
   - 反：你双掌平推，如排云见日，直直撞在{foe}{part}。
   - 正：你左掌虚引，右掌贴着他小臂滑进去，掌根在{foe}{part}上一吐。
9. **名物、节令合乎明代江南。** 不写晚荷配三月、马褂、价目表、鞠躬；写杏花、缎袍、木牌、作揖。不用近代名句（千里冰封……），不拿成语凑数。
10. **一个比喻、一句套话全项目只用一回，写之前先搜一下。**
    - 反：焦五、过江龙、艄公都「稳得像钉子」。
    - 正：焦五「站在湿跳板上，船晃人不晃」。
11. **标点：** 对白用「」，里层用『』；「——」「……」一段至多两处，能用句号断开就断开。
12. **地方要有地方的声音和东西。** 苏州写评话、弹词、园林、苏绣；镇江写醋、写三怪；瓜洲写鲥鱼汛、写潮；扬州写盐商、运河、早茶。

武功介绍另加两条：写来历和气象，不写门派标签、不写机制（「境界越高越容易闪开」归界面）；一门武功的招名出自一个体系（一阳指按卦象递进、停云剑法全取陶诗）。杀招的题字统一写「· 杀招」。

## 二、门派声口

| 门派 | 声口 | 自称／称人 | 示范一句 | 要避免 |
|---|---|---|---|---|
| 少林 | 禅机：借眼前的东西说理，问多答少 | 老衲／施主 | 长老指了指檐下的铜钟：「你问金钟罩怎么练？它挂在那里三百年了，你去问它。」 | 「我佛慈悲」挂在嘴边 |
| 武当 | 冲和：慢，圆，顺势，不争 | 贫道、老道／居士、小友 | 道长慢慢收了桩：「急什么？江水往东流了几千年，几时见它急过。」 | 合掌、合十 |
| 峨眉 | 清峻：话短，句冷，不容商量 | 贫尼／居士 | 师太眼也不睁：「手上沾过血的，不必开口。」 | 长篇自述身世 |
| 华山 | 剑气：直，硬，有锋芒，有名门的傲 | 老朽、在下／足下 | 先生把剑往鞘里一送：「华山的剑，宁折不弯。要学弯的，去武当。」 | 「机缘」「撞大运」 |
| 桃花岛 | 孤傲：冷嘲俗人，藐视礼法，引经据典又反着用 | 我／你 | 曲蘅头也不抬：「圣贤书上的话，十句有九句是哄笨人的。剩下一句，你也未必听得懂。」 | 讲功德、在乎名声 |
| 铁掌帮 | 江湖气：讲地界、讲账、讲面子，粗而不脏，笑里有刀 | 我、老子／兄弟、某爷 | 雷震山把茶碗一磕：「苏州城的规矩，三成写在府衙的告示上，七成写在我这本账上。」 | 「只看结果」这类今人话 |
| 丐帮 | 市井、仗义，典故实在，比喻贴着讨饭的身份 | 老叫化／小兄弟 | 「补丁怎么缝，气就怎么攒，这叫百衲功。」 | 文绉绉 |
| 军伍 | 短令、粗直，讲军令和袍泽 | 俺、本什长／小子 | 「半步崩拳打天下——那半步，得你自己走。」 | 江湖黑话 |

## 三、照着写的好文字

1. guazhou.ts：「江伯补网的时候爱坐在这截树根上……树根叫他坐得发亮。」——不写思念，只写一截被人坐亮的树根。
2. prologue.ts：「江伯看了你半天，没说话，只是那天晚上多给你盛了一碗鱼汤。」
3. guazhou.ts：「一身渔家短打，脚上却是黑面白底的官靴。见你望过来，其中一人拉低了斗笠。」——伏笔全靠一双靴子。
4. genji-yan.ts：「刀是朝心口来的，他拿手接住了。」
5. genji-yan.ts：「他走过的地方，青苔一根也没倒。」——写轻功不用一个术语。
6. caoshangfei.ts，账房：「我记过那笔账——一文没赔，记的是一文没赔。」
7. caoshangfei.ts：「他沉默了很久，久到油灯结了一朵灯花。」
8. shishi-guazhou.ts，六叔：「盐是官家的盐，船是盐商的船，江——江是打鱼的江。」
9. shanmen-shaolin.ts，圆慧：「长老收人，看心。我拦人，看刀。」
10. suzhou.ts，严捕头：「他的皂衣旧，靴底新——靴子是他自己掏钱换的，府衙发的那个料子，走不了夜路。」
11. shanmen-tiezhang.ts，孟娘子：「这铺子是我男人的命换的，交了平安钱，就是告诉他，他的命不值钱。」
12. shanmen-emei.ts，清音诀入门：「佛前的油灯芯子响，江上的浪头响，你自己的心跳也响——数得出三种响，才算入门。」
13. roads.ts，待渡亭：有一行刻得极深，像是用剑划的：「一水之隔，二十年。」

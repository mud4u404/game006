# 总体设计

## 一、定位

**一句话**：一个能在手机上点着玩的金庸式江湖。世界自己在运转，玩家想走哪条路都行，武功靠苦练和搭配变强。

参照的体验：
- **GTA 的自由**：有一条主线串起世界，但玩家随时可以去做别的。不同的选择会在世界里留下长久的后果。
- **传统文字 MUD 的魅力**：场景描写、招式描写，都靠文字的想象力撑起来。
- **新世代的界面**：不用输入指令，名词点一下，能做的动作就地展开。信息层级清楚，重复操作交给挂机。

## 二、世界观

### 2.1 时代

架空王朝**大胤**，景和十二年。以明朝中叶为蓝本，制度和风物仿明，但人物与事件都是虚构的，不受史实约束。

- **朝廷**：
  - 皇帝年少，东厂督主曹无咎权倾朝野。
  - 锦衣卫与东厂明争暗斗。
  - 六扇门负责缉捕江湖要犯，夹在两者之间。
  - 两淮盐政腐败，私盐泛滥。
- **边关**：北虏连年犯边，九边军镇兵饷时常拖欠。有藩王在暗中养兵。
- **东南**：海禁未开，倭寇与海商勾连，沿海不宁。
- **江湖**：门派、帮会、世家、镖局、盐枭、绿林各据一方。正派未必正，邪派未必邪。

### 2.2 势力

| 势力 | 代表 | 立场 | 与玩家的关系 |
|---|---|---|---|
| 东厂 | 督主曹无咎 | 黑水盟的靠山 | 主线大敌；也可以投靠，走黑暗路线 |
| 锦衣卫 | 北镇抚司千户 | 与东厂争权 | 朝廷线的一个入口；手段狠辣，加入会涨恶名 |
| 六扇门 | 总捕头陆千帆，人称「铁面」 | 守法，但被各方掣肘 | 朝廷线的正途入口 |
| 边军 | 大同、宣府诸镇 | 缺饷，有人被收买 | 军伍线 |
| 漕帮 | 新任舵主秦红绡 | 运河上的江湖，被黑风寨劫了盐 | 帮会线；第一回的盟友 |
| 威远镖局 | 少镖头赵铁衣 | 靠信义吃饭 | 镖局线 |
| 苍梧剑派 | 掌门「青崖先生」顾长风 | 名门正派 | 门派线；掌门本人是黑水盟的一员 |
| 少林、武当、峨眉、唐门等 | — | 各有门规与恩怨 | 门派线的其他选择，后续区域开放 |
| 黑水盟 | 东厂、两淮盐运使、苍梧掌门、大盐商 | 靠私盐敛财、养兵 | 主线的真正对手，二十年前寒江灭门的元凶 |
| 黑风寨等绿林 | 屠千山 | 黑水盟在下面的爪牙 | 初期对手 |

### 2.3 天下地图

地图分四层：**天下 → 道 → 地点（城镇、门派、关隘、荒野、秘境）→ 场景**。

| 区域 | 代表地点 | 主要内容 | 开放顺序 |
|---|---|---|---|
| 江南道 | 扬州、瓜洲、镇江寒江渚、苏州 | 序章、第一到第三幕；漕帮、镖局、六扇门、苍梧剑派 | 首发 |
| 中原 | 开封、洛阳、嵩山少林 | 武林大会、门派线扩展 | 第二批 |
| 京畿 | 京城、通州码头 | 朝廷线终点、终章 | 第二批 |
| 九边 | 大同、宣府 | 军伍线、第四幕 | 第二批 |
| 巴蜀 | 成都、峨眉、唐门 | 门派、奇遇 | 后续 |
| 东海 | 舟山、宁波 | 倭寇、海商、海上奇遇 | 后续 |
| 关中 | 长安、华山 | 门派、古墓秘境 | 后续 |

做大世界的方法：
- **核心地点手工精做**：大城市、门派山门、主线场景，每个地方都有独特的人和事。
- **路途和荒野按规则生成**：官道、山林、小村、客栈，配上随机事件，保证走到哪里都有内容。
- **长途一键赶路**：骑马、坐车、乘船都可以，途中遇到事情会停下来，交给玩家处理。

## 三、核心循环

| 尺度 | 循环 | 玩家的感受 |
|---|---|---|
| 几分钟 | 探索 → 交谈或触发事件 → 战斗 → 收获 | 每一处都有人可聊、有事可做 |
| 几小时 | 接主线或差事 → 晋升身份 → 学到新武功 → 去新地方 | 一步步混出名堂 |
| 几十小时 | 选择身份路线、经营人情、积累名号 → 自立门派或走向结局 | 自己写下一段江湖传奇 |

贯穿三个尺度的是**活的世界**：时间会流逝，NPC 有自己的目标，江湖大事不等玩家，自己会发生。闭关出来，江湖可能已经变了样。

## 四、玩法系统

### 4.1 探索与时间
- 场景页的结构已经在原型里定下：场景描写、此处有谁、可做的动作、去处。
- 时间以时辰计。赶路、交谈、战斗、闭关都会消耗时间。
- 昼夜和天气会影响事件。比如夜里城门关闭，雨天渡口停船。
- 季节和节庆会触发对应的活动，比如元宵灯会、端午龙舟、武林大会。

### 4.2 战斗
已经在原型里定下：
- **即时回合**：大约每 1.5 秒一合，自动对拆，配金庸式描写。
- **见招拆招，以己之长**：
  - 对手出重招时，可选的应对来自玩家练成的武功：硬接、闪避、拆招、抢攻。
  - 每种应对都标出成算。成算由双方修为比较得出，没有固定答案。
  - 超时则凭本能应对，成算打折。
- **趁虚而入**：对手露出破绽时，底部操作区出现提示条，点中就是一记重击。
- **攻守之势**：决定谁出手更多、谁更容易露出破绽。
- **其他**：运功蓄力、绝招题字、伤势图、首领分阶段、围观群众、战后说书。

### 4.3 武功与修炼

**基本概念**
| 概念 | 含义 |
|---|---|
| 品级 | 先天资质，分凡、良、上、绝、神、禁 |
| 境界 | 后天成就，九重：初窥门径、略有小成、融会贯通、炉火纯青、登堂入室、出神入化、一代宗师、返璞归真、大乘 |
| 熟练度 | 当前一重之内的进度 |

**武功分类**
- 内功：决定内力，支撑硬接
- 外功：拳、掌、指、剑、刀、枪、棍、鞭、暗器，各有招式
- 轻功：支撑闪避和身法
- 绝技：怒气满时可用

**获取途径**
- 门派传授
- 秘籍和残卷
- 奇遇和高人点拨
- 偷学：观战时有一定几率领悟对方招式
- 买卖
- 自创：自立门派之后

**修炼途径**
- 实战：应对成功、击败强敌都会增加熟练度
- 闭关：挂机修炼
- 请教：消耗人情或银两
- 研读秘籍
- 突破：高境界需要特定的契机，比如宿敌、试炼、顿悟事件

**武学数值框架**

细节放到路线图第 5 步，先定原则：
- 品级、境界、熟练度、人物修为、属性、克制关系和临场状态，都先折算成「点数」再相加。
- 双方点数之差用一条 S 形曲线换算成成算：差 0 为五成，差 10 约七成半，差 20 约九成。
- 「成不成」和「威力多大」分开计算。
- 系数不靠估，先写下平衡目标，再反推系数，最后用模拟验证。例如：
  - 同一境界，品级高一档，大约多一成成算。
  - 凡品练到大乘，约等于绝品练到炉火纯青。
  - 克制关系最多只抵一个半境界的差距。
- **人物修为**单设一条大境界阶梯：不入流、三流、二流、一流、绝顶、宗师。高出两阶以上，形成明显压制。
- **克制关系**包括三类：
  - 刚柔阴阳
  - 兵器长短
  - 特定武功相克。这一类须通过奇遇或请教才能得知。

### 4.4 身份路线

| 路线 | 晋升阶梯 | 日常差事（会随机生成） | 独有收获 | 代价与冲突 |
|---|---|---|---|---|
| 门派 | 记名弟子 → 外门 → 内门 → 真传 → 长老 → 掌门 | 采药、护送、巡山、比武、除害 | 系统的武学传承、门派商店、援手 | 门规约束；与敌对门派结仇；叛门会被追杀 |
| 六扇门 | 捕快 → 捕头 → 总捕 → 名捕 | 缉拿要犯：查线索、追踪、动手或劝降 | 官身、卷宗权限、免于通缉 | 江湖人对官差有戒心；要受上命掣肘 |
| 锦衣卫 | 力士 → 校尉 → 百户 → 千户 | 侦缉、抄家、暗杀 | 特权大、来钱快 | 恶名上涨；江湖与朝中树敌 |
| 军伍 | 小卒 → 伍长 → 百户 → 千户 → 游击 → 参将 → 总兵 | 巡哨、守城、夜袭，以及大型战役 | 军功、兵权、战场绝学 | 擅自离营算逃兵；被派往前线 |
| 镖局 | 趟子手 → 镖师 → 镖头 → 总镖头 → 自开镖局 | 押镖：选路线、应对劫镖、处理途中意外 | 银两、各地人脉、熟悉路途 | 失镖要赔；会得罪绿林 |
| 帮会 | 帮众 → 香主 → 舵主 → 长老 | 护航、收数、帮会火并 | 地盘、眼线、消息 | 卷入帮派仇杀 |
| 自立门派 | 开宗立派 → 收徒 → 扬名 → 一代宗师 | 门派事务：传功、守山、外交、争地 | 自定门规、自创武学、徒弟和产业 | 需要名号、银两和武功大成；会被各派视为对手 |
| 游侠 | 不设阶梯，靠名号说话 | 悬赏、奇遇、打抱不平 | 最自由，奇遇更多 | 缺少靠山，什么事都得靠自己 |

**规则**
- 相容的身份可以同时持有，比如门派弟子兼镖师。
- 冲突的身份不能同时持有，比如六扇门和锦衣卫，两个敌对门派。
- 退出某个身份有代价，也会留下后果。

### 4.5 人情

**关系阶梯**
| 方向 | 阶梯 |
|---|---|
| 正向 | 素不相识 → 点头之交 → 相谈甚欢 → 知交 → 结拜兄弟或情缘 |
| 负向 | 心存芥蒂 → 有隙 → 仇敌 |

**改变关系的方式**
交谈、赠礼、并肩作战、替对方办事、切磋，以及选择题。偷窃、背叛、站错队会损伤关系。

**NPC 会主动做事**
- 每个重要 NPC 都有自己的目标和日程，会在不同地点之间移动。
- 关系到了一定程度，他们会主动找上门：求助、邀约、报信，甚至寻仇。

**特殊关系**
- 师徒：可以拜高人为师；自立门派后可以收徒。
- 红颜与兄弟：有完整的个人故事线，会影响结局。

### 4.6 声望与名号
- **侠义与恶名**：两条独立的值，不互相抵消。
- **势力声望**：对每个势力分别记录，决定能否拜师、能否得到折扣，以及会不会被追杀。
- **名号**：由玩家的事迹自动生成，比如原型里的「渡口一剑」，以后还会有「夜盗府衙的那位」。江湖人会用名号称呼你。
- **江湖传闻与说书**：玩家做过的大事，会被说书人编成段子，在酒馆和茶楼里流传。这是本作的标志性体验。

### 4.7 经济
- **收入**：差事、镖银、军饷、门派月例、悬赏、买卖、帮会分红；自立门派后还有产业收入。
- **支出**：伤药、兵器护具、秘籍、请教、打点官府、门派建设。
- **目标**：前期银两紧张，逼玩家去接差事；后期银两主要用在大投入上，比如开宗立派、买下产业。

### 4.8 挂机与世界运转
- **闭关**：可选一日、七日或一月。期间时间流逝，武功和内力增长。出关时给一份「江湖见闻」，原型里已经实现。
- **离线时间**：离线也算修炼，但设上限。
- **江湖大事按时间推进**：
  - 不管玩家参与与否，都会发生：武林大会、边关战事、倭寇登岸、灾荒、门派更迭。
  - 玩家错过了，结果也会如实写进世界。

### 4.9 失败与死亡
- 角色不会永久死亡。
- 战败后视情况处理：被人救下，或被抓进牢里，或被敌人放过，同时损失银两、时间或身上的物品。
- 失败也会推进世界：任务没办成、人没救下，后果会留在世界里，而不是让玩家读档重来。

## 五、任务体系

| 类型 | 来源 | 特点 |
|---|---|---|
| 主线（章回） | 寒江旧案 | 手工精做；有多种推进方式，可以搁置 |
| 身份线 | 各身份的晋升任务 | 手工精做；每一阶都有一次晋升考验 |
| 差事 | 各身份的日常 | 用模板随机生成：押镖、缉拿、军功、门派事务、悬赏 |
| 人物线 | 红颜、兄弟、宿敌 | 由关系阶段触发，决定能否结拜、能否结情缘，也可能反目 |
| 奇遇 | 地点、时间、条件触发 | 武功、神兵、秘境的主要来源，也是游侠路线的主要乐趣 |
| 江湖大事 | 世界时间线 | 限时；参与与否都会有后果 |

**设计原则**
1. **多种解法**：每个手工任务至少有两种解法，从武力、人情、计谋、银两、潜行里选。
2. **后果持久**：NPC 会记住你做过的事，世界状态随之改变。
3. **提示靠世界**：任务线索尽量从世界里获得，比如传闻、说书、告示、闲谈，而不是由系统直接派发。

**界面**
- 「江湖」页顶部的主线横幅，换成当前追踪的任务。点一下就自动赶路过去。
- 长按横幅，或点横幅旁的图标，打开任务簿，查看所有进行中的事。

## 六、首发范围（建议）

- **区域**：江南道，包括瓜洲、扬州、镇江寒江渚、苏州，约 30 处精做地点，外加若干随机野外。
- **主线**：序章、第一幕和第二幕；第三幕的三条线做齐。第四幕和终章随第二批区域一起推出。
- **身份线**：每条线做到中段晋升。镖局和六扇门两条做完整，门派做苍梧剑派一派，帮会做漕帮。
- **武功**：约 40 门，覆盖六个品级。
- **角色**：主要人物约 12 人，有台词的 NPC 约 80 人。
